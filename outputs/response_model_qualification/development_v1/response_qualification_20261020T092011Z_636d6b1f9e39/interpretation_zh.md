# 冻结试验的结果解释

本试验完整执行并通过审计，**候选二阶状态响应模型没有通过独立预测资格**。
这是方法组件的负结果，不是采集失败；原资格门槛没有调整。

| 分别判断的事项 | 本轮证据 | 结论 |
|---|---|---|
| 数值合法性 | 六个 TRAIN 模型均保存；独立加权回归重建通过 | 数值实现成立 |
| 当前预测能力 | 18 组主比较二阶减同数据线性为 +0.09474 毫米，95% 区间 [+0.05134,+0.13969] | 未通过预定资格 |
| 含获取成本的任务收益 | 新模型从未控制动作；所有采集都保留 C8 | 本轮未检验，不能声称改善或恶化任务效用 |

旧线性、新线性、新二阶的主 RMSE 分别为 0.38882、0.36109、0.45583 毫米。
二阶既未优于同数据线性，也未低于旧冻结线性。六格中，推物变化、到达不变、到达变化、
开门变化均同时差于两个线性参考；推物不变的局部改善不能替代完整人口的预定门槛。
这几个逐格方向是对保存表格的描述，没有追加子组检验、重新选择任务或调整模型。

CAL 中二阶模型的三个任务残差中位数均较低，但到达与开门的高分位尾部较大；
独立 QUAL 的后续任务段表现没有满足资格。这支持“名义数据上的经验误差不能代替
独立时序预测资格”的判断。它不能单独区分模型结构、训练覆盖、动作分布变化、
接触／隐藏状态、噪声与闭环相关性的作用，也不能据此认定唯一失败原因。

资格主比较使用真参数代入原有输入接口。即使给出这项评价端信息，二阶候选仍未通过；
它并没有证明在线扰动估计已经准确，也没有检验逆控制。实际施加动作的补充输入同样
没有将二阶整体误差降到新线性以下；这改变了输入语义，剩余误差不是物理无噪声误差。

108 条 QUAL 全部登记；其中 92 条有实际任务尾段响应，16 条没有。六格分母和缺失原因
均保留，18 个独立组都有可用主响应。主估计按冻结的实际响应与整组等权规则计算，
没有将早结束补为零，也不能将这个条件于已执行响应的预测指标解释为完整任务成功率。

270 条固定采集轨迹中观察到成功 67 条，其余 203 条在固定窗口截止时未观察到成功。
这不等于 500 步完整任务失败率，更不是三个预测模型的任务对照；全部记录都在
allocation_registry.json 与 failure_registry.json，未隐去难例。

按冻结协议，封存本轮负结果，停止围绕本版 ARX 添加门控或更新选择规则，不启动
有限幅度更新试验。重新研究响应模型需要新的可检验解释和独立训练／资格设计，
不能借本 QUAL 人口修改特征、阈值或采样数。移动前获取决策、任务强基线、独立部署
历史、消融与新颖性证明仍是后续研究要求；CCF A 目标没有完成。
