# 中途干预执行资格 v2：可检查的状态见证

在`codex/continuous-state-witness-v1`完成实现、配置、软件检查、独立审计器和仓库检查后，本地提交冻结，再生成唯一清单并执行一次。未冻结之前不创建本协议的MetaWorld任务。v1的15次执行及NOT_QUALIFIED结论保持不变。

## 唯一新增的执行机制

沿用v1公开准备器、固定策略、一次连续初始重置、四步保存C4、八步估计C8、C8控制到第16步，以及五种固定操作。新增的私有见证观察器在INITIAL、BOUNDARY、FINAL读取当前状态并立即写入独立压缩日志，不进入公开准备器或干预器，不改变命令、世界、随机数或预算。

原始完整Python语义指纹和原生指纹全部保留。新见证保存旧完整指纹对应的可检查图：节点、别名和数组布局，数组/字节缓冲区内容保留哈希，标量状态保留编码。每次构建都必须与未修改的旧state_signature一致，并检查构建前后的原生及完整Python状态不变。

比较图只修改**准确类型**`gymnasium.wrappers.common.RecordEpisodeStatistics`的两个字段：

1. 已初始化的`episode_start_time`计时值映射为0.0，未初始化的整数−1保持原样；拒绝非有限值、其他负数及错误类型。
2. `time_queue`中每个有限非负浮点计时值映射为0.0；保留队列节点身份、长度、容量和引用结构。队列若被其他状态字段引用，拒绝投影。

其他字段、策略、控制预算、未来噪声、全部随机数状态、环境状态、奖励、步数、统计队列结构及数组别名都保留。未知统计字段、子类、被修改的方法或未审查库源码拒绝使用。只接受本项目固定工厂产生的已登记包装器顺序和三种任务类；不把此投影推广到可能读取计时信息进行控制的任意程序。

源码审查依据：已安装Gymnasium统计包装器只用这两个字段累计时长与输出`info.episode.t`；固定策略读取当前观测，准备器/干预器不读取这些计时字段；本工厂外层检查点、随机任务选择及Gym检查包装器不基于计时选择控制动作。组件证据仍是主机生成的数据，不是独立外部真实性或通用隐藏状态等价证明。

## 新人口与不变约束

严格顺序：push-v3种子21600，reach-v3种子21601，door-open-v3种子21602；每个任务分别执行CONTINUE_CURRENT、SWITCH_SAVED、RUN_UNCORRECTED、STOP、DIRECT_CURRENT，共15次。21603–21799保留，21400–21402已经使用，21403–21599及所有旧保留区继续不动。

原始噪声为SeedSequence([seed,47001])派生的500×3 float32高斯带，标准差0.05。真实偏置为[0.12,−0.08]，二维映射单位矩阵、死区零，只进入私有执行及评价记录。固定四步程序为float32(0.4)的+x、+y、−x、−y，重复一轮；不重选设计、不改模型或控制策略。

每次最多500控制步，全局最多7500控制步、15受控初始重置、420000请求仿真帧。每次工厂50次任务生成重置加一次受控初始重置；每次重置500帧，每控制步5帧。禁止恢复、捕获模拟器快照、换未来噪声、拼接轨迹、替换无效估计或补选种子。C4只是保存但此前未应用的候选，不是历史成功记忆。

## 费用

每个变体仍计完整历史名义成本3840控制步、480受控重置、24480全部重置、12259200帧，按各自3个单元摊销。历史设计3次枚举/432候选另列。先前v1的1377控制步、15受控重置、765全部重置和389385帧作为已付开发费用单列，不重新收集。

新增政策查询、参数拟合及nfev、全部物理尝试/返回、工厂/受控重置、仿真帧、45份状态见证构建及计算耗时、审计重算都保存。软件验证的原生帧和前向计算另列，不充作科学任务。新增API、名义训练、选择器拟合和策略权重更新为零。

## 独立审计与资格

1. 15次完整执行，全部第16步边界仍可运行且C4/C8有效；无效或提前结束保留，资格不完整。
2. 每个任务五程序的初始观测、16步物理轨迹、原生状态及新比较指纹匹配。完整指纹与所有组件差异仍报告。
3. 三个任务的CONTINUE_CURRENT与DIRECT_CURRENT完整物理轨迹、最终观测、原生状态、新比较指纹和步骤/查询计数匹配。
4. 至少一个任务的继续C8、切换C4及未纠正首条命令三者不同；否则资格不通过，不改变边界或种子。
5. 每个STOP在第16步后新增零步，仍进入失败分母和500截止损失。
6. 复用未修改的v1独立事件语法，重建保存选择、实际命令、噪声消费、物理时钟、连续性及费用。新审计另核对45份私有记录与相应完整源指纹、节点图、组件、精确投影和两份日志的时间夹界：锚定源事件先落盘，见证构建并落盘，然后才有下一个源事件。
7. 公开对象不含状态图、随机数、真值、种子或未来信息。全部异常/不可用案例保留。任何完整性失败禁止通过资格。

公开选择和命令依然由v1已保存API接口执行；此处“API接口”指本地程序接口，本轮没有在线大模型请求。数学估计器、策略、编码、状态图序列化及投影共享已披露，外层分配、来源绑定、双日志顺序、消费关系、匹配及费用由独立审计器检查。

## 完成条件与后续范围

清单绑定所有实现、测试、协议、配置、软件资格、历史来源和运行库。冻结后不改实现再重跑本人口。物理异常保存部分记录并停止；完整采集后只读审计并生成中文报告。执行报告区分完整性、资格和任务表现，不做小样本方法优势区间或后验阈值选择。
