## 问题、用途与拒绝的替代

本次检验受限OCCAM相关表现参考能否在自身纠正形成的真实时序历史中工作，
并以完整截止损失超过固定参考。它是A主线的标准参考资格，不是新获取
决策、完整OCCAM复现、模型适用范围算法或论文贡献。实际获取仍是预定臂，
模型每最多16步只在四个合法PI时间常数中选择；固定低层政策不训练。

[OCCAM v1](https://arxiv.org/html/2406.17620v1)已联合表现预测、真实控制
参数执行与反馈适应；本次必须有元训练与适应两个因素，而不是只做训练内
导出验证。[模型适用范围工作](https://arxiv.org/html/2401.04007v2)已研究
不准模型的状态动作适用域及任务相关轨迹获取，普通误差预测或门控不新。
本协议不声称取得两者之外的具体机制，也不代替完整程序风险／DR、简单
重加权、CPC、同历史被动适应和任务相关获取等未来强参考与消融要求。

训练内全窗口MSE不能冒称此前已预测；旧固定行为上的建议不能冒称部署；
窗口费用不能改名完整Q；数值合法、前瞻预测与完整任务收益分别判断。
没有收益则保留负结果，停止围绕该版表现接收者叠加获取选择规则。

## 两级审计与停止规则

完整NATIVE进程／字节审计及动态／控制／模型审计通过，全部模型程序至少
有真实预测窗口、适应版本至少一次实际更新，才能一次QUAL。技术错误、
超时、资源停止关闭分配及预留；保留异常栈、部分流和未启动null，不重试、
续接、延长或用旧数据填充。只读审计入口失败另留回执，不伪称物理失败；
没有通过的审计就不能晋级，读者修复须单独版本化并保留原失败。

进程审计独立读取nonce／PID／请求／回执／原始gzip成员和账本，禁用主
分类器、执行器、资源公式、请求检查与真实Popen。完整审计重建所有动作、
float32变换→XYZ实际噪声→最终裁剪、500步预算、RNG／钟和原生见证；
RAW同源前缀和同获取后状态按完整人口核对，C8前缀单独核对。

重放共享原actor／固定政策，明确披露；另实现标量费用／PI／原C8映射，
独立dense前向和标量后验、最终批后验。严格公开特征提取是共享源，因果
历史由独立记录检查重建；不冒称完全独立特征实现或物理重仿真。独立数学
检查时禁用主provider／actor／forecast／update／basis_forward。

2. 前瞻预测：仅评价当前程序实际选择并执行的窗口，预测先于结果。每轨迹
   内窗口等权，再按独立组重采样。与同窗口上的冻结TRAIN常数均值比较，
   主META_CONTINUE的MSE差95%上界须小于0，三个任务点差均小于0且都有
   预测数据。缺失记null及原因、不填零；条件于有预测窗口的完整分母和
   各任务／条件／时点18格全部展示。这不证明未执行候选排序或获取收益。
3. 完整任务资格：唯一主程序META_ADAPT__CONTINUE，完整54个单元的截止

   MOVE_INTEGRAL，七个差的整组bootstrap双侧95%区间上界都须严格小于0。
   这是七比较的交集门，不能只挑有利比较替换；成功率变化全部披露。
