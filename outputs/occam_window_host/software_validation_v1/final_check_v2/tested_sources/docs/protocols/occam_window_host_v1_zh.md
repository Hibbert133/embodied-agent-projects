# OCCAM相关表现参考：连续窗口主机资格 v1

2026-10-28。先冻结收集器、数组测试、审计与本协议并本地提交，再执行一次原生

本阶段不是新颖性、任务收益、响应模型资格或CCF A完成。

## 性能反馈及完整任务目标

预算500个实际控制步；成功的截止损失为实际总步数，失败为500。观测只用已保存
公开39维状态及终止标志：reach取hand坐标，push/door取object坐标；goal为36:39。
势函数固定为到公开goal的欧氏距离（单位米，以1米尺度截断至1），成功、终止、
截断、预算截止或基础设施失败时为0。它是粗糙公共代理，不能证明接触/模型有效。

一个真实段的费用为 `deadline_charge_steps/500 + Phi(end)-Phi(start)`。
活段/成功段的charge是实际步数；不成功的终段加剩余失败惩罚，且只加一次。
**整个已执行序列的段费用之和，加初始Phi，再乘500，严格还原截止损失。**
未执行的失败惩罚另列，绝不冒充交互步、补轨迹或改变物理预算。

这是标准[势函数差分](https://people.eecs.berkeley.edu/~russell/papers/icml99-shaping.pdf)
的核账使用；整体恒等不意味着逐窗口贪心/模型近似具有全局最优或安全保证。
模型只预测当前候选持有最多16步的段费用，不把它称为完整未来任务Q值。
粗糙位置势函数与短时选择可能损害任务，必须在未来自身历史的完整损失比较中披露。

前缀、实际获取与控制尾部均计费。尾部每16步从当前真实状态选一次T，末段取
剩余预算。实际提前成功/终止短段也保存真实费用标签；沿用已冻结核心的
`end_partial`，不更新后验，不丢该案例，不制造完整未来观察。未来元训练若使用
这些终段标签，只能在另行冻结的目标中作评分点，不能冒充完整支持窗口。

## 连续执行与输入

固定三任务政策，每个任务控制步恰好一次原始政策查询；同一当前观测和实际
积分，只改变RAW PI时间常数，保留Z/grip；底层政策权重固定。
初始RAW PI0.5，实际边界后执行已分配的CONTINUE/VALIDATE8/MOVE_MEASURE。
VALIDATE8是普通任务继续，不能宣称额外新探测；MOVE使用原LOCAL_PID连续移动
及已有8步测量，未到锚点可没有测量，完整理由保留，无新响应拟合/逆控制。
不使用获取数据选择获取动作：这是主机参考前置，不是A主线的新获取机制。

OCCAM相关核心来源为[论文](https://arxiv.org/html/2406.17620v1)及上阶段锁定作者源。
只枚举四T=.125/.5/2/8，beta=0，奖励权重=-1。当前预测不加Q，完整反馈更新
一次Q；历史8步编码，当前积分和全部真实历史来自已发生记录；不传seed、真
扰动、实际加噪动作、私有native状态、未来结果或时钟/RNG状态。

所有query、四候选basis/prediction、选择、rate计划、PI发送命令、实际执行与
反馈按顺序保存并在执行前flush/fsync。实际执行必须消费已保存的选择和计划。
每步核对同一世界地址、噪声游标/不可变tape、真实历史、重置数、5物理帧及
.0125秒连续时钟。rate切换保留积分；原生见证核对首个rate前后和共同获取后。
这些是运行和记录完整性证据，不是独立物理重演或一般隐状态充分性证明。

## 一次原生软件人口、费用与停止

登记见`occam_window_host_seeds_v1.json`。采集前的v2双解析器查询无冲突；准备
时复核原源未变，并对当前全登记（排除本协议自身登记）再做独立审计。
三组对应boundary16/32/64和CONTINUE/VALIDATE8/MOVE_MEASURE；三任务、两条件、
两个未训练构造模型，共36次执行。两构造模型仅最后层斜率先验符号相反，
首个合法T选择不同；其他规则相同，比较共同获取轨迹和实际首命令。
它们是显式软件测试工具，不能用于学习/校准/选新方法、比较科学收益或替代
后续独立资格数据。完整36项、不完整/失败均保留，不因某任务未触发窗口而替换。

上限18,000控制步、36次受控初始重置、1,836次全部重置、1,008,000物理帧。
最多1,116次完整反馈滤波，审计再重算最多1,116次及最多36次整段联合高斯求解；
最多18,000次实际固定政策查询、审计另外最多18,000次。每步只有一次真实发送。
网络、模型科学训练、Adam、C8/响应拟合、低层政策训练均0。
复用CPU和机器人运行时，不安装依赖；初始存储>=4GiB，紧急余量512MiB。

先做最多3次数组开发检查和1次正式检查，各次最多2000次显式线性求解，
所有失败、源码快照、次数及耗时保留；不创建/重置/推进环境，不调用API。
正式软件检查源码绑定沿用原2487项，不重复历史仿真；新增检查计唯一数。
两环境/旧来源所需回执按哈希绑定，本次主运行时编译/依赖、秘密/差异/暂存
与磁盘字节检查通过后提交。原生人口只执行一次，基础设施错误停止且保留
部分数据，不重置撤销、不重跑替换、不扩样；修复需要新协议与新人口。

独立审计逐步复算float32执行器变换→实际噪声→最终裁剪、PI/积分、完整成本、
因果历史和决策时间，核对native见证；同时用标量逐步和及整段联合高斯条件化
核对窗口费用和后验。记录回放共享原actor/获取模块，明确披露这一非独立部分。
至少一对原生选择实际改变命令；没有触发或完整度不足则不能通过软件资格。
