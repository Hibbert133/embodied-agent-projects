# 联合、条件与边缘响应似然的区别

这里是线性高斯系统的矩阵恒等式核对，没有新机器人交互，也不改变正在运行的任务协议。
它解释一个容易混淆的地方：只拟合后6步响应，可能表示两种不同的统计操作。

将8步位移分成最早两步yE和后6步yL，假设整体均值为Fθ、协方差C且不随θ改变。
令K=CLE CEE⁻¹，S=CLL−K CEL，则：

    p(yE,yL | θ) = p(yE | θ) p(yL | yE,θ)
    E[yL | yE,θ] = K yE + (FL−K FE)θ
    Cov[yL | yE,θ] = S

因此，完整联合信息矩阵等于早期边缘信息加后期条件信息：

    Ifull = FEᵀ CEE⁻¹ FE + (FL−K FE)ᵀ S⁻¹ (FL−K FE)。

但直接不使用yE时，后6步的边缘模型是均值FLθ、协方差CLL，信息矩阵为
FLᵀ CLL⁻¹ FL。它不等于“给定已观察的yE后，只使用后6步条件项”。
物理瞬态使早期命令继续影响FL；不读取早期输出，也可能从后期运动中获取早期输入的参数信息。

确定性参考采用d(t)=ρd(t−1)+0.01[X(t)θ+ε(t)]、已知d(0)=0、
独立高斯创新标准差0.05、无传感误差和裁剪。这是明确定义的数学初始条件，
不是向实际MuJoCo轨迹补零历史。完整GLS与全部8步创新回归完全相同；
条件后6步GLS与第3–8步创新回归相同。

两种输入次序、三个ρ、每组64个确定性响应向量，共384组恒等式通过，
最大绝对误差1.78e−15。块状原探测、ρ=0.4时，后6步边缘信息减条件信息的
特征值约为[-62.927,0,430.430]，正负均存在；不能一般地说二者谁在所有参数方向上信息更多。
ρ=0时二者相同。结果保存在[likelihood_check.json](likelihood_check.json)，
代码为[likelihood_identity.py](likelihood_identity.py)。

本项目JOINT_DROP2使用联合工作模型的后6步边缘协方差与全部过去命令，
并不等同于旧ARX的历史条件响应。因此，“联合模型胜过ARX”与“增加最早两步
输出的收益”需要分开解释。资格实验已经保留了这一区别；上述理想恒等式没有
证明真实MuJoCo模型满足线性高斯、无传感误差或精确重置条件，也没有确定其改进的唯一原因。
这些都是标准概率分解与GLS性质，不是新算法、新定理或任务收益证据。
