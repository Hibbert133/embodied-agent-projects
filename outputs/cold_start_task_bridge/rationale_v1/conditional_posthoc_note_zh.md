# 同一响应模型的条件参照事后诊断

本诊断只复用上一轮已经观察过的96条资格轨迹，没有读取当前56流任务结果，
没有执行环境、重置或API，也没有更改当前八种任务程序和晋级门槛。
它不是新的独立确认，也不能回写原资格结论。

保持联合模型的均值、残差协方差、参数边界和优化预算不变，将后6步位移对最早两步
位移作高斯条件化。使用条件均值mL(θ)+K[yE−mE(θ)]和Schur协方差，
而不是JOINT_DROP2的边缘协方差。K只由原已冻结的名义残差协方差计算；
拟合接口只接受模型与可见ColdPrefix，真实扰动仅用于拟合后的评价。

这一参照表明，本批“后6步边缘响应”和“后6步条件响应”的结果并不相同；
同模型条件参照也不等于原ARX观察模型。不能把主模型对ARX的差异只归因于多用了两步，
也不能仅凭这组数字确定真实物理系统的唯一改进机制。

解析自检在三个已知AR(1)瞬态系数下，将条件优化结果与后6步创新的闭式回归比较并通过。
这些自检不涉及实际MuJoCo数据。旧资格数据新增96次参数拟合，记录102次函数求值；
另外三个解析自检也调用了数值优化，分列在JSON的self_check中。
连续高斯剪裁均值和固定协方差仍是工作模型，不是实际浮点噪声或任务收益保证。
