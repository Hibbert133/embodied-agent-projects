# 有限纠正动作与最终任务代价之间需要的价值联系

这是一份方法问题草稿，没有训练新模型或启动额外实验。它不改变正在执行的十种固定对照，也不把下列标准恒等式声称为创新。

此前随机比较的目标是实际历史上近期响应的平均。要联系最终任务，近期响应必须有明确的任务价值含义。令 H_t 是 Agent 可用的完整可见历史，π₀ 是规定好的继续执行基准，V⁰_t(H_t) 是从该历史开始、随后按 π₀ 执行的真实剩余截止损失。这里是因果继续执行价值，不是只在 π₀ 已访问状态上的样本均值。

注册一个有限选项 β：实际执行 q 步指定纠正，随后回到 π₀ 的控制规则；不恢复模拟器状态。其代价优势为

    A⁰_β(H_t) = E[C_(t:t+q) + V⁰_(t+q)(H_(t+q)) | H_t, β] - V⁰_t(H_t).

在终止处按成本定义处理吸收状态和失败处罚，C 包含该段已发生的代价。两个选项的差异中，当前共同的 V⁰_t 抵消。若估计值函数在两个选项实际会到达的后继历史上有误差界 ε，则两个选项优势差的误差至多为两侧预期后继误差之和。这个结论来自三角不等式；只在旧政策访问域里验证误差不够。

对连续执行的选项策略，以真实 V⁰ 写每个块的代价加价值变化，求和后中间项相消：

    J(π) - J(π₀) = E_π Σ_k [C_k + V⁰_(t_(k+1))(H_(t_(k+1))) - V⁰_(t_k)(H_(t_k))].

这是有限时域的表现差异／望远镜关系。它针对实际访问的历史，不要求这些历史曾由基准政策访问；但估计它所需要的价值支持恰恰是困难所在。若每块在旧／新选项之间以概率 p_k 随机指派，基准选项的真实优势为零，则右侧等于 E_π Σ_k p_k τ_k，τ_k 是当时两个有限选项的条件代价差。p_k 随历史改变时，不能将未加权的过去平均 τ 当成累计任务收益。

因此近期效应在以下条件下才获得任务解释：响应是块代价加真实或受控误差的基准尾价值；选项结束后确实使用规定的尾政策；累计权重和真实访问历史正确。普通位移改善、任意进展势函数和未经验证的 critic 都不自动满足这些条件。过去平均的区间也不能单独给未来永久换控制器的结论。

截止损失与实际交互步数必须分开。失败／提前停止按 500 记分时，数学成本需要包含相应终止处罚；它不是继续执行了那些实际环境步。后续若采用此目标，应同时报告真实步数和失败率。

这给出下一候选需要补足的工作：用终局监督建立尾价值，说明价值误差适用的历史／动作域，以及新选项把机器人带出该域时如何支付证据费用、限制选项或放弃更新。目前没有可继承的校准界，也没有已验证的在线选择器。两个近期记录相同而终局不同的反例并未被消除。

相关已有路线的官方摘要已核对：[TRPO](https://proceedings.mlr.press/v37/schulman15.html)研究带改进依据的政策优化；[SPIBB](https://proceedings.mlr.press/v97/laroche19a.html)在批数据不确定时借助基准政策；[MBPO](https://arxiv.org/abs/1906.08253)讨论模型使用偏差并采用短模型轨迹。这里没有复现这些算法或把其保证移植到当前机器人。价值引导、有限视窗和退回基准均不是可单独主张的新颖性。
