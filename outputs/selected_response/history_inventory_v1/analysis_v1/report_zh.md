# 已有移动指令能否支持历史辨识：只读盘点

这是对上一轮72次已审计执行的探索性描述，没有使用正在采集的名义训练数据，没有新增仿真、模型拟合或API调用。

每例只统计移向测量点期间已执行并保存的指令，截止于探测前的移动证据保存事件。最初C8、后续八步探测和真扰动均不进入秩计算。条件名称只用于事后分组。

二维仿射映射需要三个独立的输入特征：x指令、y指令、常数1。这里对这三列矩阵做奇异值分解，绝对数值秩阈值固定为1e-10；列归一化条件数仅描述输入几何。

满秩只说明指令方向没有代数退化。真实位移还受位置、竖直动作、夹爪、未观测动力学和噪声影响；闭环指令也依赖已有观测。它不证明响应模型适用、参数估计准确或预测区间有效。

当前选定测量点模型针对进入前四帧加八步平面、零夹爪指令训练。不能截掉移动指令中的z/夹爪分量，或把全部运动拼入该模型，再当作合格的历史基线。新历史模型需要覆盖真实运动范围的名义数据及独立响应验证。

后续比较须同时保留：沿用旧C8、移动积分、合格的历史辨识，以及在同一移动后额外支付探测费用的更新。参数辨识和真实任务续跑应分别评价。

本盘点不是额外探测有益或无益的证明，也不改变旧实验结论。全部案例见 `all_cases.json`；输入哈希见 `analysis_started.json`。
