# 为什么总体预测变准仍不够

本轮冻结候选未通过；以下是结果后的解释，不新增拟合、阈值或在线控制。

全轨迹剩余步RMSE为80.27042，但稳定尾段起点为178.17973。这里的起点是 max(8,最终非空控制选择时刻)，不是所有方法的最初决定点；NO_PROBE的最初决定在0步。

同状态候选差的预测误差是 e(H,旧)−e(H,新)，不是某个候选的总体误差。三角不等式只能用这两个具体输入处的误差约束它；全来源均方误差不能提供逐历史约束。本轮配对差MAE 28.18960 比恒零预测 27.72917 更高，已经直接否决候选区分能力的开发门。

还有一个标准抽样分布问题。每轨迹等权、内部均匀抽样的分布P，和每轨迹只取稳定尾段起点的分布Q不同。对本轮有限数据，Q/P在起点等于该轨迹样本数n，其余为0，故

    E_Q[e²] ≤ max(n) E_P[e²]。

这是换测度的普通不等式，不是新理论，也不是新流上的保证。样本数范围7–124；把总体RMSE代入只得到约893.85步的粗界，比剩余预算还大，因此没有实用的决策证书。不能把整段预测变准等同于起点选得更好；也不能据此唯一归因于抽样权重，模型表示和监督噪声等因素并未被因果隔离。

关键配对的实际伤害完整保留：条件4、push-v3、未来重复1，预测保留旧估计少花0.855步；实际旧估计500步失败，更新74步成功。当前数据只提供一次配对未来实现，不能把该值叫作已知条件期望。

下一机制必须先解决候选差与实际任务代价的联系，在明确支持域上检验误差，并保留循环16步点估计强基线。不能在本银行调整保守阈值、重新选特征或把最好的事后模型换成主模型。若提出后继，应使用独立新协议；当前结果不授权新种子执行，也不满足贡献、独立评估或完整论文要求。
