# 四步标准基线任务比较草案

本草案为[四步估计与探测程序](short_probe_design_reference_20261018_zh.md)准备独立任务比较。
它补齐便宜强基线，不提出新获取算法。所有方法均从当前单元的受控重置开始，不带跨单元缓存，
因此本轮结果不评价时序复用或变化检测。相应[规划配置](../../configs/short_probe_reference/planning_v1.json)
明确标为不可执行；当前同状态机制测量须先完成审计与本地交付，之后另行实现并冻结新协议。

## 七个完整任务程序

名义模型保持既有联合响应模型与完整来源。DOPT 程序由三个任务各自的名义模型，按已实现的
144 项固定动作库和单位变换工作点确定，保存全部候选与最终选择后，再开始任何新物理执行。
BALANCED4 固定为 +x、−x、+y、−y，各单轴幅度为实际 float32(0.4)。DOPT 的第二个四步
固定重复第一个四步的保存程序。所有程序共用原点逆补偿、动作约束和官方固定政策。

| 程序 | 实际行为 |
|---|---|
| NO_PROBE | 从重置状态执行未纠正政策 |
| ORIGINAL8_UPDATE | 原 BLOCK8 后，用未修改的八步联合估计器纠正 |
| BALANCED4_UPDATE | 固定均衡四步后，用四步边缘估计器纠正 |
| DOPT4_UPDATE | 保存的 DOPT 四步后，拟合并纠正 |
| DOPT8_UPDATE | 完成两轮保存的 DOPT 四步，用真实八步重新拟合并纠正 |
| DOPT4_KEEP_AT8 | 第四步保存四步拟合，继续相同额外四步，第八步使用保存的四步拟合 |
| DOPT4_FALLBACK8 | 四步拟合有效则立即纠正；无效则真实补测四步，用全部八步拟合并纠正 |

DOPT4_KEEP_AT8 的四步拟合无效时仍执行既定额外四步；若探测未使任务结束，第八步停止，
不偷用八步拟合替代。这个运动控制的无效行为与可部署的 DOPT4_FALLBACK8 分开保留。
所有方法在实际成功、终止或截断时立即结束；提前成功无需强行拟合或继续探测。
其余无效拟合均停止。失败和停止的截止损失为 500，成功计含探测的全部实际步数。
停止不填充未执行步骤，不从成功率分母删除。

## 配对人口与样本量依据

拟采用三故障族 BIAS、COLUMN_Y、DEADZONE，三种单元间变化方式不变、突变、渐变，
每格六个独立流，共 54 流。每流 12 单元，三个任务各四次，共 648 个配对单元、
4,536 次方法执行。生成公式沿用[既有参考协议](../protocols/strong_chronological_reference_development_v1.md)，
在新实现中显式版本化六次重复，不修改旧生成器。拟用新任务种子 20200–20847、
生成源 67001–67054，20848–21199 保留；预检拟用 21200–21208，21209–21399 保留。
冻结时还须再次核对全部已用和保留范围。当前草案没有执行或正式分配这些种子。

样本量借用[历史规划](../../configs/cold_start_task_bridge/planning_v1.json)中的配对流标准差
51.20785077975331 步。双侧 α=0.05、20 步改善、目标功效 0.8 的正态近似需 52 流，
按九因素格取整为 54。这是不同历史比较的方差代理，不是四步基线的已知方差或功效保证。
同一代理若针对仅四步改善，需要约 1,287 流；本规模不能据不显著结果断言四步收益不存在，
也不能声称等效或非劣效。新方法独立确认的样本量仍需按其目标另行冻结。

每方法、每单元独立构造环境并执行一次受控初始重置，总预算 500 步，噪声标准差 0.05。
沿用源 47001 的原噪声带构造，七方法按相同任务种子和实际步时钟配对。探测接任务时，
环境、随机源和噪声索引保持连续；本草案不采用状态复制或恢复。
匹配核对限于注册的初始物理见证、噪声和真实前缀，不声称完整隐藏状态等同性。

## 比较与记录审计

主比较为 DOPT4_FALLBACK8 减 ORIGINAL8_UPDATE 的平均截止损失。六个次比较在规划配置中
逐项保存，覆盖固定四步、程序设计、同一额外前缀后的更新、额外运动、无效回退和完整八步程序。
同时报告全部方法的成功、失败、停止、实际控制步、专门探测步、拟合次数和优化器 nfev。
采用完整流为重采样单位，在九格内各六流分层 bootstrap 10,000 次，随机源 20261022；
次比较标为未多重校正。这里没有新算法晋级门槛。

记录审计需验证全部七方法的初始见证；四个 DOPT 方法的真实前四步；
DOPT8_UPDATE 与 DOPT4_KEEP_AT8 的真实前八步；以及回退方法实际补测时的对应八步前缀。
未完成前缀保留结束原因，不能凑成完整匹配。DOPT4_KEEP_AT8 必须消费第四步保存的参数，
回退方法只有实际取得完整八步后才能调用旧八步接口。每次程序选择、拟合及控制器应用，
均须保存因果输入、输出和消费关系，且先于相应执行及任务结果。

预检拟为九单元、每任务三次，BIAS 前五单元 [.12,−.08]、后四单元 [−.14,.10]。
预检只检验记录、预算、时间、前缀和保存选择的执行，并至少实际完成一条四步有效拟合到任务政策的链路。
回退分支若未出现，如实记录；非法拟合、重复探测、预算拒绝和失败回退由软件测试覆盖。
不据预检任务分数选择动作库、阈值或方法。任何错误均保留该次失败，不重跑同一人口。

## 资源上限与冻结前工作

预检计划上限为 31,500 控制步、63 次受控重置、180 万请求帧。
MAIN 上限为 2,268,000 控制步、4,536 次受控重置、1.28 亿请求帧。
按每环境共 51 次重置、每次 500 帧和每控制步 5 帧推算，MAIN 最大请求帧为 127,008,000；
这是预算计算，实际费用以全生命周期账本为准。独立重放增加的工厂重置费用必须完整计入。

NO_PROBE 不承担名义模型来源费用。其余六方法各单列完整既有来源的 3,840 控制步、
480 次受控重置、24,480 次全部重置、12,259,200 请求帧，按 648 单元摊销，
不除以七方法总执行数。共享来源的实际历史采集只计一次；新增程序枚举、拟合、政策查询与
审计重算分别记录。新增名义模型拟合、选择器拟合、政策训练和 API 调用均拟为零。

四步估计器、局部设计器与[公开回调执行组件](../../src/probe/short_probe_execution_reference_v1.py)已完成软件验证。
执行组件每次核对 DOPT 保存表时重新计算 144 个候选，将此计算单列；实际动作仍消费保存程序。
物理主机的零步起点、连续时钟、费用仪表、物理记录审计与独立统计审计仍须实现，
经过仓库必需检查后冻结源码、配置、协议和清单，
再依次执行唯一预检与 MAIN。任务结果即使正向，也只提高后继获取机制需要超过的标准；
[新贡献、独立方法确认和完整论文](publication_path_v1.md)仍是继续推进的目标。
