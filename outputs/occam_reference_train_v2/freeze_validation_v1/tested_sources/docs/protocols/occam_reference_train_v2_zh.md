## 固定任务、物理与行为

三任务push/reach/door-open-v3，两条件UNCHANGED/CHANGED；每组三个任务共享
分组生成的干预，实际边界16/32/64由组号循环确定。固定原低层政策、RAW PI0.5
前缀、初始未知偏置(.12,-.08)、噪声sigma=.05、每步5物理帧/.0125秒，最多500
控制步。变化系数域沿用原独立参考(.75–1.25对角、±.2交叉及偏置)；不宣称OOD。
控制层看不到真扰动、实际噪声、seed、随机状态、私有native状态或未来结果。

每个任务/条件均交叉CONTINUE、VALIDATE8、MOVE_MEASURE及两种行为。
VALIDATE8是真实任务继续，不称新物理探测；MOVE沿用LOCAL_PID及原8步测量，
到不了锚点保留原因、可能没有测量；没有新前向/逆模型或C8拟合。
两行为均在当前真实状态每最多16步持有一个T=.125/.5/2/8，携带实际积分。

- RANDOM_WINDOW：每个窗口按预先登记、独立命名空间生成的均匀四T表分配。
- BLOCK_FIXED：同一表的首T保持至结束，与前者首个T相同；后续真实状态各自发展。

随机表在执行前承诺，不由任务结果或估计挑选。它属于行为分配，不是模型
预测，后续不改成较好T。两行为没有在线滤波、拟合或LLM，恰好一次政策查询
驱动每个任务步，实际发送消费已保存声明及PI计划。获取、噪声游标、世界、
时钟、初始重置连续，不恢复已经发生的位移。

## 反馈与数据防泄漏

沿用已冻结的公开势差窗口费用：真实截止费用增量/500+Phi(end)-Phi(start)，
终端Phi=0，位置势使用固定1米尺度；完整段和可还原截止损失。失败未执行惩罚
与真实交互分开。窗口预测不等于完整未来风险Q，贪心/校准或任务好坏不能由
这个代数恒等推出；这是标准势函数差分的工程核账，不是贡献。

训练投影只接受task、真实initial、全部实际history及已执行窗口：每个query
恰好等于该决定以前的历史切片；measurement由真实执行行复算。实际未来行
只供监督标签，不回填为入口特征。私有字段、旧/未来数据、缺/重/换历史拒绝。
NumPy跨运行时标量复算容差1e-12，保留原不可变标签，不重标任务结果。
提前成功/终止的短窗也作为评分标签；不得补轨迹或删除。没有窗口的案例
明确登记缺失，仍留在完整人口和任务结果分母。模型只读取TRAIN公开投影，
不读NATIVE、CAL、QUAL、原始私有流/真扰动/实际噪声或注册参数表。

标准化仅拟合TRAIN：先每轨迹等权、轨迹内窗口等权，填充帧mask=0保持全零；
真实历史行共同尺度，连续特征尺度下限.05，任务one-hot不变。无窗口没有
虚构特征或标签。统计和训练曝光的可用性按完整人口另外披露。
将标准化仿射变换折入网络首层，并以零方差固定常数基还原目标均值、正确
缩放输出/R协方差；部署仍用原严格公开输入与JSON接口，不在线拟合标准化。

## 模型、固定学习预算与消融

复用既有CPU Torch2.2.2+cpu/NumPy1.26.4隔离环境，不安装依赖或改机器人运行时。
float64、单线程、确定性，初始化/抽样RNG独立登记。公开历史8×83，descriptor87；
encoder664→64→16，head103→256→256→256→8，ReLU；最后线性权重8维、输出1。
权重均值初始1/sqrt(8)，P/Q/R因子I，可学习因子的平方构造协方差；非法/非有限
直接停止，不偷偷加jitter、夹协方差或回退其他模型。梯度范数10不是安全保证。

先1000次预训练尝试；从同一预训练参数/优化器状态分叉：4000次META，4000次
普通ERM。保留PRETRAIN、META_FINAL、MATCHED_ERM_FINAL三份，不按结果选checkpoint。
共享预训练只支付一次，总尝试9000、Adam更新<=9000；空batch不更新、不重抽。
匹配的是更新尝试数与案例曝光，不声称FLOPs或墙钟相等；META的额外滤波/
反传费用必须单列。
实际共享计算与各方法单独训练费用分开：META最多5000、PRETRAIN最多1000、
匹配ERM最多5000；不能把这三项之和11000说成实际重复执行过的更新。
每次8条已分配TRAIN轨迹均匀有放回抽样，含无窗口案例的零数据贡献；每轨迹
损失为全部真实窗口MSE。AdamW lr=.001、weight_decay=.0001，参数不看旧QUAL。
两个长训练分支使用完全相同的案例抽样序列；META支持长度RNG另流，不能暗改
对照所见的数据。真实Adam尝试/完成、空batch、抽样、耗时和失败单列。

META使用完整非终端窗口的随机长度时间前缀，长度0到min(30,可用数)；0支持
用先验，不能把终止短窗当完成支持窗口。滤波可微、每支持窗一次Q，支持后
按原算法的全样本MSE评分。这是离线元目标，**不是前瞻预测验证**；独立部署
仍只能用决定时已发生历史。最多960,000次内层更新、1,000,000次显式Torch
线性求解、训练墙钟7200秒（逐尝试检查）；底层自动微分FLOPs不冒称完整计数。
预算或数值错误停止，保存失败/参数数组和已完成checkpoint；不重启训练或
挑可用旧checkpoint冒充成功，不追加样本。三个任务若没有任何可用标签不能
训练成三任务参考；缺失不通过重采解决。

数学审计不重训：主运行时复算TRAIN标准化、跨Torch/NumPy导出，原/标准化
反馈均值与协方差、独立整段高斯条件化；最多5000次分析求解。它只检验实现/
数值合法性，不代表当前预测力或含获取成本的任务收益。

## 测试、冻结、失败及独立后继

新增纯数组/合成与假记录检查覆盖padding、未来泄漏、终段、权重、量纲、
未知字段、保存选择/反馈顺序、NATIVE36及TRAIN648完整人口循环。人口循环
物理/数值内部stub明确披露；原生读者仍逐步核对实际float32变换→噪声→最后
裁剪、PI/积分、时间、案例身份、共同获取和全成本。记录回放共享原actor/
获取原语，不冒称独立物理重演。异常守卫和日志同样保存。
软件开发最多3次及正式1次；每次NumPy/Torch求解各<=1000，Torch构造Adam
最多1次，累计<=4次；不创建/重置/推进环境，不调用API或读旧研究人口。
源码绑定复用原2522项，新增检查独立计数；编译、两环境依赖、秘密、真实
索引补扫（含解压）、差异、磁盘/索引/提交字节通过后本地提交。

采集/训练/审计都是一次分配，失败及部分数据保存，不自动重跑、补人口或
降低门槛。只读读者软件修复需单独源码/预算冻结且不得重采；原失败费用累计。
本阶段零在线LLM、低层政策学习、前向/逆模型训练；标准表现网络学习单列。

后续科学CAL与最终自身时序人口须在查看其结果前另行冻结完整协议：保留
DIRECT_C8、积分、廉价全时固定四T/同历史固定与被动适应、获取不更新/始终
获取及完整任务风险/标准检测等强参考。OCCAM需与context-only、no-meta及
预算匹配ERM比较；主标准仍完整新人口平均截止损失优于DIRECT_C8和积分，
同时披露成功率、全部失败与独立组/流不确定性，不能拿MSE替代任务收益。
三程序/固定参数/收益预测/势差/元学习已有研究，独立新获取机制、消融与
CCF A贡献均未建立。原MDE/Residual/OCCAM/GAUGE/Poke等查新要求仍完整。
