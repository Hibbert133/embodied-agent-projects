# 拒绝无效被动更新：控制流资格 v1

本阶段在 `codex/passive-supported-reference-v1` 完成两条标准被动参考的工程实现。
它补足[后继方法要求](../research/decision_cost_identification_requirements_20261016_zh.md)
已经指出的对照缺口，不是新获取算法。原时序实验及其292条被动停止保持原样，
不能用此实现给旧停止补成任务成功。

## 两条固定参考

| 名称 | 更新时刻 | 使用的响应项 | 无效拟合时 |
|---|---|---|---|
| PASSIVE8_KEEP | 实际第8步之后，未结束才尝试一次 | 实际8步提供的6个AR2响应项 | 保留当前已保存控制器并实际继续 |
| PASSIVE64_PERIODIC16_KEEP | 未结束时每实际16步尝试 | 最近至多64个真实响应项，历史来自连续实际轨迹 | 保留最近一次已应用的控制器并实际继续 |

两者的全部动作来自固定底层政策经当前控制器变换，不另加诊断动作。
500步是全部实际动作预算；正常任务动作、被动测量不可重复收费。
初始没有本方法缓存则使用身份映射，有缓存则使用本方法较早成功的参数。
满秩、条件数、优化与逆映射的门槛沿用原标准ARX估计器，不按已知结果调参。
有效拟合不证明真实动力学、逆映射任务准确性或概率校准。

## 因果与缓存合同

只有完成的可见观测、实际发送命令和冻结名义模型进入拟合。接口不接受种子、
真实扰动、未来结果、其他方法历史或环境重置能力。调用者保有一个连续的物理
环境与噪声时钟；此纯控制原语没有 `reset` 或环境工厂调用。

每次控制器选择与每条发送命令须先交给主机持久化，主机返回事件名、连续序号、
保存时间与同一载荷。执行消费返回的已保存载荷。载荷改写、序号不连续或未来
保存时间触发失败，保存部分记录，不用替代控制器掩盖执行错误。
这些是局部Agent事件序号；未来物理主机的全局生命周期序号应在外层分别保存。

较晚无效拟合不撤销本任务较早已应用的有效更新。只有实际任务成功，最后应用
的有效新拟合才成为本方法新的已验证点缓存；无新拟合的成功保留旧来源不续期，
失败清空缓存。冷启动身份映射不作为“新验证参数”写入。

独立控制流回放从观测、命令、事件和自己的来源重建全部拟合与选择，不调用主
执行函数。它共享冻结数值估计器、指令编码和严格缓存模式，不能声称独立验证
物理模型、模拟器隐藏状态、真实重置或私有噪声。真实主机的审计另行完成。

## 本阶段验证与边界

新增测试使用明确标注的确定性回调系统：检查有效拟合确实改变发送命令，
无效拟合后真实继续、保留最近更新、来源不续期、跨方法／未来来源拒绝、
500步预算、提前结束、篡改拒绝、执行异常的部分账及独立回放。
它们是软件资格测试，不是MetaWorld研究结果。

本阶段不采集新科学仿真、不使用新或保留任务种子、不调用API、不拟合名义
模型、不训练底层政策，不提供任务成功率或方法比较。未来机器人比较须先
独立冻结物理主机、原始记录／费用审计、配置、人口和统计协议，再一次执行。
名义来源仍完整计21010步／288次受控重置，旧工厂来源成本未知不能记0。
近期辨识中的在线拟合次数与优化器开销须按实际发生记录。

运行仓库要求的全量测试、编译、依赖、秘密及差异检查后本地提交。本阶段
完成也不满足新方法、独立确认或CCF A完整论文的完成条件。
