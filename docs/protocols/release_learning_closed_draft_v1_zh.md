## 拟议机制及信息界面

固定三任务 push-v3、reach-v3、door-open-v3；每次最多500步，噪声0.05。
获取前使用公共完整历史、当前观测、控制记忆和剩余预算，选择 CONTINUE、
VALIDATE8 或 MOVE_MEASURE。获取真实执行，只有一次受控初始重置。
CONTINUE 不增加物理动作；VALIDATE8 执行8步正常任务 PI 并推进积分；
MOVE_MEASURE 使用旧 LOCAL_PID 最多64步移动，再执行8步测量，任务积分携带。
移动或测量后均从当前真实状态接续，不重置、回滚或复用未执行轨迹。

返回记录持久化并封存后，主机才用独立 PCG64 随机数一次决定额外轨迹是否释放。
随机化不改变当前物理状态、控制记忆或噪声游标。屏蔽与完整接收者保留相同的
完整先前公共历史、实际终点、耗时、阶段计数、结束原因和任务记忆；只有获取
期间的额外逐步轨迹不同。屏蔽不等于无信息，也不能当作全部物理/信息中介分解。
空获取的两个输入及选择必须相同。真扰动、噪声、种子、未来结局不进入模型。

接收者从四个现有 PI 时间常数0.125/0.5/2/8秒中选择，只改变增益，不清零积分。
每步固定底层策略查询一次；选择、子计划与发送命令先保存再消费执行。
接收者共同基准64中心 RBF 加同容量64中心残差；共同残差和轨迹残差用同一事实
人口。预学习器使用32中心 RBF，9组宽度/岭系数；目标为完整任务截止损失，
含移动、验证、测量和失败费用一次。M、F 使用标准随机释放 AIPW，D=F−M。
此标准统计构造、两个阶段和增益适应不构成新颖性。
