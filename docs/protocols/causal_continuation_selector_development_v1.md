# 八步历史条件代价选择器的前瞻开发协议

本轮实现标准经验代价选择器，在新算子流中真实先决策、后执行。动机来自
[固定连续前缀测量](../../reports/conditional_continuation_interpretation_v1.md)，
但不把其离线查询表改称在线 Agent，不恢复旧两阶段候选或调整旧失败门。
标准回归和最近邻不是算法创新；完整发表要求仍见
[发表路径](../research/publication_path_v1.md)。

## 训练源和固定模型

只使用旧 conditional-continuation 的 24 个前缀、八算子流、四未来的监督。
旧源 672 次真实执行全部计费为 101,069 步／672 控制重置；共同八步五分支的 480
结果及初始七分支的 672 结果是明确标识的离线反事实监督，不是在线自然经验。用旧提交的 Git 字节
与已通过审计的原始 SHA 认证；新分支的协议变更不得覆盖旧源或旧结果。

独立严格对象只允许任务、九次可见观察、八次实际命令、第八步的有效
Gaussian 参考均值与协方差、当前固定政策动作和剩余预算。未来轨迹、
真算子、流／种子／重复、隐藏状态、噪声承诺和结果均不进入该对象。

固定 28 维输入：六参数分别按 (1,1,.3,1,1,.3) 缩放；六个对应协方差对角
经 log1p 相对平方尺度变换；当前手到目标、物体到目标、手到物体的三维
相对位置各除 .1；最近一次手位移除 .01；当前政策动作截到 [-1,1]。
这些是可见特征，协方差没有物理或概率资格。

每任务八个源上下文分别拟合四个分支减 DIRECT 的损失差。主 RBF 使用四
未来均值，直接复用标准 KernelModel：训练均值／标准差标准化，尺度下限
1e-6，非零成对平方距离中位数核宽度，岭系数 1，损失尺度 500，不搜索。
另保存同输入同算法、只用未来 0 目标的 SINGLE_FUTURE_RBF；MEAN_COST_NEAREST
用相同训练标准化空间的最近一例与其四未来平均差；TASK_MEAN 只用该任务
八例平均差，不读当前历史特征。八步选择平局顺序为 DIRECT、PASSIVE、
POINT16_CYCLE、UPDATE、KEEP。训练在代码冻结之后只执行一次；工件哈希
进入评价清单。没有根据测试结果换模型或超参数的选择步骤。

另加 TASK_FULL_PORTFOLIO：仅凭已知任务，在初始时刻按完整七分支来源
均值选方案，可选不探测及原宽十六步；平局依 NO_PROBE、DIRECT、PASSIVE、
POINT16_CYCLE、UPDATE、KEEP、POINT16_WIDE。其选择也必须先保存再执行；
它不需要八步历史，并单列为不属于共同八步后的基准。七分支来源核对
相同初始观察与声明积分／任务见证，不能把不同程序称为共同八步。

## 新人口和真实执行

12600–12647 为十六新算子流 × 三任务；每前缀两个独立未来，共 96 单元。
两个八流块分别使用算子生成 nonce 47001／47002，仅执行静态 A；原生成器
中的 B 家族名称不能当成本轮独立故障家族。12648–12999 与全部旧保留种子
不用。噪声沿用不可变 prefix/future 实现和 namespace 46003／46005，新的
任务种子保证与旧源隔离。未来 0／1 在开始交互前生成；执行中无重播种。

七种原固定方案加五种监督选择基准共 1,152 次执行。固定政策、噪声 .05、一次
控制初始重置、500 总步、最多十六专门探测步、后续至少 32 任务步不变。
四个八步选择器实际走完八步，用其真实可见证据保存 SELECT_CONTINUATION，再
消费保存的分支选择。五分支严格沿用旧定义；不在失败后切换固定基线。
选择、纠正器和 STEP_INTENT 必须先于各自执行与结果保存。早结束保留
完整分母；没有继续决策者单列。两个未来的前缀和选择必须相同。

## 对照和开发判据

主对比预先固定为 MEAN_COST_RBF 减 POINT16_CYCLE，报告成功差、实际步和
截止损失差。主候选开发信号要求：零泄漏／预算／连续性违规，成功次数
至少与全部对照中最高者相同，主损失差的算子流分层配对 95% 区间
上端小于零，且不被任一固定或标准选择器在成功和损失上同时支配。原固定
七方法和四个标准选择基准全部报告；不能只挑胜过 DIRECT 的一项。

独立单位为十六算子流；反射与非反射各八流内重采样，10,000 次、种子
20261015。其他对比明确标为补充、未做多重比较校正。通过也只说明标准
基准在本开发范围的收益，不是算法新颖性、独立方法确认或论文完成。
失败保存，不在 12600–12647 上调整特征、核、分支或阈值。

## 审计和全部费用

新最多 576,000 环境步／1,152 控制初始重置／33,000,000 请求模拟帧。
全部工厂临时重置也记录。六种原名义方法完整承担 21,010／288 旧名义源；
五个监督选择基准额外各承担完整 101,069／672 训练源，按 96 单元摊销，同时
单列源物理采集只计一次和在线费用，不能用少量在线节省隐藏离线成本。
API、自然记忆写入、政策训练均为零。

审计重新提取监督、重建训练模型／核方程和每个可见输入，再核对保存预测
决定了实际分支。剥离已独立验证的选择事件后，逐步复用旧固定分支的
保存动作、噪声、时间和生命周期核对；这部分复用须在报告披露。跨方法
共同前缀共 864 对，跨未来共 576 对；选择器同前缀的选择不变性另核对。
不重新仿真动力学，不把列明字段匹配称完整隐藏状态证明。
