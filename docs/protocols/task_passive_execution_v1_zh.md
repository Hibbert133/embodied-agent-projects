# 任务期间被动积分适应：独立开发与资格执行协议 v1

这是新的强工程参考试验。冻结先于任何原生检查或科学采集；不复采旧人口，不恢复旧 ARX／GRU 有效性，不把 F20 条件预测器直接作为名义植物求逆。父结果为本地提交 `4a6faadfafd218cb6ee9697650c6d59948088930`，历史原始记录和负结果保持不变。新响应预测器训练、策略训练和在线 LLM API 调用均为 **0**。

## 研究问题及作用边界

当前必须补齐任务期间持续更新的强被动对照，才能判断移动前获取是否还有额外价值。原 MOVE_INTEGRAL 在移动阶段积分，之后保持纠正，不能代表任务期间持续积分。这里检验标准任务 PI 的完整任务表现；不是新颖算法、模型预测资格或安全证明。

分别判断参数数值合法、当前预测能力和包含获取成本的完整任务收益。数值合法的标定逆矩阵只用于已有命令映射；不声称物理响应模型或任务收益由此成立。限幅、投影抗饱和、停止和回退均不构成安全保证。

## 固定策略、信号及更新顺序

使用 MetaWorld 3.1.1 三任务的原固定脚本策略。每个任务步骤只查询一次当前观测，保存原始 float32 策略动作。原策略位置比例增益为 push 10、reach 5、door-open 25，单位为策略动作／米。策略返回动作尚未裁剪，因此 XY 除以对应增益可还原当前策略阶段目标相对手位置的误差，不能将其称为最终任务误差或扰动真值。

基准发送命令 `base` 严格沿用已有 `encode_controller`：原始策略动作先裁剪到 [-1,1] 并转 float64，以保存的逆标定矩阵 B 和偏置映射 XY，再整体裁剪并舍入 float32。未标定程序使用精确单位阵和零偏置。矩阵、偏置只来自当前真实 C8 或旧移动积分；拒绝 Oracle 来源。

控制周期固定为 0.0125 秒。对每个采用任务 PI 的步骤：

1. `e = raw_xy / P`，不使用已裁剪的策略动作构造误差。
2. `J = clip(I + dt * B @ (P * e) / Ti, -2, 2)`。
3. `sent_xy = float32(clip(base_xy + J, -1, 1))`；Z／抓取保持有界基准发送命令。
4. 保存严格查询、完整数值计划、摘要和实际命令；执行器消费已保存计划，禁止未保存的替代命令。
5. 收到当前实际物理回执后，才提交 `I_next = actual_sent_xy - base_xy`。无回执不推进积分。

幅度上限 2 是两个有界 XY 命令之间的最大差，不是经验安全阈值。保存前积分限制与最终发送裁剪分别统计；float32 舍入差不算裁剪。参数候选固定为 Ti = **0.125／0.5／2／8 秒**，是事先选择的工程时间尺度网格，不根据旧人口、旧命令差误差或新任务结果修改。任务 PI 初值为零；隐藏扰动改变时不重置。

## 程序及共同移动

| 程序 | 初始标定 | 任务 PI 起点 | 移动后基准 |
|---|---|---|---|
| NO_PROBE | 无 | 无 | 无移动，原策略有界命令 |
| DIRECT_C8 | 原八步 | 无 | 无移动，原 C8 |
| MOVE_KEEP_C8 | 原八步 | 无 | 原 C8 |
| MOVE_INTEGRAL | 原八步 | 无 | 原移动阶段积分 |
| RAW_TASK_PI | 无 | 第 0 步 | 无移动，单位命令映射 |
| DIRECT_TASK_PI | 原八步 | 第 8 步 | 无移动，C8 |
| MOVE_KEEP_TASK_PI | 原八步 | 真实移动结束后 | 原 C8 |
| MOVE_INTEGRAL_TASK_PI | 原八步 | 真实移动结束后 | 原移动阶段积分 |

所有 MOVE 程序在边界之前保留 C8，使用完全相同的已有 LOCAL_PID 移动过程（最多 64 步）、锚点和停止条件；包括 MOVE_PI 程序。移动积分与新增任务积分分开保存，新任务积分在真实移动结束后为零。核对共同移动的每个实际命令、响应和移动后私有状态见证。未完成或提前成功也完整登记，不强行移动到虚构共同状态。

直接 PI 在 C8 后已经更新，而 MOVE_PI 先移动再更新；两者是完整程序比较，不能据它们的不同访问状态声称孤立更新的因果效果。

## 扰动与连续执行

初始条件固定为 A = I、b = (0.12,-0.08)、死区为零。不变条件保持初始参数；变化条件在实际执行到 16／32／64 步且尚未结束时，切换到按新独立组生成的仿射参数：两个对角项各 U[0.75,1.25]，交叉项各 U[-0.2,0.2]，两个偏置各 U[-0.2,0.2]，死区为零。仅宿主知道真实参数；在线 PI 不接收条件、边界标签、种子、噪声、随机数状态或私有状态。

一次工厂创建和一次受控初始重置后，环境、随机数、噪声游标和时钟连续。完整 500×3、标准差 0.05 的 float32 噪声带只在第零步安装；不能替换未来噪声。真实执行顺序为 float32 仿射／死区 → XYZ 加实际噪声 → 最终裁剪。隐藏改变只更新宿主仿射系数，以前后状态见证验证环境、噪声、时钟及账本不变。不变条件也保存同样的边界核对事件。提前成功／无效标定时不强迫到达边界。

相同单元的程序从各自一次受控初始重置真实运行、共享配对噪声；不是恢复中途环境，也不是在线可用的反事实经验。每次执行最多 500 控制步；不生成未执行的未来。

## 冻结、选择与资格门槛

先提交实现、配置、协议、来源／依赖／测试哈希，再创建独占 manifest。依赖版本与完整文件哈希锁定；原生与科学入口检查实现没有漂移、无未提交科学代码、无已有同阶段目录。网络运输拦截，API 尝试也应为零。

原生软件阶段完整保留 36 次执行。每个 PI 程序在两个端点 Ti 上须至少有一个案例实际执行了与基准不同的 PI 命令；同时审计全部三任务和共同 C8／移动前缀。提前成功不强迫继续，也不允许换种子修复覆盖；覆盖不足则原生契约不完整，不能开始 DEV。

DEV 不看中间结果调整设计。每个 PI 样式在**完整六组人口**上最小化截止损失整数和，平局选择更大 Ti。四个样式的选定参数全部保留；再按相同损失选择一个主样式，平局按 RAW、DIRECT、MOVE_KEEP、MOVE_INTEGRAL 的固定顺序。候选须在全部新开发人口上的平均截止损失严格低于 DIRECT_C8 和 MOVE_INTEGRAL，否则保存负结果，**不执行 QUAL，不追加样本**。

DEV 独立记录审计通过后写出独占 selection.json，绑定完整数据与统计源码哈希，且锁定时间必须早于任何 QUAL 事件。QUAL 使用九个全新组，固定参数与一个主样式，保留四个原对照和四个 PI 样式。不得观察资格结果后换主样式或参数。

两项共同主要比较为锁定主程序减 DIRECT_C8、减 MOVE_INTEGRAL 的**完整平均截止损失**。按三个边界层内的完整独立组 bootstrap 10,000 次；DEV 随机种子 202610390，QUAL 202610391。资格门槛要求完整九组人口及审计通过，且两项主要损失差的 95% 区间上界均小于零。所有程序成功率、任务×条件分层和全部 28 个资格二级配对比较完整披露；二级区间未经多重比较校正，只作描述。不把相关时间步／任务／程序当独立样本，不筛困难任务。

截止损失为成功时的实际全部控制步，否则为 500；初始探测、移动和任务已经计入一次。无效 C4／C8 停止，不让另一基线代执行；停止保持分母和失败惩罚。软件／账本异常则立即停止该阶段并保留失败，不静默修复续跑。不补采、不更换种子、不根据结果增加样本。

## 来源费用、审计、报告及停止

公开记录保存每个查询、原策略动作、参数／基准、PI 数值计划、命令、真实回执后积分提交和结果；私有日志另存完整来源生成状态见证。独立只读审计复算策略输出、C4/C8、全部 PI 数值、变换／噪声／裁剪、命令与结果先后、连续时钟、每次重置和物理帧。PI 公式另有不调用在线 PI 内核的数值重建。纯数组／合成记录测试不得构造、重置或推进环境。
