# 同一决策状态恢复的工程资格 v2

v1在初始观测JSON记录处失败，原数据与费用保留。v2只修复NumPy记录边界并增加
记录集成测试，原生胶囊实现、恢复条件和相等标准不变；绑定v1失败清单和摘要。

本轮建立后继任务价值采集需要的评价者恢复工具，非新算法、自然在线记忆、
条件期望估计或任务效果实验。旧的所有物理见证资格和报告不升级、不补造。
源码、配置、测试、记录审计和本协议须先通过仓库检查并提交，再准备唯一清单。
未冻结前仅可运行明确的小型MuJoCo软件夹具，不创建MetaWorld任务。

## 固定人口和操作

只用新种子19000–19011。两个重复×起步8／488步×push/reach/door三任务，
共12次工厂创建和受控初始重置。19012–19199及所有旧保留不执行。
环境和三条官方固定政策沿用原注册工厂，不移除包装器。每次先执行BLOCK8，
较长前缀继续原政策至488步。这里success信息不终止机械资格测试；真正的
terminated/truncated必须停止，不能在终止后继续调用step。

从当前状态捕获一个私有、同进程的状态胶囊。先直接执行DIRECT_0（最多32步），
然后按PROBE8_0、DIRECT_1、PROBE8_1依次恢复胶囊再执行。PROBE8先执行
8个固定探测动作再执行政策；各分支最多用到逻辑500步。晚前缀必须验证第12步
时间上限标志；早前缀各32步。各方案只是恢复一致性的不同程序，不是新控制器。

命令float32，私有固定偏置[.1,-.06]后加xyz σ=.05噪声并clip，夹爪不加噪声。
500行噪声带用SeedSequence([seed,64001])生成；游标属于评价者逻辑状态。
恢复逻辑时钟和游标是本轮明确的评价者分支权限，不能称为部署过程中的连续探测。
全局真实交互和生命周期账本永不回退；每条实际分支全部重新付费。

## 状态范围和拒绝条件

绑定本机MuJoCo 3.3.0、MetaWorld 3.1.1、Gymnasium 1.3.0的源码和原生DLL。
通过同版本C接口复制完整mjModel/mjData到原地址，不调用Env序列化、构造、
reset、step或mj_forward来恢复。复制的原生状态含运行时模型参数、mocap、
控制、激活、暖启动及派生数据。对包装器、基础任务、政策、渲染器非活动字段，
保存明确白名单的Python对象图、NumPy/标准库RNG与Python数组共享关系。
动态任务字段和Gym空间RNG在其实际对象图内；原生数组视图恢复共享关系。

仅限单Python线程、同一环境／政策所有者，无插件、原生线程池、外部回调、
活动渲染器或不识别的Python对象。未知对象／ABI、结构化或object数组、未解析
外部内存视图、改变的原生对象／分配尺寸、被修改的胶囊或共享类状态均拒绝。
MT1的注册闭包仅作为受指纹约束的EnvSpec静态元数据保留，从不调用构造器。
胶囊不从文件加载，也不进入代理、LLM、缓存检索或新训练输入。

每次恢复前有意扰动运行时模型、mocap／暖启动、任务计数／历史观测、包装器
计数、RNG和私有上下文。恢复前后完整原生哈希及Python语义图签名须与捕获
一致，物理地址不变，真实账本不变。Python pickle字节不是语义规范化形式，
不拿其布局变化冒充状态差；保存负载哈希另用于胶囊防篡改。

各步额外读取已预先定种的环境、空间和全局RNG作为一致性见证。Gym的统计
包装器会使用不可回退的墙钟；只排除info.episode.t的轨迹相等比较，仍完整
保存它与全部耗时。不得排除奖励、成功、观测、终止、累计奖励或长度字段。
事件序号、执行墙钟时间戳及单调费用账本另作因果和费用审计，不要求两次重复
的这些元数据数值相同；模拟时间和逻辑步时钟仍须相同。

需12完整上下文、24对重复轨迹和全部晚前缀时间上限检查。独立记录审计不调用
