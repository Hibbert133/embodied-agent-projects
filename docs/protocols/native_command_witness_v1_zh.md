# 原生命令目标见证与公开输入：收集器资格 v1

本阶段承接已完成的零交互诊断，仅验证新收集器、执行链及公开数据边界；
不是响应训练、模型资格、纠正算法或任务效果实验。零在线LLM API、零模型拟合。
先实现、数组测试、独立审计、分配/费用检查和本地冻结，再执行一次新人口。

## 全部人口与费用

固定18次：三任务×三个介入时点16/32/64×不变/变化，3组，每组3任务×2条件。
环境种子70000–70008各在两条件使用；70009–70099登记预留，不执行。准备清单
前扫描全部配置、历史manifest和种子协议，确认无已使用或预留冲突。新范围不复用
旧训练、QUAL或最终留出。两条件同环境种子/噪声，共同前缀独立重演，不恢复状态。

沿用固定Sawyer策略及已验证LOCAL_PID_KEEP完整程序：RAW PI时间常数.5推进到
介入点，至多64步附近PID移动，8步固定四方向测量，再携带原任务积分继续至成功
或500步截止。P=8、D=16、I=.32、积分限幅.5、移动命令限幅.5、保留100步任务
余量均保持原值。没有新参数/参考更新；提前成功、未到位、短窗口及失败保留。
扰动初始I、偏置(.12,-.08)、零死区；变化在实际到达边界之后才发生，家族为既有
对角U(.75,1.25)、非对角U(-.2,.2)、偏置U(-.2,.2)，不变条件保留初始参数。
随机源2026102302与环境/噪声分离，噪声标准差.05、命名空间2026102301。

最大9,000控制步、18受控重置、900工厂目标生成重置、918全部重置、504,000物理帧
（18×25,500+9,000×5）。一次受控重置之后环境、噪声、时钟连续；不capture/restore。
所有工厂/控制重置与do_simulation帧真实计量；超预算或部分执行异常停止，完整失败
记录保留，不补采。新模型训练/拟合、C4/C8推断、审计复算拟合和在线LLM调用上限均0。
独立审计可额外查询固定策略，但只能读保存观测，查询数及CPU时间单列。
采集前至少2GiB磁盘空间，执行中保留512MiB紧急空间；没有自动删除记录。

## 执行、私有见证与公开导出

执行器沿用原ProbeSession float32链：仿射/死区→XYZ实际噪声→最终动作裁剪→
环境set_xyz_action的float32尺度.01→float64目标相加→工作空间逐步裁剪。
新代码只读每次实际执行前后mocap位置/四元数、原生签名、世界地址及物理时间，
写入单独private_targets。实际目标值、真扰动、噪声和施加动作不返回公开actor，
不作为在线模型或训练的特权输入/标签。

源代码先验为重置目标(0,.6,.2)、工作空间下界(-.5,.4,.05)、上界(.5,1,.5)。
本轮第一次用原生数值检查这些先验与输入累计关系。mocap与手部观测坐标不同，
差值可能含站点偏移，不能称为物理预测误差或直接归因于动态滞后。

公开名义摘要仍只用过去实际发送命令，假设恒等变换、零执行噪声；它不是实际
目标、概率均值或安全状态。每步先保存actor命令及摘要计划，检查回执未被修改，
持久化公开/私有前态，再实际执行一次，之后消费摘要计划并保存后态。
底层策略仅在真实任务步查询一次；测量和移动遵守原固定宏，无网络、重置撤销或
新参数估计。两条件实际共同前缀、变换边界前后世界/RNG/时钟不变由审计核对。

public_trajectories严格只含schema、任务、初始39维观测与实际步骤；步骤只含
当前步号、发送命令、真实前/后观测及执行后的公开名义摘要。没有种子、条件标签、
真实参数、实际动作、噪声或私有mocap。public_prefix(at)只读取已完成前缀；当前
步后观测及未来行不能影响返回的当前输入。未来后继观测将来可作监督目标，不能
作为同一步预测特征。Native数据仅收集器资格，不自动变为新模型训练/最终评价数据。

## 测试、审计与资格门

18项数组/记录测试：完整公开actor与真实固定策略在数组容器上执行；调用安装
未绑定算术方法，不实例化环境。数组账本中的“重置/步”只是合成记录，不计真实
交互。独立重建已知模型、保留已知累计模型失配、检查映射/加噪/裁剪和精度，
拒绝噪声游标错位、时钟/世界替换、计划篡改、私有字段及伪造历史，检验未来行不影响
当前前缀。拟合守卫测试实际阻断优化器调用，没有真实拟合。旧1,815项检查按源码
哈希复用，没有重跑旧仿真；新合计1,833项唯一检查，不重复计数开发/正式复跑。

独立审计禁用主native_values/run_live/public_prefix和公开摘要算术，另写逐轴float32
缩放/float64累加/裁剪，核对全部私有前后态、公开摘要、保存命令、原生数据布局、
世界/噪声/时钟连续、全部重置/帧及公开导出。输入变换与控制PI/移动另用既有独立
公式；固定策略从真实保存观测回放。共享来源分组器/控制程序回放明确披露，不冒充
独立重演物理。只有物理时钟累计采用1e-9秒容差；目标累计的资格要求逐位一致。

软件合同同时要求：18次记录完整、每个实际动作/目标累计精确、无新拟合/API/
恢复、每任务×条件至少一个实际完整8步窗口。完整数据审计与合同门分别报告；
有效记录中的目标递推失配保留为合同负结果，不能当成坏样本删除。
任一门未通过停止；不能看结果后放宽、换目标、补样本或启动响应训练。
3组/9配对环境仅软件资格，不宣称充分统计功效、预测收益、任务收益或安全性。
