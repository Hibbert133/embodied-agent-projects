# 未知一般仿射执行器：前向点模型的实际纠正验证 v1

本轮从名义预测推进到实际决策与执行：未知、逐轨迹固定的仿射 xy
执行器下，冻结的名义前向模型能否支持有效纠正？这是标准辨识／输入
补偿方法的前瞻任务桥，不将它称作新算法。完整 CCF A 目标仍要求新的
方法／问题、竞争性取证和独立时变流评估。

## 资格与使用边界

前向模型先前的六组 1-mm/覆盖门失败，原结果、门槛和保留种子不变。
本轮明确在模拟器里检验**未认证的点模型假设**，不使用其失败区间批准
动作，不调用 response_transfer.py，不宣布执行器响应、概率或机器人
安全资格。有效参数拟合只意味着可执行的数值点估计；模型失配、部分
可观测动态和饱和仍可能使估计的有效算子不同于真实执行器。

## 人群、扰动与固定政策

10600–10607 × push-v3/reach-v3/door-open-v3 × 四种固定条件，共 96 单元。
10608–10799 保留。每单元 12 个注册方法，共 1,152 次方法执行，最多
576,000 环境步／1,152 次初始重置。是八个开发种子簇，不是投稿所需的
独立长期非平稳流；不据这一人群确认泛化。

条件由配置冻结：未扰动、增益耦合+偏置、37 度旋转增益+偏置、反射
剪切+偏置。不是供代理查表选择的四个假设；它们只属于评估器。代理
估计未知一般二维仿射参数，不知道当前矩阵、偏置或条件 ID。矩阵与
偏置在一个轨迹内不变，xyz 高斯噪声标准差 0.05，夹爪不加噪。代理
只获得实际发送命令和可见状态，不能看到实际加噪动作、种子或 RNG。

使用官方固定 Sawyer v3 策略，不改变政策权重。公共动作接口先将政策
希望动作截断至 [-1,1]，再做注册的 xy 仿射补偿，最后截断发送命令。
评估器施加真实 xy 算子、xyz 噪声，再按环境空间截断实际输入。
每轨迹只有一次初始环境／执行器重置，最多 500 **探测+任务总步**；
探测到任务以及被动更新之间状态、位移历史、RNG 连续。成功或终止后
不再执行。方法共享同一单元的初态与噪声序列，信息／运动效果用匹配
探测运动对照解释；不同方法的后续运动不相同。

## 注册方法

| 方法 | 证据与控制 |
|---|---|
| NO_PROBE | 无探测、未纠正固定政策。 |
| PROBE8_NO_CORRECTION | 四方向各两步，共八步；随后未纠正政策。 |
| PROBE16_NO_CORRECTION | 原四方向各四步十六步；随后未纠正政策。 |
| DYNAMIC_OLS16 | 十六步，保留原动态 OLS 偏置补偿语义及非法拟合返回零补偿。 |
| PRIOR_AFFINE16 / PRIOR_NEAREST16 | 十六步，原同数据校准仿射／近邻偏置方法，保留原离散补偿集合。原资格只覆盖其原作用域。 |
| FWD_LINEAR8 / FWD_LINEAR16 | 相应探测后，用冻结每任务线性前向模型估计一般仿射输入映射；实际使用其逆映射补偿。 |
| FWD_QUADRATIC8 / FWD_QUADRATIC16 | 同样证据，用冻结状态二阶模型做标准有界预测误差辨识，实际使用所选点估计补偿。 |
| PASSIVE_LINEAR | 无专门探测，先执行未纠正政策；每 16 个任务步从最近至多 64 个已完成样本更新线性有效算子。非法更新保留已保存的上一控制器，尚无有效估计时为未纠正。 |
| ORACLE16 | 仅评估器知道真实算子，十六步后使用真实逆映射；标为理想参数参照，不能进入代理训练、拟合或选择。 |

八步探测是每方向两步，**不是十六步程序的前八步**。两步真实位移
历史之后才有前向样本，所以八步给出六个样本。十六步给出十四个。
所有实际步均计费。未达到完整探测且环境结束时保留其真实结果，不
伪造补充测量；探测若已成功，任务无需再执行。

## 点辨识与执行语义

名义前向模型来自 10200–10215 的训练，模型文件在此前已经冻结。本轮
不再训练它，也不从 10400–10415 或本轮任务结局调参数。对每个过去样本
q 与已发送 xy 命令 u，拟合六参数 `[M|b]`，使冻结模型在当前可见状态、
过去两次 xyz 位移与假设名义输入 `clip(Mu+b)` 下预测的 xy 位移接近
实际已观察位移。z 与夹爪命令不变。目标仅来自已完成可见转移，不含
当前真实参数、实际噪声动作或未来结果。

线性模型用闭式线性解初始化，再用一个注册的有界预测误差求解处理
输入饱和；二阶模型有四个固定的正交旋转初始化，不查真实条件。标准
SciPy 1.15.3 `least_squares(method=trf, loss=linear)`，解析 Jacobian，
ftol/xtol/gtol 均 1e-8、x_scale=1、每起点最多 64 次函数评价。残差除以
0.001 米仅为数值缩放，不是噪声界。拟合最低六样本，增广输入秩 3、
缩放条件数不大于 1e6；系数界 ±2、偏置界 ±0.3；估计矩阵奇异值在
[0.25,4] 才能逆映射。所有数值条件预先固定，不提供置信认证。

动作补偿为 `u_sent=clip(inv(Mhat)*(u_policy-bhat))`，z／夹爪沿用希望
动作。所选控制器在后续执行前保存；执行器使用保存的控制器，不能
根据真实算子或结局替换选择。每次更新记录过去样本数、摘要、候选
求解和拟合失败。前向固定探测方法非法拟合后停止，留在 96 分母中，
不由 Oracle 或另一方法代执行。历史基线与被动法的注册回退行为单独
记录，不把其拟合失败改写成拟合成功。

在探测均值输入不饱和时，组合名义模型是一个有用假设；在饱和边界，
“截断均值后加噪”与“真实变换均值加噪后截断”不完全等价。部分状态
可见及名义模型误差也可能破坏组合。这些是被检验假设，不是隐含证明。

## 统计、任务门与成本

全部 96 单元和停止案例保留。报告总体／任务／真实条件的任务成功、
实际总步、探测步、停止与无效更新、拟合延迟、参数误差（评估器仅在
选择／执行后计算）、执行轨迹。配对与 bootstrap 单位是八个任务种子
簇，每簇保留三个任务、四个条件及全部方法；不把 1,152 执行当 iid。

五个前向方法各有预注册任务效应对比：四个固定探测方法对其相同
探测运动对照，被动法对 NO_PROBE。给出固定 10,000 次种子簇 bootstrap
99% 区间，同时展示所有五个对比；这只是开发数据的不确定性描述，
不是精确有限样本或同时覆盖定理。某前向方法的效应区间下端大于零、
成功数不低于 NO_PROBE，才记“点辨识任务桥可用”。另列同访问的
线性／二阶／被动方法是否以不低成功数和较低总成本支配它；被便宜
标准方法支配不支持新的主动取证方法。不存在“模型参数更准就晋升”。

无 API、记忆、政策权重更新或跨案例学习。每个前向方法完整承担其
模型来源研究 **21,010 步／288 重置**（训练 6,763、校准 7,250、资格
6,997），包括原失败资格，不仅计实际用于拟合的训练部分。旧校准方法
承担完整 2,304 步／144 重置；无先验基线为零离线资源。在线与按 96
单元摊销资源分别报告。全研究实际收集把两个来源银行各计一次，不
重复相加，也不能因共享而说免费；失败／部分执行成本保留。

秘密扫描及差异检查，本地提交后只生成一次 manifest 并执行一次。
已有 status 拒绝重启。保存全部前后可见状态、原始政策／实际发送命令、
状态/RNG 链、执行前选择、控制器版本、连续衔接和费用。异常保留部分
轨迹、已完成费用与无法确认的执行尝试，不自行重跑原种子。

独立离线审计不重新仿真：重建过去位移／样本、拟合或其注册求解、
控制器选择与实际发送命令、前后状态/RNG、停止与成本，检查 Oracle
只在评估器方法出现。真实参数误差只能事后报告，不进入代理选择。
中文报告保留任何负效应、停止、未扰动损害和强基线支配；本地提交。

预测误差辨识、固定模型补偿和被动在线辨识属于标准方法。软件使用
[SciPy 有界非线性最小二乘](https://docs.scipy.org/doc/scipy-1.15.3/reference/generated/scipy.optimize.least_squares.html)，
其解为局部最小而非全局／物理正确性证明。机器人在线模型适应已有
[Saviolo 等的相关研究](https://publications.syscop.de/Saviolo2024.pdf)；本轮
未复现其完整控制框架。更广任务结果和一个任务桥不能替代新颖性复核。
