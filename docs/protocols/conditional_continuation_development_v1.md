# 固定连续八步前缀的条件继续策略：冻结开发协议 v1

研究问题及旧实验区别见 [问题说明](../research/conditional_continuation_question_v1.md)。
本轮不调整旧 IVR、Gaussian 权重或旧失败门，不训练／宣称新在线方法。

## 人口与随机设计

新种子 12200–12223，八算子流 × 三任务，24 个固定八步可见前缀上下文。
每个上下文四个独立后续噪声实现，96 单元、七固定方法，共 672 次真实执行。
12224–12599 及全部旧保留范围不用。算子生成种子 46001，沿用旧八流生成器
的静态 A 映射；旧 B 转移家族不作为本轮隔离家族，也不执行旧种子或算子。

任务种子为 `12200+stream*3+task_index`。交互之前，使用
`[seed,task_index,46003]` 生成前八步三轴噪声，用
`[seed,task_index,46005,future_index+1]` 生成剩余 492 步噪声。
标准差 .05，转为 little-endian float32，并保存只读数组及评价器摘要。
每次 step 消费一行；记录已消费噪声历史的哈希，绝不把整个未来数组哈希
冒充当前 RNG 状态。轨迹中没有播种、切换生成器、回退或重置。

相同前缀的四个未来实现、同一实现的各方法都实际创建独立环境并重新走
前缀；不复制／恢复任何模拟器状态。每次只允许一个控制初始重置，后续
连续执行到成功、终止或 500 步。未来噪声及真值始终属于评价器，不进拟合
或控制器输入；事先生成噪声没有执行未来环境或提供未来任务结果。

## 固定方法及控制

| 方法 | 行为 |
|---|---|
| DIRECT_G8 | 宽八探测后建 Gaussian 参考，直接用其有界纠正器执行固定政策。 |
| KEEP_G8_AFTER16 | 同宽八建参考，再宽八探测；仍消费保存的第八步纠正器。 |
| UPDATE_G16 | 同宽八后再宽八，使用全部真实数据重建 Gaussian 参考再执行。 |
| POINT16_CYCLE | 同样两次宽八，执行点估计逆纠正；无效逆停止并保留失败。 |
| PASSIVE_G16 | 同宽八建参考，执行八步实际政策并观测；再用全部真实数据更新参考后继续政策。 |
| POINT16_WIDE | 原四方向各四步的十六步固定程序，点逆纠正；总体强基线。 |
| NO_PROBE | 不探测，直接固定政策；总体基线。 |

宽八为 ±.4、四方向各两步，gripper=0。Gaussian 均使用固定参数先验、
名义 LINEAR_ARX、旧 CALIBRATION 初始六步经验 RMS、λ=.01、ρ=1；没有新拟合
超参数或似然资格。八步仅提供六个合格历史样本。最多十六步专门探测，
选择额外八步须保留 32 步任务预算。PASSIVE 的八步是任务政策步，包含在
500 总步内，成功即结束；不能当成额外八步专门探测或免费环境交互。

每个实际选择和控制器先保存，执行器消费保存 JSON。KEEP 必须绑定第八步
控制器，不能偷换成第十六步重拟合。PASSIVE 的政策块也必须消费已保存的
第八步控制器，随后才用其真实观测更新。全部失败和早期结束保留分母。

## 前缀资格与分析

对五个同前缀可行方法，核对同一实现之间、以及四未来实现之间的前八步
命令、原政策、观测、已消费噪声哈希及声明积分／模型／任务见证。
原宽十六和 NO_PROBE 只核对自身四未来前缀重复，不把它们当成同八步决策
可用分支。见证不是完整隐状态证明。八步前已结束者单列，无继续决策，
仍纳入完整任务分母；不删除或补做案例。

逐前缀、逐固定方法报告四未来的成功、真实步、截止损失均值／范围、
以及各继续策略减 DIRECT_G8 的四个配对损失。截止损失成功取实际总步，
失败／停止取 500。范围不是置信区间；四样本不足以声称逐状态条件概率保证。

评价器的 leave-one-future-out 查询表对每个留出实现，只接收其他三个
未来实现的五分支损失。按训练平均损失最小选分支，平局固定顺序
DIRECT_G8、PASSIVE_G16、POINT16_CYCLE、UPDATE_G16、KEEP_G8_AFTER16。
选择后才读取留出分支的结果做诊断评价。所有物理分支在分析前已执行，
故这不是选择先于真实任务的在线 Agent，也不是真正最优策略上界。
这里的隔离指纯选择函数没有留出结果输入，不声称离线分析尚未载入完整文件。
初始前缀已经结束的案例使用 DIRECT_G8，单列为不需要继续决策。

主诊断为查询表对始终 DIRECT_G8 的留出平均截止损失差，同时报告成功差、
所选分支与选择训练来源；不能用单次赢家一致率替代平均损失评价。
按八个独立算子流先汇总三任务／四未来，在反射与非反射各四流内分别
重采样四流，10,000 次、种子 20261015，给出配对百分位 95% 区间。
所有查询表训练和留出重复依赖留在流内，不把 96 单元当独立算子。

这是固定容量开发测量，不是确认性功效设计，没有可提升为算法成功的门。
即使主诊断有利，也需可见特征方法、强固定分支竞争与独立在线确认。
未观察到跨未来查询收益也不证明条件最优策略不存在；不改分支、噪声或
样本量去获得有利结果。

## 全部费用与执行约束

最多 336,000 个新 Env.step／672 次控制初始重置／19,000,000 个
do_simulation 请求帧；目标工厂临时重置和控制安置分列。
所有名义方法完整承担旧 21,010 步／288 次控制重置来源，按 96 单元摊销；
旧源物理采集只计一次。查询表依赖全部反事实采集，必须披露整批成本，
所选分支损失不能冒充部署中的物理成本节省。

源、配置、协议、问题说明和审计器经必需检查并提交后冻结，一次执行。
保存噪声承诺、选择、全部实际轨迹及失败；异常或观察超时不重启。
审计独立重建噪声、程序、保存控制器和费用，明确披露复用数学函数；
不重仿真动力学，不调用 API，不写自然经验记忆，不更新政策权重。
