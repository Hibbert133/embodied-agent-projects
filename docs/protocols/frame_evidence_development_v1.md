# 坐标框架歧义与行动相关信息：独立开发协议 v1

本协议服务于持续的 CCF A 研究目标，检验尚未满足的行动相关信息前提。
它不延长在线 API 小试，也不改动旧扰动、校准模型、种子或结果。
在线 API 小试的 14/16 对 16/16 负收益结果保留。

## 问题和先验边界

采用一个事先构造、可代数解释的二世界诊断：同一前缀的观察相同，但不同
纠正动作可能获得不同任务结果。构造例只能验证存在性，不能估计真实机器人
故障的频率，不能直接作为新算法或发表证据。两类可选坐标旋转事先公开；
当前世界标签、注入参数、执行动作、种子、随机数状态和任务结果属于评估器。
系统辨识函数只能接收固定模型和实际已获得的命令/观察轨迹。

使用不变的 push-v3、SawyerPushV3Policy 和 xyz 高斯噪声标准差 0.05。
本版本独立规定：先将策略希望的动作截断到 [-1,1]，施加纠正，再将发送
命令截断到 [-1,1]；执行器对有界命令施加平面旋转与偏置、xyz 噪声，最后
按环境动作空间截断。所有方法共用该接口。旧实验的截断次序不被追溯改写。

两个评估上下文：

- FRAME0：R=I，b=(-0.1,+0.1)。
- FRAME90：R=[[0,-1],[1,0]]，b=(+0.1,-0.1)。

命令 (+0.2,0) 在两者中的无噪声响应均为 (+0.1,+0.1)；命令
(-0.2,0) 分别为 (-0.3,+0.1) 和 (+0.1,-0.3)。相同任务种子下的
两个上下文共用相同执行噪声序列，以建立精确配对的不可区分见证；这不是
两个真实在线经历。上述参数在所有新任务结果出现前固定，禁止幅度/角度扫描。

固定的候选动作空间是 FRAME_A、FRAME_B 和 UNCORRECTED。FRAME_A
使用 I 与命令偏移 (+0.1,-0.1)，FRAME_B 使用逆 90 度旋转与偏移
(+0.1,+0.1)，UNCORRECTED 使用 I 与零偏移。纠正对整个策略执行保持不变。
这些是事先给定的候选控制器，不是在线访问当前真实参数的 Oracle。
固定候选的评估结果仅用于结构见证，不能作为部署经验或训练标签。

## 名义模型与廉价标准基线

只重新利用原校准的 72 条训练轨迹（8900–8907、已知命令、零偏置名义
执行器）拟合标准 ARX：delta[t]=A delta[t-1]+B command_xy[t]+c。
每条 16 步轨迹提供 15 个样本，共 1,080 个。按列 RMS 缩放最小二乘，
要求设计秩 5、缩放条件数 <=1e6、B 最小奇异值 >=1e-8、条件数 <=1e6。
模型在 manifest 中保存、散列并冻结，早于本轮任何任务执行。原资格数据
8908–8915 不参加拟合，也不能称为这个 ARX/旋转模型的独立资格认证。
所有访问先验的方法均报告完整旧校准成本 2,304 步/144 次初始重置，
本轮按 16 单元摊销为 144 步/9 次额外重置；本轮不再物理收集校准。

标准辨识基线对两个固定旋转分别计算 ARX 残差，拟合独立自由常数项后
比较均方残差；均值经 B 的逆给出等效命令偏移，仅作诊断。残差相差不超过
1e-12 时按 FRAME_A 打破数值平局。输入围绕均值的最大偏差 <=1e-8
时明确标记常量输入不可区分并选择 FRAME_A。不得将秩、残差或选择当成
置信证书；不拟合概率、任务成功预测、阈值或学习策略。

## 人群、对照和预算

新任务种子 9800–9807 × 两上下文 =16 单元，9808–9999 保留。
所有状态均纳入，不能仅选择失败状态。十一方法共 176 个物理执行，各自
500 总在线步，最多 88,000 步；每个执行只有一次初始环境/执行器重置。
探测直接衔接任务，不重置环境或噪声随机数流。

| 方法 | 探测 | 选择 | 离线资源 |
|---|---|---|---|
| FIXED_A_PREFIX4 | +x 四步 | 固定 A | 无 |
| FIXED_B_PREFIX4 | +x 四步 | 固定 B | 无 |
| UNCORRECTED_PREFIX4 | +x 四步 | 无纠正 | 无 |
| MODEL_REPEAT8 | +x 八步 | 标准 ARX 选择 | 完整旧校准 |
| MODEL_REVERSE8 | +x 四步、-x 四步 | 标准 ARX 选择 | 完整旧校准 |
| MODEL_SYM16 | +x、-x、+y、-y 各四步 | 标准 ARX 选择 | 完整旧校准 |
| LEGACY_AFFINE16 | 同十六步 | 旧仿射估计及旧有界补偿网格 | 完整旧校准 |
| LEGACY_NEAREST16 | 同十六步 | 旧最近邻及同补偿网格 | 完整旧校准 |
| FIXED_A_REVERSE8 | 同反向八步 | 固定 A | 无 |
| FIXED_B_REVERSE8 | 同反向八步 | 固定 B | 无 |
| NO_PROBE | 无 | 无纠正 | 无 |

幅度均为 0.2，z/夹爪探测命令为零。METHOD_REPEAT8 与 REVERSE8 的状态
运动不同，因此两者的任务对比是配置总效果，不能把全部收益归因于信息。
两条 FIXED_*_REVERSE8 在相同实际探测下隔离纠正选择；四步候选用于
不改变观察的结构见证。旧仿射/最近邻只作为依赖旧假设的基线，其旧资格
不保证旋转下可用。各方法不读取其他方法或上下文的在线结果。

## 冻结判断与统计

结构门要求八个种子的共同四步和重复八步观察在两上下文逐值相同，反向
八步观察在每个种子不同；至少六个种子的固定三候选成功集均非空且互不
相交；对应上下文的固定 A/B 在共同四步后合计至少 14/16 成功。
上下文盲上界为每种子三个固定候选跨两世界成功数的最大值；知上下文
上界为每世界三个候选成功数的最大值之和。两者均为评估器上界。

标准基线可行性门同时要求：反向八步正确旋转选择 >=14/16，任务成功
>=14/16；比重复八步和任一个固定反向八步至少多四次成功；不低于旧
仿射、最近邻和不探测成功数；比标准十六步最多少一次成功。所有完整性、信息边界、
预算、衔接违规为零。结构和标准基线两门分别报告；总通过只是开发前提。
任何失败均保留，不重跑、不增大变换、不调节残差模型或门槛。

全部十一行结果、两个上下文和全部失败逐例公开。报告反向八步对各基线的
配对差和 10,000 次任务种子簇重抽样 95% 区间；两世界、十一方法同种子
保持一簇，只有八个独立簇。区间是探索性描述，不作多重比较后的优越性保证。
零 API、零记忆、零策略权重更新。门通过也不授权自动提高论文贡献声明。

## 留痕、审计与一次执行

先通过仓库测试、编译、依赖、秘密扫描与差异检查，提交实现/协议/配置，
从干净提交生成唯一 manifest，然后一次性执行。已存在状态文件时拒绝重启。
当前选择在任务开始前写入 decisions.jsonl；执行器读取已保存的选择。
保存完整 39 维前后观察、命令、评估器执行输入、环境状态/RNG 连接、
模型、声明和结果。独立离线审计重拟合训练模型、重放可见证据决策，检查
逐步策略命令、旋转/噪声/截断、配对、人群、预算和全部成本；不重新仿真
任务动力学。失败/停止不能用其他基线代执行。

事件使用连续编号与高分辨率 `perf_counter_ns` 单调计数器检查先后顺序；
UTC 时间只用于显示，系统时钟回跳单独记录，不据此推翻单调执行顺序。

背景：任务相关探索已由 [Liang 等 RSS 2020](https://roboticsproceedings.org/rss16/p085.html)
研究；按行动区域取证已由 [Javdani 等 AISTATS 2014](https://proceedings.mlr.press/v33/javdani14.html)
研究。本轮是这类标准思想的先决条件诊断，不将重复/反向探测本身当作创新。
