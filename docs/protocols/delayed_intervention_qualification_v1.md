# 中途干预执行资格 v1

本协议准备在 `codex/delayed-intervention-qualification-v1` 实施。采集器、独立审计器与测试必须全部完成、通过仓库检查并本地提交，然后才可生成唯一清单和运行一次。单独写下本文件不表示实现已冻结，也不启动任务。

## 目的与边界

验证已实现的公开中途干预器和私有主机接口能否在 MetaWorld 的真实当前状态上消费保存的选择，保持物理时间、原始噪声和预算连续。三个任务使用固定官方策略；动作噪声标准差 0.05，总控制预算每次 500 步。原先所有冻结研究和保留种子不变。

这是执行资格，不是新方法收益研究。操作由预先固定的枚举指定，没有在线触发器、训练选择器或 LLM。三个任务各一个来源种子，不能估计普遍任务优势、变化检测能力或论文主结论。旧四步/八步正式比较未证明四步优先方案优于原八步；其结果原样保留。

## 同一真实前缀与已保存候选

从一次受控初始重置开始，执行固定 float32(0.4) 的 `+x,+y,−x,−y` 四步，再重复一轮。这个程序是此前名义设计保存的 FOUR_002；本次不重新选择设计，也不根据资格结果改动动作。

第 4 步仅使用实际前四步可见数据，沿用已实现的四步边缘估计器，保存纠正候选 C4。它是同一任务中计算但尚未用于任务动作的候选，不能称为曾成功应用的旧技能或自然记忆。第 8 步使用完整真实八步前缀拟合并保存 C8。之后固定策略由 C8 纠正，实际执行到第 16 步。

四步或八步估计无效，或者任务在边界之前已经结束，都保留原样并标记边界不可用，不替换候选、不延长前缀、不重置、不补选种子。估计只针对原始受控重置后的前缀；没有把第 16 步当作新重置，也没有进行中途或接触阶段重新辨识。

每个种子分别从独立构造但匹配的初始状态执行五个完整程序。每个程序都实际支付自己的前缀费用。禁止复制或恢复模拟器状态、安装新的未来噪声，或拼接其他程序的后缀。

| 操作 | 第16步之后 |
|---|---|
| CONTINUE_CURRENT | 干预器消费已保存 C8，继续固定策略。 |
| SWITCH_SAVED | 干预器消费同一任务保存的 C4，继续固定策略。 |
| RUN_UNCORRECTED | 干预器消费恒等映射，继续固定策略。 |
| STOP | 保存停止选择，不再执行物理步骤，保留失败分母和500步截止损失。 |
| DIRECT_CURRENT | 独立普通循环继续使用 C8，不调用新干预器，作为行为保持对照。 |

公开决策对象仅含任务、当前可见观测、已消耗步数和两个已保存的纠正参数。种子、真实偏置、随机数状态、噪声带、原生状态和未来结果保留在私有主机及评价记录中。主机独立检查实际政策查询、保存命令和来源引用；独立审计重新核对相同关系。

## 固定人口与完整预算

严格按任务和操作列表顺序执行：push-v3 用 21400，reach-v3 用 21401，door-open-v3 用 21402；每种操作一次，共 15 次执行。21403–21599 保留。受控真实偏置统一为 [0.12,−0.08]，二维映射为单位矩阵，死区为零。其真值不得进入公开准备器或干预器。

原始噪声带沿用 SeedSequence([task_seed,47001]) 派生的 500×3 float32 高斯样本，按真实步骤消费；前缀与任务之间不重置噪声。五种程序的匹配只依赖预先分配的同一种子，所有方法拥有自己的连续完整执行。

最多 7,500 个控制步、15 次受控重置、420,000 个请求仿真帧。每次工厂创建还有 50 次任务生成重置，每次重置请求 500 帧；满预算最大费用是 15×25,500+7,500×5=420,000 帧。实际停止与提前结束按实际步骤计费。

所有变体都依赖共同的校准前缀，因此各自计完整历史来源：3,840 控制步、480 受控重置、24,480 全部重置、12,259,200 帧；按每变体三个来源单元摊销，不能除以15次总执行。来源实际只收集过一次，本轮新增为零。既有名义设计三次枚举、432 个候选另列，本次不再进行设计枚举。

保存全部参数拟合、优化器 nfev、政策查询、控制尝试/返回、工厂/初始重置、请求/完成/异常未知帧及总耗时。异常后的未知费用不能填零。新的 API 调用、名义训练、选择器训练和政策权重更新均为零。

## 冻结验收条件

执行资格必须同时满足：

1. 全部 15 次分配执行都有完整记录；15 个边界均在第16步仍可运行，且 C4/C8 有效。早结束和无效边界保留并使资格不完整，不作成功替代。
2. 每任务五程序的初始观测、原生状态见证、16步物理前缀与边界见证匹配。主机见证不是独立外部真实性或通用隐藏状态证明。
3. 三个任务中，CONTINUE_CURRENT 和 DIRECT_CURRENT 的完整实际物理步骤、结束观测、原生/语义状态见证及步骤计数一致。比较字段排除日志序号、墙钟时间和 Gym episode.t 等运行计时。
4. 每个干预选择先保存，所用候选来自该会话已写日志；命令先保存，再物理执行，再保存结果。独立重建所有固定政策命令及纠偏映射，检查引用顺序。
5. 至少一个任务的 CONTINUE_CURRENT、SWITCH_SAVED 和 RUN_UNCORRECTED 发出三个不同的首条干预后命令。若饱和等原因导致未观察到该见证，保留未满足结论，不更换任务或触发时刻。
6. 所有 STOP 在边界之后新增零物理步骤。每次执行恰有一次受控重置，无中途重置、恢复、捕获或噪声替换；控制步骤、五帧时钟与全局费用一致且不超预算。
7. 所有公开记录只含所定义的已发生可见数据；保存全部结果、停止、失败和边界不可用案例。任何审计失败阻止通过声明。

操作结果仅描述，不计算小样本策略优越性的置信区间、不据此选择新方法或扩大人口。C4 从未在前缀任务步骤中使用，因此 SWITCH_SAVED 只验证切换保存的参数，不是回到过去的物理状态，也不证明跨任务回退技能。

## 记录、审计与失败处理

清单绑定本协议、配置、全部实现及测试、已有原型源码、完成的标准基线来源、名义模型、库与政策哈希和源码提交。实现有任何改变都需要新版本；冻结后不得修改实现再沿用当前任务人口。

采集阶段使用独立进程，保存原始压缩事件、逐执行记录、费用、状态及完成回执。物理异常立即停止采集并保存部分执行，不能以观察超时作为进程死亡证据，也不能重启同一人口。完整采集后再启动只读独立日志审计、结果汇总与中文报告。检查器可以共享已披露的固定政策、估计器、float32扰动数学和哈希工具，但必须独立检查外层分配、因果顺序、候选消费、匹配关系和费用聚合。

报告区分执行资格、任务结果和新算法证据。资格即使通过，也不能替代中途辨识资格、合法历史上的触发与决策方法、强基线、独立策略验证、消融或完整论文要求。
