# 四步与八步标准基线独立任务比较协议 v1

本协议在 `codex/short-probe-reference-v1` 上定义新的独立任务比较；执行配置为
`configs/short_probe_reference/development_v1.json`。源码、配置、协议及审计全部本地提交后，
才能生成不可覆盖的清单，依次运行一次 SMOKE 和一次 MAIN。此前 planning_v1 草案仍不可执行。
历史数据、失败记录、冻结文件及保留种子不改动。本协议不训练新选择器或宣称方法创新。

## 科学问题与来源

比较从受控初始状态开始的七种完整程序，检查四步标准估计和名义模型设计的探测动作，
相对于原八步基线的任务损失与费用。这补齐后继获取方法必须超过的便宜对照。
此前同状态续跑研究的平均更新收益不是本轮各方法的部署结果。

名义联合响应模型来自已完成的 cold_start_evidence qualification_v1，模型原始文件 SHA256
为 `08d2f6a7451e8e6f63aed9bf5bd15ce34158b2c219025547a483f6d925b423ad`。
现有 paired_probe_effects 主实验的完成、记录审计和数值审计作为前置依赖，哈希逐项写在配置。
新清单同时绑定其 778 个冻结输入、运行库/原生库/政策哈希及全部新实现、测试、协议和配置。

三个任务的名义探测程序已提前保存于
`outputs/short_probe_reference/design_preparation_v1/nominal_designs_v1.json`，SHA256 为
`5d706153dae9939ded3824ef616ea976cd0b967996895e785cd95b1f6a14bfc4`。
每任务枚举 144 项固定库，在单位变换工作点最大化工作 Fisher 行列式，严格并列取首项。
三个任务均选择 FOUR_002，即 +x、+y、−x、−y。实际执行消费已保存程序；每次验证重算
144 个候选的计算费用另计。不按本轮任务表现重选动作。局部名义设计不保证实际最优或物理校准。

## 七个注册程序

| 方法 | 行为 |
|---|---|
| NO_PROBE | 从受控初始状态直接运行未纠正固定政策 |
| ORIGINAL8_UPDATE | 原 BLOCK8，随后使用原八步联合估计器纠正 |
| BALANCED4_UPDATE | +x、−x、+y、−y 四步，随后四步边缘估计并纠正 |
| DOPT4_UPDATE | 已保存 DOPT 四步，随后四步边缘估计并纠正 |
| DOPT8_UPDATE | 两轮同一保存的四步程序，真实八步联合估计并纠正 |
| DOPT4_KEEP_AT8 | 第四步保存拟合，再执行第二轮四步；第八步消费第四步保存参数 |
| DOPT4_FALLBACK8 | 四步拟合有效则立即执行；无效才真实补四步，用全八步重估并纠正 |

动作幅度是实际 float32(0.4)，估计器和控制器沿用已经测试的版本，政策权重不更新。
四步使用八步模型的前八维协方差边缘，不取精度矩阵切片；有效性由既有秩、界限与数值检查决定。
KEEP_AT8 在四步拟合无效时仍执行规定的额外四步，然后停止，不替换成八步拟合。
其他拟合无效也停止，只有 FALLBACK8 有注册的补测分支。成功、终止或截断时立即结束；
提前成功不强行继续探测或拟合。所有停止、失败、提前结束保留在分母中。

每方法每单元独立构造环境、进行一次受控重置，然后连续执行，总计最多 500 个控制步。
探测到任务不复制、不恢复、不重置环境或随机状态。探测保留至少 32 个任务步。
固定官方政策覆盖 push-v3、reach-v3、door-open-v3；输入噪声标准差 0.05，
原始噪声带由 SeedSequence([task_seed,47001]) 生成，按实际步时钟消费。七方法用同种子配对。
真实扰动、种子和私有状态只属于宿主与评价，不能传给公开代理、估计器或动作选择。

## 固定人口、种子与预算

MAIN 有 6 次重复 × 3 个故障族 × 3 种变化方式，共 54 条流，每流 12 单元。
故障族为 BIAS、COLUMN_Y、DEADZONE；变化方式为 UNCHANGED、ABRUPT、GRADUAL。
按重复、故障族、变化方式的嵌套顺序编号流 s=0…53，生成源为 67001+s。
沿用冻结的 states、blend、fraction 数学生成器；各单元内故障固定，单元间按注册方式改变。
第 i 单元的任务索引为 (i+repeat+family_index+schedule_index)%3，种子为 20200+12s+i。
共 648 单元、4,536 次执行，实际任务种子 20200–20847；20848–21199 保留。

SMOKE 是一条九单元流，种子 21200–21208；21209–21399 保留。任务索引 (i+1)%3。
单位矩阵、零死区；前五单元偏置 [.12,−.08]，后四单元 [−.14,.10]，共 63 次执行。
预检仅检验流程，不用其成功率选动作、方法、阈值或扩大人口。

| 阶段 | 控制步上限 | 受控重置上限 | 请求仿真帧上限 |
|---|---:|---:|---:|
| SMOKE | 31,500 | 63 | 1,800,000 |
| MAIN | 2,268,000 | 4,536 | 128,000,000 |

每次工厂生成另有 50 次重置，每次重置 100 次五帧仿真请求。因此每执行 51 次全部重置，
25,500 个重置帧，再加每控制步 5 帧。MAIN 上限预算所需最多 127,008,000 帧。
账本计实际请求、完成和异常不确定帧；错误后不补跑或以替代方法覆盖。
物理异常保留部分执行与关闭错误，未知优化器成本明确标记未知，不写成零。

54 流的规模参考历史配对流标准差 51.20785077975331：双侧 α=.05、目标改善 20 步、
功效 .8 的正态近似需 52 流，按九格取整为 54。此历史方差不是本轮方差保证。
同一代理下检测四步改善约需 1,287 流；本研究不支持小效应功效、等效或非劣效保证。

## 比较、统计与完整费用

截止损失：成功为含探测的实际总步数；失败或停止为 500。费用始终是实际执行数，
停止不填充到 500。主比较为 DOPT4_FALLBACK8 减 ORIGINAL8_UPDATE 的平均截止损失。
六个次比较按以下固定顺序报告，均未多重校正：

1. BALANCED4_UPDATE − ORIGINAL8_UPDATE；
2. DOPT4_UPDATE − BALANCED4_UPDATE；
3. DOPT8_UPDATE − DOPT4_KEEP_AT8；
4. DOPT4_KEEP_AT8 − DOPT4_UPDATE；
5. DOPT4_FALLBACK8 − DOPT4_UPDATE；
6. DOPT8_UPDATE − ORIGINAL8_UPDATE。

负值表示左侧更好。MAIN 用完整流重采样：先按故障族、再按变化方式遍历九格，
各格用 NumPy default_rng(20261022) 的 choice(ids,size=(10000,6),replace=True) 依序抽取。
同一抽样用于七方法；每流等量 12 单元，54 流均值等于人口均值。95%区间取 .025/.975 分位数。
SMOKE 只有一条流，不报告总体区间。按任务、故障族和变化方式报告描述统计，不为其单独造区间。
保存全部执行、全部失败和全部停止 CSV，不筛选最好案例。没有新算法晋级门槛。

六个依赖名义模型的方法各承担完整来源 3,840 控制步、480 受控重置、24,480 全部重置、
12,259,200 请求帧；按阶段的 9 或 648 个单元摊销，不除以七方法总执行数。
NO_PROBE 无名义模型来源费用。共享历史来源实际只收集一次，不记为本轮新增。
已有设计准备三次枚举、432 候选；每次执行设计核对、在线拟合、nfev、政策查询分别计数。
独立审计重算的拟合、nfev、设计及政策查询另列。新增名义训练、选择器训练、政策更新、API 调用为零。

## 独立审计与执行顺序

每条记录含 run ID、manifest ID、source Git commit。外层人口字段使用 study_phase，
保留 phase 给物理生命周期和公开动作阶段，避免覆盖。请求和选择先保存，再执行，再记录结果。
原始压缩日志、每流完整记录、汇总、费用和报告保留精确字节及哈希。

记录审计自行重建人口及摘要，按全局事件序号与时钟验证工厂、唯一受控重置、探测和政策。
核对保存命令实际消费、官方政策输出、扰动与私有噪声、五帧时钟连续、完整重置费用和关闭状态。
每单元核对七方法初始观测/原生状态见证，四个 DOPT 方法前四步，DOPT8 与 KEEP_AT8 前八步，
以及 FALLBACK8 实际补测时的八步前缀；提前结束只核对已观察前缀并保留原因。
KEEP_AT8 必须消费保存的四步参数；八步接口必须确有完整八步。
预检必须至少有一次有效四步拟合被 RUN_FITTED 选择并真正用于后续 POLICY 步。

数值审计独立编写人口统计、对比与费用聚合，不调用分析函数；逐字段核对统计、区间、费用与 CSV。
浮点绝对容差 1e−9，整数、布尔、字段集合和语义严格一致。共享 NumPy PRNG/quantile 明确披露。
记录审计共享冻结故障数学生成器、数值估计/设计/控制器、固定政策与哈希工具。
审计不重跑环境；日志中的物理见证来自执行进程，不能当作独立物理复现或完整隐藏状态证明。

固定五阶段为 collect、record_audit、analyze、numeric_audit、report，每阶段独立子进程、保存输出和返回码。
任何失败停止当前流水线并保留原始记录；同一人口不重跑。MAIN 要求 SMOKE 五阶段全通过、
真实四步链路、原始哈希及可读中文报告齐全，并仍在同一冻结源码提交。
完成实现后运行仓库要求的单元测试、编译、依赖、秘密扫描和差异检查，本地提交后再生成唯一清单：

```powershell
.venv\Scripts\python.exe scripts/run_short_probe_reference_v1.py prepare
.venv\Scripts\python.exe scripts/short_probe_reference_pipeline_v1.py pipeline --manifest <saved-manifest> --phase SMOKE
.venv\Scripts\python.exe scripts/short_probe_reference_pipeline_v1.py pipeline --manifest <saved-manifest> --phase MAIN
```

清单准备检查所有本轮源码、配置及协议已跟踪提交；无关历史未跟踪结果不纳入也不删除。
SMOKE 与 MAIN 间不修改实现或提交调参，结果收集和审计完成后单独本地提交，不自动推送。
本轮固定程序没有跨单元历史，不评价自然记忆、时序选择器或变化检测；结果无论正负均保留。
CCF A 目标仍要求明确新贡献、强基线、新方法独立验证、消融、复现材料与完整论文。
