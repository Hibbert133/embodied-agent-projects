# 同状态强探测与任务收益重复性：冻结开发协议 v1

本协议承接 d644b2b 的同状态只读核查，解决中途强固定探测的真实对照缺失。
它测量决策目标，不提出已成立的新算法；CCF A 完整研究目标保持不变。
旧 10800–10943、所有旧保留种子、代码、数据和负结果都不改动。

## 人口、缓存与重复

新任务种子 11200–11247：八个独立算子流 × 三任务，每组两个任务种子。
第一个用于一次原幅度十六步的冷源辨识，第二个用于全部方法执行；
11248–11499 保留。源算子为新银行 A；执行为 UNCHANGED=A、CHANGED=B，
交叉四个提前指定的噪声实现。名义上下文共 48，实际配对前缀共 192；
每前缀十二方法，共 2,304 次案例，另有 24 次冷源采集。

来源缓存只由自己的冷源可见轨迹拟合一次，在该流／任务的所有案例、
情景、重复和方法间固定；分支自己的新估计只能用于该分支，没有跨案例
写入或自然经验记忆。无效源辨识导致所有需要旧控制的方法保存
STOP_NO_SOURCE_CACHE；这些失败保留在完整分母，不用假缓存或强基线代执行。
无旧缓存时的中途比较单列为不可配对；早期固定及未纠正基线仍真实运行。

四次实现从初始噪声种子开始，整条各自连续；每个重复内，各方法共享同一
噪声起点，初始环境种子相同。重复之间六步观察可能不同，因此这里只估计
同一名义上下文上的重复性，不能冒充条件于一个完全固定物理状态的后缀分布。
真算子、种子、RNG、重复编号和未来结果从代理输入排除。

## 实际分支和强对照

每次真实案例使用独立新环境与一次控制环境初始重置。中途方法真实执行
旧控制下六步前缀，再执行自己的分支；CACHE_CONTINUE 前六政策步必须逐项
精确相同。核对完整观察、命令、原始政策动作、成功／终止／截断及执行器
RNG，不容许近似匹配。中途与缓存参照还保存声明的 MuJoCo 积分状态见证。
该见证不授权复制／恢复状态；没有回滚、探测后重置或中途重新播种。

| 方法 | 行为 |
|---|---|
| CACHE_CONTINUE | 始终使用固定旧源控制。 |
| MID8 / MID16 | 六步后原 ±0.2 八／十六步，拟合后固定政策。 |
| MID8_WIDE / MID16_WIDE | 六步后 ±0.4 八／十六步，拟合后固定政策。 |
| MID8_WIDE_KEEP / MID16_WIDE_KEEP | 同样六步与同样宽探测，采集后预先选择继续旧控制，不使用新估计；不是拟合失败后的事后回退。 |
| G_OPTIMAL / RESPONSE_SET | 沿用冻结行动响应 v1 的六步判断、有限微探测库及原十六步刷新；假设与失败语义保持原样。 |
| EARLY8_WIDE / EARLY16_WIDE | 从初始状态直接宽八／十六步，保留总体强基线。 |
| NO_PROBE | 从初始状态使用未纠正固定政策。 |

保持三个固定任务政策、噪声标准差 0.05、每案例包含前缀／探测／任务在内
最多 500 步。源采集每个最多十六步；新登记控制步最多 1,152,384，控制初始
重置最多 2,328。探测保留 32 任务步，最多十六微步骤与一次固定刷新。
非法拟合停止，纳入分母；没有事后回退或 Oracle 代执行。
动作和控制器先保存，执行器读取保存 JSON 再执行。

没有成功／终止的六步完整案例才需要中途决策；提前结束者仍保留完整结果，
不计作主动取证收益。没有满足配对资格的单元记录原因，不补造分支。

## 任务目标与重复性门

分别报告成功、停止、实际总步／探测／任务步、源费用和无效拟合。
预先定义 deadline_loss：成功用实际总步；失败或停止统一为 500。
它用于描述任务截止损失，使提前停止的低实际步数不能冒充好结局；
物理步骤仍按真实数值另计，成功率依然是独立指标。这是固定代理目标，
不是新的最优效用或事后权重。

主配对固定为 MID16_WIDE 对 CACHE_CONTINUE。每名义上下文四个已配对实现
给出损失改善符号 +1、恶化 -1、相等 0；同时出现正负即方向反转。
leave-one-out 用其余三个符号之和的正负预测当前非零符号，其余和为零
则弃权，不给弃权算对。门要求全部四重复可配对、非平局上下文至少 24、
方向反转占非平局上下文不超过 25%，已预测非零符号一致率至少 75%，
非零符号预测覆盖至少 75%。
同时披露预测覆盖／弃权；此开发重复性门不授予概率保证或选择器资格。
缺失源／完整配对人口时门不通过。

所有十二方法、三任务、两情景、八流、四重复和全部失败展示。其余中途
方法与缓存参照是描述对照；不能看结果后换主配对。没有新 bootstrap、
阈值选择、监督分类器、LLM 或记忆。本轮不过门不能在这些结果上训练
替代选择器；过门也需要另行冻结的新估计机制、相关算法对比和独立确认。

宽八／十六的更新与 KEEP 分支另核对直到探测完成的所有真实状态、动作与
RNG，并比较同一探测后状态上的更新作用。探测中已经结束的案例单列。
更新减 KEEP 衡量使用当前估计的分支效果；KEEP 减 CACHE_CONTINUE 衡量
同旧控制下加入探测运动和时间的效果。两者不被命名为纯信息价值或保证，
不看结果后改主重复性端点，也不拼接未真实执行的回退轨迹。

## 全部初始化与原来源费用

新增仪器只观察 SawyerXYZEnv.reset、MujocoEnv.do_simulation 和
metaworld._make_tasks，并恰好一次转交原函数；不改命令、随机状态或物理值。
分别记目标工厂临时重置、控制重置、完成／异常 do_simulation 请求及其帧。
顶层重置的双 reset_model 安置动作计入帧，不能混入 Env.step 指标。
包源文件、版本与仪器源码在 manifest 中绑定。总 do_simulation 请求帧
上限 66,000,000，调用前检查；异常请求的帧列为不确定，不伪称完成。
观察范围不是所有 C 引擎计算、渲染、mj_forward 或真实机器人费用。

所有使用名义模型的方法完整计入已审计来源 21,010 登记控制步／288 重置，
按 192 单元摊销；NO_PROBE 无此费用。需要旧缓存的方法另承担完整本轮冷源
成本，按同一 192 单元摊销。冷源和名义数据物理上各采集一次，不能重复加
成多方法的新增仿真。旧名义工厂内部费用仅作原条件推算，新初始化则实际测量。
