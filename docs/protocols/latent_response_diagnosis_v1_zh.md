# 响应失败与任务改善余地：零新增交互诊断 v1

本协议在完整诊断导出前冻结。前置交付为26887a6：792次响应组件执行及独立
记录/模型/统计审计完成，SS_SENT未通过资格。本轮不重启旧实验、不改原比较，
不训练、选择或部署新模型，不新增种子、环境交互、优化器更新或在线LLM调用。
所有新增结果均为**事后描述性分析**，不作新的资格、显著性或任务收益主张。

## 完整来源与两个不同问题

来源A读取响应研究全部SOFTWARE36/TRAIN216/CAL108/QUAL432，共792执行、59268步。
原始结果、不可用窗口、失败、检查点和私有原生数值均保留。SOFTWARE没有运行
预测，保持“按协议未运行模型”，不伪造预测或将其当作新的误差样本。
来源B读取旧标准获取参考QUAL全部540执行、65854步、54个配对任务单元/9独立组。
两个人口不得混合推断，合计只读1332个已执行记录、125122个已保存控制步。
历史物理与拟合费用分别追溯，不能把只读分析称作原始数据免费。

第一问题：当前失败是否只可能来自独立人口的分布变化？用冻结最终权重在全部
4186个实际TRAIN窗口上复算原训练目标，同时区分入口和后续窗口。若网络在
相同TRAIN目标上已落后于既有直接岭回归，这反驳“纯粹由新人口分布变化解释”
这一充分解释，仍不能唯一归因于容量、优化、目标或噪声。

第二问题：既有真实获取/后继程序在完整任务上还剩多少记录内改善余地？这不
由预测误差代替，而从已执行菜单的完整截止损失描述。即使乐观菜单有余地，
也不证明能从公开证据识别、更不证明新方法自身历史部署会获益。

## 预测、检查点及缺失约定

TRAIN使用保存的公开bundle与实际轨迹/命令包相互核对，保留全部实际连续前缀
掩码。全部8种最终模型均复算；4种神经方法的1000、2000、3000、4000、5000步
检查点**仅在TRAIN**复算。5000步与最终权重一致，不能据曲线挑选或替换模型。
CAL/QUAL只读取动作执行前保存的入口FORECAST_RESULT；不得用其他检查点、重新
拟合或事后更好预测替代。不创建反事实环境或未执行观测/标签。固定模型接口
返回8个预测量时，未实际发生的时域用掩码标记、不计误差，不作为已执行轨迹。

每次主分析/独立审计至多100464个固定权重模型/查询前向（TRAIN最终33488+
早期检查点66976），加读取3424个既有CAL/QUAL预测。全部预测行103888，最终
窗口诊断行36912。前向次数不是新的模型拟合或独立统计样本，运行耗时另记。

窗口分为入口k=0及1--8、9--16、17--24，另给ALL_WINDOWS整体；分箱与整体是
重叠描述，不能把它们当作独立重复。没有窗口的箱保留None及原因，不填零。
单步模型H8不适用；短实际包只使用已发生的标签，不虚构最早或未来位移。

原神经训练目标是每任务均匀选可用轨迹、再均匀选窗口、再平均其实际有效XY
累计位移平方误差。本轮完整TRAIN目标按这个确切层级计算；不把它误称为原
岭回归完全相同的优化目标（部分窗口/时域加权可不同）。跨人口描述另在轨迹内
平均，然后按独立组组织/等组汇总；缺失与每项指标支持量并列。原QUAL完整分配
1m惩罚及其原始区间原样引用，不被新权重或诊断取代。

## 误差累积与评估端状态分解

对已实际执行的窗口，累计预测误差为e_h，令e_0=0、d_h=e_h-e_(h-1)，分别保存
终点平方误差、Σ||d_h||²/2和全部有符号交叉项，核对代数恒等式。交叉项可为负。
完整H8专用项与短窗口/单步的末端项分开，不能混合时域解释。

同一窗口的误差还分为：(预测位移−公开名义目标位移)+(名义目标位移−实测原生
目标位移)+(原生目标位移−实测手部位移)。保存三个平方项与所有交叉项，不能
把范数直接相加、将其中某项称为物理无噪声误差，或据相关性确定唯一机制。
真实原生数值/故障/噪声仅用于评估，绝不进入模型查询或训练标签。

入口同时描述名义与原生目标差、手部与原生目标差、前一步手部运动、手部与
物体距离、在冻结TRAIN标准化坐标中的幅度。没有新适用域分类器/阈值/校准模型；
这些量既不是概率保证，也不能直接当作在线收益或更新门。缺少接触力/接触对，
距离仅是代理。已声明包的XY预测不能滚动生成未来反馈任务轨迹。

## 完整任务菜单与不可逆获取

源码确认旧参考研究的共同前缀是RAW PI时间常数0.5，而不是C8。完整菜单为
RAW_CONTINUE、FIXED_PD_KEEP、FIXED_PID_KEEP、LOCAL_PD_KEEP、LOCAL_PID_KEEP、
LOCAL_PID_REFERENCE_RESET、LOCAL_PID_REFERENCE_CARRY、LOCAL_PID_REFERENCE_RESET_NO_PROBE。
另列RAW_CONTINUE、LOCAL_PID_KEEP、RESET、CARRY四个同获取/采用分支子菜单，不能
以较窄子菜单冒充全部动作机会。对全部54单元重新核对相同前缀（378对）。DIRECT_C8和MOVE_INTEGRAL保留为
外部完整程序强对照；其不同初始前缀不得伪装成该移动前状态的可切换动作。

完整截止损失为原始成功总步数，否则500；获取/验证/测量已包含其中，不再
重复计费。逐单元保存全部菜单损失及所有并列最小值，所得“记录内乐观菜单”
看到了未来结果，不能当作可部署策略、可学习性或off-policy估计证明。

对RESET/CARRY同时描述L_ref-L_raw=(L_keep-L_raw)+(L_ref-L_keep)。第一项包含
移动/测量费用及获取后的状态和后续控制变化，不能只叫固定探测步数；第二项
仍保留所有分配，不按实际采用/拒绝窗口筛选因果结论。恢复/停止后均来自保存
的真实状态，不重置撤销位移。旧10程序完整均值/成功分母与原统计逐项核对，
不重新定义旧主次比较或区间。不产生新的p值/置信区间。
