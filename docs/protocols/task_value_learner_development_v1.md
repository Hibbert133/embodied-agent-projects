# 两阶段分支收益学习：开发复用协议 v1

本协议在既有完整结果已知的情况下提出，属于开发数据复用，不是独立确认。
它承接探测后收益的重复性门，但不能把该门改称学习算法的验证结果。
新代码、配置、提取契约和评价程序在读取逐案标签训练前本地提交，执行一次，
失败也保存；不在同一数据上更换核、特征、岭系数、阈值或分组后再宣称通过。

## 可检验机制

现有响应有效性和信息宽度不直接预测任务价值；原固定更新还可能因逆映射
不稳定而停止。新候选同时建模一次测量的完整任务代价和测量后的控制选择。
探测前以六步真实旧控制历史、自己的旧纠正和当前观察选择继续旧控制、
宽八步或宽十六步。探测后用刚实际获得的观察及主机拟合，选择 KEEP 或 UPDATE。
无效新拟合不允许 UPDATE，但 KEEP 仍需使用真实同探测分支，不能虚构回退。

这里采用标准 RBF 核岭回归作为可执行基准：它本身不是新算法，两个标准
回归器的组合也不能自动作为 CCF A 贡献。候选要检验的是：明确建模探测后
控制选择是否改变探测前选择，并能在同权限强基线面前产生任务收益。

## 数据、权限和时间

六步状态。保持原始清单、全部源代码、轨迹、审计、成本和负结果不变。
原执行有八个独立算子流，三任务、两情景、四噪声实现；不能按重复随机拆分

只存在于评估器数据；模型输入的独立严格对象拒绝这些字段。

前输入只含初始和前六步可见观察、命令与原政策动作、旧纠正数值和剩余预算。
后输入增加该实际宽探测后的观察、命令与可见拟合诊断；不能读后续政策步、
其他探测长度的证据或训练之外的标签。现有全分支结局是明确标识的离线监督
目标，不能成为代理证据、自然经验记忆或在线反事实设施。

五个可选择的真实分支为 CACHE_CONTINUE、MID8_WIDE、MID16_WIDE 和对应
两个 KEEP。使用原 v3 审计绑定全部源字节，重新核对共享六步与完整探测前缀。
宽更新与 KEEP 必须在相同探测后观察、命令、声明的积分见证及 RNG 上匹配。
未匹配、缺失、已结束或证据跨界者导致本协议失败，不补造未执行分支。

## 两阶段拟合与分组

每任务单独拟合。后模型回归 `(UPDATE截止损失 - KEEP截止损失)/500`；
合法拟合且预测负值时 UPDATE，否则 KEEP。截止损失沿用成功为总步、失败
或停止为 500，原实际步和成功率仍单独报告。

前模型回归选定后策略相对 CACHE 的截止损失差，输出宽八和宽十六的两头。
其训练目标不能使用同训练案例拟合出的后模型决定 KEEP/UPDATE：在每个前
训练集内部再留一整个算子流，后模型预测该流，按实际分支结局建立前目标。
这使前模型训练目标包含后模型在未参与拟合流上的真实错误，而非先取标签最优。
外层同样留一整流，共八折；外层的流绝不进入任一内层、标准化、核宽度或
最终模型拟合。每折训练来源和所有预测、动作、选择分支结局均保存。

核宽度为当前训练样本标准化特征的非零成对平方距离中位数；岭系数固定 1，
尺度下限 1e-6，损失尺度 500。前预测与零比较取最小，平局依继续、八、十六
排序；后平局 KEEP。没有超参数搜索、分类器改写、bootstrap 或新概率保证。

只与 CACHE 比。所有模型保留折外失败、实际控制步和截止损失。
