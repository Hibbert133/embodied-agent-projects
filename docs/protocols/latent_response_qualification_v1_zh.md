# 已声明命令的公开历史多步响应：训练与独立资格 v1

本协议在新物理采集前冻结，覆盖新收集器、公开训练出口、训练和两级独立审计。
前置为native_command_witness的完整记录审计及原生合同PASSED。旧的DESIGN_ONLY
草稿保留；此协议提供独立的可执行分配，不改变任何旧模型、QUAL或统计比较。
实际配置为`configs/movement_task/latent_response_qualification_v1.json`，确切分配
及费用由版本化`latent_response_io_v1.config()`逐项核对。任何不一致阻止采样。

## 科学问题及结论边界

检验由真实公开IO历史初始化的隐状态，是否能在**入口已知**的外生命令上预测八步
累计手部XY位移；同时检验名义SENT摘要是否有帮助。此前SENT与原生实际目标不等，
故将其作为可能有害的输入，不能称作实际隐藏状态、无偏估计或安全参考。
不重复旧pose/history联合回归、GRU1/16单步实验或F20任务选择器。

数值合法、当前预测能力及含获取成本的任务收益是三个不同判断。本轮仅进行
前向预测组件资格，没有训练获取决策、逆控制或任务收益。网络/编码器是标准
辨识基线，未提出新算法。测试、组件改进或基线改进均不完成CCF A目标。

## 连续收集和因果边界

固定现有三任务及其固定底层策略。一次受控初始重置；先执行原RAW PI时间常数
0.5秒到16/32/64真实控制步，再执行原LOCAL_PID（P8、D16、I0.32、积分界0.5，
最多64步，原锚点和就绪条件）。期间任务积分挂起，返回时携带原积分。不得调参。
变化仅在实际存活边界替换输入仿射，不改变世界、时钟、随机数状态或噪声游标。

预先声明全部包命令，Z/夹爪为0，XY为float32、每轴绝对值不超过float32(0.8)。
TRAIN执行32步均匀随机命令；其余阶段分别执行固定8步循环
`(+.4,0),(0,+.4),(-.4,0),(0,-.4)`两次与独立均匀随机8步。
就绪后先保存查询及全部模型预测，再执行首个包动作。预测不选择收集器动作。
未来反馈策略动作依赖未来观测，不当成入口已知命令。模型失败不能由基线替换。
收集在包结束或环境早停时停止，**无完整任务尾段**。响应时域未成功不是500步
任务失败，未来完整任务研究必须重新计入所有获取成本与失败惩罚。

公开查询严格包含task、实际已完成时钟、最后1--16个真实39维观测、每帧的上一
实际发送命令4维、真实上一输入可用标记、名义目标减当前手部的3维差、入口已知
的8个命令。最初帧没有上一输入，以显式缺失标记和占位0表示，不伪造位移历史。
排除种子、私有目标/力/接触、真变换、实际噪声/施加动作和未来结果。mocap等只
写评估流，不作为训练输入或特权监督标签。

每步保存私有原生目标数值/四元数、地址、时钟；完整原生/RNG签名只在初末及
真实故障边界记录。不得声称逐步测得未保存的RNG签名。独立审计逐项核对实际
float32仿射/死区→XYZ噪声→最终裁剪→原生float32增量/float64目标累计、公开
名义累计、预测先于动作、同单元共同前缀、世界地址和物理费用。

## 严格TRAIN与模型

只有SOFTWARE原生数值逐步精确及每任务×包至少一个实际响应均通过才进入TRAIN。
完整TRAIN记录审计后，仅从公开轨迹与公开包元数据导出监督窗口；从入口到
min(实际响应数−1,24)逐点开始，未来8步命令必须属于预声明32步。
标签是从该查询真实手部到实际后继手部的累计XY差。短包只保留实际连续前缀，
掩码其余占位0，损失不读取占位内容；不模拟未执行轨迹。无窗口保留缺失原因。
每任务至少24条实际响应轨迹、16个完整入口包，否则无拟合、无额外采样。

标准化只用TRAIN，按轨迹→窗口→真实历史帧等权；逐通道scale<=1e-6改为1。
16×(观测39+上一u4+输入可用1+帧有效1)+名义差3=723维。真实缺失早期帧
内部补0且显式掩码，不能把补0帧当成真实位移。

|模型|固定定义|
|---|---|
|SS_SENT（唯一主候选）|723→32tanh→8tanh编码；状态和当前u/.8拼12→32tanh→8，h'=tanh(h+增量)；8→2输出增量，累计8步，单位0.01m；24130参数|
|SS_NO_SENT|完全同结构/容量/初值/采样；仅将最后3摘要输入通道置0|
|SS_CURRENT_SENT|完全同结构/初值/采样；前15历史帧内部置0，保留真实当前帧及摘要|
|DIRECT_MLP_H8|同723→32→8编码及同编码初值；隐状态+全部8命令32维→32tanh→16直接累计位移；25272参数|
|DIRECT_RIDGE_H8|相同723历史及全部32命令、加截距，共756维；每个时域独立加权岭回归0.001，截距不惩罚|
|PERSIST_ZERO|确定性零位移，无拟合|
|HISTORY_LINEAR10、QUADRATIC_STATE20|旧强单步形式，独立新同数据重训；实际入口前两步拼接，不伪造位移。每条实际轨迹权1，只拟合包内响应|

每任务一个模型/方法。直接岭每时域只对有实际该响应的窗口拟合，每轨迹总权1。
神经训练均匀抽有窗口轨迹，再均匀抽该轨迹窗口，batch32；连续前缀mask的累计
位移平方误差按每样本有效响应元素平均，再平均batch。固定Adam0.001、
betas0.9/0.999、eps1e-8，无衰减/裁剪/学习率计划/早停；CPU单线程、float32、
每个模型5000更新，一个固定初值，全部同采样日程。12神经训练60000更新；
9闭式模型30个岭系统（直接24+单步6），加3零参考，共24模型对象、21拟合模型。
每100更新进度/损失、每1000更新参数快照。异常/超时保留已完成模型/快照，
不重试，不从CAL/QUAL挑模型、容量或最优任务。

神经运行使用已独立锁定Python3.12/Torch2.2.2+cpu/NumPy1.26.4隔离环境，
文件SHA核对。闭式训练用固定主环境。隔离子进程只读严格公开TRAINbundle；
CAL/QUAL此时尚未采集。神经子进程硬超时7200秒，无重试，仅终止自己拥有的
进程树并保存回执。模型审计独立特征/标准化/正则方程重算30系统；神经不重训
优化器，另核对初值/5000步采样日程、独立NumPy公式及Torch double前向。
审计30次重算必须列费用，不能称作零拟合。

## CAL、冻结锁和一次性独立QUAL

模型独立审计后采集CAL；仅汇报经验0.5/0.9/0.95误差分位，不选模型、不拟合
阈值/区间或后续控制。至少每任务一个完整包才允许锁定。CAL记录与统计分别
独立审计后，在QUAL目录存在前写模型锁，绑定TRAIN模型、CAL记录及全部审计
文件SHA。随后一次性采集全部432 QUAL。任何失败停止后续阶段，禁止加样本。

统计只用入口已保存FORECAST_RESULT，不能用审计重算预测替换失败/异常结果。
H8=sqrt(八步XY累计位移平方误差/16)，H1=sqrt(首步XY误差平方和/2)。
有效原始误差单列；完整分配损失为min(1m,原始误差)，无入口/短实际时域/
无效预测一律1m。Decimal80基于str(float)计算，半偶舍入到整数纳米；不在0
附近使用浮点容差改符号。单步模型的H8为缺失不适用，不填0。

预登记全部门必须同时满足：

- SS_SENT的完整人口H8损失，分别减SS_NO_SENT及DIRECT_MLP_H8的两个主比较，
  95%整组bootstrap区间上界均严格小于0。这是联合交集要求，不挑胜出对照。
- 完整H8均值严格低于DIRECT_RIDGE_H8、PERSIST_ZERO、SS_CURRENT_SENT。
- 完整H1均值严格低于H10及F20。
- 全24任务×初始×变化×包分层各至少3个完整首8步；18组每组至少一个完整包。
- 全部方法的已保存预测无效次数为0。缺失不能从分母删除。

18独立组按三个时点分层、每层6组，有放回10000次。以每组整数纳米差总和
整组抽样、除完整分配432。线性1/40和39/40分位使用精确有理数。区间条件于
本次单个固定TRAIN来源及神经初值，不包括跨训练种子不确定性，不声称功效充分。
CAL不作资格检验。QUAL状态只有QUALIFIED_FORWARD_COMPONENT_ONLY或NOT_QUALIFIED。
