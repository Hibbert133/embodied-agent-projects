# 完整资格成本附录软件协议 v1

2026-10-29。独立的只读资源记账入口，不改变科学实验、主比较、门限、
原报告或样本分配。正在运行的资格实验和1393个冻结源码保持原样。
本协议不读取部分QUAL结局，不新增仿真、重置、策略查询、模型推断、
拟合、参数更新、seed或在线LLM调用。所有新增分析均是**事后资源记账**。

## 来源与进入条件

唯一科学来源为7abaec83b085冻结的OCCAM参考资格实验，manifest_id为
19347fbe7b039fabd536c411d74e87a823bd0925cd2bee9e5705329cdb77f78d。
先提交本附录软件、协议、纯构造测试、复用守卫与源码哈希。仅在原QUAL
1566次全部完成、进程审计、完整数学审计、原统计、独立统计审计、原中文
报告和原管线终态均通过完整性检查后，才读取结局并创建analysis_v1。
科学收益门允许失败，不用正结果作为读取条件。任何技术不完整则不分析
局部人口。采用已冻结first-window工具的读取守卫和完整性入口，明确
复用其JSON、SHA和准入检查；这不是独立物理重采样。

登记全部NATIVE174和QUAL1566，共1740次，包括原样的任务失败、短窗、
没有模型声明或没有参数更新的案例。每阶段29个实际程序完整保留，
GLOBAL_PI_0500是同一执行的别名，不能再加一次执行或费用。原始case、
原摘要和原审计哈希在分析前后核对。分析与独立复算合计上限1800秒；
输出create-only，失败保留failure.json，不覆盖、重试或改总体。

## 实际生命周期与完整损失

逐案例使用ledger_after_close减ledger_before，且前一案例结束账本须
等于下一案例开始账本。累计终值不能再逐案例相加。每次包括50次工厂
目标生成reset和1次受控reset：共51次全部reset，25500个设置物理帧，
另加每个实际控制步5帧。根计数和各阶段差分必须一致，未完成步骤不补造。
阶段合计与原审计的控制步、全部reset、实际物理帧逐项核对。

成功截止损失为实际控制步，失败仍为500；未执行的失败惩罚只作为损失
差额，不生成物理帧或重复加到实际交互费中。本附录不改原截止损失，
不由新的费用投影选择胜者或改变原科学通过标准。

## 模型与审计计算

保留每例固定政策查询数、所有provider窗口、实际NN声明、4候选预测、
参数更新、C4/C8拟合意图及优化器报告的nfev。固定PI也有provider窗口，
不能把它们全部计作NN预测；FROZEN观察窗口不能计作参数更新。
filter_update_attempts与原full_feedback_windows字段实际表示已采用更新
数，不重新解释为所有完整物理窗口。

对META／ERM程序，固定源码可重建：首次声明前1次模型会话初始化；
每声明1次basis_forward批次，包含4个候选；每个实际更新1次核心solve；
对称eig验证数为3×初始化会话+12×声明+3×更新。只重建固定核心中的
这些调用，不称为直接插桩，不包含所有底层BLAS、优化器或系统内部运算。
主收集与审计的actor重放分开报告。独立最终batch solve仅在训练模型
实际更新数大于0时计1次。原审计总solve应等于actor更新加独立batch，
legacy的冷启动拟合／内部线性求解保留在原cold guard字段，不混入核心。

case.wall_ns包含设置、环境、政策、模型、记录和关闭的主机总时间；
collection和完整audit的阶段wall另列，不伪称隔离的模型推断延迟。
资格LLM调用数和tokens为0，平均API延迟为null／不适用，不能记为0毫秒。
本次只读分析单列自身wall及文件读取／hash计数；两遍案例读取和两遍
案例目录hash之外仍有源码、准入及原报告链的额外hash，明确披露。
