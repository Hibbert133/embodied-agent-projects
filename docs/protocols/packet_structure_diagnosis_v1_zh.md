## 问题与范围

原任务级固定线性模型在独立 QUAL 没有超过强瞬时参考。要区分：
当前线性命令响应类本身无法表示的部分、保存模型尚未解释的反对称部分、
输入最终裁剪与私有原生目标工作空间裁剪。它们都不能直接代表任务收益或唯一物理原因。

登记全部864个已执行案例/288个家族，四分割、三任务、不变/变化、IN_TASK/MOVE、
16/32/64边界、包内H1…H16；零入口和短窗口均登记为缺失原因，不填零。
同一真实入口的ZERO/PLUS/MINUS组成一个观测单元，不把共同前缀重复加权。
每个H只有三角色都实际执行到H才有对称分解；原评分允许部分配对可用，本分析
因问题不同需要完整三角色，须披露该额外选择，不替换原648端点的全人口评价。

令实测手部位置为 y0,y+,y-（同世界坐标 XY，零命令并非物理静止）。定义
e=(y++y-)/2-y0，o=(y+-y-)/2。任何同入口、对整个已知包线性的命令响应预测，
对三配对的预测受限为(p,-p,-2p)。三个配对、两个XY轴的平均平方误差分解为

`MSE = ||p-o||² + ||e||²/3`。

因此 `||e||²/3` 是该有限家族/H上的线性命令类事后表示下界。这个代数事实不新颖，
下界用已知结果计算，不是行动前预测，也不构造每家族的“oracle拟合器”。
不解参数，不实例化新模型，不输出可部署的p。分别记录观测分解和保存预测分解次数。
此下界不能直接用于原平均RMSE/裁剪/缺失惩罚评分，也不能证明全局统计不可识别。

读取原 CAL/QUAL 保存的五模型全部预测，不重算任何预测。若保存三预测因浮点数
不完全落在线性子空间，先作固定算术分量投影，用正交缺陷的交叉项保留完整恒等式：
`p=(p0+ - p0- -2p+-)/6`，`r=(p0+-p,p0-+p,p+--(-2p))`。
直接MSE等于 `||p-o||² + ||e||²/3 + (sum||ri||²-2e·(r1+r2))/6`。
末项可有符号，不删除，不把数值误差伪装成物理成分。保存defect与恒等式误差。
SOFTWARE/TRAIN没有数值预测，标记未保存预测，不以零预测替代。

## 执行器与原生目标

读取已保存实际施加动作、原生 BEFORE/AFTER/QUERY 目标及真扰动，仅作评估。
按旧冻结命名空间确定性复算噪声带，计为带再生/算术检查，不是新独立随机样本。
严格复算 float32 仿射/死区→XYZ加噪→最终裁剪，逐位核对全部实际包动作。
再用已保存前原生目标加float32(.01*appliedXYZ)、工作空间裁剪，逐位核对后目标。
分别记最终动作裁剪、目标工作空间裁剪和实际输入的偶分量；不以输出等于边界
代替“发生裁剪”，以裁剪前/后的严格差异判断。所有真参数/噪声/原生状态禁入在线方法。

原生目标也分解出偶分量 en。定义 et=e-en，仅作为手部-目标的代数差。
`||e||²/3 = ||en||²/3 + ||et||²/3 + 2 en·et/3`，保留交叉项。
不将这些量称为可加因果方差、无噪声物理误差、接触原因或模型唯一失配来源。
共享加噪仍可经非线性系统与不同角色轨迹交互；本数据无重复周期独立噪声设计，
不能套用完整BLA噪声分离结论。裁剪后的输入与模型的发送命令也不是同一语义。
