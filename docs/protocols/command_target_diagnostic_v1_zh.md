# 公开命令累计摘要与完整保存记录诊断 v1

本轮为**事后描述性分析**，冻结后执行一次完整遍历及独立复算。
没有新采集、模拟器创建、重置、环境推进、模型训练/拟合或在线LLM API。
不分配新种子，不修改历史比较、资格门、控制器或来源结果。

## 问题、先验及三种判断

安装的MetaWorld控制接口先裁剪传入动作，用float32的XYZ动作乘0.01，
再加到float64的mocap目标，逐步裁剪到工作空间。机器人观测的手部位置
与该命令目标是不同变量，也可能来自不同的体/站点坐标。
零差、固定坐标偏移、动态/接触约束均需另行区分，不能仅凭二者差值归因。

三任务源代码声明受控重置目标为(0,0.6,0.2)，工作空间下界
(-0.5,0.4,0.05)、上界(0.5,1,0.5)。本轮显式使用这些公开环境先验，
不是从运行时读取私有mocap。先验不自动适用于真机或任意环境版本。
冻结清单绑定安装代码、任务重置代码、原执行器和全部来源记录。
数组替身调用安装的未绑定算术方法检查float32/float64及逐步裁剪；
不实例化环境。旧原生见证只有私有数组哈希，没有mocap数值，故不能
独立证明旧轨迹的重建目标等于实际私有目标。未来收集器需先补充仅评估端
原生mocap前后见证并验证，再讨论新模型训练；在线端不能读取该见证。

数值/因果合法性、当前物理预测能力、含获取成本的任务收益分别评价。
本轮只检查第一类算术和数据边界，提供模型输入问题的证据；不提供后两类资格。
新公开摘要只是一种工作参考，不是隐藏状态观测、统计均值、置信区间或安全保证。

## 全部人口、重建及分层

固定读取：旧selected_response全部TRAIN 1,152次/75,641步；最新标准获取
SOFTWARE_NATIVE全部60次/10,633步、QUAL全部540次/65,854步。
总计1,752次/152,128个已保存控制步，不读取旧selected_response的QUAL。
旧TRAIN只采集到测量窗口，其success=False不能当作任务失败。
所有短轨迹、提前成功、未移动、未测量及失败均保留；无数据写null及原因。

从真实CONTROLLED_INITIAL和连续STEP_COMPLETE开始，按原事件顺序递推：

1. 公开SENT：仅保存的发送命令，假设输入变换为恒等、执行噪声为零。
2. 评估APPLIED：保存的executed_action_oracle，条件于上述公开先验。
3. 评估TRUE_ZERO_NOISE：当前真参数变换发送命令，去执行噪声后最终裁剪。

后两者严格评估端专用。变化事件仅在已保存边界发生时更新真参数。
同一保存反馈命令流保持固定，第三项不是零噪声闭环的新物理轨迹。
代数分解q_applied−q_sent=(q_applied−q_zero)+(q_zero−q_sent)仅是向量恒等式；
工作空间裁剪使范数贡献不能加和，也不单独识别物理噪声、模型失配或因果效果。

逐步表包含三参考前后值、真实观测、工作空间裁剪、各差值及初始坐标差的变化。
测量入口必须先于探测数据，核对其四条历史来自当时保存的真实观测。
入口表不使用后续结果形成特征。噪声游标与logical_step严格核对。

逐轨迹/阶段汇总包含全部三任务、条件及原程序；移动阶段按原0.235m抬升
转换，保留LIFT/POST_LIFT及1–8、9–16、17–32、33–64固定分段。
其它阶段完整保留，并另有65步以后尾部；空分段不能填零。
先在轨迹内求均值，再按独立组汇总。旧TRAIN每连续9个登记单元组成一组
（三任务×三个时点），最新研究沿用登记group。组、程序和条件分别展示，
不把多个MOVE程序的共同前缀当作额外独立样本。规范获取入口固定LOCAL_PID_KEEP；
其余程序保留在分程序表中，不拼接提高入口样本数。不做显著性检验或阈值筛选。

## 冻结、独立审计与失败处理

实现、配置、此协议、数组/保存记录测试及环境/拟合/网络守卫检查后本地提交。
此前已通过的1,797项唯一测试按源码哈希复用，新增17项测试单列，不能相加重复运行次数。
新运行清单要求已冻结源码、历史完整文件及安装源码哈希一致且已跟踪区干净。
输出新目录，排他写入；异常留存，不覆盖或补采。

独立审计禁用主分析的trace/arithmetic/grouped/stats及变换入口，另写float32
输入变换、逐轴累加、阶段归约及整组汇总，核对全部派生字段与分母；
共用只读来源分组适配器，明确披露这一非独立部分。来源审计已独立通过，
本轮另外核对源字节、序号/时间、每条轨迹步数和全体来源计数。
审计浮点比较绝对容差1e-9、相对1e-10；整数、字符串、布尔、字段集合精确比较。
测试包含错误精度、裁剪位置、映射/逆映射混淆、游标、未来数据、短/空阶段及篡改。
记录分析/审计耗时；所有新交互、拟合与在线API均须为零。
大于32MiB的新结果提交分片和索引并实际恢复核对；保留原件与恢复副本。
普通/暂存差异、秘密扫描及索引与磁盘字节核对后，结果独立本地提交，不推送/合并。

## 后续与新颖性边界

旧附近点联合响应模型已经失败，不能把同一位置/短历史回归改名重跑。
本轮不在旧QUAL上选择输入摘要、模型容量、参数或门槛，也不修复旧ARX/F20。
如果命令状态问题值得独立检验，下一协议必须先规定新的真实收集器与仅评估端
原生见证资格；公开摘要、未知输入变换/噪声和模型适用条件明确区分；
TRAIN/CAL/独立资格、失败惩罚、完整获取费用、强预测及任务基线分别冻结。
先验证预测，不把预测误差下降当作纠正或获取决策收益。

初始状态处理、物理先验、残差控制和历史辨识均为已有路线。本轮额外原文阅读
包括[初始条件辨识](https://arxiv.org/html/1504.08196v3)摘要/引言、
[脉冲响应实验设计](https://arxiv.org/html/2012.08126)2.2–2.3节及部分3节、
[机器人模型辨识综述](https://www.annualreviews.org/content/journals/10.1146/annurev-control-061523-102310)摘要。
LTI初始条件/持续激励结论不能转为本接触、非线性及未知输入噪声环境的保证。
模型适用范围、Residual RL、OCCAM、GAUGE和Poke and Strike等既有查新继续保留。
潜在论文机制仍须证明获取动作改变状态与适用性时的具体决策区别，并通过
强对照、消融和新方法自身独立时序部署；本次诊断不完成CCF A目标。
