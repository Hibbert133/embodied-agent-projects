# 联合响应辨识的独立任务桥接冻结协议

本研究检验受控重置后8步联合响应估计，是否带来固定底层策略的任务收益。
标准系统辨识方法不是新算法；本研究不能代替完整CCF A贡献、时变流评价或论文。
源辨识资格已通过，但全部8步减后6步的区间跨0，保留两者，不声称最早两步已证明有效。

## 一次执行的人群与预算

先提交冻结源码、配置、测试、功效规划和审计，再一次执行新种子14600–14767。
7个新算子源51001–51007，每源8个静态A扰动流，合计56流；三任务、两未来噪声，
336配对单元、八固定程序共2688次实际执行。14768–14999及所有此前冻结保留范围不用。
前一份未冻结设计的16流与暂拟预留范围在观察任何新任务结果前被本协议替代。

固定56流依据历史点8减点16的配对流标准差51.20785077975331步，以20步改善、
双侧alpha0.05与目标功效0.8作正态近似需52流，向完整8流生成块取56。
这是借用另一历史对照方差的规划假设，不是新主比较的已知方差或功效保证。
样本量及规划文件在新结果前冻结；不扩样、不根据中期结果停样或重跑。

每次只有一个受控初始重置，含探测总预算500 Env.step。总上限1344000步、
2688次受控重置、80000000个请求仿真帧。工厂内部目标生成重置完整记录。
噪声仍为0.05；不可变前8步噪声与492步未来噪声在执行前生成并分开承诺。
同单元跨程序实际重放同8步前缀；同方法跨未来的前8步也核对，无状态复制、回滚、
中途重置或重新播种。保留初始状态、实际动作的评价者见证及每步噪声历史散列。

## 八种固定程序

| 代码 | 行为 |
|---|---|
| JOINT8 | 原8步后，读取已冻结的联合响应模型，拟合全部8步位移，保存逆补偿后执行固定策略 |
| JOINT_DROP2_8 | 同模型与实际8步前缀，只去掉前两步自身的响应项；早期命令物理影响仍保留 |
| SAME_DATA_POINT8 | 同实际8步，读取同批名义校准的ARX并执行点逆补偿 |
| OLD_POINT8 | 原8步后旧ARX点逆补偿，保留便宜强基线 |
| OLD_G8 | 原8步后旧Gaussian风险目标，保持原正则化与命令约束 |
| OLD_POINT16_CYCLE | 实际执行两轮相同8步，再用旧ARX拟合全部历史并逆补偿 |
| NO_PROBE | 从初始状态执行未纠正固定策略 |
| IDENTITY_AFTER8 | 原8步后发送未纠正固定策略，扰动继续存在 |

点方法共用原affine_controller和encode_controller，不能改变策略权重或纠正规则。
无效点逆补偿停止；Gaussian构造失败也停止，保留原Gaussian不同于点法的构造条件。
停止不以其他方法代执行，仍计入336分母及500分截止损失。探测中提前成功/结束也完整保留。
每个纠正器的模型源散列、因果观测散列、参数和决策先保存，执行器消费保存对象。

新模型只接受受控重置后真实可见ColdPrefix，不接收种子、注入参数、实际受扰动作、
随机状态或未来。旧ARX只接收完成的可见历史。source truth仅供注入与评价。
不用新任务数据重拟合名义模型；新增名义训练、API调用、记忆写入和策略更新均0。

## 冻结比较和开发门槛

主比较JOINT8减OLD_POINT8的平均截止损失。成功计含探测总步，失败/停止计500。
56个完整扰动流为重采样单位，偶奇各28流分层bootstrap10000次，随机数20261017。
流内三任务、两未来不当作独立流。成功率与实际步数配对差同时报告。

六个次比较是JOINT8分别减SAME_DATA_POINT8、JOINT_DROP2_8、OLD_G8、
OLD_POINT16_CYCLE、NO_PROBE和IDENTITY_AFTER8，标注未多重校正。
NO_PROBE的比较是完整程序效果，不是相同探测后状态上的效果。

开发组件门槛同时要求：主损失差95%区间上端<0；JOINT8成功数不低于OLD_POINT8；
成功数不低于OLD_G8和OLD_POINT16_CYCLE两者；平均截止损失不高于这两个强对照。
后两项是注册的观察竞争性门槛，不是非劣效置信界。通过也不能声称创新或普遍优胜。
