# 在线 API 探测与纠正闭环验证 v1

## 冻结目标

用户明确授权实现并执行本协议。它单独版本化，不修改历史实验。
目标是验证在线 GLM 选择真实驱动连续探测和任务纠正；接口通过与任务收益分开判断。
本轮不研究记忆、校准失配或跨任务迁移，不作为新算法或 CCF A 发表证据。

## 人口与预算

任务种子 9400–9403 与 fault_01–fault_04 完全交叉，共 16 单元；9404–9599 保留。
全部状态纳入，不筛选失败或根据结果扩容。9401 在旧配置中作为 bootstrap 随机数使用，不是旧环境种子分配。
保持 push-v3、SawyerPushV3Policy、加性偏置以及标准差 0.05 的 xyz 执行噪声。
每个单元分别执行 NO_PROBE、CONT_NO_CORRECTION、CONT_DYNAMIC、PRIOR_AFFINE、PRIOR_NEAREST、LLM_AGENT。
各方法拥有独立环境及执行器，共享该单元的初始状态和噪声命名空间 3457；所有实际探测轨迹必须匹配。
每次执行最多 500 步，探测为固定连续 16 步程序、余下最多 484 步策略执行。
仅一次初始重置，探测/策略边界不重置环境或执行器随机数。构造器内部初始化不计为 Agent 重置。
最多 96 次方法执行、48,000 环境步。API 等待期间暂停仿真，延迟另计，不能称为实体机器人实时控制。

## API 决策与执行边界

PRE_PROBE 接收初始可见观测、校准模型卡片、候选及预算，只能选择 PROBE_16、RUN_UNCORRECTED、ABSTAIN。
POST_PROBE 接收完成的真实轨迹、当前观测和主机生成的未纠正/仿射/最近邻/数值有效动态 OLS 候选；只能选择任务候选或 ABSTAIN。
主机纠正使用已冻结模型和已有幅值网格；LLM 不生成数值，不修改模型，不更新策略。
仅完整且非终止的 16 步探测可进入 POST_PROBE。探测期间成功或终止立即结束，不调用后续 API。
响应恰有 action_id、evidence_ids、reason 三个字段；ID 限于本请求候选和证据，reason 至多 240 字符。
纠正选择必须引用 probe。候选字段 operation 表示离散操作，避免与既有 Oracle executed-action 字段混淆。
真值、环境种子、随机数状态、未选分支和未来结果不得进入 API 消息。
每次使用独立单条消息，不传入历史或记忆。保存请求、原始响应、候选和校验后的选择，随后才执行。
执行器逐步使用保存的纠正，记录完整可见观测、固定策略原始指令和加入纠正后的指令。
API 主动停止或调用失败时停止当前任务，保留失败分母，不能用基线代执行。

## 固定调用资源与失败语义

模型 glm-5.2，temperature 0，max_tokens 512，进程硬期限 210 秒，SDK transport retries 0。
一次健康预检、最多 32 次决策主调用及七次格式修复，共至多 40 次尝试；每个逻辑决策最多修复一次。
每次尝试包括超时都消耗额度；只有响应格式/语义失败可修复，传输错误和硬超时不重试。
连续两次非健康逻辑决策失败后打开断路器，后续案例记为 ABSTAIN/CIRCUIT_OPEN；有效的主动停止不算接口失败。
预检失败保存 FAILED_API_PREFLIGHT，零仿真种子、零环境创建，不补跑或调整参数。
保存实际 tokens 和延迟；超时或供应商不提供的用量标记未知，不能计为零计费。
沿用现有 DPAPI 配置；密钥只经进程环境传入工作进程，不写入请求、日志、命令或 Git。

## 校准成本

绑定此前独立检验通过的 response_calibration_20261013T105913Z_bfbd86c7c1dd 模型及其哈希。
仿射、最近邻和 LLM 都计入完整 2,304 离线步与 144 次离线重置，按本轮 16 单元摊销：每单元增加 144 步和九次重置。
物理校准数据只采集过一次，不重复计为本轮新增仿真。其他基线离线成本为零。
各方法的所有任务单元都计入平均在线成本；停止的低步数不能解读为效率改善。

## 验收与审计

接口门槛：非健康逻辑决策有效率至少 0.9；至少一条真实的 API 探测选择→探测→有效非零纠正选择→任务执行链；信息/预算/衔接违规为零。
有效的主动 ABSTAIN 计入有效决策，但不是任务成功；无 API 尝试的断路停止计为无效逻辑决策。
任务结果只描述 16 单元和四个独立种子簇，不作显著性或新算法判断。
独立审计从原始 API 响应重放候选与调用/修复/断路逻辑，核对全事件顺序、种子/方法配对、控制命令、完整观测连续性及每步随机数推进。
审计不再次调用 API、不重新仿真动力学；每项产物绑定运行标识、清单标识和源提交。
冻结之前运行全部必需检查；源/配置/协议提交后从干净状态生成唯一清单并执行一次。
失败或不完整结果保留；本协议不允许改提示词、改阈值、补种子、替换运行、调用记忆或执行保留种子。
