## 数据对象与真正的完整风险

目标是固定完整程序π的截止损失，包含移动／验证／测量和失败惩罚；
概率和Q都以当时完整公开历史、目标内部状态及剩余预算为条件。Q对应
采用当前候选后继续**目标完整程序**的剩余损失，不是16步局部费用。
声明只标示该语义，不能替代真实Q训练／来源审计。当前OCCAM相关bank
的短窗预测不能通过改字段名成为完整Q。

数学接口注册全部源案例、分组、目标程序及Q版本、独立训练组、源与
目标前缀程序ID、原实际物理步数、完整截止损失和全部事实段。仅在已
核对共同前缀的同一入口评价；DIRECT_C8等不同前缀不能默认互换。若
未来评价移动前获取，获取本身必须作为真实选择段进入序列及费用。

每个事实段包含开始步、实际步数、一次损失收费、终止／成功、前后
历史SHA与原选择／结果时间。非终止与成功段按实际步数收费；最终失败
段收剩余截止惩罚，不能再另加一次获取或失败费。初始阶段提前结束
没有决定时保留其完整损失与实际费用。零步继续动作、真实短终止、
截止或环境提前结束均可以明示，不补造未来物理步骤。

## 标准算子与零权重后缀

记μ为已声明工作日志的条件动作核，π为目标动作核，
`w_t=Π_{j≤t} π(a_j|h_j)/μ(a_j|h_j)`、`w_-1=1`，
`Vhat_t=Σ_a π(a|h_t) Qhat(h_t,a)`。在未折扣的完整收费单位下：

`Lhat_DR=prefix_charge+Σ_t [w_t(c_t-Qhat_t(a_t))+w_(t-1)Vhat_t]`。

此式只是标准递推的前向展开；独立审计用从终端0开始的反向式
`Vhat_t+rho_t*(c_t+DR_next-Qhat_t(a_t))`复算。逐决定IS和DM同样保留。
实现用Fraction精确算术，避免权重或零符号被浮点溢出掩盖；共享Fraction
基础库明确披露，不称为完全独立数值系统或新证明。

首次目标给事实动作的概率为0时，保留该决定的Vhat项，此后权重一直为0。
不需要、也不接受额外目标后缀声明；不向目标控制器喂未选择的反馈、不
重建其未访问状态或后验。完整源轨迹及源失败仍登记，但不贴为目标终局。
Q为0时精确退化为逐决定IS。单案例DR可超出0–500，原样保留及标记；
不裁权、不自归一化、不把损失上限当作DR估计量范围或风险保证。

## 支持、信息时序与独立数据

必须明确条件动作核口径，不能将BLOCK_FIXED与RANDOM_WINDOW混合后
每步都当独立1/4，不能把动作核乘积称完整物理轨迹概率。接口检查所存
菜单上的局部支持，但不由此证明所有目标可达历史的全局正性、外生性、
环境核不变或抽样条件。缺少结构性支持声明或发现目标正概率／日志0
概率，登记支持缺失、估计null。分母保留；任一案例缺失会阻止完整组均值。
需要实际工作随机化设计及来源审计，文本声明与SHA格式检查不提供证书。

目标及Q拟合组不得包含评价组。同一目标程序版本可搭配独立组分割得到
的Q；不同目标程序版本不能冒称一个目标。算子只检查已传入标识，真正
组／seed库存、训练来源哈希、政策内部状态和严格公开特征还须独立验证。
当前TRAIN训练过该bank，不能把它重用为目标独立评价；当前QUAL也不
重新标成新风险模型训练集。当前人口不通过本协议开放任何真实估计。

离线Q推断可以在历史结果产生后执行，只要模型／目标独立于评价数据，
且特征严格截在当时历史。故不错误要求“离线Q的墙钟早于旧结果”；
接口检查feature_cutoff及原选择→结果顺序，上游必须核对SHA对应的
真实过去输入。合法时间字段不能证明没有隐含信息泄漏，算子不声称
端到端泄漏资格。真实在线部署的预测先落盘要求依旧有效。
