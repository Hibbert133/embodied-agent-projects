# 探测后不纠正的连续前缀对照协议

本轮为补充缺失强基线的开发测量，非新算法试验。保留旧实验，先冻结实现、配置、问题和记录审计，再对新种子执行一次。十种固定方法包括原七种和 IDENTITY_AFTER8、IDENTITY_AFTER16_CYCLE、IDENTITY_AFTER16_PASSIVE，不训练选择器、不调用 API、不写记忆或更新固定政策权重。

新任务种子 13000-13047，对应 16 个新算子流和三个原有任务；各两个不同未来噪声实现，共 96 单元、960 次实际执行。新生成随机数为 48001/48002；相同仿射算子族，每流只用静态 A。13048-13399 及全部旧保留范围保持不用，不根据已观察的失败例选择新算子或状态。

环境、固定政策、噪声标准差 0.05、每次总预算 500 步、八步共同噪声以及后续独立噪声语义均沿用既有连续协议。每次只有一次受控初始重置；所有探测、旧纠正政策和后续原政策在真实状态及噪声流上连续执行。总受控步上限 480,000，受控重置 960，完整工厂和控制模拟请求帧上限 29,000,000。工厂临时重置及名义来源 21,010 步/288 次受控重置单列，不能只报控制初始重置。

新方法在注册边界保存 identity_controller，再由执行器读取该保存选择执行原始固定政策命令。IDENTITY_AFTER8 无前向拟合；IDENTITY_AFTER16_CYCLE 两次相同八步探测，也无前向拟合；IDENTITY_AFTER16_PASSIVE 必须先用八步估计执行八步任务，再撤去纠正。若八步估计失败，后一方案按停止保留，不能换成其他方案代执行。身份延续不使用真实执行器参数或未来结局。

NO_PROBE、IDENTITY_AFTER8、IDENTITY_AFTER16_CYCLE 不需要名义预测模型，部署归属离线费用为零。IDENTITY_AFTER16_PASSIVE 和其他拟合纠正方法各承担完整 21,010 步/288 控制重置的名义来源，按每方法 96 单元另行摊销；共同来源的物理采集只记一次。

主比较为 IDENTITY_AFTER8 减 DIRECT_G8。次比较为 IDENTITY_AFTER16_CYCLE 减 POINT16_CYCLE、IDENTITY_AFTER16_PASSIVE 减 PASSIVE_G16，单列且不做多重比较调整，不根据结果改主比较。成功记包括探测的实际总步，失败或停止记 500，分母始终每方法 96。按十六算子流分层重采样 10,000 次：偶数／奇数流各八个，固定随机数 20261015；未来实现和任务不充作独立算子流。

核对所有八步可行分支的 768 对共同前缀，再核对两种十六步身份对照的 192 对前缀，以及 480 对跨未来八步前缀。保留早结束、停止及全部失败；不得为得到完整前缀重跑或过滤案例。记录观察、命令、原政策、实际动作、噪声历史、物理见证和时钟，审计选择先于执行以及原始动作确实来自保存身份控制器。记录审计复用既有 Gaussian／点拟合和生命周期核对，独立重建噪声与实际扰动；不声称完整隐藏状态或物理模型保证。

本轮没有算法晋级门。无论哪个固定对照获胜，都不作为 CCF A 创新或新方法独立确认。当前问题仍要求新的机制、合适的独立验证、更广故障和时序变化评价，以及完整论文。
