## 任务记忆接口

公开TaskMemory保存任务、实际已完成步数、当前39维公开观测、保存的合法纠正映射、任务PI积分及已注册时间常数。普通任务步委托原PIPlan精确算术；保存计划只能消费一次，收到下一连续步回执后才提交积分。已有PI源码不改。

移动等中断使用显式suspend/resume。中断期间任务积分冻结；返回时接收全部连续的新观测回执、更新已付步数与实际位置，保持旧纠正／任务积分／时间常数。不能把经过的移动时间补算成未执行的任务积分。验证若执行的是正常任务PI步骤，则每一步照实际回执提交积分，不能混成“全部冻结”。零长度返回合法；结束、跳步、过预算、复用token和静默重置均须拒绝。

控制器增益更新用明确CARRY或EXPLICIT_RESET模式，后二者是不同对照。保持积分不保证无突跳、稳定或安全；该模块只核对公开回执的连续性，不能认证真实物理过程，未来原生执行器仍须核对环境／RNG／时钟及先保存后执行。

## 完整成本与两阶段估计

以C表示第一选项实际发生的控制步，Y表示其后剩余截止损失，前缀已付t。完整损失为t+C+Y，失败为500；失败提前停止不虚构消耗满500步。CONTINUE可直接完成整段任务，因此C包含实际继续任务步，不能一律叫额外获取成本。第一选项中提前结束时没有第二选择；Y为已知终止罚值或0，不填一个虚拟KEEP动作。

标准参考使用`D2=V2+rho2*(Y-Q2(B))`及`D1=V1+rho1*(C+D2-Q1(A))`，其中V按固定目标策略加权模型预测，rho为目标／报告的行为概率。终止选项直接令D2=终止剩余损失。完整估计为t+D1；不裁剪估计结果到[0,500]，以免改变恒等式。数值合法的报告概率仍可能与真实行为不符，须保留两者均错误的有偏反例。

目标策略和预测在结果之前固定；父历史、已选动作、实际后继时间和控制器记忆均绑定。公开查询拒绝种子、真实参数、未来结果与未知字段。完整可见历史或足够状态／相应假设仍是后继真实估计问题，不能从本有限模型自动推广到部分观测机器人。

## 有限模型与完整人口

固定两个可见前缀code（16／32步）、三个第一选项、两个非终止后继位置、两个采用动作和成功／失败分支。包括选项内提前成功和失败。全枚举44个正概率有限模型原子，不采样、不创建随机流；每条原子只有自己的终局。另做4个固定第一目标策略×2个第二策略×6个误设条件，共2,112个估计记录／48个汇总。

行为概率固定为(.3,.3,.4)和(.5,.5)；错误报告概率为(.6,.2,.2)和(.8,.2)。正确预测由已知有限模型条件均值构造，明确是评价端oracle参考，不是已训练或可部署模型；其他预测固定0或常数。模型包含一个故意构造的机会／代价对照：移动后的状态分布会影响任务成本，行为下的随机采用均值可能与固定的后继采用规则不同。这只是数值反例，不能证明真实机器人的获取收益。

五种按阶段正确的组合共40项均值恒等式须在绝对1e-9内成立；第六种两者均错保留全部8项偏差，不要求其通过无偏性。另报告IS、纯模型、行为边际均值和估计超出[0,500]的原子；不要求DR在每个误设下都降低方差。独立枚举／代数审计不得调用主估计器、主世界生成器或主真值函数，复核全部终止／费用／概率／估计与汇总。
