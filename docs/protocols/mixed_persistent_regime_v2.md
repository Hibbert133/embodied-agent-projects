# Mixed Persistent Regime Benchmark v2 — tuning protocol

The tuning split crosses seeds 4200--4224 with four preregistered bias/noise
regimes. It collects initial failures, repeated-probe evidence, and paired
compensation/retry fresh-verification outcomes. Both candidates use independent
resets and the same paired verification random namespace.

This split may assess initial-failure prevalence and exclusive/both/neither
recovery diversity. It cannot train or evaluate GLM, write operational memory,
or support an online-adaptation claim. A later chronological stream requires a
separate frozen config, manifest, and commit after the tuning report is fixed.
