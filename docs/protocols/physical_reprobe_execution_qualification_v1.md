# 连续中途重新探测执行资格 v1

本协议检验真实MetaWorld执行中，机器人能否在不中途重置的情况下移动至规定测量位置并取得新探测窗口。它不校准中途响应，不拟合新纠正，不比较任务收益，也不宣称新颖性。

## 冻结对象与人群

使用已提交的`physical_reprobe_v1.py`和独立版本化的`physical_reprobe_host_v2.py`，沿用原C4/C8准备、固定任务策略、0.05执行噪声和500步总预算。主机v2按每案例真实重置前账本计算重置差值，修复v1把累计重置误当单案例次数的问题，不清零累计费用；旧v1及其软件记录保留。九个独立初始案例：介入时刻16、32、64各配推物、到达、开门三任务，种子依序22400–22408。22409–22599及所有旧保留区不使用。不同介入时刻使用不同种子，不把结果当作同状态时间效应比较。

全部案例注入同一固定xy偏置(0.12,−0.08)，矩阵恒等、死区为0。故障与种子只在评估器；代理只看当前观测、已发送动作、已用步数与自己先前保存的纠正。此执行资格不覆盖任务内突变、渐变或其他故障族。

## 完整程序

每案例只进行一次受控初始重置，先运行原先的4步、8步拟合以及C8策略到第16步。随后用同一C8继续至事先分配的介入时刻；期间若成功、终止、截断或初始拟合失败，保留该案例并记边界不可用，不额外探测、不替换。

边界可用时运行一次“移到测量位置，再探测8步”。最多64个移动步、8个探测步，必须保留100个后续任务步。移动条件、反馈参数、探测程序和范围检查均沿用已提交的软件组件，不在本批结果上修改。新窗口完成或操作停止后立即结束采集，不把剩余预算补给任务控制器。所有操作中断、位置不可达、范围退出、提前结束及无窗口案例留在九案例分母中。

主机总控制上限4500步、受控重置9次、仿真帧252000。根据本程序实际控制步还必须不超过984，即三任务乘以(16+72)+(32+72)+(64+72)。任务工厂的50次目标生成重置/案例也单独收费；总重置预期459次，工厂与初始重置共229500帧，加全部控制帧。每步固定推进5帧、0.0125秒；不得替换噪声、恢复快照、修改未来或从别的轨迹拼接新窗口。

## 资格判据与声明边界

先要求完整记录审计通过，九个案例全部结束并保留、三份私有状态见证/案例完整、预算及连续性违规为0。再要求每个任务至少一个完整的8步新窗口；否则执行资格为`NOT_QUALIFIED`。提前成功不会被重新标成探测成功。

这是小规模执行可用性门，不是概率保证、任务成功率估计或独立信息精度资格。即使通过，`measurement_model_qualified`与任务收益声明保持false。可见测量位置与运动检查不证明与初始重置同分布，也不是碰撞安全证明。没有在线API调用、名义模型重训、选择器训练或策略权重更新。
