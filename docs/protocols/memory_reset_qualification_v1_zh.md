# 任务积分重置与获取收益的标准反机制资格 v1

承接已交付的响应模型负结果、完整任务机会诊断和有限信息参考。旧参考更新同时改变任务积分和发送偏置，尚未以真实完整任务比较零移动的积分清零。本轮先检验一个更廉价的标准控制解释，避免将控制器记忆的作用归因于新测量。它是进入新学习机制设计前的强对照资格，不是已学到的方法、算法创新或 CCF A 目标完成。失败 SS/ARX、旧 QUAL、全部原比较和来源费用保持不变。

先实现收集器、纯数组测试、独立物理/数值与统计审计、完整配置及种子登记并提交冻结；干净工作树上生成新 manifest；一次执行原生软件人口，契约通过后一次独立 QUAL。任何未通过项停止并保留部分，不追加、重试、换种子或修改门槛。在线 LLM API、响应/策略学习、优化器训练均零。

## 可证伪解释与三个不同判断

假设是旧参考采用的一部分表现变化来自任务积分状态切换，而非必须重新获取的物理参数。RAW_RESET_I 与 RAW_CONTINUE 检验是否可通过零额外移动的记忆操作改善完整损失；LOCAL_PID_RESET_I 与 KEEP 检验在同样真实获取状态后的积分作用；REFERENCE_RESET 与 RESET_I 检验额外参考偏置的作用。它们都可能更差，完整披露。

积分清零的数值合法性通过严格记忆映射检验；当前响应预测能力本轮没有新模型、不作资格主张；任务收益只通过独立完整执行和全成本统计检验。三个判断不能互相替代。时间点是预定实验安排，所有固定程序均不读取变化标签、真扰动、实际噪声、私有物理状态或未来结果。

标准 PID 已有清零与积分保持接口，[ROS control_toolbox 官方说明](https://control.ros.org/rolling/doc/api/classcontrol__toolbox_1_1Pid.html)明确介绍 reset 及积分保持。它也说明保持积分有避免重新积累的用途，因此清零不能预设有益。本轮是指定时点的清零，不是误差过零触发的 Clegg 控制；无无扰切换、稳定或安全保证。原查新表中的模型适用范围、Residual RL、OCCAM、GAUGE、Poke and Strike 与双重控制/收益学习要求继续有效；此标准对照不替代任何已有路线比较。

## 十个固定程序

|程序|实际行为|
|---|---|
|RAW_CONTINUE|原 RAW 任务 PI，T=0.5，继续任务|
|RAW_NOOP|同 RAW；边界保存并消费一次恒等记忆操作，完整轨迹必须与 RAW 相同|
|RAW_RESET_I|同 RAW；活边界只将任务积分 XY 清零，不执行移动或测量|
|DIRECT_C8|原 C4/C8 初始辨识与 C8 继续，逐字复用历史程序|
|MOVE_INTEGRAL|原 C8 前缀、附近移动积分补偿与继续，逐字复用历史程序|
|LOCAL_PID_KEEP|RAW 前缀、附近 PID 移动及 8 步测量，保持原任务积分/纠正|
|LOCAL_PID_RESET_I|完全相同获取，完整窗口且存活时只清零任务积分，纠正仍为原身份映射|
|LOCAL_PID_REFERENCE_RESET|完全相同获取，采用移动参考偏置并清零任务积分|
|LOCAL_PID_REFERENCE_CARRY|完全相同获取，采用移动参考偏置并保持任务积分|
|LOCAL_PID_REFERENCE_RESET_NO_PROBE|相同移动到位后采用参考偏置/清零积分，不执行 8 步测量|

新增记忆操作不修改观测、环境、时钟、噪声游标、基础纠正、PI 增益或底层策略。计划严格绑定当前记忆哈希，主机先持久化计划再消费；NOOP 和原本为零的清零也不能重复消费。操作前后保存物理/native/Python/RNG 见证，必须逐字段不变。普通任务步仅查询一次原固定策略；发送命令仍由原 PI 生成并实际执行。

原附近 PID 的 P=8、位移 D=16、XY 积分增益0.32、积分界0.5、命令界0.5，移动最多64步、测量8步、保留100步任务余量。任务积分在获取期间冻结，返回最后实际状态后继续。RESET_I 与测量后的 REFERENCE_RESET 使用相同完整窗口准入，测量不足则 KEEP；提前结束保留原因，不制造任务步。NO_PROBE 沿用原实际到位条件。没有分支通过重置撤销已经发生的位移。

每单元内八个 RAW 程序共享实际前缀，两个 C8 程序共享另一个实际前缀。五个 LOCAL_PID 程序共享探测前移动；四个测量程序共享获取后状态。全部分别从受控初始执行、全部分别付费，无克隆或恢复环境。跨程序公共见证仅比较已明确的时间统计投影，不宣称普遍行为等价；NOOP 另外核对全部实际命令、原策略动作、响应、噪声和时钟。

## 软件契约、主比较和失败处理

原生门要求全部90案例完整审计、18对完整 NOOP 轨迹相同、72对共同前缀、18对共同移动及18对共同测量后状态相同；物理/预算/因果违规零；至少一次实际直接清零和一次实际移动后清零。晚时点提前成功、原本零积分、缺窗口均保留，不要求每个晚状态都有更新。该门不使用任务收益选增益或程序。未通过则不采集 QUAL。

唯一主要比较：完整54单元的 `RAW_RESET_I − RAW_CONTINUE` 截止损失；成功用实际完整总步数，失败/停止罚500，移动和测量已包含、不得重复收费。整组配对 bootstrap95%上界严格小于零才支持这个标准重置参考。成功率变化全披露，无暗加的成功率非劣门；小人口不宣称充分功效或最终学习算法资格。

固定次要比较：LOCAL_PID_RESET_I−KEEP，REFERENCE_RESET−RESET_I，CARRY−REFERENCE_RESET，测量后REFERENCE_RESET−NO_PROBE，RAW_RESET_I−DIRECT_C8/MOVE_INTEGRAL，以及全部程序−RAW_CONTINUE。不换主角，不挑任务/变化条件/时点，不以接受/拒绝子集推断因果收益。即使次要参考较好也不能替代主比较。将来新方法还须在完整独立自身历史人口平均损失低于 DIRECT_C8、积分及更强标准参考，并补齐变化检测、历史辨识、始终获取/不更新、任务相关获取和机制消融。

独立单位为9组，按16/32/64三层各3组整组重采样10,000次，bootstrap种子202610235；保留同组任务/条件相关性。整数6单元组总损失上按1/40与39/40精确线性分位，再除54。区间未多重校正，条件于当前冻结源控制/名义模型；不含名义模型重训变异。不把时间步当独立样本。

程序异常停止该阶段、保留全部前缀和错误记录，不重跑或追加；旧初始 C4/C8 无效按原程序失败/损失500，不用其他方法代执行。所有提前成功、缺失更新原因、窗口失败、500步失败和成功转失败/反向改善保留完整分母。标准清零若无优势，封存此版本，不基于该 QUAL 再添加门控或调清零时点。
