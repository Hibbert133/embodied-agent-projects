# 积分反馈重新探测：预先冻结的四组资格对照

上一轮 `bd8e9fd` 保存了真实负结果：原PD在偏差不变时取得6/9窗口，变化时0/9。该轮是本阶段的机制动机，不用于挑选新案例、拟合或调参。本阶段比较常规抗偏差反馈能否帮助重新取得测量，尚不研究最终任务收益。

## 方法与增益来源

原PD：位置误差乘8，减最近一次真实位移乘16；每坐标限制到±0.5，再施加保存的C8和最终±1动作限制。新增PID保留这些项，只在xy增加离散积分。初值为零，提议更新为 `I + 0.32*位置误差`，积分本身限制在±0.5。若更新会进一步推向内部控制饱和，则拒绝该坐标的更新；若映射后的更新进一步推向最终动作饱和，则拒绝整次更新。升高到测量高度前保持初始xy目标，之后切换到原测量位置；切换保留已实际积累的积分。

0.32取自理想单步运动学增益g=0.01下 `Kp²*g/2` 的设计启发，Kp沿用8。包含原位移反馈的未饱和三状态离散线性化要通过特征值模小于1的软件检查；这不是MuJoCo或接触系统的稳定性保证。积分上限沿用原中间控制幅度0.5，不通过本轮科学结果选择参数。软件理想反例只检查正负常偏差下控制链路确实改变，不代替物理证据。

积分、PID与抗饱和均为常规控制思想，参考[Åström 与 Murray 控制教材](https://www.cds.caltech.edu/~murray/FBS/Chapter_10_-_PID_Control.html)。本方法不作创新声明。

每次实际移动前先保存积分更新，再保存实际命令，主机核验后执行。移动结束后、任何新探测之前，保存 `旧C8偏移 + 旧C8矩阵*积分` 组成的补偿参考。原C8矩阵不变。该参考不声称辨识真实扰动或保证任务有效；即使未到位或提前结束也保留。未来完整任务研究必须比较这个只利用移动数据的参考，不能把移动中学到的补偿归功于后续8步。

## 新人口、匹配与预算

新种子22800–22808，依次对应介入步16、32、64，每个时刻分别为推物、到达、开门。22809–22999和所有历史保留区不用。每单元按固定次序执行四组：偏差不变/PD、偏差不变/PID、偏差变化/PD、偏差变化/PID，共36次实际执行、9个四组单元。相同初始环境种子和原始噪声序列，独立实际执行，变化前核对四组完整初始、边界状态和物理前缀。不同介入时刻使用不同种子，不把它们当作时间选择的因果对照。

沿用初始偏差(0.12,−0.08)、恒等矩阵、零死区、噪声标准差0.05。变化组在移动前安装偏差(−0.12,0.08)，其他项不变；不变组安装原偏差。公开输入不含条件标签、真实偏差、种子、随机数状态或未来结果；仅包含预定方法名及允许的可见数据。每次只有一次受控初始重置，原C4/C8准备及到介入步的实际执行不变。环境、随机数、策略保持连续，不复制/恢复状态，不重抽噪声。

## 预定判据与审计

先要求36次完整记录、108份完整私有状态图、每单元3个与首组的变化前匹配，以及全部决策/执行顺序、噪声、信息边界和费用审计通过。然后要求PID在两种条件下每个任务至少取得一个完整窗口，才记有限执行资格QUALIFIED，否则NOT_QUALIFIED。PD保留作原程序对照，不要求它通过该门槛。失败不换种子、不扩样、不调整64步上限或进入门槛。

报告四组全部案例、停止理由、费用和各条件下PID减PD的完整窗口计数差。计数只描述这9个单元，不作为成功概率保证。中途成功不等于取得探测窗口，窗口也不等于任务收益。

独立审计不执行采集器或代理控制器，通过独立标量积分公式重建更新、命令及探测前补偿。测试要拒绝篡改积分、方法、补偿、私有安装时间、公开泄漏和预算，保存部分物理失败，拒绝再次运行同一人口。原PD行为在相同合成回调上与冻结旧操作逐命令一致。完整单测、编译、依赖、秘密及差异检查通过后本地提交冻结，再生成唯一清单、只采集一次，独立审计后写中文报告及本地结果提交。

发表目标仍要求可区分的新贡献、真实中途模型校准、额外探测相对移动补偿与强基线的完整成本任务收益、独立变化流和消融、可复现论文；本阶段不替代这些要求。
