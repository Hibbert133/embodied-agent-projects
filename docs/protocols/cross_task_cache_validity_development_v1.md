# 跨任务旧估计的预测有效性检查 v1

本轮是已完成数据的事后压力检查，不是新任务验证或自然在线缓存。目标是先
检验选择器所需的预测前提，避免把标准参数估计的任务收益误当成可靠失效检测。
冻结本协议、配置、代码、测试和独立数值审计后一次执行，不增加机器人交互，
不执行任何新或保留种子，不调阈值或训练选择器；完整投稿目标仍保持不变。

## 全量来源和交叉方式

使用已审计任务桥接的全部56扰动条件、三任务的JOINT8可见起步轨迹。两次
未来重复具有相同前8步，先逐项核对后去重：保留168条独特前缀，登记168条
重复。只读取前8步可见指令、39维观测和已保存的JOINT8参数，不读取任务
结局、隐藏动作、真实扰动、种子或未来状态给预测器。不重新优化任何控制器。

每扰动条件取三任务的全部六个有序不同任务对。UNCHANGED把同条件源任务
估计移到目标任务；CHANGED把目标换成同一8条件生成块中的下一个条件，
末项循环到首项。每层336对，共672对；源／目标任务与扰动条件边际完全一致。
原始扰动清单仅由评价者验证同／异标签。这个人工配对不是历史时间顺序，
不声称改变标签前后执行了真实迁移或缓存重用。

## 两个标准参考和严格输入

源点参数theta取已保存的JOINT8拟合。用同任务冻结校准模型计算8步均值
Jacobian J_s、工作残差协方差 C_s，令 V_s=(J_s^T C_s^-1 J_s)^-1。
这是局部信息逆，不是经验证的后验；保持边界活动标记。不替换奇异信息或
非法输入，保存失败并停止本次分析，不重新采样。当前来源的保存点均有效。

PredictionQuery只含目标任务、可见初始观测、已计划2／4／8步指令及已完成
受控重置声明；没有目标响应。SourceBelief只含源任务、保存参数、上述局部
协方差、可见证据摘要和边界标记。严格拒绝任何额外字段。

PLUGIN使用目标工作协方差 C_t。SOURCE_UNCERTAINTY使用
S_t=C_t+J_t V_s J_t^T。均值均取目标校准模型对源点参数的预测。
第二个参考是标准线性化误差传播，不是本项目新算法，也不是完整贝叶斯积分。
两者忽略校准模型估计不确定性、模型偏差与非线性／参数边界效应。

先写出并flush预测记录，再把对应长度的实际响应交给独立评分接口并计算
q=(y-m)^T S^-1(y-m)。2／4／8步分别用4／8／16自由度卡方参考的95%
分位数；另预注册三次查看Bonferroni阈值alpha/3，报告任一次越界。
各长度的5%不是整个顺序检验的5%。在精确独立线性高斯、已知误差方差和
无偏高斯源参数误差条件下，协方差相加与边际卡方参考成立，联合界由并集界
得到；当前MuJoCo数据不满足这些已证明条件，因此所有概率标记仍未获资格。

## 完整报告和分析边界

报告全部4032预测分数和1344个“配对×参考”的三查看记录；每种参考每长度
分别给出未变误报、已变漏报与检出、边界活动数。主要诊断项为加入源不确定性
后的4步未变误报。所有参考／长度都披露，不事后选最好的一项。

CHANGED配对会在同块内重复使用其他条件，因此56条件不能当独立诊断单位。
以七个完整生成块重采样10000次（随机源20261018），给描述性95%区间；
七块很少，区间不是正式概率资格证明。下端高于5%视为与名义误报相矛盾的
证据；其他情况保持未定，不晋级可靠性或新方法。禁止依结果调整协方差、
阈值、探测方向、配对、模型或门槛，不能在同数据再验证修复方法。

离线预测先于评分只验证本次程序的信息分离，不代表预测早于旧仿真实际发生。
本轮没有纠正后的分支执行，不能把虚拟2／4步费用写成真实节省，不能给出
复用成功率或新算法任务收益。未报警只是未拒绝，不能证明缓存有效。

来源完整任务银行440012受控步／2688初始重置、134400工厂重置和70744060
请求仿真帧；联合模型来源3840步／480受控重置。历史旧ARX来源21010／288
另列为任务银行上游费用，其工厂费用未知。共享来源只收集一次。本次新增
环境步、重置、控制器优化、政策训练、记忆和API均0；168个局部协方差与
4032次预测评分的数值计算单列，不能混同免费物理测量。

独立审计从相同冻结前缀重建源局部信息、预测均值／协方差、完整评分、全部
边际／配对计数和七块区间；不用主预测与评分函数。允许复用来源解析和摘要
序列化辅助，需披露。保存源码与来源清单、原始评分、费用、中文报告及验证。
