## 计算对象及严格边界

冻结当前已安装的三政策、Action与move源码哈希。手工展开既有政策的叶子：
push三位置叶×两夹爪叶；door三位置叶、夹爪固定1；reach无分支、夹爪0。
严格保留对象偏移、判断先后、>阈值与float32输出。对所有实际采用后的
TAIL_TASK命令，用真实当前观测复算原始政策输出，与记录逐项精确相等；
Z/夹爪发送命令必须等于原始输出的最终发送裁剪。输入复制，避免door政策
原实现对解析视图的原地偏移影响原记录。缺少最早历史时不伪造位移。

每个实际配对步有观测sA/sB与真实叶mA/mB。另评价两个合成函数值f(mA,sB)、
f(mB,sA)，不改变观测、推进环境或发送命令；它们可能不满足该叶条件，
**不是物理可执行轨迹／任务反事实**。用对称两因子代数分解：

```
mode = ((f(mB,sA)-f(mA,sA)) + (f(mB,sB)-f(mA,sB)))/2
state = ((f(mA,sB)-f(mA,sA)) + (f(mB,sB)-f(mB,sA)))/2
delta = mode + state
```

分别在原始float32政策输出及clip[-1,1]发送层做分解，只汇总Z/夹爪。
报告有无差异、幅度L1与能量；能量恒等式Edelta=Emode+Estate+2交叉项，
交叉项可负、分量可抵消，不能把Emode/Edelta当因果百分比。
独立标量实现不调用主签名/叶/分解/汇总函数。reach模式项须恒零；第一
真实XY发送分歧前状态相同，该步原始政策及Z/夹爪分解须全零。
