# 连续任务序列中的缓存复用与刷新：标准参考 v1

本轮补齐真实时间顺序及实际任务执行。它是标准参考和机制压力实验，不把
高斯变化检测、IVR、缓存或均衡试验设计包装成新算法。完整CCF A贡献、
新方法的独立确认与论文要求仍未完成。此前全部结果、阈值和保留种子不变。

## 冻结人口、三类扰动与时间顺序

先冻结实现、配置、测试、记录审计和统计代码。一次预检使用16000–16005，
六个任务单元×十一方法共66次实际执行；16006–16999保留。通过完整性
预检后，同一冻结实现执行主实验：三扰动族×三变化方式×四独立重复，
36个流，每流12个先后任务，三个任务各四次，共432单元×十一方法
=4752次实际执行。仅使用17000–17431，17432–17999保留。所有旧保留
范围不变。15000–15999本轮不使用，不把跳号解释为已消耗。

任务固定为push-v3、reach-v3、door-open-v3，按配置确定的轮转顺序，
全人口每任务144单元。每流开始各方法自己的缓存和CUSUM归零；方法必须
完成当前实际分支并记录结果后，才能进入下一单元。禁止跨方法／流缓存。
不训练政策权重，不调用API，不将评价者分支当成自然代理经验。

三族为BIAS（单位矩阵加偏置）、COLUMN_Y（仅y指令列变化，x列与偏置
保持）、DEADZONE（仿射后按轴施加死区及重缩放）。噪声在上述映射后、
最终截断前加入xyz，标准差0.05；夹爪不加噪。固定公式与随机源62001–
62036在观察任务结果前写进清单。真实扰动仅为评价者字段。

UNCHANGED保持A；ABRUPT在单元6从A换到B；GRADUAL使用
clip((episode-2)/7,0,1)线性插值，末三单元保持B。扰动在每单元内
固定、只在单元间改变；本实验不声称检验了单元途中的突变。死区超出
仿射纠正族，全部失败仍保留，不按该族结果修改模型。

预检是六个轮转任务，前三单元轻度偏置A、后三单元偏置B；用来检查
真实工厂、状态、费用、选择消费与缓存事务，不能用其任务分数调方法。
预检失败则保存部分记录并停止主实验；修复须显式版本化，不能覆盖重启。

## 全部方法与固定底层政策

使用原官方Sawyer v3固定政策，每单元一次受控初始重置，探测到任务
连续衔接、总共500步。发送值先由保存控制器编码并截断，再经隐藏
执行器及私有噪声。噪声为每单元固定500行float32时间带，源47001；
不同方法使用相同物理步时钟上的噪声，不为改变探测长度重置随机状态。

原BLOCK8每方向连续两步，顺序+x、-x、+y、-y；BALANCED8每方向
各一步并重复两轮。COLUMN_Y的A/B对BLOCK8前四步的确定性执行值
完全相同，但对含y方向的BALANCED前四步不同；这是解析支持盲区，
实际任务影响须由本轮结果检验，不能据代数恒等式预填任务结局。

| 代码 | 中文解释与规则 |
|---|---|
| NO_PROBE | 不探测、不纠正 |
| ALWAYS8 | 每次BLOCK8后用原冻结联合估计纠正 |
| ALWAYS16_OLD | 原BLOCK8重复两轮，旧ARX点估计；保留强长探测参照 |
| STALE | 无缓存时BLOCK8；否则直接沿用上次成功参数 |
| PERIODIC4 | 无缓存或序号为4的倍数时BLOCK8；否则沿用缓存 |
| PASSIVE_RECENT8 | 用缓存或身份映射先执行8步任务动作，以当前真实近期历史拟合旧ARX，再更新纠正 |
| CUSUM4 | 有缓存时BLOCK4检查，源不确定性q标准化z=(q-8)/4，g=max(0,g+z-0.5)，g≥5刷新至8；无缓存先8 |
| PLUGIN4 | BLOCK4点预测超过名义95%卡方阈值便继续4步刷新，否则沿用 |
| UNCERTAINTY4 | 同上，但加入源参数不确定性传播 |
| BALANCED4 | 有缓存时均衡前4步检查；需刷新则完成均衡8；无缓存仍BLOCK8 |
| TASK_IVR4 | BLOCK4源不确定性检查；报警或当前任务指令的预期相对方差降低≥25%时继续至8，否则沿用 |

TASK_IVR4是有限指令IVR的适配参考，使用当前实际观测上的政策指令，
不进行未来状态滚动，也不移植GAUGE的完整验证生命周期。相对方差不是
任务收益或获取费用的估计。CUSUM阈值预先固定，未获平均误报周期资格。
所有概率均为未获物理资格的工作参考，不声称单元内／跨单元误报保证。

主比较UNCERTAINTY4减ALWAYS8；注册次比较BALANCED4减UNCERTAINTY4、
UNCERTAINTY4减PLUGIN4、UNCERTAINTY4减TASK_IVR4，次比较不做多重校正。
同时展示十一方法完整结果及分层，不选择最好配置代替主比较。

## 缓存事务与信息边界

只有自己实际选择的新拟合控制器完成任务并成功，才可写入新参数缓存。
缓存记录保存源单元、任务、可见证据摘要及局部协方差。复用成功不更新
源时间、参数或协方差；任一任务失败／停止后清空自己的缓存与CUSUM。
新拟合失败立即停止，不回退旧缓存或改用基线代执行。新拟合成功而信息
矩阵不可用时保留任务成功，但拒绝缓存写入并单列原因。

源触及参数界时，短检查不能确认复用，继续8步。目标超校准范围或检查
数值非法则停止。旧ARX两个参照按原逆稳定性条件执行；其缓存不冒充
联合高斯证据。联合模型仅用于受控重置后的前8步开环xy观测，不能
延伸到任务中途的接触状态。被动近期历史使用原ARX接口、披露其局限。

代理接口只接收当前可见前缀、当前政策指令、自己较早成功缓存和CUSUM。
严格拒绝真实扰动、种子、随机数状态、变化类别、未来状态／结果。选择
必须先保存并flush；实际程序、控制器和缓存来源使用保存记录。底层
政策动作每步从实际观测计算，不读取其他方法未来或未请求观测。
