# 纠正器条件化剩余代价估计：冻结开发协议 v1

本轮是标准价值回归组件的开发资格检验，不是新算法、在线自然记忆、
独立新样本确认或误差证书。旧 RBF 的特征、核及结果均不修改。已有960条
完整轨迹的结局已观察，故整个来源都是开发数据。新源码、配置、审计器和
本协议经要求检查并提交后，才提取数据及执行一次冻结拟合。

来源固定为配置绑定的 post_probe_identity 批次：16个算子流、3任务、
2未来实现、10种固定方法。验证来源提交中的35个原始文件和已通过审计，
以及来源清单绑定的671个 Git 输入。所有失败、停止及过早结束均在元数据
保留；无法提供稳定尾段者列明原因，不伪造样本。新增环境步、重置、
API、政策权重训练、控制器拟合及新/保留任务种子执行均为零。

只提取最后一次非空已保存纠正器选择后、至少完成8步历史的稳定任务尾段。
从 start=max(8,最后选择时刻) 开始每4步采样，并包括最后一个非终止状态。
每条轨迹的全部采样权重合计1，避免500步失败得到更多训练权重。
标签为 (最终截止损失−当前步)/(500−当前步)。成功按包括探测的总步计分；
失败/停止按500，和实际交互成本分开。标签是一次实现的 MC 结果，不是
已知条件期望。预测截到[0,1]后乘剩余步数。

Agent 输入为严格 TailEvidence：任务、截至当前的9个观测(各39维)、
8个历史请求命令(各4维)、当前固定政策命令、已知候选纠正器的当前输出、
候选在5个固定输入上的二维输出、公开纠正器种类和剩余预算。
拒绝未知键、嵌套真值、种子、实际受扰执行动作与未来反馈。
支持严格公共身份/估计仿射/局部Gaussian保存格式，拒绝旧Oracle/Legacy。
标签、算子流、方法名、未来编号只存在离线分析元数据。

90维特征固定为：当前观测39；目标−手、目标−物体、物体−手各3除以0.1；
最后两次手位移各3除以0.01；原政策4；候选命令4；候选命令场10；
最近8次二维请求与手响应的均值4、各自对称协方差6、交叉矩4(响应除0.01)；
剩余/500；身份/仿射/Gaussian种类onehot3。不做训练标准差缩放。

逐任务、留整个算子流交叉拟合。一个流的所有方法、任务与未来重复均不得
进入该折训练；三任务独立建模。6种预测器：任务常数、任务×纠正器种类
常数、完整密集RFF(主模型)、密集线性、仅每轨迹最早样本RFF、去候选
纠正特征RFF。去候选版本将58:72及87:90清零。RFF采用256个标准正态
频率和均匀[0,2π]相位，固定随机数20261016，输入除sqrt(90)，输出为
[1,sqrt(2/256)cos(xω+相位)]。线性为[1,x/sqrt(90)]。岭系数1，截距
不惩罚。共4×3×16=192个交叉拟合回归，另保存主模型全来源3个非部署
参考；常数统计不算岭拟合。不得见结果后调参数、更换主模型或追加拟合。

报告每种模型的轨迹等权归一化/剩余步RMSE、最早样本误差、任务与流分层。
配对主检验固定 KEEP_G8_AFTER16 对 UPDATE_G16：独立比较实际前16步
全部观测、命令、噪声承诺及物理见证，当前Agent特征只读取可见部分。
两者在同一历史处使用不同Gaussian纠正；任务×种类常数、去候选模型
应给零预测差。比较预测代价差与实际配对差的MAE；相等选择UPDATE。
从已执行银行读取所选结局仅称离线交叉拟合选择，不能称新执行政策。

组件开发门同时要求：主模型轨迹等权剩余步RMSE严格优于任务×种类常数；
同种纠正器配对差MAE严格优于恒零差；离线选择的平均截止损失不高于、
成功数不低于总选UPDATE。任一失败保留负结果，不进入新控制器确认。
即便通过，也不能得到新选项到达历史的误差界、任务收益保证或创新结论。

独立审计重新构造特征、标签、权重、分组、岭正规方程、预测和配对统计；
明确复用旧公共纠正器命令数学及NumPy，不宣称独立物理模型实现。
来源完整费用180930步/960受控重置和名义21010步/288重置分别披露，
新拟合时间/模型大小另列，不将数据当免费自然经验。中文报告优先中文
方法名，括号保留代号。要求仓库全测试、编译、依赖、秘密扫描和差异检查。
