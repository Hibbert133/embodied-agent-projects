## 行为与信息边界

固定三个任务与旧底层策略。RAW_TASK_PI_T0.5从真实初始观测开始，每个任务步查询原策略一次，消耗已保存的PI计划，在实际回执后提交积分。仿射／死区变换、XYZ实际噪声、最终裁剪沿用float32执行链。扰动、种子、RNG、未来结果和私有物理见证不进入公开控制器。

在16／32／64步的真实前缀边界，按预先分配的程序保存选择、当前记忆、one-hot行为概率。CONTINUE不收取获取步；VALIDATE8执行最多8个正常任务PI步并按实际回执提交积分；MOVE_MEASURE8保存suspend token，冻结任务积分，使用已版本化的固定可见位置反馈最多移动64步，再按已有条件实际执行8步测量。两者均保留100步任务余量，提前终止按真实状态处理。

MOVE窗口采用已有WarmWindow的可见位置、运动、高度和间距条件，不冒充初始重置ColdPrefix，不重新拟合。返回时消费全部连续物理回执，更新已付步数和当前观测，保持原纠正／积分／时间常数。任何未到测量位置、测量不完整、范围退出或拒绝后，均从实际状态保留原控制继续。不得重置、回放或恢复环境撤销已付位移。

后继动作只有KEEP，没有虚构的UPDATE、重辨识或新参数采用。本资格只检查真实获取→当前状态→保留继续链路。确定性第一分配没有跨动作正概率支持，不能作为随机双阶段DR数据或已学获取策略；后续必须另分训练／校准／自身历史评价。保持积分不等于无扰切换、稳定性或安全保证。
