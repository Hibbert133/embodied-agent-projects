# 受控重置初期证据：冻结辨识资格协议

本轮先资格检验新组件，不执行任务纠正策略，不声称新算法创新。旧点8、
16步、RFF和尾价值全部冻结结果保留；不在旧银行重调特征、阈值或估计器。

动机是AR2观察器在8步探测中仅使用第3–8步的条件响应。本参考通过独立
名义校准学习重置后8步的下三角响应矩阵，联合使用8个实际位移；不补
虚拟零历史。有限时域响应、GLS和岭回归为已有系统辨识技术，不作为新定理。

新源码、配置、测试和独立审计先提交冻结，再一次执行：训练128条/任务，
3任务共384条。训练种子14000–14383，14384–14599保留。训练为已知名义
I/0执行器，先确定8步独立均匀xy命令[-.9,.9]，z/夹爪请求0；命令随机源
54001与执行噪声54002分开。实际动作噪声仍为0.05，初始重置与8步连续。

先保存全部TRAIN，再仅用TRAIN拟合每任务联合响应与同数据LINEAR_ARX。
联合均值逐时刻回归到当前及过去命令的连续高斯裁剪期望，岭1e-6；R为
训练联合残差协方差/(128−17)，0.05对角收缩加1e-12单位阵。三任务分别
保存模型、训练身份和SHA，模型冻结事件必须先于第一个资格实例。
连续高斯只是工作均值，不对实际float32噪声法律作精确概率声明。

新资格种子13800–13847，16算子流×3任务×2独立前缀噪声，共96条。
13848–13999及全部旧保留范围不用。算子生成50001/50002，仍只用静态A。
每条只实际执行原8步对称探测一次，4估计器在同一已保存可见前缀上离线
推断：JOINT_FULL8、联合模型不使用前2步输出JOINT_DROP2、同数据ARX8、旧ARX8。
DROP2仍在因果响应矩阵中保留全部已发送命令，不能删掉早期物理作用。

ColdPrefix只接受任务、初始可见39维观测、已完成命令/观测、明确受控初始
重置标志。拒绝种子、实际受扰动作、未来、真A/b及未知字段。模型适用域
为初始手位置在训练范围外加0.01、初始手物体距离至少0.08、重置后开环
xy前8步。下三角结构必须精确拒绝未来输入。资格不足或逆不稳按无效记录，
不替代。所有参数和数值边界见配置/源码；不从资格结果选择模型参数。

参数目标仅评价者读取真实A/b。分数为 ||Ahat−A||F + ||bhat−b||2/0.4；
无效/短前缀分别按8与1作A/b误差处罚，分母始终96。主比较FULL8减同数据
ARX8，16算子流成组重采样10000次，随机数20261016，95%区间上端须<0；
同时FULL8有效率≥0.95，FULL8减DROP2平均分数须<0。所有条件同时通过才
允许制定新的任务桥接协议；参数更准并不证明任务收益。与旧ARX比较为
未校正描述，不作替换主比较。不得依据结果扩样或重跑本次种子。
