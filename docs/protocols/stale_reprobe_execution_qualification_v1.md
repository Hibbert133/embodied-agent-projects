# 旧纠正失效后的重新探测：配对执行资格

问题：保存的C8已经实际用于任务后，若执行偏差变化，原移动与8步探测程序还能否取得新窗口？旧9例只有不变偏差，理想运动学反例不是MetaWorld证据；本轮补真实、连续、配对检查，不训练新响应模型，不研究触发器或任务收益。

## 人口、冻结与处理

新种子22600–22608各为一个任务单元：16、32、64三个介入步分别配推物、到达、开门。每单元实际执行UNCHANGED和CHANGED两次，共18次执行、9个配对。22609–22799及全部旧保留区不用。不同介入步使用不同种子，不作为时间选择因果比较。实现、配置、审计、测试和本协议本地提交后生成唯一清单，只采集一次，失败不换种子或重跑。

两臂都以相同种子、相同初始偏差(0.12,−0.08)、恒等矩阵、零死区和同一已登记0.05噪声序列独立从唯一受控重置开始。执行原C4/C8准备并用保存的C8到计划介入步。每个案例是一次实际执行，不用状态恢复、噪声重抽或轨迹拼接。配对核对变化前完整原生状态、Python语义图和全部物理轨迹；仅允许先前已审查的统计包装器计时投影。

若到介入步仍可继续，先保存私有边界见证，再保存评价器上下文安装意图：UNCHANGED继续原偏差，CHANGED改为(−0.12,0.08)，矩阵和死区不变。主机消费已保存的目标条件；安装本身没有物理步、查询、重置或状态变化，并保存完成事件。变化从下一实际控制步生效，发生在移动之前，不延迟到已经到达测量位置之后。评价器条件、变化标签及种子不进入代理公开载荷。

两臂使用原封不动的`physical_reprobe_v1`与主机v2：保留旧C8，最多64步位置反馈，再一次8步固定探测，需保留100步任务预算。没有积分项、重新拟合或Oracle纠正，也不安装新warm模型。操作完成或停止后结束采集。提前成功、终止、无效初始拟合及介入边界不可用的案例不安装新条件、不替换、不探测，保留在全部18例及9个配对中。

## 费用与判据

每执行500步总预算；全轮上限9000控制步、18受控重置、504000仿真帧，按预定程序还须不超过1968控制步。18次工厂各50次目标生成重置加受控初始重置，共918次重置、459000初始/工厂帧；每控制步5帧，实际程序帧上限468840。完整历史名义费用3840控制步、480受控重置、24480全部重置、12259200帧单独报告，按9任务单元摊销426.666667历史控制步/单元，两臂分别承担同一完整先验来源费用，不因配对重复执行而减半。

首先要求全部18例、54份私有见证、9个变化前配对及事件/噪声/预算/信息边界审计通过。然后两臂各自每种任务至少一个完整窗口，才记执行资格QUALIFIED；否则NOT_QUALIFIED，原失败原样保留。该门仅检验有限执行可用性，不是成功率概率保证；不为得到通过而扩样或改门槛。

报告两臂每任务完整窗口数、全部配对的完整窗口差、移动/探测费用和停止理由；提前任务成功不计探测成功，也不据这些截断执行声称任务收益。无模型辨识、任务效益、新颖性或CCF A投稿就绪声明；API、新名义训练和策略更新均为0。

## 独立审计和软件检查

独立记录语法重建初期拟合、实际C8执行、变化前延长、私有上下文安装、移动与探测。每一物理步按当时已保存的评价器条件和原始噪声重算实际动作，拒绝早变、晚变、遗漏变化、未知公开字段或重复安装；核对变化先于移动且没有变更保存的旧纠正。只读状态见证在初始、变化前边界及最终保存，不能用于恢复环境或输入代理。

测试覆盖同任务多案例累计账本、两种条件的实际动作差、真实前缀匹配、未到边界不安装、部分失败保存、处理/命令/时间/噪声/状态/分配篡改，以及安装发生在重新探测之后或重复安装的拒绝。必须通过全仓库单测、编译、依赖、秘密和差异检查后再冻结采集。中文报告、原始日志、审计及过程费用均保存，并本地提交；不推送或合并。
