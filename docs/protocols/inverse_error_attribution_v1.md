# 已保存逆映射的评估器误差分解协议

本轮不启动新机器人仿真，不拟合或修改纠正器。分析对象仅为已审计的两批
DIRECT 与 PASSIVE 轨迹：旧八流四未来及后续十六流二未来，各 96 对，共
192 对。它们的结局已在此前分析中观察，因此本轮是冻结规则的数据复用
诊断，不能称独立确认实验或新算法收益。

## 固定范围与边界

先完成代码、配置、恒等式说明、审计及必要测试并提交冻结，再对两个源
执行一次分析。所有来源须核对历史 Git 字节、原始输出 SHA、原审计身份
和固定名义模型。两源完整银行共 234,519 步／1,824 控制重置，另有名义源
21,010／288；都是既有来源，新环境步、重置、API 调用和纠正器拟合均为零。

每对核对最初十六步的实际命令、观察、原政策、噪声历史和执行动作。
保留所有 192 对；提前成功或没有已保存十六步估计者单列，不删除、补造
或重跑。只读取已保存的第八步和第十六步 Gaussian 均值、协方差及原结局。

OracleActuation 和记录的 executed_action_oracle 只在 src/analysis 及
分析脚本中使用。它们不能成为 Agent 特征、训练标签筛选、决策门或新的
控制参数。名义 LINEAR_ARX 保持原样，也不改此前核回归和失败判据。

## 三项预测残差与五项参数误差

具体公式见[恒等式与解释边界](../research/inverse_error_accounting_v1.md)。
在同一实际可见历史上，用固定预测器分别计算：真实均值映射下的预测、
记录的实际执行输入下的预测，以及主机 float32 无新增噪声参考动作下的预测。
把总残差分为执行输入下的预测残差、模型传播的输入噪声、实现与浮点项。
平方误差必须保存交叉项，不能把三项范数归一化成所谓因果贡献比例。

对裁剪后的线性预测器构造真实参数到保存参数之间的有限变化矩阵。
参数差分解为上述三项的伪逆投影、保存拟合残差修正，以及有限变化矩阵
的零空间分量。每个前缀核对响应变化、残差合计、参数合计与有符号方向
投影恒等式。参数伪逆相对截断 1e-10，源拟合边界判定容差 1e-8，固定
数值核对容差保持代码所列值，不按结果调整。

三项残差是固定预测器下的会计分解。原预测器用有噪声的请求命令训练，
裁剪后的无噪声参考动作也不等于随机执行动作的条件均值。
把它用于已执行输入不等于已知无噪声物理模型；残差还可能含未观测状态、
历史近似及其他不适用因素。分解不是对特定物理原因的干预识别。

## 输出与审计

逐例保存真实主机参数、已保存估计、增益及偏置误差、三个预测残差的
均方与交叉项、五个参数误差向量及其有符号方向投影、裁剪／边界／秩。
按源、任务及八／十六步分组报告均值，另比较探测与新增政策步的残差。
任务改善、恶化、相同、成功变失败等原结局均保留；不做阈值搜索、AUC
选门或事后晋级判据，不把后续源包装为此假设的预注册确认。

审计复用来源抽取与绑定，但用直接系数和逐元素公式独立计算预测与
有限变化矩阵，再核对保存的分量。核对通过只代表来源和数值会计一致。
后续如果要检验工具变量、模型适用性或新更新机制，仍需独立新协议。
本轮不能满足完整发表目标中的新颖方法与独立任务收益要求。
