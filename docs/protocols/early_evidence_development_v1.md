# 早期测量之后的继续探测：冻结开发协议 v1

本阶段改变可用证据：从初始状态先执行完整的宽八步对称测量，然后判断
额外测量的任务作用。它不改写旧数据，不训练／调节旧两阶段核模型，不将
普通早停、局部高斯设计或有界逆控制命名为已成立的新算法。

## 新数据与真实分支

新种子 11500–11523，八个算子流 × 三任务，一个任务种子每流／任务，
四个提前指定噪声实现，共 96 单元。11524–11799 保留；旧全部保留范围不动。
沿用旧生成器的 A 算子域，在新生成种子 44001 上取混合偏置、增益／耦合
及交替反射的静态未知映射。旧 B 转移的家族标签不作为本轮分层，也不将
这些 A 映射声称为三个隔离家族。所有方法同一单元共享初始任务种子和噪声起点，
各自真实创建环境并只进行一次控制初始重置，无状态复制、回滚或中途重播种。

| 方法 | 实际行为 |
|---|---|
| POINT8 | 初始宽八（±0.4，四方向各二步），点估计后固定政策；无效逆拟合停止。 |
| POINT16_CYCLE | 同样宽八后再执行同样宽八，使用全部可见测量点估计后政策。 |
| POINT16_WIDE | 保留强固定原宽十六（四方向各四步），点估计后政策。 |
| GAUSS8 | 与 POINT8 同探测，局部高斯矩的有界控制参考。 |
| GAUSS16_CYCLE | 与 POINT16_CYCLE 同探测，有界控制参考。 |
| IVR_GLOBAL16 | 同宽八后两次四步采集，按均匀九点指令分布的 IVR 选择，最后有界控制。 |
| IVR_TASK16 | 同宽八后两次四步采集，按冻结名义政策指令分布的 IVR 选择，最后有界控制。 |
| NO_PROBE | 初始直接执行未纠正固定政策。 |

八方法共 768 次方法执行，500 步总预算包含所有探测与任务，噪声标准差
0.05，探测 gripper=0，底层政策保持固定。全研究控制步最多 384,000，控制
初始重置最多 768，do_simulation 请求帧最多 24,000,000。保存拟合、评分、
选择和控制器后，执行器只消费保存 JSON；不可用事后基线动作替代。

原前向预测从第三步才可请求，所以初始宽八提供六个可见模型样本；这个
条件对相同八步方法完全一致，不虚构前两步标签。先宽八再宽八的程序与
原四方向各四步程序不同，必须保留后者总体基线，不能将程序重排当作同轨迹。

## 标准参考的明确范围

局部高斯参考的均值取相同可见误差点拟合；若存在有限参数但其直接逆不稳，
可以使用有界凸目标，而非强行执行旧无效逆。参数不存在或矩阵非有限则停止。
协方差为先验正则信息加当前预测 Jacobian 的逆，尺度沿用名义 CALIBRATION
前六步的经验 RMS。参数先验方差固定 `(1,1,.09,1,1,.09)`，两轴有界逆的
指令正则 λ=.01、预测矩风险权重 ρ=1，均不按本轮结果调整。

这是条件于点／局部 Jacobian、名义模型和经验尺度的高斯近似。数据相关、
名义模型失配、饱和和噪声尾部没有被证明符合真实似然；概率、物理响应和
安全资格始终为 false。评分局部考虑均值上的饱和导数；有界控制最小化
未饱和仿射矩的二次代理，不能当作实际受扰控制代价的精确 Bayes 风险。

IVR 三个程序为 X4、Y4、ZERO4，前两个各正负二步，按四次结果无关协方差
更新比较未来方差减小。每实际完成一个程序后从当前真实样本重新计算均值
与协方差，再选下一程序；不喂假想标签。没有信息阈值或提前停止。

TASK 分布只用已冻结名义 TRAIN 中 POLICY_ONLY 原政策 xy 输出，截断至
[-1,1]、就近舍入至 .25 网格（NumPy ties-to-even）、按频数归一；不使用 CALIBRATION／QUALIFICATION
结局或本轮轨迹。GLOBAL 为 {-1,0,1}² 等权九点。两个参考的全部其余配置相同。
这只适配 GAUGE 的任务 IVR 和有界逆思想，不复现其独立验证停止、真实
quadruped 稳态量测、硬件授权监控或物理保证，不能沿用原论文结论。

## 目标、配对与费用

损失（成功取实际总步，失败／停止取 500），并分别报告成功、停止和真实步。

见证上必须匹配。提前结束者保留分母、单列不可作继续决策；无效估计停止
保留失败，不补做政策分支。该见证不授权克隆完整隐状态。
