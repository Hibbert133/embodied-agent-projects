# 固定接收者的旧来源前缀支持检查 v1

2026-10-28。只读、事后、训练来源内的描述性检查，不是离策略价值估计、
独立部署或新获取算法。新增环境交互／重置／物理帧／底层策略查询／神经
训练／批量模型拟合／新 seed／在线 LLM API 全为零。分析端网络前向、
递归后验更新和求解必须另行计数，不能统称“没有模型运算”。

当前独立 QUAL 及其全部冻结输入、参数、阈值、主比较不变。不读取其结局
或依表现选择模型。本检查在完整结果未知时固定四个已有接收者：
META_ADAPT、META_FROZEN、ERM_ADAPT、ERM_FROZEN；两个既定 raw bank、beta=0、
history=8、原递归规则和候选时间常数不变。不含 PRETRAIN 或挑选 checkpoint。

## 问题与来源

问题仅为：给定相同已分配获取动作，旧 RANDOM_WINDOW／BLOCK_FIXED 记录
的增益选择在哪一窗首次与固定学习接收者不同？旧后半段不能由此前一个
相同建议自动成为该接收者的结局。检查全部完整 TRAIN648、3296 实际窗、
18 独立组；四份回放为2592份分析，绝不是2592次机器人执行或独立样本。
沿用原 source manifest、双审计、公开轨迹投影和完整缺失／失败分母。
真扰动、噪声、私有状态或接触标签不进入分析预测器。

这些 bank 本来就用该 TRAIN 训练过，参数可能包含这些轨迹后段的训练信息。
因此这里不是独立前瞻误差、泛化或无偏 OPE。即使逐次查询只取当时历史，
也不能把同来源回放叫成“无训练来源复用的在线评价”。当前 QUAL 的独立
数据权限仍由其自己的冻结协议保证，不受此检查替代。

## 严格停止及缺失规则

每条来源轨迹、每个接收者均从相同冻结先验独立开始，不共享适应状态。
只提交当前来源窗的严格公开 query，验证其 history 正好等于来源真实历史
截至 completed_steps 的前缀。保存来源行／窗索引和 query SHA-256、完整
四候选声明、来源／接收者增益选择；不把来源 spec 中的 seed／条件标签
传给模型。尚未观察的窗口标签不能参与该次声明。

增益相同才向接收者提交该窗事实 measurement 和实际结束观测；完整窗按
ADAPT／FROZEN 规则更新或保持，终端短窗不更新。增益首次不同时立即停止，
不传该不同行为的反馈，不再提交后续 query，也不生成接收者未执行的尾段。
不为离轨历史新增强制反馈语义，不用模型输出填补物理结局。

空轨迹分别记录边界前结束／获取后无任务窗；不调用模型，不给匹配率填0。
短窗、成功／失败、未达到时点和所有任务／条件／时点／获取／行为层保留。
输出所有648来源×4接收者、全部匹配／首次分歧声明、18组及432个完整分层
（每接收者108层，每层原始6条）。轨迹内匹配窗比例→组内→组等权，
缺失显式登记，不给长轨迹更多统计权重，不计算任务收益置信区间。

“全部观测增益相同”只是本检查的选择一致性事实；不能单独证明另一个
程序的全部低层发送命令、状态或隐藏时钟相同。本检查不重查底层策略、
不重放环境，也不将任何接收者的截止损失填入表中。原始来源结局只标为
来源结局；不能把匹配子集作独立成功率或完整风险模型的全部监督标签。

## 冻结、审计与费用上限

先完成纯数组／合成时序测试、源码／输入绑定和 create-only 冻结记录，再
扫描完整记录。主计算与独立审计各语义解析一次公开流；哈希另记字节遍历。
声明输出按<=4MiB分片，保存索引与计数，不复制大 query，以来源行窗索引
及 SHA 精确引用已归档的公开流。旧大文件、记录及恢复副本均不改。

主计算上限13184次模型声明、52736个候选预测、13184次分析端后验更新／
线性求解。独立审计上限相同数量的基函数重算与标量后验更新，不调用
主 provider／主前向／主更新；严格公开特征抽取共享并披露。全阶段活动
时间上限1800秒，超出保留部分分析，不启动或重试任何环境／科学人口。
实际矩阵 eig／solve 次数、声明、反馈、更新、文件及耗时分别登记。

测试须检出首次分歧后的反馈／再查询、未来历史、旧 query 顺序错误、
终端短窗更新、冻结后验变化、跨轨迹状态污染、非法动作与计数／组权重错误。
独立 reader 重建全部选择、首次分歧、后验、缺失和统计；主模型／回放函数
在审计时禁用。旧6项比较、全部冻结源码／bank／原始文件哈希保持不变。

## 后续决定边界

本检查不选择新的控制器或幅度、不触发新机器人采集，也不为当前接收者
增加门控。当前资格若无竞争力，按原停止规则封存此版参考。
完整 Q／DR 仍须明确目标后继程序、数据权限、序贯概率／支持及停止机制，
并用独立自身历史部署验证；不能以回放的少数相符案例或难算密度比替代。
本检查、工作概率、标准风险门或数值通过均不构成 A 的具体新颖性。
