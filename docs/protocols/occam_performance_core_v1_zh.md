## 本阶段冻结范围

1. 严格公开历史编码：真实初始观测、逐步实际观测/发送命令、当前积分、任务、
   预算及候选T。未知/私有/种子/未来标签字段拒绝；历史缺少早期段拒绝。
   窗口不足部分有显式mask，零填充不是实际位移。
2. 可学习的历史编码器、增益/任务描述到多输出基函数网络，最后低维高斯权重。
   用可微递归滤波和全样本MSE实现标准元目标；支持子集与顺序必须显式提供。
   参数构造/维度可配，**没有冻结机器人架构、评价指标、训练数据或元批次**。
3. NumPy生产核心与Torch训练核心。Phi方向为输出×基数，作者代码转置存储。
   当前权重预测不加Q；完成窗口反馈先加Q，再按保存的Phi更新。Joseph协方差
   与作者直接式数学等价，数值差异披露。不隐藏加抖动、协方差重置或剪裁。
   Q/P允许数值半正定、R必须正定；这不是稳定、校准或安全保证。
4. 线性性能奖励的均值与协方差传播，最大化均值+带符号beta×标准差。
   四合法T全枚举，确定性平局顺序；在此有限空间内替代随机搜索，不冒称
   已复现作者连续/进化搜索。beta方向显式，不悄悄把保守罚变探索奖。
5. 声明—完成/提前结束的软件状态机：保存的候选、Phi、旧后验版本及窗口
   完成预算一致才更新，禁止更换实际T、重复/提前/过时反馈。短窗只保留实际
   已用步数并结束、不虚构完整标签。**尚无认证原生主机或实际执行证明**。
6. 严格JSON基函数导出，NumPy推理核对Torch；主运行时不新增Torch依赖。

`f0d3afb3b9369d19b3ed3cd20408c88628296b02`，读取basis_kf.py、lsr_net.py、
random_search.py。作者算法和方法名称不归本项目；此为独立实现的受限核心。
原始文件不复制进本仓库，保存URL/提交/字节哈希。GitHub API树查询曾403限流，
改用普通公开Git部分克隆，未执行上游训练、采集或安装脚本。

主实现使用float64验证、Joseph式及严格拒绝非法协方差。元训练目标在支持集
适应后计算全样本MSE，与所读算法一致；支持点的时间/组语义由未来协议定义，
不能拿旧来源固定政策的标签冒作新自适应政策结局。预测协方差分为latent及
加R后的observation；默认候选评分用latent，匹配所读作者函数。

## 验证与完整软件预算

NumPy主运行时跑18项核心测试；已有独立CPU运行时Torch2.2.2+cpu/NumPy1.26.4
跑相同18项及6项可微测试，共24唯一项/42次执行，重复不增加唯一数。
元梯度中央差分、跨NumPy/Torch推理与整段联合高斯条件化、非方阵Phi、
Q=0、奇异先验、相关R、输入不变、带符号奖励、时间/预算/重复/篡改反馈、
私有字段、缺历史、短窗均测试。仅一个合成Adam更新，明确记为1次优化，
不叫“零训练”；机器人科学模型拟合为0。允许最多3次开发检查加1次正式检查，
每次最多1次合成Adam；全部尝试累计、失败与源码保留，总上限4次，不用于调旧结果。

另对12个预定义非方阵/多输出合成案例，比较本核心、Torch实现、整段高斯
参考和作者已审查kalman_step函数。只从锁定源AST提取这一纯数学函数执行，
禁止上游其他代码。参考函数12次逆运算，主/独立24次NumPy求解和12次Torch
求解单列。原始源哈希先检查；每次检查最多1000次各类合成线性求解/逆、5000次协方差谱及叶/基
函数评价、1次合成Adam；超限停止，不自动重跑或忽略失败。

所有测试阻断联网与机器人构造/导入；隔离运行时未安装模拟器，仍加导入阻断
和旧实验数据读阻断。正式软件入口不创建、重置、推进环境，不重查机器人
政策，不分配种子。构造随机数仅数学夹具，不是机器人种子登记。
