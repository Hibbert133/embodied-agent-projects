# 行动响应缓存验证与时变流 开发协议 v1

本轮从已完成的误差诊断推进到实际候选算法：当前可见短轨迹是否支持
继续使用自己的旧点控制器，或者需要哪一种额外测量？与强线性十六步、
宽幅度短探测、近期辨识、周期刷新、残差检测和标准实验设计比较。
这是新的模拟器假设实验，不能把之前失败的置信门改成通过。原 API
负结果、所有原任务数据和保留范围不变，持续 CCF A 目标仍未完成。

## 冻结人口与资源

八个独立流簇，每簇三任务（push-v3、reach-v3、door-open-v3）、六个
连续案例，另交叉 STATIONARY 与 MIXED 两种评估器情景，共 288 单元。
新任务种子 10800–10943；10944–11199 保留，10608–10799 等旧保留不变。
种子对应流／任务／案例，两个情景和十六方法使用同一单元初态、相同
噪声序列，后续运动可不同。每方法案例一次环境／执行器初始重置、
最多 **500 总步**，探测、政策前缀及实际任务均计费。状态、真实位移
历史和 RNG 在所有衔接处连续，不进行探测后重置。

十六方法共 **4,608 执行**，最多 **2,304,000 新环境步／4,608 重置**。
官方固定 Sawyer v3 政策不改权重，xyz 噪声标准差 0.05，夹爪不加噪。
指令先按公共政策接口截断，再应用所选 xy 点控制器并截断发送值；
评估器施加隐藏仿射映射、float32 xyz 噪声，最后按环境动作空间截断。
成功或终止后停止。无 API、策略学习或验证式情景记忆写入。

每种方法只拥有本流／任务／情景下自己过去的参数缓存，不借用其他
方法、当前未来轨迹或真实参数。参数缓存是标准辨识模型：有效点拟合
先于任务结局保存，可供下个案例使用，包括本次随后失败的任务；它不是
宣称成功可转移的 episodic record。参数更新数单独报告，不称作记忆收益。

## 隐藏时变设计

评估器生成器使用冻结 namespace 42801，先于任何新任务执行保存完整
算子银行。八个流分为偏置变化、增益耦合变化和方向奇偶变化，初始
旋转、增益、剪切、偏置连续取值。矩阵系数不超过 ±2、偏置不超过
±0.3，最小奇异值至少 0.35、最大不超过 2。代理仍拟合一般六参数，
不在银行中查表，不能读取银行、流号、情景、条件标签、种子或 RNG。

STATIONARY 始终使用 A；MIXED 的突变位置在案例 1–3（从零计）中
预先随机生成，之后另有一个 B/C 中点和 C。B→C 保持同一奇偶性，
渐变不会故意穿过奇异矩阵。每个案例内真实算子固定，案例间可改变。
变化时刻不交给代理。两情景改变了物理任务分布，不能当作保持边际
难度不变的纯耦合干预；算法对比以同一情景内的配对单元为准。

## 名义模型与参考尺度

只使用原训练冻结的每任务 LINEAR_ARX，完整源银行为 21,010 步／288
重置。名义六组 1-mm／覆盖失败仍失败，不重拟合，不调用旧的
response_transfer.py，也不将其 qualification 设为 True。

参考尺度只读取原 **CALIBRATION 10300–10315** 的前六个已执行步骤，
有两步真实位移历史后，用步骤 3–6 的可见 xy 目标减原保存线性预测。
每个名义种子先取两个程序的较大平均平方残差，再对十六种子平均并
开方，最小数值尺度 1e-6 米。只使用名义已发送命令和观察，不使用
输入噪声真值、最新只读诊断的私有残差或 QUALIFICATION 10400–10415。
不读取任务成功或完整轨迹最大误差来选择前缀、阈值和程序。

这是新的**经验参考 RMS**，不是通过检验的误差包络。`2*sigma/sqrt(n)`
仅是当前仿真假设的均值误差尺度：相关机器人步骤、改变的输入、接触和
非平稳情景均可能破坏它。该参考只在实现／配置／协议提交后从旧 CAL
计算，保存散列后才执行新种子。原模型和区间结论不改变。方法的物理
响应资格、概率保证、安全保证始终 False；本轮主要检验任务竞争性，
不以数值“兼容”宣称新置信认证。

## 候选验证与采集

缓存点模型预测 F_cache(可见历史,发送命令)。对当前已完成转移计算
可见残差 `r = observed_delta_xy - F_cache`，按完全相同的已发送 xy
命令分组求均值。假设在当前测量阶段有局部仿射**均值残差**
`Gamma*[u_x,u_y,1]`，每输出的两个斜率界 ±20 mm、截距界 ±10 mm。
这些是声明的数值模型域，不是从当前评估数据估出的物理界。

在分组均值误差假设下，LP 约束为
`abs(x_i Gamma_j - mean_r_i_j) <= 2*sigma/sqrt(n_i)`。数值以 mm 表示，
SciPy 1.15.3 HiGHS，primal／dual tolerance 均 1e-9，maxiter 1000。
不把 solver 容差或经验 RMS 当作证明。求每个查询的最小／最大残差。
行动范围是公共固定政策接口的四个 xy 角点及零点，经缓存点控制器
映射到实际发送命令；没有先跑未来政策来获得范围。

允许均值差异为 0.1 mm 加缓存预测 xy 信号幅值的 50%，信号相对零
政策动作计算。所有查询都在差异范围内时提议 REUSE；有一个查询的
整个区间超出范围时拒绝缓存并请求原十六步刷新；区间交叠且不确定
时补测。约束不一致标为模型／误差假设被拒，不标为执行器物理变点。
LP 数值失败停止并纳入失败分母。

条件性说明：若真实局部均值残差在声明系数域内，且每个当前自适应
分组的均值误差界成立，则真实系数在可行集内，其查询均值在 LP 区间
内。所有区间包含在容许差异内才支持这个**条件性均值判断**。它不是
新的集合辨识定理，不给未来单次噪声、任务成功或完整轨迹覆盖保证。
本轮没有验证这些条件，在线执行属于另行注册的未认证模拟器假设。

缓存存在时，候选先执行六个政策前缀步，实际进展也计入成本。补测
库为 ZERO4、WIDE_X4、WIDE_Y4：零四步，或 ±0.4 轴命令各两步。
至多十六个额外微探测步，且每次保留至少三十二任务步。提出测量选择
时，只用过去拟合的残差点模型预测假想新测量，并求最坏归一化区间
宽度的下降；假想数据明确不属于观测。不同补测成本均为四步，预先
按分数／程序 ID 确定平局。达到微探测上限仍不确定，执行一次原 ±0.2
十六步刷新。该刷新是公开的算法分支，不能隐匿为缓存验证成功。

刷新拟合只用这次真实新探测的可见样本，位移历史保持连续。冷启动
十六步有十四个带历史样本；已有前缀后十六步刷新可有十六个样本。
使用原固定有界预测误差辨识与逆稳定域，非法拟合停止，没有 Oracle
代执行。选择／控制器和每一步指令均先保存，执行器消费保存 JSON。

## 全部对照与消融

| 方法 | 固定行为 |
|---|---|
| NO_PROBE | 未纠正政策，无模型先验。 |
| FIXED8 / FIXED16 | 每案例原 ±0.2 八／十六步后重新拟合。保留强十六步。 |
| FIXED8_WIDE / FIXED16_WIDE | 每案例 ±0.4 八／十六步，匹配新增更强激励访问。 |
| CACHE_ONLY | 冷启动原十六步，之后不验证地复用自己的旧点模型。 |
| PERIODIC2 / PERIODIC3 | 冷启动及案例号除以 2／3 余零时原十六步刷新，其余复用。 |
| RECENT_WINDOW | 无专门探测，先用自己的旧点或未纠正政策；每十六任务步用最近至多六十四样本辨识，非法更新保持上一点。 |
| RESIDUAL_CUSUM | 冷启动原十六步；之后六步前缀，依次积累 `max(0,S+max_abs_residual/sigma-1)`，超过 4 刷新，否则复用。是固定 Page 式参考，非最优或 Bayesian 检测。 |
| G_OPTIMAL | 同样前缀与程序库；分组加权线性残差点估计加 ridge 1e-6 的信息矩阵、2 sigma 预测均值标准误，检查同一行动范围。选择降低最大未归一化预测方差的程序。这是有限程序的贪心 G-optimal 参考，未复现 task-optimal LQR 全算法。 |
| RESPONSE_SET | 上述有界均值残差区间与定向采集候选。 |
| RESPONSE_POINT | 删除区间，只用加权最小二乘点残差判断，不要求方向充分性。 |
| RESPONSE_GEOMETRY | 判断中把残差置零，保留真实命令／计数，删除数据驱动有效性证据；真实轨迹不改写。 |
| RESPONSE_NO_COST | 忽略早停，先用满十六微探测步再判断；可行集不一致时用 G 方差选择继续测量，数值失败仍停止。 |
| ORACLE16 | 仅评估器知道真实参数，原十六步后真逆映射参照；不缓存给代理，不是最优任务策略或安全定理。 |

G-optimal、响应区间、动作相关实验设计和采集后控制表现已有成熟工作：
[Wagenmaker 等，ICML 2021](https://proceedings.mlr.press/v139/wagenmaker21a.html)
已给出线性动态系统的任务导向探索；
[最优实验设计综述](https://www.cambridge.org/core/services/aop-cambridge-core/content/view/38BBD0DC1A0386FDF306B6C0167DF7D9/S0962492924000023a.pdf/optimal-experimental-design-formulations-and-computations.pdf)
讨论 G 等准则。它们的条件与算法不能从名称继承到本仿真。当前候选
的新颖性仍待完整复核，强基线获胜必须保留。

## 预注册统计与竞争门

每方法分母 288，包括停止、无效拟合和当前所有状态。分别报告任务／
情景／故障族／时间位置的成功、实际在线／探测步、缓存复用、刷新、
停止、更新失败与所有源费用。模型先验方法都完整承担 21,010／288
来源，按本轮 288 单元摊销；NO_PROBE 和评估器参照无该先验费用。
物理来源只计一次，不重复加十几次，也不因复用而说免费。

统计单位是八个独立流簇，保留其三任务、两情景、六案例和全部方法。
固定 10,000 次 stream bootstrap、99% 描述区间，展示预先指定的
RESPONSE_SET 对 FIXED16、FIXED8_WIDE、FIXED16_WIDE、PERIODIC2、G_OPTIMAL
成功与步数对比。它不是精确有限样本或同时覆盖保证，不据少量差值
宣布显著性。预算决定八流开发规模，不称作有足够功效的投稿确认。

竞争门要求候选成功数不低于强十六步／宽八步／宽十六步／G 参考，
且其平均摊销步更低，同时不能被任何十一种可用基线以不低成功数和
更低摊销步支配。该门只是竞争性开发筛选；通过也不完成新颖性、
置信资格、独立非平稳复验或论文。失败不调尺度、容差、库或种子重跑。

## 冻结与审计

完整实现、配置、协议、审计器以及仓库必需检查先本地提交。干净源
生成唯一 manifest、私有算子银行与经验参考尺度，然后执行一次。
已有 status 拒绝重启；异常保留部分轨迹、已完成成本和不确定尝试。
输出压缩保存完整可见前后状态、固定政策原始／发送命令、实时先保存
的选择与指令、预测快照、缓存版本、RNG、序号和时间戳。

流式审计不创建机器人环境或重新仿真动力学。它在只提供已记录观察的
重放环境中复算注册规划／预测／LP／点求解，并独立核对注入算术、RNG、
保存事件顺序、实际指令、缓存归属、连续历史和全部费用。明确披露
复用的数学函数，不能把重放说成完全独立算法或物理资格。中文报告
展示全部强对照、负结果、变化不等于行动错误的范围，以及消融。
