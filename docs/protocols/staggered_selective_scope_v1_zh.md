# 延迟校准与选择性采用：精确适用范围构造 v1

这是**已知公式的精确数学构造**，不是机器人试验、SI-OCP复现或反驳其定理，
不是新算法、统计发现或任务收益资格。预期结果由构造直接可推，不作盲测或
随机蒙特卡洛。完整CCF A目标仍需新机制、强对照、独立自身时序任务优势。

## 要排除的错误推论

候选“多步长期覆盖率95%→在阈值小时停止验证并采用就有95%可靠性”缺少
选择后的证据。SI-OCP的长期覆盖及其点态转换还依赖已测状态、残差时间
Lipschitz和控制器递归可行等条件；本项目的离散位置/白噪声/接触与部分
隐藏状态没有满足这些条件，不能移植其安全保证。本构造只否定上述推论。

## 固定构造与明确费用

五种延迟P=1/2/4/8/16，每种P条交错校准线程，每线程400个预测。α=1/20、
η=1、初始q=0。预测i的线程j=i modP，标签恰在i+P揭晓；先处理当前已到期
的旧标签及阈值，再保存当前预测，当前标签绝不进入选择请求。

评价端分数S_i在floor(i/P) mod20=0时为1，否则0。标签是明确构造，不是
物理残差或机器人不利更新标签。各线程收到旧标签后，以该次已保存预测
的阈值判定err=1(S>q)，更新q←q+err−1/20。所有计算用Fraction精确有理数。
阈值在0与19/20间周期运行，不需负阈值、投影或浮点误差来制造例子。

先作每线程20轮完整热身，再用当时已可见q=0作为选择条件。每20轮里有
一轮不覆盖，边际覆盖正好19/20；热身后被选的轮恰好全不覆盖。选择不看
当前分数，只看过去阈值。停止于第一次被选预测时同样没有选后保证。

每例预测400P、标签400P、阈值更新400P；主共12400预测/12400更新，三类
事件加每例首尾共37210事件。独立实现用1/20整数单位重建12400更新；不是
额外预测样本或学习模型。所有延迟/热身/平局/标签延时均固定，不看输出
选有利构造。尾端等待已登记标签揭晓，不丢失pending，不生成新物理结果。

## 独立核验与边界

代码/配置/协议/审计先冻结提交，再执行一次到独占目录。主有理数生成器
禁用后，独立实现从事件流逐条用整数更新/约分重建，核对完整字段、预测
先于标签、到期次序、全部分母、选择及边际/选后覆盖、终端阈值和望远镜
恒等式q_end−q_start=misses−αN。禁止把相关线程或构造轮数当独立机器人组。

不把“分数区间未覆盖”直接叫作“有害更新”或“任务失败”，也不证明所有
自适应验证都不可能有效。在线multivalid、选择后推断、风险控制等已有更
强方法；这个教科书性质的范围反例本身不是本项目创新。只关闭以长期
边际覆盖直接替代采用证据的推论，不关闭正确使用该参考作经验不确定性。
