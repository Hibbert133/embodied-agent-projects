# 随机近期效应参考的数学资格检查

本轮在 codex/relative-update-evidence-v1 上实现标准参考，不启动 MetaWorld、不调用 API、不读取真实参数来选动作、不拟合控制器。此前全部结果、算子流和保留种子保持不变。数值合成随机种子不属于机器人任务种子。

冻结代码、配置、本协议、数学说明和审计后执行一次。五个预先规定情形分别为静态零效应、可预测漂移下零效应、小正效应、强正效应和近期效应翻转；每种 256 条路径，各 64 次数字随机指派，共 81,920 次合成响应、245,760 个有序事件。完整保留所有路径，不筛选成功或显著结果。

每步先保存严格可见请求，再由独立指派随机源选择旧／新命令，最后才计算并观察合成响应。噪声随机源独立，所有生成真值只在评估器事件中保存。指派概率限制 [0.1,0.9]，每步保留 32 步声明任务预算；此预算仅测试软件约束，不代表机器人执行。请求／重复指派／结果顺序违规均拒绝。

报告 8/16/32/64 的过去历史平均效应覆盖、正／负区间比例与空集，另报任意时刻覆盖失败和错误解释为当前效应的次数；后者不是原目标的覆盖错误。α=0.05、ρ=4 固定，不按输出调整。有限蒙特卡洛覆盖率不证明统计定理，已列数学假设也不自动对机器人成立。
