# 同状态首次命令分歧的响应差：标准学习构件开发 v1

## 目的与旧结论

上一轮固定VALIDATE8/.125与15/18原生单元事实相容、3未知，不能证明学习收益；原生MOVE链0及原审计软件失败保留。本轮不扩旧人口、不换bank0、不重开ARX/F20评分接口或旧响应资格，而是明确比较：同一真实状态下改变发送命令，实际响应差与名义预测的关系，以及标准成对回归能否比零效应和简单全局矩阵更好。

这是**旧TRAIN上的事后描述与标准构件学习开发**，不是新的算法贡献、独立物理响应资格或完整任务收益。来源A1有648实际TRAIN执行/9独立组/54任务条件单元/162获取节点。原先1296四方法人口与CAL、TEST、旧QUAL和最新54原生结果均不用于新拟合或调参。全部来源成本与旧负结果继续保留。

## 首次分歧及物理语义

每节点原四率.125/.5/2/8已全部实际运行；登记六对，共972对。核对初始native/Python/RNG见证、同外生噪声承诺、共同获取返回步、完整相同发送命令前缀和相同实际响应。只在两条事实轨迹首次float32发送命令不同的实际步，比较各自真实下一观测；不得在分歧后沿另一轨迹生成未执行状态。

分歧必须发生在真实采用率后的TAIL_TASK，原始固定策略动作和Z/夹爪命令相同。历史只取该时点已完成的最后两次真实XYZ位移，带精确步索引；禁止伪造最早两段位移或用未来观测。目标为Δd=dB−dA，d=(nextXY−currentXY)/.01，两个next都实际发生。它是在保存的共同随机量实现下的有限命令响应差，不是无噪声物理因果效应或总体平均处理效果。

另以实际施加动作之差作诊断，并独立复核原float32仿射/死区→XYZ实际噪声→最终裁剪顺序与噪声游标。真实参数、噪声、实际施加动作只保存在独立oracle_diagnostics文件，不进入模型输入或训练标签。即使共同噪声相同，裁剪和动力学仍可产生非线性影响；实际施加动作代入改变输入语义，不能把剩余误差称无噪声误差。数值零或零实际动作差的比值标缺失，不填0。

全部972对保留：决策前结束、获取结束、整条事实命令相同均单独标记。没有定义首分歧的对不虚构一步目标，也不把其误差补零来拉低均值。所有预测指标明确限于有实际分歧的条件人口；按任务/条件/时点/获取/率对/组完整登记可用分母，不能由条件预测推广完整任务或不可用节点。

## 固定模型与数据隔离

公开输入是当前39维观测、最后两条真实公开转移、两个当前发送命令及已完成步数。模型使用固定16维φ：常数、手XYZ、物体相对手XYZ、夹爪状态、两个历史XYZ位移/.01、共同Z/夹爪命令。无种子、组号、条件、真实扰动、噪声、未来结果或私有状态。组号仅用于整组拆分和统计，不进入数值特征。

|方法|固定定义|
|---|---|
|ZERO_EFFECT|预测Δd=0|
|NOMINAL_SENT|预测Δd=Δu，是原未资格工作映射的动作差，不称真实动力学|
|GLOBAL_SCALAR|所有任务共用一个标量α×Δu|
|GLOBAL_MATRIX|共用2×2矩阵×Δu|
|ABSOLUTE_CONTEXT|同一公开数据的两端dA/dB，拟合φ与φ⊗u的48维直接位移岭回归；预测相减|
|PAIRED_CONTEXT|主方法，拟合32维φ⊗Δu到Δd的岭回归，零差、反号和同状态环路一致性自动满足|

成对回归、消去共同截距和约束线性作用是标准思想，不声称新估计理论。主方法只改变监督目标，未将F20旧名义跟踪参考换权重复跑。其输出是当前成对控制响应差，不是绝对植物、任意逆模型或任务收益估计；绝对偏置仍未识别，禁止直接拿它作植物反演或安全保证。

固定ridge=.01；仅以训练折加权RMS缩放设计列，不作均值中心化，零RMS列用1，不调超参数/特征/初始化。层级权重为独立组→可用任务/条件单元→获取节点→分歧率对逐层等权，六对相关率比较不当独立样本。

留一个整TRAIN组，9折，每折训练其余8组，模型同时覆盖三个任务，不按任务挑超参数。四个需拟合模型×9=36次科学ridge，独立用增强最小二乘重拟合36次；无神经训练。纯数组测试单列最多1次solve与1次lstsq，不当科学新模型。所有原始标签和先前六项比较不变。
