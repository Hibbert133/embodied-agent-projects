# 附近测量点响应模型：名义训练与独立辨识协议 v1

本协议在分支 `codex/selected-response-qualification-v1` 冻结后执行一次，承接
已审计的附近点 PID 执行资格与 selected-response 软件参考。旧实验、保留种子、
固定策略、控制增益和响应模型结构均不修改。它检验额外测量的辨识增量，
不执行估计后的任务纠正，不是主动获取算法、任务收益或发表资格证明。

## 问题与五个参考

三个同数据模型为 SELECTED_INPUT_ONLY、SELECTED_HISTORY、SELECTED_POSE_HISTORY。
分别使用探测指令、再加入进入前运动历史、再加入绝对手部位置交互。
模型与数值拒绝规则保持 `src/probe/selected_response_reference_v1.py` 不变。
另保留 SAVED_C8（最初八步的估计）和 RELOCATION_INTEGRAL（移动结束时已保存的
积分补偿）。后者继承 C8 的矩阵，只更新偏移；它不是通用的矩阵辨识器。
其正向参数由保存的纠正矩阵 M 和偏移 o 重建为 A=M^-1、b=-A·o。
不能把移动中已获得的信息归因于后面的八步脉冲。

## 连续执行、冻结和停止

每次只有一个受控初始重置；MetaWorld 工厂的50次目标生成重置分别计量。
初期C4/C8准备、固定策略推进到边界、LOCAL_PID移动及8步探测连续衔接，
保留同一环境、随机数状态和时钟。噪声标准差 .05，旧命名空间47001。
每次最多500控制步；移动最多64步，探测8步，保留100步任务余量但本实验不使用。
TRAIN 不安装条件切换，主机检查完整前史及后续动作一直满足名义机制。
QUALIFY 使用已冻结的固定八步探测程序，不调用随机 TRAIN 程序。

1. 保存清单后只采集一次 TRAIN；提前结束、未到位、探测越界均保留。
2. 独立逐案例审计重建命令、私有连续状态、噪声、费用和事件顺序。
3. 仅从完整 TRAIN 拟合每任务三个模型，共9次模型拟合/72个因果输出回归。
   每任务少于160个窗口、条件激励不足等都记录为失败，不追加训练尝试。
4. 先保存模型及哈希，再用独立数值实现从 TRAIN 重建全部模型。
   模型未就绪或审计未通过时，不创建 QUALIFY 环境。
5. 模型审计完成后才采集一次 QUALIFY；再分别执行记录审计、评价与数值审计。

所有阶段使用独占输出目录，重复调用被拒绝。意外异常、部分原生步及未完成
拟合尝试保留日志；不凭工具观察超时重启，不重新运行已使用种子。
训练支持失败时报告这次负结果，不能启动留出人口或改模型后重跑本协议。

## 预先登记的评价

所有288次执行均保留。没有到达计划边界时，所有方法记
PLANNED_BOUNDARY_UNAVAILABLE，使用共同惩罚；这不是已发生条件变化后的估计误差，
也不是任务失败。提前成功单列。边界已达到但探测失败时，新模型用惩罚，已保存的
C8/积分参考仍评价。估计器仅接收严格的 SelectedAnchorWindow。

分数为 Frobenius(Ahat−A)+L2(bhat−b)/.4，越小越好。无效或不可用估计固定
矩阵误差8、偏移误差1、总惩罚10.5。无效拟合即使含参数也不使用其误差替代惩罚。
同时列出有效率、有效案例误差、全部失败原因和每任务/条件完整窗口比例。
前两项误差的惩罚尺度是人为固定评价约定，不是任务损失。

主要候选 SELECTED_POSE_HISTORY 分别减 SELECTED_HISTORY 和 RELOCATION_INTEGRAL。
对16个独立算子组内18个案例先求平均差，再整组 bootstrap 10,000次，种子20261020，
两比较共用抽样索引，报告2.5%/97.5%分位区间。两区间上界均<0才通过增量门槛。
同时要求每个任务×条件完整比例≥.5，完整窗口中的候选有效比例≥.9；也单列
全人口有效率，禁止把条件有效率写成全人口成功率。本轮16组是有限开发资格研究，
不是宣称已具备完整论文评价功效；区间不构成模型校准或物理概率保证。
任一门槛失败保留 NOT_QUALIFIED，不改惩罚、范围、模型、分组或样本量。

TRAIN 上限125,952控制步、1,152受控重置、58,752全部重置、30,005,760请求仿真帧；
QUALIFY 上限31,488控制步、288受控重置、14,688全部重置、7,501,440帧。
合计紧上限157,440控制步和37,507,200帧；独立每执行500步总帽为720,000步。
全部实际工厂费、早停费、移动费、探测费、初期C4/C8拟合、数值优化次数及墙钟分别保存。
新 API、自然记忆、策略权重训练、估计后任务执行均为0。

每个新模型收费含完整 TRAIN、完整 QUALIFY 和历史名义源3,840控制步/480受控重置/
24,480全部重置/12,259,200帧。按144个配对单元摊销。C8参考止于边界前实际证据；
积分参考止于探测前证据，不向它们收取新响应训练和后续探测费。它们是同一实际
采集前缀的证据成本，不是假造的任务续跑。实际物理采集只发生一次，不能把五个
方法摊销账相加当作实际总采集费。审计重复计算费用和软件夹具费用单独列出。

记录审计不执行采集器、控制操作或物理仿真，逐案例重建公开语法与私有图；
数值审计独立重建训练回归、推断、惩罚、分组统计和费用。私有哈希是来源见证，
并非外部真实物理验证。独立优化可能有不同迭代计数，两份计算费分别报告，
实际评价计数来自保存的结果；数值容差为绝对2e-8、相对2e-7。
标准检查包括全测试、compileall、pip check、暂存秘密扫描与差异检查。
最终中文报告区分执行可用、辨识资格与尚未验证的任务收益；不将任何组件通过
改写为算法创新或完整 CCF A 目标已达成。

## 执行顺序

使用仓库 `.venv` 的 Python。先执行 `scripts/collect_selected_response_v1.py prepare`，
它输出唯一清单路径。以下命令中的 `<manifest>` 指该路径，各步成功后才进入下一步：

```text
python scripts/collect_selected_response_v1.py train --manifest <manifest>
python scripts/audit_selected_response_v1.py train --manifest <manifest>
python scripts/collect_selected_response_v1.py fit --manifest <manifest>
python scripts/audit_selected_response_analysis_v1.py models --manifest <manifest>
python scripts/collect_selected_response_v1.py qualify --manifest <manifest>
python scripts/audit_selected_response_v1.py qualify --manifest <manifest>
python scripts/evaluate_selected_response_v1.py --manifest <manifest>
python scripts/audit_selected_response_analysis_v1.py evaluation --manifest <manifest>
```

模型拟合程序保留不满足训练支持的结果，需确认 `models.json` 状态为
READY_FOR_INDEPENDENT_QUALIFICATION 才能继续；后续程序也会拒绝未就绪模型。
上述命令不是可重复运行的演示脚本，已存在输出表示该次尝试已被消费。
