|MOVE_INTEGRAL|逐字复用原C8前缀、附近PID移动积分补偿和继续，无额外8步测量|

所有RAW程序在同一单元、条件共享完全相同的实际前缀；两个C8基线共享另一个真实C8前缀。不同前缀只能比较完整程序，不能代填后继结果。附近PID三种测量后行为共享实际移动/测量和返回私有状态；NO_PROBE共享探测前的实际移动状态。全部通过新初始执行获得，不克隆/恢复环境，全部各自付费。

移动沿用现有`local_reprobe_v1`增益与位置条件：P=8、位移D=16、XY积分增益0.32、积分界0.5、移动命令界0.5，移动至多64步、测量8步、保留100步任务余量。固定目标(0,0.6,0.25)，附近目标使用原可见位置/物体高度规则。RAW任务积分在移动/探测期间冻结，返回最后实际观测；普通任务步每步固定策略查询一次并按实际回执提交积分。任何失败/拒绝后都从当前状态继续，不重置撤销位移。

参考偏移是在移动结束、探测前形成的旧积分参考，不是新物理M/b辨识。它不输入真扰动、噪声或未来结果。新计划严格绑定当前记忆和保存的公开参考，主机执行被保存的映射/积分模式；非法/过期/重复计划拒绝。完整窗口只作为注册程序的采用条件，**不证明模型适用性或参数正确**。CARRY和RESET不保证无扰切换、稳定或安全；新映射统一带未取得物理辨识/任务效果资格标记。

NO_PROBE控制防止把移动已经提供的纠正归因于额外探测。其准备失败/提前结束则保留原控制；不伪造完整测量窗口。其他参考分支没有真实完整窗口时保留原纠正和任务积分。MOVE_INTEGRAL保持原基线的实际行为，包括其原有未到位处理，不为了新程序而改弱。

## 原生契约与一次性失败处理

原生60项完整记录审计、C4/C8实际执行、RESET/CARRY都至少有一次真实采用，环境/预算/衔接违规0，才能开始QUAL。数组测试的假回执或mock初始拟合不替代此门。公共选择/计划写入journal并flush/fsync后才能实际步进；保存每个命令、结果、参考、积分模式、返还状态、真实行为概率和全部私有见证/账本。

任何软件/数值异常停止该一次性阶段并保留部分，不能覆盖、重试、换种子或追加。原C4/C8无效则按原基线停止案例、截止损失500，无基线代执行。提前成功、窗口不足/越界、移动上限和全部失败保留全部分母；不制造额外任务步或虚构采用。原生覆盖失败则不开始QUAL。

## 独立QUAL两个分开的资格判断

**获取可用性**固定以LOCAL_PID_KEEP为参考，与FIXED_PD_KEEP比较：完整窗口/全部54分配≥0.5，三任务×两条件每格至少3/9完整窗口，窗口比例配对整组bootstrap95%下界>0。提前结束仍在54分母，另列可用数。这只支持单独设计中途模型，不证明窗口可辨识、响应模型合格或获取净收益。

**参考采用效用**唯一预定主比较：LOCAL_PID_REFERENCE_RESET减LOCAL_PID_KEEP完整截止损失，配对整组bootstrap95%上界<0，且每任务至少一次真实RESET采用。所有54分配保留，未采用的程序行为也纳入；不以采用/拒绝子集作因果比较。这个门只检验同获取状态后的标准参考分支，不证明它在获取前超过RAW、C8、积分或NO_PROBE完整程序。

CARRY减KEEP、测量后RESET减NO_PROBE RESET及所有程序减RAW均固定报告为次要未校正区间；不选择表现最佳者、不把CARRY换成主比较。最终新方法依然必须以完整获取代价在新的自身历史中超过全部强参考。任一资格失败保留负结果，不围绕该参考版本追加门控/样本/调参；不得以软件/分支门降低原论文标准。

重采样单位为9个独立组，介入层各3组，组内三任务/两条件相关性保留。bootstrap10,000次，种子202610701。每组先求6个单元的整数总损失/窗口数，再重采样整组。95%分位数在整数总和上按1/40、39/40作精确线性插值，再除54，严格零符号，不因浮点一ULP改门槛。所有区间未作多重校正，条件于当前冻结来源模型，不包含重训变异，不是物理保证。
