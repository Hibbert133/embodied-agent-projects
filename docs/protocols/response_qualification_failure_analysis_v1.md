# 响应模型资格失败的只读诊断 v1

全部新增结果为**事后描述性分析**，不重新检验或更换原资格门槛，不在旧 QUAL 上
调整模型、参数、阈值、正则化、训练权重或样本。新的假设只能在独立数据检验。
原 NOT_QUALIFIED、六格、18 组、16 条缺少任务尾段和全部记录保持原样。

仅使用冻结的 270 条 TRAIN／CAL／QUAL 记录和三个既定模型。严格重建真实初始历史，
最早两步标为缺少 AR2 历史。逐步、逐轨迹、三任务／两条件、抬升／抬升后与移动
1–8／9–16／17–32／33–64 段全部保留。统计先轨迹内、再组内、最后独立组等权；
短段、常数相关序列与无尾段为 null，不填零，不把时间步当独立样本。

检查四类可能解释：

1. 名义 TRAIN 覆盖与 QUAL 状态／动作分布差异。以原 TRAIN 标准化及逐维样本范围、
   原二阶加权设计 Gram＋原 ridge 的几何杠杆描述覆盖。只计算几何，不使用新响应目标
   拟合模型，不把经验范围或杠杆当准入阈值、误差界或安全保证。
2. 特征与模型复杂度混淆。保存设计秩、条件数、有效自由度和固定二阶的常数、一阶及
   二阶各组分量。这是代数分解，既不删项形成新候选，也不构成消融后的任务结果。
3. 输入语义与噪声。复算全部 float32 仿射／死区→XYZ 实际噪声→最终裁剪，三种既定
   预测输入分别披露。独立验证 e_true²＝e_applied²＋δ预测²＋2e_applied·δ预测；δ同时
   包含噪声、浮点与接口提前裁剪差异，不称为物理噪声误差。未来实际动作只进入评价。
4. 有限历史与闭环数据。对误差、命令、历史位移和实际噪声给出滞后 0／1／2 的轨迹内
   相关与误差自相关；位置、物体运动只作接触代理，不能证明唯一原因或识别估计偏差。

QUAL 的 UNCHANGED 是边界不再切换，不是从名义初始条件运行。名义训练和偏置资格、
10 维线性与 20 维二阶之间同时改变了多个因素；当前数据不识别各因素的因果作用。

输出：逐步诊断、全部轨迹阶段、组汇总、缺失登记、来源哈希、中文报告和独立核对。
新环境创建／控制步／重置／物理帧／在线 API／响应模型拟合／选择器全部为零；
分析耗时及三个诊断几何矩阵的计算单列。入口使用既有只读 guard 阻断模拟器、网络、
子进程及优化器导入。测试只使用纯数组和保存记录，不发现或运行原生仿真测试。
原 1,450 项测试通过源码哈希复用，新增纯数据测试、编译、依赖和秘密／差异核对。

后续实验仅为设计稿，独立训练／CAL／验证需要新的种子登记、样本与功效设计、
收集器和审计冻结及后续授权。本轮不占用任何预留种子，也不启动采集或 API。
