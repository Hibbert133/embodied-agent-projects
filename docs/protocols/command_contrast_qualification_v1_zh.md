## 独立科学人口与五条实际分支

九个独立组，每组包括 push-v3、reach-v3、door-open-v3，NOMINAL／RANDOM 两个固定上下文，FEEDBACK8／BALANCED8 两种已规定测量程序。组 0–2 在第三条固定探测命令之前查询；组 3–5 在实际移动后的第一条测量命令前查询；组 6–8 在实际八条测量后的第一条任务命令前查询。每组三个任务种子，共 27 个独立环境种子；组内共享随机参数导致相关，不能按执行或时间步当作独立样本。

三种目标阶段各有三组，组内的原定任务干预边界依次为 16／32／64。完整分配为 108 个单元。每单元五条实际分支：BASELINE、X_PLUS、X_MINUS、Y_PLUS、Y_MINUS，共 540 次执行。科学种子 61000–61026；61027–61999 预留不用。每组／任务环境种子为 `61000+3*group+task_index`。上下文、程序、候选之间的种子复用属于显式匹配，不能增加独立组数。

新随机命名空间：固定组仿射 110001、完整噪声带 110002、平衡测量排列 110003。RANDOM 的对角项 U[.75,1.25]、交叉项 U[-.2,.2]、偏置 U[-.2,.2]，死区为零；NOMINAL 为恒等变换。上下文在一次执行内不改变。XYZ 噪声标准差 .05，从受控初始时刻固定一条 500×3 的 float32 噪声带。不得在目标点重新抽样、替换未来噪声或改变游标。

BASELINE 分支真实到达查询点后，先保存全部五条命令及全部六个任务匹配预测器的预测，再执行它自己的查询命令。其余分支各自新建环境并作一次受控初始重置，真实执行相同前缀；核对公开轨迹、原生状态、已审核的 Python 状态比较投影、过去噪声和时钟一致后，只消费先前保存的同单元计划。不能按先前结果重新产生候选、重训或替换预测。每条分支只执行一条查询命令，之后结束本分支，不伪造完整任务结局。

候选定义：保持基准发送命令的 Z／抓手分量；XY 分别加 ±.25，裁剪到 [-1,1]，**在预测之前量化为 float32 的实际发送值**。旧前置核对使用 float64 理想偏移，属于历史不同接口，不能直接当成本轮物理命令。裁剪后的重复方向标签仍保存并实际执行，不合并、不删除。当前输入只含三个真实连续观测、当前基准命令和候选，排除真实扰动、实际执行噪声、种子、私有状态和未来响应。评估端才读取真值。

## 前缀、不可用点和连续性

沿用冻结的八条固定初始探测、C4 仅保存、C8 控制、固定策略至边界、LOCAL_PID 实际移动最多 64 步，以及两种八条测量程序。旧 actor 声明完整程序上限 168；新收集器在目标 COMMAND 保存之前截断，只消费一个查询命令，绝不执行旧程序剩余尾段。因此科学人口每次上限分别为 3、boundary+65、boundary+73，最高 137，且总硬上限仍为 500。

到目标前成功、环境终止、C4/C8 无效等均登记为不可用并保留全部分配。其他四个分支仍真实执行其分配的前缀，核对相同不可用原因与相同结束前缀。不能使用另一控制器代执行、补零或补采。若同前缀不一致、命令未按保存选择执行、预算或审计失败，立即终止本次一遍式采集，保留已采数据和失败记录，不重试科学人口、不追加种子、不以难例不可用为由改变程序。

每次执行工厂构造、一次受控初始重置，之后环境对象、原生 model/data 地址、噪声带、游标和物理时钟连续。没有快照捕获／恢复、目标点重置或状态复制。工厂内部目标生成的 50 次重置逐条计费，不能省略。状态见证是源生成的私有审核证据，不是独立重建物理世界或安全证明。Python 比较投影仅允许已审核的统计包装器墙钟字段变化，不能使用全 Python 哈希去比较不同执行的墙钟值。
