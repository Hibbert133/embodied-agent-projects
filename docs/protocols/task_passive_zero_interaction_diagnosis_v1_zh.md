# 任务期间被动参考后的零交互诊断 v1

本协议记录**事后描述性分析**的范围，不能作为预注册的新方法效果验证。读取已完成的1,188次原生／DEV／QUAL执行；保留原门槛、参数、八种资格程序及全部失败。新增环境构造、重置、推进、在线LLM API和参数拟合均为0。入口硬拦截环境与拟合调用，完整保存来源／源码哈希。

第一部分区分输入纠正与任务控制。以每步实际访问的观测和唯一保存策略查询，复算PI基准发送命令。在评估端用真实注入的仿射／死区参数和实际噪声核对float32“变换→XYZ加噪→最终裁剪”。比较实际PI命令、未执行基准命令和同状态原始有界策略命令的输入映射差。分别报告零噪声输入映射和同一保存噪声下的输入映射；这些都不是机器人无噪声运动、未执行控制器未来或任务收益。真参数／噪声不进入预测查询。

同一单元、条件的初始C8仅用DIRECT_C8作规范来源，核对其他C8程序保存参数一致，不重新拟合；保留数值无效、未拟合、短轨迹和缺失原因。报告相对初始注入执行器系数的误差，不将其称为名义物理模型误差。

第二部分检查一个标准增量控制前提：当前响应能否由前一真实响应加命令差解释。使用全部18个既有线性模型（两来源银行×三特征×三任务），没有选模型、改系数、调阈值或训练。对每个模型分别复算：原始当前预测；前一真实XY位移加XY命令差；前一真实位移加完整四维命令差；当前原始预测加前一已知预测残差。ZERO与前一真实位移PERSIST为共同参考。

共同评价只含实际步骤n≥3，输入为o[n−3:n]四个真实观测、前一发送命令及当前已选发送命令；目标o[n+1]仅在评估端读取。后一个残差公式是标准固定单位增益残差延续，不是新算法或新拟合。XY局部命令差资格不自动推广到Z／抓手系数；完整四维公式单独标明这一限制。模型查询不产生或填补任何未执行轨迹。

全部轨迹登记、逐步诊断、逐轨迹窗口及分层表完整输出。三个任务×计划不变／变化条件保留全分母；实际变化暴露另列。窗口包括实际命令阶段、公开策略几何阶段、移动抬升／抬升后，以及第1–8、9–16、17–32、33–64步。缺少连续策略查询时不伪造参考变化；没有接触力／接触对，只报告几何代理。全局先在轨迹内平均，再在同组轨迹间平均，最后等权平均完整独立组；缺失阶段单列可用组，不填零或把长轨迹加权为更多独立样本。

测试使用纯数组、已知合成模型和保存记录，检验未来数据排除、噪声游标与执行顺序、映射／逆映射区分、初始历史、残差延续的代数、模型失配、零长度窗口和分组权重。独立复算核对步骤与模型误差表，原资格主要比较文件的哈希必须不变。

后续判断必须分别说明支持证据、反证及无法区分的原因。即使某个增量公式误差较小，也不能宣称其已可逆控制、适用于新控制器访问状态或改善任务。INDI／增量控制已有文献，执行器带宽、延迟和对齐条件不能直接借用为本项目保证。若证据支持进一步检查，另行冻结控制接口、目标响应、命令约束、数据／参数选择和独立资格；本人口不调参、不补采、不更换主方法。
