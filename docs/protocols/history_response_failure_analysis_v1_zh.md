# 历史响应资格失败：零交互诊断 v1

本轮由持续研究目标授权，只读取已封存的756次执行、30个模型和独立审计结果。
**所有新增分析均为事后描述性分析**，实施前固化程序也不将其改称预登记确认性研究。
原资格NOT_QUALIFIED、全部五方法比较、主区间、24格和68个无尾段案例保持原样。
旧1296次ARX及270次响应资格的负结果、原始记录和恢复副本全部保留。

## 具体问题与不可替换的判断

先核对数值合法性及原始预测；再检查当前预测能力；任务收益另行验证。
本轮没有机器人控制、新动作、训练、重新拟合、超参数/窗口/尺度变体或API调用。
末次训练批次损失不能替代完整TRAIN拟合误差，也不证明收敛。较小输入标准差仅是待检验线索。

诊断覆盖全部TRAIN216、CAL108、TEST432例；原t≥2真实历史目标，两个来源×两个部署程序、
三个任务、所有名义/随机/偏置及不变/改变条件，原全部八阶段均保留。每轨迹内汇总后按
独立组等权，不用时间步充当独立样本。没有阶段响应时预测误差为null并登记原因。

检查：

1. 在原匹配TRAIN来源上完整复算五个模型及各阶段误差，区分训练内拟合不足和迁移恶化。
   末批损失是更新前的随机批，完整误差是保存权重，不能要求二者相等。
2. 原训练轨迹等权、轨迹内目标均匀的标准化损失，分解为阶段采样质量和误差贡献。
   空阶段对实际优化目标的加和质量为0，阶段预测误差仍为null；两者不可混淆。
3. 加入两个无参数描述性预测参考：零XY位移、沿用最近一次真实XY位移。它们不控制机器人，
   不替换原门槛，也不将较弱新参考当作通过条件。
4. 使用保存的TRAIN均值/尺度检查43维当前公开输入，逐轨迹记录|z|超过3/5/10、超出原TRAIN
   当前t≥2范围的比例和各维.95分位数。窗口的真实最早两帧不是该范围估计的参考样本，
   不能将它们自然超界解释为新分布失效。范围/标准差仅为描述，不是适用域保证。
5. 在原权重和真实窗口下复算最后一帧的重置门/更新门(.01,.99)、候选/隐藏状态(|h|>.99)
   描述和前激活RMS；按43维给出单维输入仿射RMS贡献。单维贡献不含交叉抵消项与偏置，
   不能相加当作完整输出误差的因果分解。所有维度均保存，不只输出“最有利”维度。
6. 误差与实际原始噪声的滞后0/1/2相关，以及误差自相关。沿真实轨迹索引，跨阶段使用真实
   过去样本，不重置滞后、不填零。噪声仅在评价端重建，不能进入预测特征。
   相关不证明唯一误差来源；执行器有仿射变换和裁剪，不能将相关或剩余误差称为物理噪声下界。

## 隔离、验证和复算

源manifest、模型、原统计和已提交结果哈希在配置/来源表中绑定。原TEST411440个预测、
34560个阶段指标逐一比对。全部71773个源步、70261条共同历史响应、756例必须登记完整。
新增模拟器导入/创建/重置/推进、网络/子进程、优化器及回归拟合入口在分析进程中被阻断。
新增测试仅用纯数组与合成序列；沿用冻结源码未变的1489项回执，不重复原生仿真夹具。

独立实现重建全部RMSE、标准化质量、43维输入统计、所有GRU门描述、相关和分组汇总。
它不运行原训练器或优化器，保存权重的前向也与旧已审计接口相核对。旧模型/配置/记录
不被修改。分析耗时和纯计算次数另列；物理交互、API、模型拟合和参数变体均为0。

## 后续与停止

输出须同时给支持证据、反证和无法区分的原因，不因一个尺度或相关性就认定唯一成因。
不继续给该失败GRU/ARX添加接受门控，不在旧TEST上试新窗口、归一化、残差网络或控制器。
下一步必须依证据明确：先做独立训练资格设计，或检验强线性工作模型的控制相关性，
或当前证据不足以支持新采集。新增训练/采集只能在单独协议中冻结，费用单列。

CCF A目标仍包括可测量的新决策机制、强对照、方法自身独立时序部署和消融。
通用历史编码、残差学习、任务相关模型或双重控制价值式均不是本项目的新颖性证据。
