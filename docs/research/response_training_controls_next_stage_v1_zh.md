# 从训练受控检查到控制相关资格：后续约束

2026-10-22；设计说明，**不修改正在执行的 a7a3375 冻结试验，不是新采集协议**。未选择新模型、阈值、环境种子或交互预算，不运行新的机器人任务或在线API。

## 新查到的直接近邻

[AD-WM: Action-Discriminative World Models for Counterfactual Model Predictive Control](https://arxiv.org/html/2609.30264v1)，2026-09-24 v1。已读摘要、§III及§IV-D/V：其视觉潜模型用残差预测和动作恢复辅助损失保留动作信息，并在共享候选序列上计算全局排序与CEM选择集的后悔量。作者同时指出固定候选诊断不能代替自适应CEM轨迹，外部方法训练／推理权限不同，真实机器人实验有人工子目标和非随机模型分块等限制。这里不引用其成功率作为本项目的证据，不宣称本项目复现了该视觉MPC系统。

因此，“事实预测好不等于动作比较好”、残差预测、动作恢复辅助损失和选择集合上的后悔诊断均已有直接研究。本项目不能把增加反事实候选评价或改变预测损失本身当作新颖性。未来应保留同权限的动作敏感参考，并明确真实获取造成的后续状态、采用／拒绝及费用如何进入决策；仅写一般价值式仍不足以构成区别。

本项目另有一个接口层面的推论，**不是上述论文的实验结论**：当前预测目标只有XY位移，完整发送命令有XYZ／抓取四维，局部2×4响应矩阵的秩最多2，不能要求从这两个物理输出普遍恢复全部四维命令。候选只改变XY时也可能遇到接触、死区或裁剪造成的多对一响应。正确预测“候选效果相同”不应被错误地惩罚为动作不敏感。因此不能直接移植全动作恢复损失；应先定义哪些可行候选和物理响应对当前任务有可辨识的差别，再实际检验这些差别，不能仅靠数值非奇异参数声明可逆。

[Calibrated Value-Aware Model Learning with Probabilistic Environment Models](https://proceedings.mlr.press/v267/voelcker25a.html)，ICML2025；另读[arXiv v1](https://arxiv.org/html/2505.22772v1) §3–4，其标题使用“Stochastic”而非正式页面的“Probabilistic”。正式PDF链接本次工具抓取失败，理论阅读范围以该v1明示。论文研究采样型价值感知替代损失中的方差项及最小值校准问题；这里的“校准”不是经验95%预测区间覆盖。它提示不能把任务相关标签或随机单次结果当作天然正确的代理损失。其MDP／函数类假设不自动适用于本项目，不能借用定理保证实际机器人更新收益。

## 源码已证实的基线语义

`src/probe/movement_task_reference_v1.py` 中，`INTEGRAL_UPDATE` 只在 `REPOSITION` 循环内发生；随后 `MOVEMENT_TASK_DECISION` 保存 `RUN_SAVED_INTEGRAL`，任务循环每步只用该保存控制器编码固定策略输出。故旧 `MOVE_INTEGRAL` 是**经真实移动获得、随后保持的积分补偿**。它依然是必须保留的强对照，但不能被称为任务期间持续更新的积分反馈。

未来基线表还应单列“任务过程中不额外移动的被动更新／标准扰动观测器／历史辨识”一类同权限方法。其具体接口、名义模型、抗饱和、更新频率和成本要另行冻结并资格验证，不能直接省掉旧移动就假定获得相同积分估计；也不能未执行就声称它更优。当前没有实现或评价该新基线。

## 三个不可替换的证据层

|问题|应有的证据|本轮受控训练能证明什么|
|---|---|---|
|实现和数值是否合法|严格可见输入、真实时序、相同初始化／采样、有限参数及独立前向／回归审计|仅开发人口的实现证据；旧资格保持原样|
|模型是否支持实际控制比较|独立执行的可行命令／候选之间的真实响应差，核对共同时刻历史与实际发送命令|本轮只预测已执行动作，不能声称获得未执行动作的真实响应|
|纠正或获取是否改善任务|保持连续状态、独立时序部署，含全部验证／移动／失败惩罚的500步截止损失|本轮无新控制执行，不能据RMSE给出任务收益|

若后续确需控制相关资格，应在新数据前冻结可行候选、幅度、状态阶段、数据用途、样本量与完整费用。每条真实分支从一次受控初始重置开始，各自实际执行共同前缀，再消费事先保存的候选；配对评价不能恢复快照撤销获取位移。执行器仿射／死区、实际噪声和最终裁剪顺序保持一致。裁剪导致候选相同或无可比方向时保留原因和完整分母，不虚构局部Jacobian。真实扰动和耦合噪声只用于评估。

匹配来源模型若在混合扰动下用“发送命令”训练，它只是该来源分布下的工作预测器，不能未经检验就当成“名义物理施加动作模型”求逆。输入语义、命令干预下的响应差和反演的命令裁剪都须另验。观察性相关或小残差不能识别唯一物理原因。

## 获取—采用主线仍需的实质进展

未来拟研究的是：一次真实获取既改变状态，也产生决定是否采用纠正的证据；拒绝纠正之后仍从获取后的真实状态继续。既有论文已覆盖一般双重控制、任务相关探索和模型适用域，故需要具体可计算机制与可证伪的区别。

完整方法必须与同预算的独立分解、忽略获取后状态、忽略拒绝后继续等消融，以及DIRECT_C8、原MOVE_INTEGRAL、始终获取、不更新、标准变化检测、历史辨识、任务相关获取、合适的双重控制近似和合格被动更新参考比较。最终评价使用方法自身形成的新时序历史，平均截止损失同时优于DIRECT_C8和积分，全部任务和失败保留。

错误更新的任务标签需要同一真实获取后“采用／保留”的实际配对后续及完整伴随成本。随机一次差值是一个实现值，不应被当成稳定的条件期望或记忆真标签；未知部分应明示。不能以离线完美预知选择、已知扰动分类或源码测试通过替代部署证据。

本轮训练结果无论正负，都只决定下一步设计。若神经表示仍无竞争力，停止围绕该版网络添加选择规则；强线性工作模型也须经过控制相关资格。若连合格标准纠正／被动适应都已消除获取价值，应保留该反证，而非削弱基线或筛选任务。CCF A目标仍未完成，不能由这份说明或另一个标准基线试验替代。
