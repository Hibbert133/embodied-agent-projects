# 命令累计状态诊断后的决定

结论：先制定新响应模型的独立训练与资格协议，第一道门必须是新收集器的
原生目标见证、公开输入和变换/噪声语义资格。当前不支持把名义累计目标
直接当成实际状态，也不足以跳过这些门启动大规模训练或任务纠正。
本轮全部分析为**事后描述性分析**，没有新增数据、拟合、在线LLM API或阈值。

## 下一设计必须检验

1. 新收集器先在独立原生软件人口保存mocap前后数值、发送/实际动作、float32
   变换/加噪/最终裁剪、工作空间累计及完整时钟。私有见证只供评估验证，不能
   进入在线输入或给模型训练提供此前禁止的特权信息。
2. 公开输入只能用真实初始观测、已实际发送命令及过去观测；环境先验须披露，
   同预算基线获得同样访问。不能用真扰动、实际噪声、私有状态或未来结果代替
   公开状态；不能把SENT称为无偏均值。
3. 新协议须区别于失败的旧位置/短历史联合回归，预先定义同容量无摘要消融、
   强历史/前向预测对照、输入变换和噪声不确定性、全人口不可用惩罚及独立
   TRAIN/CAL/QUAL。不能在旧QUAL上选特征、容量、阈值或只留有利窗口。
4. 原生软件门、预测门、含获取成本的任务门分开。预测通过后另行冻结实际
   纠正/更新幅度/获取决策部署。保留RAW PI、DIRECT_C8、积分、始终获取、
   获取不更新、NO_PROBE及标准检测/历史辨识/任务相关参考；验证和移动真实
   执行，从实际后继状态继续，新方法使用自己的独立时序历史。
5. 新采集前冻结全部重置/物理帧、训练计算及资格失败费用。本轮没有分配种子
   或启动新训练/仿真，不围绕失败的ARX/F20增加选择规则。
