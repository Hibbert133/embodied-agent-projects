# 命令前置核对后的研究判断

2026-10-22；全部新增结论均为**事后描述性分析**。独立审计通过，不等于物理资格、任务收益或论文贡献。

## 证据支持及反证

全部18个保存线性模型在扣除其他列后都有两维XY数值激励。F20的XY命令矩阵最小奇异值为0.718822–0.792448 mm／单位发送动作；F43为0.910085–1.56179，H10为0.711174–0.798406。矩阵均非奇异，但不同预测器给出的作用强度并不相同。缺少实际干预响应时，不能判定哪个矩阵具有正确的物理方向或幅度。

53,608个不重复假设候选（13,402个来源位置×4个方向）中，1,939个发送层裁剪后与基准相同，651个超出所在训练库的逐轴命令范围；它们都保留。每个候选被三种线性模型评价，因此审计项为160,824个，不能按此把实际候选数量乘三。

全部非零查询的最大相对行空间残差只有 `2.6612127140543818e-15`，包括上述越轴范围的查询。因此，线性跨度充足不意味着插值、联合状态动作覆盖、因果识别或可用控制。没有设定支持门控阈值，没有删除越界或零差候选。

这些结果**不支持将XY数值秩不足直接认定为当前失败的原因**，也不排除闭环相关、噪声、状态条件、模型失配或逆控制放大等其他因素。F20部分完整设计秩不足与XY对比仍处于行空间可同时成立，不能据全设计秩一项裁决控制可用性。

## 明确的后续判断

继续设计**独立真实命令响应差资格**，不立即求逆、部署新纠正或增加获取门控。优先复用现有冻结线性权重，暂不增加网络结构、重新训练响应模型或用旧DEV／TEST再次确认。

新协议需要在同一真实前缀后，对保存的有界发送候选分别实际执行，预测先于该分支响应；每条实际分支一次受控初始重置，获取中的位移与随机数保持连续。不能复制状态快照、在决策点换噪声流、填入未执行的未来观测或重置撤销位移。配对噪声只属于评估，单次随机差值不能冒称稳定条件期望。

至少保留零差预测、H10、F20及F43全部参考；任务、来源程序、上下文、实际控制阶段和早期成功／不可用分母都要预先登记。只在任务尚未成功且具备真实历史时形成决策；不为了收齐样本强行推进已结束的任务。不能根据本轮651个越轴查询反过来删掉新资格中的困难候选。

该资格只回答能否预测实际局部命令差。通过后仍须另验逆纠正、命令放大／裁剪，以及含移动／验证／探测／失败惩罚的完整截止损失；不把它当成最终算法验证。

并行的研究前提是补齐**任务期间的标准被动适应**。原MOVE_INTEGRAL只在移动期间更新、随后保持，不能替代任务期间的积分／扰动观测参考。新增被动参考也需要明确目标量、单位、抗饱和、更新时刻、参数来源与完整费用，再作软件及独立执行资格；不能省掉移动却假设已有同样的估计。

在决定进一步获取机制之前，应检验合格的强被动参考是否已经解决主要问题。若它消除了获取收益，应保留这个反证，不能削弱基线来制造选择空间。现有GRU和ARX的负结果仍封存，不追加选择规则。
