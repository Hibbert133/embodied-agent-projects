# 带记忆的获取后缀与两阶段终局价值：已有路线和机制边界

2026-10-22。前一轮支持核查已发现迟启PI及RAW PI自身历史的MOVE后缀缺失。本轮把数据语义变成可运行组件，但不声称这些标准工具构成新算法。

[Jiang与Li，ICML 2016，原文§3–4](https://proceedings.mlr.press/v48/jiang16.pdf)已将DR扩展到序贯策略价值评价。这里实现两阶段、无折扣的成本形式，并显式处理选项内终止及500步截止罚值；属于标准参考。已知正确的行为概率、预先固定或恰当分离学习的目标策略／预测等条件不能省略；结构合法不证明报告概率正确。没有从原文继承机器人安全或逐历史改善保证。

[MathWorks官方控制示例](https://www.mathworks.com/help/simulink/slref/bumpless-control-transfer-between-manual-and-pid-control.html)展示通过积分跟踪处理控制切换。这里的任务积分冻结／恢复不是该完整tracking实现，更不保证无突跳；更新增益或纠正基准后，控制变化仍须实际核对。不能把状态交接称为新控制理论。

[OCCAM原文§3–4](https://arxiv.org/html/2406.17620v1)已有预测控制器表现、适应性能模型并搜索控制参数的框架。因此仅将获取后缀价值回归或增益选择做出来，仍不足以形成区别。后继要明确相较OCCAM、AA-POMDP、Dual-gatekeeper、GAUGE、Poke and Strike及模型适用范围学习，究竟解决了哪个获取后状态／适用性／采用与拒绝的具体困难。

当前可检验的机制假说是：面向实际后继状态和任务控制器记忆建模保留／采用的完整尾部损失，并在第一阶段评估该后继采用规则的价值，会比仅依据信息量、局部拟合误差或行为下随机采用均值更合适。两阶段随机数据的DR参考用于防止错误监督，不单独作为新颖性。真实动作族和学习器还未建立独立任务资格；本次数值模型不是机器人实验，也不表示任何候选已提高任务表现。

后续仍需单列原生软件契约、训练／校准／独立自身历史部署与费用；不能用合成无偏性、测试数量或旧人口的事后最小值替代任务收益及论文贡献。指定五项查新和原有全部失败继续保留。
