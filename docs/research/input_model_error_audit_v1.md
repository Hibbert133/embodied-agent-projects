# 已知输入后的模型误差与行动证据的可辨识边界

本阶段对已完成的未知仿射任务桥做只读分解，回答：输入噪声是否足以解释
当前预测残差，以及真实执行器不变时，保存的有效估计仍会变化多少。
不拟合检测器、阈值、模型、漂移界或取得新的任务结果。它服务于后续
行动响应有效性方法的设计，不作为新算法或 CCF A 目标完成的证据。

全部 1,152 方法轨迹、235,479 步、三任务、四种固定算子均纳入。保持旧
八个开发种子簇和全部保留范围，无新环境步、重置、API 或权重／点拟合。
源银行和原任务成本保留在原报告中，不把复用数据称作新的独立确认。

分析工具在读取新诊断结果前提交，运行写入新的目录。核对原审计散列、

对相同已观察历史、状态和目标 xy 位移，计算两个冻结预测器（线性和
状态二阶）在以下两种输入下的预测：真实算子下不加噪并截断的参考
输入，以及真实执行时的加噪并截断输入。前两步只建立实际位移历史，
仍计入原成本。预测器不重新训练，真实参数、噪声和任务结局不进入
任何新在线选择。原资格失败及成功率不改写。

## 精确分解与统计约束

令 y 为实际观察位移，f0 为参考输入预测，fa 为实际输入预测：

```text
r_total = f0 - y
r_model = fa - y
r_input = f0 - fa
r_total = r_model + r_input
||r_total||² = ||r_model||² + ||r_input||² + 2<r_model,r_input>
```

这里的 r_model 是给定实际输入与当前可见历史后的预测残差，可包含
未观察状态、接触、动态与模型近似误差；没有把这些来源进一步识别。
r_input 是这个冻结预测器对输入差异的响应，不是独立的真实动力学
噪声效应。参考输入也不是截断加噪输入的期望。不得把 RMSE、最大值
相加或转成无交叉项的“误差百分比”。

展示所有方法／任务／预测器／探测与政策阶段的步加权 RMSE、单轨迹
最大误差均值／p90，以及完整逐例记录。主要表使用 NO_PROBE 政策阶段，
每任务三十二轨迹，并保留两种预测器。不同方法状态、长度和指令不同，
不将其分量差解释为因果比较；相关步骤和方法不增加独立簇数。

被动估计只比较相邻**有效且实际执行的**点拟合，跳过被拒更新，并
核对估计与保存控制器的逆映射一致。报告最大系数变化的完整分布；
原静态协议保证真实算子变化为零。此处不拟合变点门或宣布误报率：
任何将估计跳变解释成真实变化的后续方法仍需独立评价。

## 不能从观测分开的因素

若未知当前动力学的允许模型族包含对输入映射的组合，则下面两世界
对所有因果策略均可产生相同观察历史：世界 A 为名义转移核 P0 加未知
执行器映射 g；世界 B 为名义执行器加转移核 P1(s'|s,u)=P0(s'|s,g(u))。
从同一初态开始，相同历史使策略选出相同命令；两个转移核给出相同
下一观察分布。归纳得到任意有限历史与状态定义任务结果的分布相同。
噪声与截断可一并包含在转移核中；例子不要求当前 MetaWorld 模型具有
这份自由度，也不宣称所有受约束的故障永远不可分。

这是因子分解的条件性不可辨识说明，不是新定理。只增加探测无法
打破这类等价；需要限制动力学／误差族、参考传感器或额外干预。若
只关心当前行动响应，两世界可属于同一个行动等价类。因此后续问题
应验证响应在当前状态／命令域是否可复用，并明确观测与误差合同；
不把“判明物理原因”当作只有点参数变化时已经实现的能力。

已有 [Lorenzen 等，Robust MPC with recursive model update](https://www.sciencedirect.com/science/article/abs/pii/S0005109819300731)
处理有界扰动下的集合模型更新并扩展至时变参数；
[Belforte 与 Gay，Optimal worst case estimation for LPV–FIR models with bounded errors](https://www.sciencedirect.com/science/article/abs/pii/S0167691104000775)
研究调度变量与输入对最坏情况辨识的影响。集合不确定性、状态／输入
作用域与最坏情况采集本身不是空白领域。后续仍需新的可执行机制、
标准控制导向采集、廉价线性十六步及独立时变流对照，不将本分析晋升
为它们的替代品。
