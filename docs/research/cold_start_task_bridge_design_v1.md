# 联合响应辨识到任务收益的后继设计

本未冻结初稿已在新任务数据采集前由[正式开发协议](../protocols/cold_start_task_bridge_development_v1.md)
替代。正式功效规划固定56流／2688次执行，种子14600–14767，保留14768–14999；
下方16流与暂拟预留范围保留为设计历史，不是当前可执行配置。

当前辨识资格通过，但尚未执行纠正后的任务。下一项必要检验是：
在同样8步实际探测后，联合响应估计是否比强点估计、Gaussian纠正和16步标准探测
带来更好的任务结果。此文是待实现并冻结的开发设计，不授权跳过源码测试或直接采集。

## 已有依据与需要保留的对照

[本次辨识](../../reports/cold_start_evidence_qualification_v1.md)中，全部8步模型平均分数0.202，
同数据ARX为0.767；二者同用384条名义轨迹。全部8步与后6步联合响应差异很小，
区间跨0，必须同时保留；不能把联合模型的改善归因于最早两步。
此前更准的参数、较低的总体价值误差都曾未能改善任务，因此不能省略任务检验。

拟比较八种固定程序，名称在最终配置中固定后不可事后更换：

| 固定程序 | 探测后的行为 | 名义数据费用 |
|---|---|---|
| 全部8步联合响应 | 完成原8步后拟合，保存逆补偿，立即执行固定策略 | 新3072步／384次受控重置 |
| 后6步联合响应 | 同轨迹、同校准模型，只去掉前两步响应目标 | 同上 |
| 同数据ARX点8 | 同轨迹，读取本轮同数据ARX估计 | 同上 |
| 旧ARX点8 | 原DIRECT_POINT8，保留便宜强基线 | 旧21010步／288次受控重置 |
| 旧Gaussian8 | 原DIRECT_G8，保留不同纠正目标的强对照 | 同上 |
| 旧点16循环 | 原POINT16_CYCLE，执行两轮8步后更新 | 同上 |
| 不探测 | 从初始状态执行固定底层策略 | 无名义拟合费用 |
| 探测8步不纠正 | 同8步后恢复未纠正指令，扰动仍存在 | 无名义拟合费用 |

所有8步后的点方法采用同一个既有逆补偿与动作约束实现。不能同时更改正则化、
底层策略或执行预算后，把差异都归于辨识方法。拟合失败立即停止并保留500分截止惩罚，
不使用其他方法代执行。每个候选必须先持久化参数及来源，再由执行器读取保存对象。

## 新数据和统计设计

拟用14600–14647的新任务种子、两个新算子生成源51001／51002，
16扰动流×三任务×两未来噪声，96配对单元、八程序共768次实际执行。
这些编号需在最终冻结前检查未被其他协议使用；14648–14999拟保留。
此处没有执行任何该范围种子。

同一单元的前8步必须实际重放为相同状态与噪声前缀，16步方案的前8步也同样核对。
只有一个受控初始重置，之后不复制、恢复或重置环境／随机源；每程序含探测总预算500步。
仍使用静态A仿射扰动与0.05噪声；本开发桥接不能代替时变、多故障族的独立方法评价。

主比较拟为全部8步联合响应减旧ARX点8的平均截止损失，成功计含探测总步，
失败／停止计500。使用完整16流成组bootstrap，流内三任务两未来不充独立样本。
与同数据ARX、后6步、Gaussian8及点16的比较须分列，完整报告任务成功和全部失败。
是否晋级的阈值、每项比较地位及固定样本量依据须在实际采集前写入可执行配置；
不得根据当前或新桥接结果决定扩样。本设计尚未注册这些具体阈值。

拟最大受控交互384000步／768次受控重置。按现有工厂50次目标生成重置、
每重置500帧和每控制步5帧推算，上限约21504000帧；实际仍须全生命周期仪表计数，
最终帧上限与编译时钟先冻结，不把推算写成已测成本。旧来源工厂内部账本不完整，单列口径。

## 与完整研究目标的关系

本桥接没有LLM、策略训练或记忆写入。若联合8步只是更好的标准辨识基线，也必须如实报告。
它的作用是确认后续“何时复用、何时重新探测”的研究是否有可靠、便宜且任务有效的估计组件。
即使结果正向，仍未建立新颖的费用决策机制、独立时变流评价或完整论文。

[已有LLM闭环工作](llm_control_prior_art_20261016_zh.md)已经包含反馈推理、数值辨识和策略检索等组合。
后续若让在线API提出实验或选择纠正，需要明确它比同信息、同预算的非LLM方法
增加了什么可测能力，并先冻结新的调用预算。不能为显示API参与而改变本次0调用结果。
