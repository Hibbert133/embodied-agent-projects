# A 主线的机制与查新复核 v2

2026-10-27。A“纠正后的适用性变化”为用户已经选择的主线，不重新询问方向。本次是采集前的文献及机制审查；没有新机器人数据、训练、参数搜索或在线 LLM API。原历史核试验的失败不因这份文件而改变。

## 当前证据能支持什么

已完成历史响应试验的预指定 HISTORY_KERNEL 在完整独立资格人口上输给 FIR：平均分配终点损失差为 +0.515457 毫米，组级区间 [+0.181516,+0.844589] 毫米；原门槛失败并封存。这个损失含不可用窗口惩罚，不是完整任务截止损失。当前状态基线还含系统上一帧与控制积分，不能称为无历史。历史核与状态核的距离维数不同，二者比较不是纯信息消融。见 [完整报告](../../reports/history_response_v1_zh.md)。

这能反对当前固定模型和配置进入反演／选择控制，不能证明所有公开历史、所有模型或 A 方向都无效。也不能把同一资格人口上另一模型较好，当作已经独立资格的新方法。旧 ARX、SS、固定时点积分清零、A1 及 FIR 的失败／不完整结论继续保留。

论文问题仍为：在获取改变物理状态、纠正改变随后动作与访问分布时，如何学习获取和采用决策，使完整截止损失超过强参考，并保留有效适应机会。数值合法性、预测能力、完整费用下的任务收益继续分别验收。

继承两项技能的失败边界与“最强反驳”检查，不把词语组合算作机制。以下是审查决定，不是机器人实验结果：

|候选描述|决定|原因／下一证据|
|---|---|---|
|纠正后命令重加权，再算信息增益|保留为强参考，关闭其独立新颖性措辞|已有任务／策略相关加权路线|
|只预测与决策相关的不确定性|保留为强参考，关闭其独立新颖性措辞|GoBOED 等已有；单纯改损失权重不足|
|用同状态上的各控制器动作组成核|保留为强参考，关闭其独立新颖性措辞|AOPS 已覆盖核心构造|
|把控制器和估计律一起展开预测获取价值|必要强参考，不能据此宣布新方法|轨迹参数化双重控制已经显式处理这种闭环|

A 主线保持开放，但当前没有通过审查的可部署新学习算法。因此**本轮不分配新机器人种子、不冻结新科学采集，也不运行训练或资格试验**。这不是取消用户目标，也不是请求再次选择方向；它是当前技术证据与贡献边界的决定。

## 下一件研究交付物必须达到的具体程度

下一机制需写出实际可计算的输入、更新律、训练目标、决策算子和停止行为，并完成与同权限强参考的等价性检查。若行为可表达为从同一公开入口选择有限个完整程序，通用完整程序风险／DR 已能表述目标；把它拆成“物理返回＋信息＋采用”不自动产生新估计能力。若额外结构是为了少数据、少计算或迁移到未见控制器，应把该资源／泛化差别定为可检验目标，而非声称标准决策理论表达不了本问题。

比较中应明确：入口与获取返回的真实公开状态、控制记忆及预算；纠正后未来查询如何在决定时预测；模型适用性如何影响实际采用／拒绝；拒绝后如何从已经改变的真实状态继续。任何返回值预测都不是实际执行收据。无法预测或不具支持的分支要保留，不补零、不用未来轨迹回填。

进入新采集前仍须单独冻结 TRAIN／CAL／自身历史最终评价、强被动和任务相关获取对照、完整费用、缺失／失败处理及必要消融。主要结果仍是完整新人口的截止损失优于 DIRECT_C8、积分和强廉价被动参考；成功率变化全部披露。原 QUAL 不调参，不能从旧有限菜单的事后最优收益推出可学习性。没有区别或收益就封存该候选。

本次文献与工程交付、测试数和远端存档均不满足 CCF A 目标。目标仍包括具体新机制、独立任务收益、强对照、消融及可供同行检验的证据。
