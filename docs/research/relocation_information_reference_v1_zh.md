# 移动过程本身提供的信息：后续比较的参考边界

本说明在积分重新探测资格采集之前写成。它是简单模型下的分析与强对照要求，不是新算法、MetaWorld物理证明或任务收益结论。

## 积分补偿能回答什么

考虑仅用于分析的无噪声、无接触、无饱和局部运动学：下一步位置变化为 `g·[A·(M·v+o)+b]`。A、b为未知执行器矩阵和偏移，M、o为保存的旧纠正，g>0。位置控制输入v由原比例/位移反馈加积分I组成；积分按 `I_next=I+ki·e` 更新，e为固定目标减当前位置，ki>0。

如果闭环收敛到有限且未饱和的静止平衡，则积分不再变化要求e=0，最近位移也为0，故v=I，且 `A·(M·I+o)+b=0`。A可逆时，保存的新偏移 `o_new=o+M·I` 等于 `−A⁻¹b`。这说明在这些强假设下，移动到位的积分本身已经包含零输入处的偏移补偿。

若随后固定该积分，用同一M执行任务指令u，则执行器输入为 `A·M·u`。因此即使偏移抵消，旧矩阵M不等于A的逆时，方向与幅度错误仍会存在。这不是仅凭一次静止平衡就能解决的。反过来，如果整个移动轨迹有足够独立的激励，它可能已经提供矩阵信息；不能预设额外8步才有这些信息。

真实程序仅要求位置与最近位移落在有限门槛内，还存在噪声、延迟、接触、动作裁剪、积分界限及提前终止，所以以上等式不直接适用于实测数据。保存的积分补偿只叫参考控制器，不叫已识别真值或置信保证。

积分与饱和现象均属于标准控制知识；见[Åström 与 Murray 的PID章节](https://www.cds.caltech.edu/~murray/FBS/Chapter_10_-_PID_Control.html)。上述平衡推导只用于明确项目里的信息来源，没有新颖性主张。

## 后续任务研究必须区分的比较

1. 原C8直接继续：既不支付移动，也不支付新探测。
2. 移动后仍用C8：隔离移动本身对任务状态的作用，支付全部移动成本。
3. 移动后使用保存的积分补偿：只用探测前实际积累的信息，不额外探测。
4. 使用完整移动轨迹的同模型估计：在适用范围和训练来源允许的前提下，使用已付费的全部轨迹信息；不能故意只给它一个积分数值。
5. 同样移动后做8步但不更新纠正：隔离测试动作本身的状态作用。
6. 同样移动后做8步，并使用独立训练、实际适用的中途模型更新纠正：完整支付移动、探测、拟合及离线成本。

比较3与6只能回答新估计相对于积分参考的价值，不能替代4与6的同数据历史信息比较。冷启动模型不能通过伪造重置标志用于中途轨迹。warm模型也不能直接扩展到未校准的长距离移动状态。模型适用范围、训练轨迹激励和动作矩阵可辨识性须先验证。

未来人口需要包含偏差不变、偏移变化、矩阵变化及渐变流，并继续保留原C8强基线；不能把只针对偏移变化的局部结果推广成一般适应能力。当前36次资格采集只检查重新取得测量的可执行性，未完成这些任务比较。
