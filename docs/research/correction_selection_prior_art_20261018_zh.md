# 纠正选择与任务价值的已有方法

任务相关获取、观测后的控制选择，以及纠正被接受或拒绝后的误差传播，均有既有路线。
当前同状态、多未来实验测量的是指定程序的任务效应；后继方法还需要给出区别于这些
路线的具体机制，不能仅将方差降低、回退规则或分支收益回归换一个名称。

## 已有方法覆盖的机制

| 原始来源与读取范围 | 已覆盖的机制 | 对本项目的约束 |
|---|---|---|
| [Task Optimal Exploration，ICML 2021，出版页摘要](https://proceedings.mlr.press/v139/wagenmaker21a.html) | 在线性动态系统中，按下游决策任务设计探索，并给出任务相关样本复杂度结果。 | 任务加权辨识已存在；本项目的非线性接触、固定程序和工作概率模型不自动满足其假设。 |

| [Trajectory Information Planning，NeurIPS 2022，出版页摘要](https://proceedings.neurips.cc/paper_files/paper/2022/hash/b90cb10d4dae058dd167388e76168c1b-Abstract-Conference.html) | 按任务最优轨迹的预期信息增益规划探索动作。 | 将未来轨迹纳入探测价值已有方法，不能只用“考虑未来”区别现有工作。 |
| [Poke and Strike，CoRL 2025，出版页摘要](https://proceedings.mlr.press/v305/aoyama25a.html) | 以特权任务政策对参数误差的敏感度构造奖励，训练探索政策，并以不确定性控制探索结束。 | 任务相关探索及停止已有组合；其额外政策训练和训练权限应单列，当前数值参考没有复现它。 |
| [GAUGE，2026 v1 预印本，第 III 节](https://arxiv.org/html/2609.32154v1) | 按规划器命令分布加权后验方差降低，并结合授权、验证停止、有界逆补偿及再校准。 | 固定不透明控制器与任务相关校准本身不构成差异；本项目的 TASK_IVR4 不是完整 GAUGE 复现。 |

| [Arcari 等，L4DC 2020，第 2 至 3 节](https://proceedings.mlr.press/v120/arcari20a/arcari20a.pdf) | 在场景树中更新模式和参数信念，再按每个场景已获得的信息优化后续控制。 | “预计探测后会选什么控制”属于已有双重控制思想，有限分支或标准价值回归不足以单独构成创新。 |
| [Donley 与 Moore，2026 v1 预印本，第 III 至 V 节](https://arxiv.org/pdf/2610.09207v1) | 传播基于规划器信息的估计误差均值和协方差，保留随机纠正分支间均值差产生的协方差，并构造任务加权风险。 | 增加接受／拒绝混合矩并非本项目新贡献。其简化递推依赖已验证范围、条件独立与两次重规划之间的开环评估假设。 |

也不提供穷尽的新颖性认证。GAUGE 与 ToIA 和当前问题的更早比较见
[既有查新记录](task_acquisition_prior_art_boundary_20261016_zh.md)。

## 数据决定接受与拒绝时需要条件量

Donley 与 Moore 的第 IV 节式 12 使用接受和拒绝分支的条件均值与协方差。
其后将分支量简化为纠正前量的递推时，假设纠正是否发生与实际估计误差在给定规划器
信息后条件独立。该假设有明确范围；本项目的拟合资格由实际响应数据决定，不能
直接借用简化递推，也不能仅凭这种依赖就断言实际独立性必然不成立。

一个标准条件概率例子说明这项检查的必要性。令纠正前标量误差 Z 以概率 2/3 取 −1，
以概率 1/3 取 2，因此均值为 0、方差为 2。只有 Z 为 2 时接受纠正，接受后误差为 0；
否则保留原误差。接受概率 q 为 1/3，纠正后的真实均值为 −2/3、方差为 2/9，
二次风险为 2/3。若将同一个 q 当作与 Z 独立，直接混合无条件纠正前矩和零误差矩，
则得到均值 0、方差和二次风险均为 4/3。

使用正确的条件分支量——拒绝均值 −1、接受均值 0、两个分支内方差均为 0——
即可恢复真实结果。这个例子没有满足上述独立性假设，因而不是对原论文的反例；
它只是条件期望与全协方差公式的应用，不是新的机器人理论或实际任务证据。

## 后继候选需要建立的区别

当前[冻结实验](../protocols/paired_probe_effects_development_v1.md)分别测量直接复用、
补测保留、补测严格更新和无效时回退。逐未来的损失分解只是指定程序之差，
未来重复只改善固定已实现隐藏状态下的测量，不能直接给出公开证据下的任务价值保证。

后继候选首先要说明：它怎样用决策时可见的数据预测总共 500 步预算剩余部分的任务损失，
怎样处理补测引起的状态变化，以及新纠正的有效性与任务效果。若只是标准分支回归、
方差加权或混合矩，应保留参考方法名称。

还需要核对训练历史与部署历史是否匹配。当前来源由固定 UNCERTAINTY4 行为形成；
改变复用或更新决策会改变后续缓存和可见历史。在该来源上评价一次建议，不能替代
候选方法按自身历史运行的独立时序评价。

最强固定程序和任务相关参考仍须保留；若进一步比较原论文算法，其模型、训练数据、
控制权限与完整费用也须明确。当前查新不选择主采集阈值、程序、样本量或种子，
不追加 API、仿真或选择器拟合。新方法、独立确认与完整论文要求仍按
[发表目标](publication_path_v1.md)推进。
