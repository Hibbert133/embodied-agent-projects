# 初始响应项未参与拟合：校准作用域与有效证据数

现有ForwardHistory需要两个已完成位移才能构造AR2查询。因此8步原对称
探测只拟合第3–8步：两次负x、两次正y、两次负y；正x响应没有直接进入
该条件似然。前两步位移仍作为后续查询的历史协变量，不能说它们完全被丢弃。
这里检查的是增加前两步自身的响应项是否有用。这不是传感器缺失，
而是观察模型的历史需求。

首先排除一个伪改进：相同固定特征Z、权重W、岭惩罚P下，令
S=(ZᵀWZ+P)⁻¹ZᵀW，则S(y₁−y₀)=Sy₁−Sy₀。直接拟合代价差和分别拟合后
相减完全等价；单独改变监督名称没有新的估计能力。裁剪顺序造成的差异
也不能当成信息收益。Dueling优势表示本身已有原文，不作为创新。

本后继改变证据模型：在独立、已知名义系统上，以事先确定的开环随机
命令校准重置后8步的因果响应矩阵。给定受控重置的当前观测，使用全部
8个真实位移做联合工作似然；不补虚拟零位移，不读取隐藏状态或测试真扰动。
矩阵下三角，未来请求不能影响过去响应。名义校准与新测试都使用0.05
执行噪声，连续高斯裁剪均值仅作工作模型，非实际浮点噪声定律的证明。

同数据ARX8和联合模型丢弃前2步是必要对照，分别区分校准数据与早期信息。
首次只做独立辨识资格检验，不把参数更准直接当任务收益。有限时域Markov
响应与广义最小二乘都是标准系统辨识方法；本阶段不声称新颖性或概率保证。
若组件通过，仍需独立任务、预算选择、时序变化及完整文献比较。

此前只查动作一致/平滑的路线也不能直接作为新贡献：
[HEC决策区域](https://proceedings.mlr.press/v33/javdani14.html)、
[策略平滑](https://arxiv.org/abs/2106.11420)、
[动作空间回报认证](https://arxiv.org/abs/2312.06436)均已有相关方案。
这里只核对其公开原文范围，未复现或继承其保证。当前代码没有可用于
完整任务代价的校准尾价值，不能掩盖此前RFF与尾价值组件的失败。
