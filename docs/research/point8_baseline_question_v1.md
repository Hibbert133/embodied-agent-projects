# 应先排除的混杂：探测数量与纠正规则

已完成尾价值组件未通过：全轨迹剩余步RMSE改善到80.27，但同状态两个
Gaussian候选的差MAE28.19差于恒零预测27.73；离线选择94/96差于总更新
95/96。不能据此继续调原RFF或选择后验阈值。

下一步先补一个必要基线，而不是把新的回归器当作创新：原对照8步为
Gaussian纠正、16步强基线为点估计；8步点估计是否已经足够尚未实际测量。
主比较只换探测数据量，使用相同点拟合与逆补偿；KEEP_POINT8_AFTER16
再将额外探测的物理运动与用于估计的新数据分开。

这是标准控制方法补齐。状态价值/动作优势分离已有
[Dueling网络](https://proceedings.mlr.press/v48/wangf16.html)，
任务导向探测已有[Liang等](https://www.roboticsproceedings.org/rss16/p085.html)，
高置信价值误差估计也有[Sajed等](https://proceedings.mlr.press/r16/sajed18a.html)。
已核对官方摘要；没有借这些摘要声称完整复现或继承保证。不能将直接学
候选差、加入风险项或多做几步探测本身包装为新贡献。

结果将决定当前静态仿射基准留下多少实际交互预算改善空间。若便宜点
估计已解决多数任务，应在未来方法比较中保留它；若增加测量有效，也须
区分估计改善与探测造成的状态改变。无论结果如何，新选择机制、未知
有效性的处理、独立时序变化/多故障评价以及完整论文仍待完成。
