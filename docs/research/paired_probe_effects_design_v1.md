# 同一状态的探测动作与参数更新效应

既有时序比较表明：少做探测不等于任务总损失下降，历史查询IVR又接近每次测8步。
新工具已通过注册条件的物理恢复资格。下一步需要确定局部信息分数遗漏的是
什么任务效应，并分开固定状态的未来噪声与不同状态的效果差异。

这是一项机制测量，尚未提出新选择器。以下均是标准控制和统计方法，不作为
创新声明：[GAUGE](https://arxiv.org/html/2609.32154v1)已有规划器命令测度下的
方差获取与再校准；[ToIA](https://arxiv.org/html/2609.19378v1)已在相同候选轨迹上
结合未来模型查询和任务代价；[Arcari等](https://proceedings.mlr.press/v120/arcari20a.html)
已有场景树中的后续辨识与控制。因此任务权重、运动代价或显式后选择本身不足以
区别于已有路线。本轮补充的是本项目尚缺的同一真实状态、多未来的程序效果证据，
不声称复现这些论文的完整系统或穷尽查新。

## 可核对的程序效果

在本方法较早成功参数缓存仍存在、且当前实际完成4步探测后仍未结束的状态，
比较R沿用旧控制、P再测4步仍用旧控制、U再测4步更新（无效即停）、K再测4步
更新（无效保留旧控制）。P、U、K共有相同额外物理前缀；更新计算只使用已观察
8步，不使用真实扰动。R与P的差异包含运动、4步费用和后续状态变化。

设失败／停止的截止损失为500，成功计全部实际逻辑步骤。对同一未来逐样本有
R-K=(R-P)+(P-K)。P-K是指定估计器及拒绝规则的更新效应，既不是纯信息价值，
也不是最优后验行动的价值。U/K同时保留，防止用无效即停的弱行为夸大更新效果。

先按冻结UNCERTAINTY4实际形成来源历史，且立即根据该次实际结果写／清缓存。
评价者未来全部新生成，不能进入后续来源历史；评价完成后恢复实际来源结束状态
及全局RNG。各程序的评价结果不写缓存，也不反过来选择来源行为。

## 可以估计什么

未来重复估计固定隐藏状态和给定旧参数下的程序效果，不自动等于代理证据e下
的条件价值。新未来与完整已实现来源历史独立；每状态8个，四程序共享相同未来。
保留单状态的Monte Carlo标准误和正负方向同时出现的情况，不把它们当校准证书。

跨有限已实现状态的均值协方差减去平均“未来协方差／重复数”，是标准噪声修正
恒等式；可为负，不做PSD裁剪。它不是固定e下不可约不确定性的估计。公开证据
的可学习性、源／部署历史分布变化、成本合理的新机制仍待单独建立。
