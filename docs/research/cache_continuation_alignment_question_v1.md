# 从同一4步前缀核对当前任务的获取收益

本页在全量时序参考采集完成后形成，属于后继开发设计，不是原实验的注册
比较，也不改变原来的四项比较、方法或结果。尚未冻结或执行本页的新分析。
基础依据是程序依赖与状态一致性，不声称新理论或新算法。

## 特殊情况：重新估计后的当前任务不使用旧缓存

不同方法通常有不同的历史缓存，不能直接把某一方法的结果当成另一个方法
在同一历史下的替代分支。但当前冻结程序存在一个需要单独核对的特殊情况：

- ALWAYS8的物理程序为BLOCK8，然后仅根据当前实际8步前缀和冻结联合模型
  估计纠正参数，再执行固定政策。旧缓存不参与这些物理指令或新估计。
- CUSUM4、PLUGIN4、UNCERTAINTY4、TASK_IVR4有缓存时先执行同一个BLOCK4。
  若在第4步选择REFRESH8，余下探测和当前任务执行程序应与ALWAYS8一致。
- 各方法在同一任务单元具有匹配的受控初始状态和按物理步排列的噪声带。
  这个条件需要用实际记录核对，不能仅凭相同种子或名义动作断言。

因此，在上述条件全部成立时，ALWAYS8可能提供“当前历史选择重新获取”
的当前任务结果，尽管其进入单元前的缓存来自自己的另一段历史。这个
替代只适用于不使用旧缓存的续接，不适用于任意方法或后续整条任务流。

前缀相同也不能单独保证可替代：还须核对政策查询无持久内部状态、额外
查询不会改变环境或随机数，以及估计器、预算、停止语义和噪声时钟一致。
现有源码和记录是待核对证据，不把本页推断当作已完成的兼容性审计。

## 目标与两种不同记录

令h包含当前可见4步前缀、自己较早验证的缓存及剩余预算。目标是当前任务：

    d(h, omega) = L_reuse(h, omega) - L_refresh(h, omega)

omega表示本单元已经实际执行的一条共同未来噪声带。两项损失都含已发生
的前4步；相减后这段共同费用抵消。新增4步及其状态影响保留在刷新项中。
这只是一个共同未来下的实现差，不是条件期望Delta(h)的精确观测。

两类记录必须分开：

1. 实际选择RUN_CACHED时，若兼容性成立，可以比较实际复用结果与ALWAYS8
   的实际刷新结果。这是已执行行为选择的复用区域中的评价者配对标签。
2. 实际选择REFRESH8时，当前方法与ALWAYS8的后续实际轨迹和结果应一致。
   这是续接可替代性的负控制；它没有提供未执行的RUN_CACHED结果。

不能把STALE或其他方法的复用结果补到第2类：其缓存参数与历史通常不同。
不能把数值停止写成缓存执行，也不能把未执行分支当成在线自然经验。

## 必须机械检查的纳入条件

未来独立分析需为全部源案例保存纳入／排除理由，至少检查：

1. 来源为已通过记录和独立统计审计的完整主实验，所有源SHA固定。
2. 当前方法属于上述四种BLOCK4参考；初始保存动作是CHECK4，入场缓存
   非空且来自本方法较早实际成功。冷启动PROBE8不是同一决策目标。
3. 实际执行完整4步FIXED_PROBE，第4步仍未结束，保存的后续动作明确。
4. 与同一任务单元ALWAYS8的初始观测、初始物理见证、前4步发送指令、
   可见响应、噪声前后哈希及第4步物理见证严格匹配。
5. 刷新分支的剩余探测、冻结模型、估计接口及政策一致。若探测提前成功，
   保留真实提前结束；若新估计无效，保留真实停止及500的截止损失。
6. 在实际REFRESH8案例上核对后续指令、可见轨迹、噪声时钟与当前任务结果。
   任何不一致都使该替代关系失败，不能用接近的成功率掩盖。

BALANCED4的暖缓存检查采用不同程序，不能借用ALWAYS8的前4步；必须排除
或另有真正匹配的参考，不能以维度相同或轨迹接近代替匹配。

## 不得运输的对象与统计限制

刷新后的旧缓存续存、写入事务和下一单元的历史，不能直接从ALWAYS8复制。
特别是探测提前成功且没有新拟合时，两个方法应保留各自的旧缓存。因此
本分析不识别整流反事实价值，不决定未来多次任务的最优刷新规则。

复用标签只存在于原行为确实选择复用的区域，具有行为选择限制；不能把
该子人口上的平均差当成所有当前历史上的获取收益。每单元也只有一条
未来噪声实现，不能由符号稳定性或单次改善宣布可学习的条件任务收益。

多个行为方法可能共享同一条ALWAYS8参考结果，且流内缓存依赖过去任务。
分析不能把新增配对行数当独立样本数。v1应先报告完整纳入流程、全部
逐例差、兼容性负控制及描述性计数，不作新的确认性检验或训练选择器。
