# 诊断后研究路线的查新边界

核对日期 2026-10-20。读取指定版本的摘要及模型适用范围／OCCAM 正文相关段落；
下表是原文机制与本项目的关系，不是完整复现、穷尽查新或新颖性认证。

| 路线与原始来源 | 原文已覆盖的机制 | 本项目仍须证明的区别 |
|---|---|---|
| [模型适用范围，ICRA 2024](https://arxiv.org/html/2401.04007v2) | 学习状态与动作上的模型偏差估计，并主动选择任务相关轨迹；分别评价适用范围准确性、可规划性与实际成功。 | 不能把“判断模型是否适用”本身当作新机制。需要明确获取后的实际状态如何改变后续采用／拒绝与完整任务价值。 |
| [Residual RL](https://arxiv.org/abs/1812.03201) | 将传统控制器与学习的残差控制结合，用于存在接触、摩擦等建模困难的任务。 | 固定幅度混合或在旧控制上加新控制只是必要工程基线，不能声称一般残差混合的新颖性。 |
| [OCCAM](https://arxiv.org/html/2406.17620v1) | 元学习表现模型及在线估计支持控制器参数适应，关注控制表现而非必须恢复物理真参数。 | “收益预测优于参数准确度”已有研究；本项目须处理获取动作的状态位移、适用性变化和完整获取成本。 |
| [GAUGE](https://arxiv.org/abs/2609.32154) | 规划器条件化的主动校准、任务相关不确定性降低及验证／停止，受稳态响应条件约束。 | 不能把任务加权探测、验证停止或有界逆映射当作新贡献；需说明移动瞬态、历史依赖与采用纠正后的状态如何进入决策。 |
| [Poke and Strike，CoRL 2025](https://proceedings.mlr.press/v305/aoyama25a.html) | 学习任务知情探索策略，以任务策略敏感性构造探索目标，并按不确定性停止。 | 任务相关探索和停止并非空白。需要与真实执行、计费、回退以及模型可能失配的获取决策区分，并实际比较。 |

当前潜在问题是：获取动作同时改变物理状态和模型适用性时，能否减少错误更新、
保留有效适应机会，并改善包含移动、验证、探测及失败费用的完整任务损失。
这仍是待研究的问题，不是已建立的贡献。原文中已有轨迹顺序依赖的讨论也意味着
不能笼统宣称“首次考虑获取改变状态”。必须给出精确机制、同权限同预算强对照、
独立时序部署与消融结果，才能判断具体区别是否成立。

本次负结果、只读诊断及后续标准模型资格协议都不替代上述证明。没有新增在线 LLM
决策 API、机器人交互或模型训练；网页原文访问属于查新读取。
