# 新相关工作与高斯参考的边界

2026-10-15 阅读 [GAUGE，2026-09-26 v1 预印本](https://arxiv.org/html/2609.32154v1)
第 III 节及实验范围：它已将任务指令分布用于固定、不可访问底层控制器的
外部响应校准，用条件方差减小选指令，再以验证停止及有界逆部署。把“冻结
技能＋任务相关探测＋纠正”组合起来不足以作为本项目创新。

本参考只适配其有限指令任务 IVR 与有界逆目标，使用二维 MetaWorld 可见
瞬态位移和旧名义模型的局部 Gaussian 信息。原文使用稳态速度量测、独立
轴 Bayesian 回归及完整授权／验证生命周期；当前使用耦合六参数局部矩，
没有复现其验证门或硬件。不能移植原作的误差、非劣界或监控保证。

高斯矩二次控制是标准均值／协方差决策；任务加权方差减小也与
[Task-Optimal Exploration](https://proceedings.mlr.press/v139/wagenmaker21a.html)
已有方向一致。条件解析正确不等于名义模型在物理接触数据上正确。

早期八步及真实继续分支用于回答此前弱可见前缀是否限制收益判断。更早
测量或更灵活的试验程序本身不是新颖性；需要明确机制、可靠目标与强基线
竞争证据，才值得另行提出并确认后继方法。
