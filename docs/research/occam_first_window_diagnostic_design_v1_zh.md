# 首窗口全候选诊断：独立资格结束后的设计稿 v1

2026-10-28。DESIGN_ONLY，不是新采集或新科学门。不改变当前 QUAL，尚无
此诊断结果。本页只用冻结程序定义与源码作设计，没有读取 QUAL 结局。
未来全部新增结果必须标为**事后描述性分析**，不替换原主比较或结论。

## 问题与证据边界

当前主要预测门用接收者实际选择窗口的MSE；它不能直接说明四候选排序
正确，也不能说明局部势差费用的贪心排序适合完整任务。数值合法、当前
预测能力和含全部获取费用的任务收益仍分别判断。

拟分别检查：

1. 在同一获取后真实起点，已保存的四候选预测能否排列实际首窗费用？
2. 四个实际恒定增益程序中，首窗费用排序与完整截止损失排序是否一致？
3. 学习接收者与其首个所选固定增益程序的实际首窗是否逐字节一致？

第2项只是恒定增益完整程序族中的对应关系。另一个接收者后来会换增益
并更新后验，因此不能将某个恒定增益的终局贴给它；也不能把事后最小
截止损失当作可实现政策、收益下界或可选择的赢家。

## 数据门与完整人口

只有同一当前 run 的 QUAL1566 收集完整、进程／完整记录审计以及原统计
计算／独立复算的完整性均通过且主结果不可变后，诊断 reader 才可读取。
不要求科学任务资格门通过；负结果同样保留并诊断。未收集、
部分、技术关闭或审计失败均拒绝，不能从运行前缀做该分析。
所有1566方法执行及失败登记；NATIVE174另列，不混进独立九组统计。
诊断分配为9组×3任务×2条件×3获取动作＝162个获取后起点，时点由组固定。

每起点涉及原24个同前缀程序的对应一组：同获取动作下4个固定T和4个
学习接收者。GLOBAL与原C8／积分等其余强参考在原完整结果中全部保留；
这里只因起点不同而不用于首窗同起点四T排序，不能从主比较删去它们。

## 对齐规则与缺失

对每个起点，在同一个已分配获取动作内部核对：初始与获取后原生状态／
RNG见证、公开query SHA、实际时钟／噪声游标、完整任务记忆及16步计划。
不可只看观测位置近似相同。模型始终只使用公开信息；私有见证仅用于
评估端对齐，不输入模型。

所有同前缀程序在第一次增益决定前均保持T=0.5、执行相同获取过程；
若提前结束没有首窗，应保留“无决定”的共同事实。若应对齐却不对齐，
标记原因，不用最近观测、另一方法、模型预测或少一项候选补齐。
不同T的实际首窗长度可以因提前成功而不同，按原计划16步及实际终止
语义保留费用；不能丢掉短窗或按步数除回去挑有利口径。

学习接收者首个已保存声明为版本0，ADAPT与FROZEN在同一bank的首个
查询前尚未更新。应核对其声明一致性，但仍登记全部方法而不虚报独立
预测样本数。所选T与对应固定T的首窗rows SHA／实际测量核对相同；失败
时明确记录对齐缺口，不靠重新推进环境“修正”。

## 固定诊断量（无通过阈值）

- 四候选预测与四个事实首窗费用的完整向量、均方误差；来源TRAIN全局
  常数参考保留。未执行的NN候选标签仅取实际固定T对齐窗，不由模型补造。
- 模型所选T的事实首窗费用减四T最小首窗费用，称“首窗选择差”，不是
  任务遗憾、可实现收益或完整风险。预测在先的原始证据仍由原冻结审计提供。
- 六对候选的排序错误：实际费用相等的对单独登记、不参与分母；预测相等
  而事实不等计0.5，反序计1、同序计0。全部事实相等则比例缺失，不填0。
  直接使用保存float值的相等关系，不根据结果挑容差。
- 同一四T族首窗费用与完整截止损失的排序关系及完整向量，保留全部
  成功／失败和500惩罚；不得再次另加已在完整截止费用里的获取开销。
- 所有模型、任务／条件／时点／获取层完整展示。先在起点计算，再组内
  平均、组间等权；缺失与分母显式登记，不将六个候选对当独立样本。

不使用该诊断产生新的显著性门、重选主方法／bank／获取动作、调阈值、
筛困难任务或挽救原失败门。对“预测准确但短窗目标不适合”的解释应同时
展示支持与反例；这些对应关系不唯一识别任务失败原因。
