# 利用整段移动记录的参考：接口与验证范围

上一轮[附近点辨识](../../reports/selected_response_identification_v1_zh.md)在冻结源
`6db2a76`上未通过门槛，结果提交为`3286b7f`。本阶段补齐后继强基线需要的数据接口，
不改变旧模型、门槛、控制器、结果或任何保留种子。

`MOVEMENT_ARX_ALL_V1`可以理解成“用整段移动记录估计动作偏差”。这里的整段是
机器人移向测量点的连续移动段，最多64步；另外保留移动开始前三帧真实观测，
用于形成两次真实位移。它不概括任务开始以来的全部历史，更不是聊天记忆。

ARX参考用之前的位移和当前发送的动作预测下一次位移，再通过预测误差估计动作
矩阵与偏移。计算复用仓库已有`LINEAR_ARX`与`infer_operator`，没有把标准辨识
换一个名字当成新算法。仓库已做过滚动被动更新的独立比较，见
[九方法报告](../../reports/strong_chronological_reference_development_v1.md)；
本接口针对的是中途移向测量点的轨迹，不重写那个已结束的实验。

## 已实现的边界

- 严格输入只有任务、实际开始步、决定步、三帧上下文、逐步请求动作和前后观测。
  39维观测及全部四个动作分量保留，竖直和夹爪指令不被悄悄改成0。
- 每一个移动响应都生成一个估计项，包括最初两步；前两次位移来自实际历史，
  不补零、不重置、不伪造冷启动、不把旧平面八步窗口扩展成任意轨迹。
- 时间步必须连续，前后观测必须衔接，最多64个移动步，决定时刻不得超过400步。
  未知字段、真值字段、未来结果、终止后动作与非有限数值被拒绝。
- 归档适配器只读到第一条已保存的`RELOCATION_EVIDENCE`。请求必须先于实际执行，
  执行完成必须先于结果记录；后面的`PROBE_ENTRY`、探测响应和任务结果不读取。
- 已完成或终止的案例返回`ENDED_NO_UPDATE`，不再拟合。没有移动的案例保留空结果。
  其他案例复用既有估计器的样本数、秩、优化与逆矩阵域检查，完整记录无效原因和
  优化计算次数。当前函数只返回诊断估计，不执行控制器或虚构保留策略的任务结果。

数值接口不能证明调用者提供的数据来自真实机器人；这由独立审计的主机记录与
来源哈希负责。三个上下文观测指向开始步之前的两个已完成动作和当前观测。
主机`logical_step`使用动作前的零起点时钟，响应对应其加一；这个约定有专门
回归测试。开发中的首次归档读取发现这一索引差异并拒绝输入，修正后通过测试；
没有重跑科学实验或覆盖历史结果。

## 已封存数据的工程回放

回放来源仍是上一轮288次资格执行，**不是新独立验证数据**。绑定原清单、五个
封存数据文件与已通过的记录审计后，重建252段实际移动历史，共7,735条响应；
另36例没有移动操作，17段在截止时已经任务成功。其余235段均至少有六条响应。
从原物理记录独立索引复算每一项的两个历史位移、当前观测、四维请求动作和
实际响应，与数值接口输出完全一致。

工程回放不在这些历史资格数据上拟合新的执行器参数，没有计算新效果比较。
新增科学仿真、策略查询、名义模型训练、参数估计和API调用均为0。相关记录见
[回放摘要](../../outputs/movement_history/replay_v1/analysis_v1/summary.json)。
软件测试另使用明确标注的合成AR2例子验证已有估计器的接入与信息边界；合成恢复
真值不构成MetaWorld上的辨识资格。全仓库测试中的仿真夹具费用另行保存。

本阶段新增16项测试；完整测试集1,341项全部通过，另通过编译、依赖、秘密扫描与
差异检查。测试起始时保存了全部源码哈希，交付复核检查源文件在测试期间没有变化。
检查结果及软件夹具计数见[交付复核](../../outputs/movement_history/validation_v1/delivery_review.json)。

## 尚须完成，不能直接推广的部分

旧ARX名义响应是否适用于当前移动状态、动作和闭环历史，仍需独立检验。
现有ARX系数字典自身没有任务来源标签；在线调用主机还必须绑定每任务模型及其
训练出处，不能仅凭系数形状相符就认为来自正确任务。
估计在数值上有效、输入矩阵满秩，均不能消除隐藏状态、反馈混淆、接触和裁剪带来
的模型失配。当前估计假设移动段内有同一个有效动作映射；未知的中途变化需要另行
处理，不能由评价器告诉方法真实变化时刻。旧名义源的完整费用与未知工厂费用必须
保留，不得因为复用已有文件就记作免费。

后续在线主机还需要在探测之前保存历史快照与拟合结果，并在实际任务续跑中消费
所保存的选择，拒绝更新或保留旧控制器的规则也必须事前冻结。新任务协议仍须对照
原C8直接继续、移动后C8、移动积分、整段移动估计、探测但不更新和探测后更新。
比较须计入全部移动与探测步数、提前成功和无效更新，不以辨识惩罚替代任务损失。

本阶段没有取得新的物理辨识或任务收益资格，没有新的LLM调用。它补充强基线的
可实现性，不完成新的获取决策机制、独立时序评价或完整CCF A论文要求。
