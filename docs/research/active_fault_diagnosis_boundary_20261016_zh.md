# 主动故障诊断原文核对与后继贡献边界

本页在时序主实验采集期间补充原文核对，不改变冻结方法、阈值、人口或
已登记比较，也不使用主实验的部分结果选择方法。

[Cheong与Manchester，2013，第二至三节](https://arxiv.org/html/1310.7262v1)
已在有限LTI候选模型、Gaussian初态与扰动假设下，以提升模型可区分性
设计有限时域输入，并考虑幅值、能量及辨别概率约束。因此有限时域响应
表示、减少诊断输入代价、补足输入激励，本身不是本项目创新。

[FIERL，2024，第四至六节](https://arxiv.org/pdf/2405.04938)
将被动故障估计与主动输入策略分开，使用受约束RL改善诊断并限制跟踪
偏离，处理连续故障参数及测试时跳变。其策略在训练与部署都遮蔽真实
状态／故障，但示例训练奖励包含对真实故障的估计误差。不能误称其将真
故障直接给策略，也不能把“诊断与策略分开”或“兼顾控制”当成新颖之处。
式18已有故障演化协方差累加；仅增加缓存年龄的方差膨胀仍不足以创新。

[Cao等，2024，出版摘要](https://pubmed.ncbi.nlm.nih.gov/38019630/)
明确把控制目标与诊断输入设计联系，用轨迹优化和物理约束协调两者。
此项只核对摘要和出版信息，未阅读全文，不移植其算法或保证。

这些原文与既有GAUGE、ToIA、HEC、事件触发学习及任务导向试验设计
核对一起，约束后继问题：需要具体说明尚未解决的困难和可执行机制，
不能仅把固定技能、探测成本、缓存和变化检测组合成新名称。

## 当前参考不能替代的强比较

TASK_IVR4只使用当前一个政策指令，不是具有规划器查询分布的完整GAUGE
复现。PASSIVE_RECENT8在设计不充分或新拟合无效时停止，没有实现“缺少
激励时跳过更新并实际继续原控制”的近期辨识版本。因此本批结果不能
支持优于所有任务导向获取或近期辨识方法的结论。

未来强比较需要同权限的任务查询分布参考、合理的缺激励处理及完整费用；
必须在新协议中真正执行，不能把当前停止案例事后补成一条成功分支。
这些是当前投稿缺口，不是根据主实验结果降低或提高的门槛。

本页是有针对性的原文核对，不是穷尽查新，也未确认新方法贡献。
