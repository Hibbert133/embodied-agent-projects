# 决策改变查询分布：进一步的已有工作边界

本页在强标准参考主采集进行时形成，不使用部分主实验分数设计方法。当前所有
控制规则、人口、25%阈值、窗口和统计代码保持冻结。以下是原文核对与对本项目
的推断，不声称穷尽查新、提出新算法或完成完整论文目标。

## 模拟器辅助探索不是空白

[ASID，ICLR 2024公开PDF](https://openreview.net/pdf?id=jNR6s6OSBT)使用初始近似
模拟器设计探索，利用实际采集的数据改进模拟器，并在其上求解后续任务政策。
它使“先用模拟器指导探索、再估计并执行”成为必须比较的已有路线。若未来
引入数字孪生／模拟参数后验，须披露额外模型、探索训练和任务政策训练权限。
本项目目前的固定底层政策与短响应模型不等同于该完整系统，也不能因此把
相似的多阶段流程称为新颖机制。本次核对公开PDF的摘要和方法描述，未复现ASID。

## 分布随决策变化也已有优化路线

[Miller等，ICML 2021第4.2节](https://proceedings.mlr.press/v139/miller21a/miller21a.pdf)
已有先通过实验设计估计分布映射、再优化performative risk的两阶段方法。
因此仅增加一个“预测决策怎样改变未来查询分布”的模型，并不足以建立新算法。
其统计／优化假设也不能直接套到本项目的接触任务或未获概率资格的响应近似。

[Mandal等，ICML 2023](https://proceedings.mlr.press/v202/mandal23a.html)的performative
RL定义涉及部署政策影响环境的奖励／转移规律。对本项目的判断是：当前单元内
扰动固定，单元间变化预先外生生成；改变控制器导致访问不同状态，是通常的
政策诱导占据分布变化。不能仅凭这一点声称已经实现了该类政策依赖环境模型。
本次对这篇只核对官方摘要与引言，不继承其收敛保证。

## 还需建立的对象

GAUGE已经使用任务查询加权IVR，ToIA已经在候选轨迹上联合考虑任务和学习。
新历史查询参考只是声明一个可获得的经验任务测度；它没有未来轨迹模型、
任务回报差估计或新颖性资格。若后继使用查询分布的闭环反馈，仍须给出区别于
上述已有方法的具体机制、相应数据权限与可检验的性质。

短响应模型仍不能默认为完整任务世界模型；库的checkpoint也不等于完整物理
状态快照。需要的实际分支／多未来证据必须在新协议中获得，不能把旧的单次
实现差直接当作条件期望，或用评价者未来数据冒充部署时自然可得的记忆。
