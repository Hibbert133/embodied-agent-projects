## 具体发现

当前获取前学习器，对同一 H/a 数据、组权重、标准化、RBF 中心和正则化，
分别拟合 M（屏蔽后的完整风险）与 D（额外轨迹效应），最后以 M+D 预测释放风险。
标准 DR 完整程序风险对照可以对相同 M 与 F 伪标签直接拟合，其中 D=F−M。

令 A=ΦᵀWΦ+Λ。特征和 Λ 不依赖标签，且这里均相同，所以在精确算术下：

```
βM + βD
= A⁻¹ΦᵀWM + A⁻¹ΦᵀW(F−M)
= A⁻¹ΦᵀWF
= βF
```

因此两个方案在任意新 H 上给出相同的完整风险，裁剪和选择之后也是同一个
政策参数化。CONTINUE 空轨迹分支已知 D=0，同样没有新增区别。CAL 对这些
预测做同一选择，也不能产生新的机制。浮点极近的并列可能改变个别选择；
这种数值差异不能拿来证明研究贡献。

这条结论针对**当前获取前 M/D 岭回归学习部分**，不否定采集后随机释放记录
作为一种实验设计的可用性，也不证明未来所有结构化方法都与标准对照等价。
它说明目前只有普通 factual-Y 回归对照还不够：若只战胜它，优势可能来自
已有的 DR 估计方式，而非本项目声称的学习结构。

## 来源与复算

DR 用于政策评价与学习早已有研究，见 [Dudík、Langford、Li，ICML 2011](https://arxiv.org/abs/1103.4601)。
上面的代数是标准线性性，本项目没有提出新统计定理。以信息传递影响下游
行为也不是新问题，见 [Chitnis 等，CoRL 2018](https://proceedings.mlr.press/v87/chitnis18a.html) 的出版摘要；
本次未通读该文方法，不据此作更强排除。此前用户指定五条路线及 DISaM、
OCCAM、CPC、MIPS 的读取边界继续有效。

复算入口 `src/analysis/release_learning_equivalence_v1.py` 只使用一组构造数组，
通过当前实际回归代码检验中心/权重相同、系数和预测的恒等关系。只有三次
合成数值求解，不是六个机器人样本、独立统计重复或新的大规模理论参考实验。
一般结论来自上述代数和源代码的共同条件，不从几个数值点外推。
