# 从局部响应走向任务价值：当前组件问题

上一轮随机近期效应并不决定最终任务收益；更接近注入参数的逆补偿也可能
让任务变差。现在检验：因果可见历史和已知纠正器，能否预测继续使用该
纠正器的剩余截止损失，尤其能否区分同一历史处的两个Gaussian纠正器。
这不是把此前失败的8个上下文RBF换参数后重试，而是固定新组件问题，
使用完整轨迹终局监督，并保留廉价常数及去纠正特征对照。

政策表示作为价值函数输入是已有路线，见
[Tang 等的 PeVFA 原文](https://arxiv.org/abs/2010.09536)。
这里输入的是固定底层政策外的纠正器命令行为，不声称复现该文算法。
随机傅里叶特征也是标准近似，见
[Rahimi 与 Recht 原文](https://papers.nips.cc/paper/2007/hash/013a006f03dbc5392effeb8f18fda755-Abstract.html)。
两篇官方摘要已核对，当前组件不能据此声称方法新颖或继承理论保证。

本轮仅在已观察来源内整流留组验证；时间步不是独立样本。MC终局标签
有噪声，观测是部分历史，同一流又有任务/未来依赖。回归误差并不是价值
误差上界；恒定纠正器尾价值也不等于“执行有限新选项后回旧基准”的价值。
后者仍需合适的后继历史支持、基准尾监督与独立前瞻任务收益验证。
失败应停止此冻结候选晋级；通过也只允许制定下一独立协议。
