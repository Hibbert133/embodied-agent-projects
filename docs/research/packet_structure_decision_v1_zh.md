## 候选与筛除

| 候选 | 判断 | 原因/后续要求 |
|---|---|---|
| 再增FIR阶数/自由参数 | rejected | 当前已比较自由因果形式；旧QUAL不调参 |
| 只保留push或door | rejected | 删除reach会破坏全部任务规则 |
| 更大网络替代同一失败头 | rejected | 没有新的可辨识机制，不重开旧GRU/SS |
| 共享加性残差修正差异预测 | rejected作为该局部论点 | 同入口差值抵消；不否认已有方法绝对预测/闭环结果 |
| 普通在线RLS局部增益 | deferred为强参考 | 标准辨识，不是单独创新 |
| 公共历史条件的乘性响应 | deferred为资格参考 | 须证明历史能预测，不能由误差存在推导可识别 |
| 获取后状态条件的模型适用性 | deferred | MDE/OCCAM邻近；需要超出组合的具体区别 |
| 获取动作后的联合信念/状态规划 | deferred | POMDP/任务相关探索已有；先建同权限强参考 |
| 纠正后访问分布与输入支持 | retained主问题A | TOM/performative prediction已知，普通重加权不算贡献 |
| 事后表示下界/原生夹限分解 | accepted本轮产物 | 0新增交互、能改变下一模型类别判断；本身不新颖 |
| 以负结果报告替代算法目标 | rejected | 不满足用户对方法和任务优势的要求 |
| 改困难条件以制造获取优势 | rejected | 须有独立现实动机与预注册，不能为赢而改基线/人口 |

## 新查的主要来源与阅读范围

- [Schoukens等，2016/2018](https://arxiv.org/html/1804.09587v1)：已读官方摘要及
  非线性检测/噪声、BLA输入依赖相关段落。对称/激励相关失配是已有路线，不声称复现其实验。
- [Schoukens等，Automatica2005](https://www.mit.bme.hu/system/files/oktatas/targyak/9132/Identification_of_linear_systems_with_no.pdf)：
  已读摘要、设定、4.3–4.4，特别是执行器非线性混淆与重复周期噪声分离条件。
  我们的短脉冲/单次耦合不具备其完整条件。
- [Feedback World Model v2，2026](https://arxiv.org/html/2605.15705v2)：已读摘要、4.2–4.3、
  附录A关键残差递推/假设、附录M增益段。反馈残差与动作相关引导已有；其收敛要求
  残差有界并趋稳及增益稳定，不能直接移植到本项目。本次不复现其基准或成功率。

旧MDE/Residual RL/OCCAM/GAUGE/Poke and Strike/TOM/AdaptOn/任务相关校准与完整
程序DR参考继续有效。本轮查新非穷尽；读者不能把检测到结构失配当作贡献成立。

## 预先写明的判断边界

若偶分量小，不能仅凭FIR失败就要求复杂非线性输入模块；还需解决历史/参数/
状态条件的反对称响应泛化。若偶分量大，同入口线性映射也有表示限制；但仍须
区分实际执行器/原生夹限、未知状态、接触与噪声交互，不能认定唯一原因。
若原生目标分量大，只支持显式考虑原生接口约束的资格需求，真实原生状态仍是
评估端私有，在线方法必须独立证明可见历史可估计。任何情况都不自动解锁新采集。
