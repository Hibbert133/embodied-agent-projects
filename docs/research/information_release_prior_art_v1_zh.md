# 随机释放候选查新与读取边界

核查日期：2026-10-23。下面只使用原始论文/出版页。读取章节、摘要与作者
结论分开；没有复现任何外部方法。表中“约束”是本项目判断，**新颖性尚未成立**。

| 原始来源 | 本次实际读取与已有路线 | 对候选的约束 |
|---|---|---|
| [模型适用范围，2024](https://arxiv.org/html/2401.04007v2) | 摘要、III–V 的设定、MDE 与轨迹获取：以真实序列学习模型偏差及适用范围，并处理后段可能不可达。 | 状态相关适用性和任务相关采集已经存在；当前原型不宣称获得一个合格的响应模型。 |
| [Residual RL](https://arxiv.org/abs/1812.03201) | 本次出版摘要，已有报告保留先前阅读：传统控制与学习残差叠加。 | 控制修正、混合和增益变化均不能独立作为新意；本候选暂不训练残差低层政策。 |
| [OCCAM](https://arxiv.org/html/2406.17620v1) | 摘要、III、IV.1–4.3：历史/任务/增益编码，元学习表现预测和递归末层适应，再优化增益。 | 直接学控制表现和选增益已有成熟参照；候选必须超过同数据直接表现模型。不能假称 OCCAM 只估物理参数。 |
| [GAUGE](https://arxiv.org/html/2609.32154v1) | 摘要、引言、III：规划命令分布上的不确定性缩减、授权过滤、验证停止、 bounded inversion 和变化后恢复。 | 任务权重、验证、停止与重新采集不是空白；其授权和统计值明确分开。当前候选的完整任务随机释放标签是待检验差异，不能靠术语成立。 |
| [Poke and Strike](https://proceedings.mlr.press/v305/aoyama25a.html) | 本次出版摘要：特权任务政策对估计误差的敏感性产生探索奖励，并按不确定性停止探索。 | 任务相关探索和停止已有研究。尚未读完全文方法，不能声称不存在某项细节。 |
| [Learning to Look / DISaM](https://proceedings.mlr.press/v270/dass25a.html) | 正式 PDF 第 3–6 页、附录 A.1 第 14 页及 A.6 第 17 页相关段；视觉检查第 4 页。信息采集/接收分解，借助真上下文下的接收动作差异训练采集，用动作分布不确定性切换。 | 两层结构本身不新。附录允许行动/观测空间重叠，不能说它绝不考虑物理影响。本候选拟检验真实返回后的随机额外轨迹与固定接收者完整终局效果，仍需严格对照。 |
| [AA-POMDP](https://arxiv.org/html/2410.03892v1) | 本次 §2–3 相关段：显式特征采集成本；批量式允许状态变化，顺序式另有不变/快速假设。 | 不能把“采集会改变状态”整体当作无人研究的问题。 |
| [Conformal Policy Control, ICML 2026](https://proceedings.mlr.press/v306/prinster26a.html) | 正式 PDF 第 3–7 页，视觉检查第 3 页；读取条件、非单调 gCRC 与多轮权重/稳定性边界。 | 基线密度裁剪与风险校准已有研究。其多轮方法考虑优化反馈；精确权重和相对稳定性等条件不能从本原型继承。确定性旧数据对未执行获取无支持，不能凭此宣布安全。 |
| [MIPS, ICML 2022](https://proceedings.mlr.press/v162/saito22a.html) | 正式 PDF 第 3–4 页，视觉检查第 3 页；嵌入边际权重及 common support/no-direct-effect 条件，作者亦分析违反条件时的偏差。 | 状态粗化和边际加权并非新算法；仅当前命令相等不代表不同积分和未来政策可合并。当前方案通过实际随机释放取得支持，不冒称消除全部混淆。 |
| [Policy-dependent optimization response](https://arxiv.org/abs/2202.12958) | 本次摘要与索引中的方法段，尚未完整通读。 | 下游优化响应改变政策值已有研究；固定接收者版本和重新闭合首先是正确评价要求，不能单独包装成创新。 |
| [QOED, RSS 2026](https://www.roboticsproceedings.org/rss22/p137.html) | 本次官方摘要：可观子空间和任务有关的信息目标，含耦合条件。 | 任务相关的信息目标本身不新；未读完整方法，不作更强排除。 |

原有 FLAIR、ASR、标准 PID、dual control、SPC、ToIA 与旧两阶段值学习的
限制继续有效，见先前查新表。旧两阶段方法的表面收益可由廉价有效性规则
解释，故本候选不能仅换名重做两阶段回归。AIPW 是标准估计器，当前并未
提出新统计定理。此次原型也不是外部方法的同权限实证比较。

候选可能的研究差异限于：将**真实获取后的额外信息效果**作为可实测、
带符号且绑定实际接收者的监督，同时显式保留共同后状态和控制记忆，
再用于获取前完整风险决策。必须通过新数据中的机制消融、强直接表现
学习对照与自身历史部署证明；如果只是固定控制器选择有效，差异就未成立。
