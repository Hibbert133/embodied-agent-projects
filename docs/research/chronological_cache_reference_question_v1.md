# 从静态预测到真实复用：先建立时序强参考

此前4步源不确定性检查在人工配对中误报3/336，但配对变化都同时改变
容易观察的方向；这不能说明任何变化都能被看见，也不能推导复用后的
任务成功。新实验将预测检查真正接到连续任务执行，保留强固定和刷新基线。

一个条件性支持反例：固定相同初始机器人状态、旧缓存与时钟，若两个
执行器的x列和偏置相同、只有y列不同，则BLOCK8前四步的发送y值全零，
确定性执行值完全相同。对每步使用相同分布的执行噪声，归纳得到前四步
完整可见轨迹分布相同。仅依赖这些观测且无额外变化先验的检测器，其在
这两个条件世界的检出率等于误报率。该结论不需要线性机器人动力学。
这是标准可观测性事实，不是新定理；是否影响任务与更完整探测能否获益，
必须实际检验。均衡4步作为便宜强参照，避免把补齐方向支持称为新方法。

固定的COLUMN_Y族实现该条件反例；BIAS与DEADZONE分别检查可见偏置
变化和仿射族之外的执行变化。不变、突变与渐变都按实际时间顺序运行，
方法只使用自己已经执行且成功验证的缓存。预检结果只作工程完整性检查，
不能用于选择阈值、删掉故障族或调新模型。

考虑源参数不确定性已有
[Hare等的变化检测研究](https://experts.illinois.edu/en/publications/toward-uncertainty-aware-quickest-change-detection/)，
任务指令加权的信息获取已有[GAUGE](https://arxiv.org/html/2609.32154v1)。
本轮CUSUM与局部IVR均为适配参考，不声称完整复现这些系统、继承其保证
或建立算法创新。真正后继还需要把信息支持、任务收益与物理获取费用联系，
在相同权限的强参照之外提供可核查差异，并以新流独立确认。

固定36流是完整因素与资源预算决定的开发人口，没有把它称为已达到某个
非劣效功效目标。完整投稿要求不变；本轮最多补强时序评价、基线和机制证据。
