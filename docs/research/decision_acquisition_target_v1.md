# 从响应有效性转向任务收益：后继研究问题 v1

这份问题定义依据[完整负结果](../../reports/action_response_development_v3.md)
与[精确同状态配对](../../reports/response_acquisition_utility_v1.md)，不是新实验
协议。它不分配或执行新种子，不修改冻结源、模型、阈值或现有记录，也不训练
选择器。CCF A 研究目标仍缺少可区分于已有工作的贡献和独立确认。

## 已有证据限定了什么

RESPONSE_SET 在全部 288 单元被宽八、宽十六和原十六步基线支配，没有复用。
在旧缓存及六步物理状态完全相同的 48 个案例中，重新取证带来七个新增成功，
但共同成功的 41 个案例共增加 882 步。不是每次辨识都值得，也不能从总体
平均步数改善推出逐案的费用改善。

G_OPTIMAL 的 55 个配对包含四个有害停止：门任务刷新估计未通过逆稳定性
检查，旧缓存分支却成功。四次均为 `UNSTABLE_ESTIMATED_INVERSE`；各优化器
正常结束、设计满秩且条件数为 1，不是求解器未收敛。详见
[原始停止证据](../../outputs/response_acquisition_utility/stop_forensics_v1/forensics.json)。
新目标需要同时考虑无效估计、测量改变的物理状态、任务成功概率和
剩余执行成本。每个分支只有一次随机实现；上述二元有利／有害不能直接变成
稳定的监督动作标签。历史重试收益的重复性失败也应保留。

旧缓存从六步状态继续成功，不等于它在失败探测之后仍会成功；那个分支并
没有被执行。不能从上述证据事后补一个“拟合失败便回退旧缓存”的虚拟胜者。

这项配对没有同一六步状态上的宽八／宽十六分支。不能把从初始重置开始的
固定基线当成从中途状态刷新后的结果。三组共享状态的结局也不能当成独立
样本数量相加。进一步收集前必须先解决这个候选可比性问题。

## 相关目标并非新颖性

将摘要阅读当成完整算法复现或穷尽式新颖性检索。

## 待实现和待检验的目标

在线输入应为当前实际可见的历史、已付出的预算、旧控制映射与合法采集程序。
候选不是抽象“获得信息”，而是包含运动、辨识与之后固定政策执行的整个
可执行分支。需要分别估计或界定：成功概率、停止／拟合风险、采集步和之后
任务步。成功与成本先分别报告；没有预注册的任务效用，不事后挑权重制造胜者。

物理分岔前必须固定同一旧控制映射和实际历史。不同动作继续真实仿真，而非
把一条轨迹的观察喂给另一条动作。若将来采用模拟器状态复制或未来噪声重采样，
必须先验证包括动力学隐状态、环境包装器、任务变量和 RNG 的复制范围，单独
登记恢复／工厂初始化费用，并明确它是评估器反事实设施。当前没有这些资格，
不能直接将复制器部署进在线流程或重跑旧种子。

强对照至少应包含同状态继续旧缓存、原八／十六、宽八／十六、任务相关标准
采集准则和原响应／G 参考，并保留从初始状态开始的强固定基线作为总体性能
参照。成功基准不通过时，低步数或更多“复用”均不能代替任务收益。

重复随机实现应先测量分支收益分布是否足够可预测；训练、开发与独立确认
分别冻结且使用新的范围。评估器全分支结果仅作明确标识的离线研究数据，
部署经验只能写入自身实际所选分支；不能把未来反事实或 Oracle 算子送入
代理、LLM、自然记忆或在线阈值。

可投稿的后继贡献需要具体的新估计器／决策机制、它在声明假设下解决的困难、
与相关算法的可核查差异，以及相对上述强对照的独立收益。通用监督学习、
再加一个阈值、修正旧成本消融或 API 接通本身，均不满足这个要求。这些问题
尚未解决，继续目标不应因本机制核查或现有中文稿而标为完成。
