# 阶段监测与任务恢复的已有工作边界

固定策略长期请求同一个动作阶段，并不自动说明何时应该介入，也不决定介入后怎样恢复。上一步的[逐步轨迹](../paper/paired_probe_case_trace_20261019_zh.md)把失败定位到具体执行行为；将其发展为获取方法，还需区别于已有的进展监测、恢复目标选择和短时纠正规划。

## 检测目标与干预目标

检测器可以估计当前政策继续执行是否会失败。获取决策则需要比较从同一当前历史出发，继续当前纠正、真实切换旧纠正、执行额外测量或停止，各自对完整剩余任务的影响。前者的高失败分数不能自行指定后者的赢家。Back on Track 已经通过学习的续跑价值和规划处理这种联系；后继方法必须说明自己解决的是哪一种额外困难。

本项目的一个具体困难是：纠正映射改变后，实际闭环政策也改变。一个仅描述旧纠正映射下进展的分数，不能未经验证就用于新映射的续跑。若学习分支价值，应以真正会被执行的映射和预算为条件；如果在线采集新证据，还必须计入测量改变的物理状态和自己形成的历史。这里提出的是适用性要求，尚未证明新颖性。

现有受控起步模型只针对初始短响应。它没有获得对接触阶段、多步纠正规划或恢复轨迹的世界模型资格。采用世界模型参考时，需要分别建立训练支持、闭环预测误差和真实干预结果，不能直接把当前模型接入规划器后继承上述论文的任务表现。

## 校准和恢复的边界

单帧的参考阈值与整个自适应轨迹的误报控制是不同声明。若采用整轨迹校准，独立单位仍应按本项目的完整来源流及部署规则定义；同一隐藏边界的八个未来不是八条独立来源流。新纠正或干预政策改变了状态分布时，原参考政策上的校准关系也需要重新检查。

恢复还必须从报警当时的真实状态开始。将参数回退到旧值，不会把已移动的物体、机械手接触或剩余预算恢复到第八步。新方法可以测试参数回退或物理恢复，但它们是不同动作，均须真实执行并记费；评价者的状态复制工具不能进入在线代理。

## 后继比较需要的可检验区别

下一步应以[完整推物人口的阶段描述](../paper/paired_push_mode_population_20261019_zh.md)约束候选，而不围绕单个失败选择阈值。候选应明确它如何从合法观测区分可恢复迟滞与持续失效，如何评价实际纠正映射下的续跑，以及为何新的测量能改变动作选择。检测准确率、恢复成功率和总任务损失分别报告，不能互相替代。

若采用阶段停留时间、普通变化检测或基于学习价值的监测，它们应作为标准参考保留。使用动作块、视觉编码器、绝对关节目标或世界模型的完整原方法，需要匹配相应权限与来源费用；受限适配要按实际实现说明，不能只沿用原方法名。新机制仍需自身历史上的独立任务验证和消融。本轮没有新仿真、阈值拟合或在线 API 决策，也没有读取正在采集的 MAIN 方法成绩。
