# 从任务改进到旧证据有效性：先检查预测误报

联合估计8步在独立静态任务上得到330/336，但最早两步的额外收益区间跨0。
这支持一个标准估计组件，尚未支持根据短前缀可靠复用或刷新。选择器如果
误把接触／任务响应差异当成扰动变化，就可能反复花费探测；过宽的不确定性
又可能把失效旧估计继续保留。需要先实测这两个方向，而不是直接承诺算法收益。

已有[不确定性感知变化检测，Hare等，2021](https://experts.illinois.edu/en/publications/toward-uncertainty-aware-quickest-change-detection/)
用后验预测分布比考虑有限训练样本的参数不确定性。这里只核对作者所属大学
的出版页摘要，没有复现其ULR算法；“检测时考虑参数不确定性”不能作为创新。
此前GAUGE和ToIA的任务获取边界也保持有效。

本次先实现透明的局部高斯参考，检查人工配对中“未变”和“已变”是否可分。
若误报明显超出名义水平，后继必须先处理预测失配；若表现可用，也仍需真正的
任务收益与获取费用建模、固定强基线、非平稳多故障族的新协议，才可能发展
有区别的机制。未拒绝缓存不是有效性证明，诊断分数也不是探测的任务价值。

该分析是事后复用，全部结果只用于确定下一项研究动作；不把它改写成独立
确认、新理论、在线性能或CCF A目标完成。详细计数与信息边界见冻结协议。
