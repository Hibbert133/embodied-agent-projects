# 选择器之外缺少的探测后不纠正对照

此前任务价值核回归失败，不能简单解释为核在所有新情境上都失效。旧冻结模型的只读复算显示，各任务新情境的最大核相似度中位数约 0.706、0.746、0.773；只有少数点完全退回任务均值。这只是已观察资料的诊断，不用于调核或改阈值。

对后续 16 流、三任务、二未来银行，在五种可行八步后续方案中，按每情境两个结局的平均损失事后选最小值为 85.14583 步，观察到的最佳固定 PASSIVE 为 86.98958，相差 1.84375。若把起点 NO_PROBE 和宽十六步加入七种完整方案，事后情境选择为 74.89583 步，相差 12.09375，成功数从 94 增至 96。这是使用当前全部结局的乐观经验比较，不能当作条件期望真值、部署政策或总体收益上界。

其中 NO_PROBE 的起点与八步后状态不同：无法把它的结局填进八步选择器的纠正候选。旧源另有不同的最佳固定任务分支，也不构成新策略的独立确认。完整出处分别是已有 conditional_continuation 和 continuation_selector 银行；本轮不重跑这些种子。

下一步先补足三个实际对照：八步探测后保持原政策；循环十六步探测后保持原政策；八步探测加八步旧纠正政策后，撤去纠正。它们分别与 DIRECT_G8、POINT16_CYCLE、PASSIVE_G16 保持相同的实际八步或十六步前缀。前缀必须分别真实执行；不能恢复状态、复制模拟器或把旧 NO_PROBE 结果当作替代执行。

这三个都是简单固定基线，不是新算法。它们若有收益，只说明原先的纠正／继续执行方案集合缺少重要选项；若无收益，也不能把起点未纠正的事后优势迁移到探测后。用新流完成这个测量，再判断是否有必要设计更复杂的任务价值模型，避免在缺少关键对照的方案集合上继续优化选择器。

任务价值导向模型与分布变化下的政策评估已有明确先例，例如 [Minimax Model Learning](https://proceedings.mlr.press/v130/voloshin21a.html)；一步预测与控制目标不一致亦已由 [Objective Mismatch](https://proceedings.mlr.press/v120/lambert20a.html)讨论。这里仅核对官方摘要和问题边界，未复现其算法，不能把“改用任务价值”本身声称为新贡献。
