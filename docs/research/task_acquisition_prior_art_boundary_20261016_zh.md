# 任务导向获取的已有工作与待建立机制

核对2026-10-16可访问的版本化原文后，当前任务桥接仍不能直接构成新的获取算法。

[GAUGE第III节及第V节](https://arxiv.org/html/2609.32154v1)以规划器命令分布加权后验方差降低，
配合验证停止与有界逆补偿；原文也指出强历史依赖和瞬态需要扩展响应状态。

[ToIA第II–III节](https://arxiv.org/html/2609.19378v1)沿同一MPPI候选轨迹，
把早期观测对后期模型查询的方差降低与任务代价结合；因此“兼顾运动和学习”也已有方法。

对本项目的推断是：固定技能、连续500步预算和诊断动作改变任务状态，提供了需要精确
定义的问题设定，但这些设定的组合本身不是已证明的新贡献。仅替换成动态响应模型、
增加任务权重、加入探测费用或让LLM选择工具，仍需要与上述路线及标准双重控制区分。

当前56流任务实验只检验冻结估计器能否改善任务，且没有选择探测预算；它不能支持
“已经学会何时复用、重测或停止”的结论。即使组件表现正向，后继仍要给出可测的
获取机制、同信息与同权限基线，以及新时序流上的独立评价。

另外，[联合与条件似然参考](../../outputs/cold_start_task_bridge/rationale_v1/likelihood_note_zh.md)
核对了一个解释边界：当前后6步联合响应消融采用边缘模型，不等同于旧ARX的条件项。
不能把模型形式、历史条件和早期输出的影响压缩成一个“多用了两步”的原因。
该参考是标准矩阵恒等式，没有证明真实物理模型或新方法创新。

本页核对的是上述两篇的具体方法设定，未复现其完整系统，也不是穷尽查新。
正在采集的任务方法、门槛和样本量保持冻结；文献核对与解释参考不会用于本批事后选方法。
