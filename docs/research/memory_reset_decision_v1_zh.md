# 标准控制记忆反机制资格：结论与下一步

本轮630次真实执行全部完成：90原生契约、540独立QUAL；三任务×两条件×三介入层，QUAL九个独立组。物理实现冻结814c7db，审计只读扩展冻结4dca769；两级记录与独立统计审计通过。原API、ARX、SS、旧完整任务与有限信息参考的结果和哈希不变。

## 主要判断未通过

唯一主比较是全54单元的RAW_RESET_I−RAW_CONTINUE完整截止损失：**−6.851852步，95%整组区间[−24.722222,7.111574]**。清零50/54成功、平均111.203704；RAW49/54成功、118.055556。上界未严格小于零，按冻结门为 `NOT_QUALIFIED`。不因点均值较低或比C8/积分更低就宣称获得独立收益，不更换主角或追加样本。

完整配对中清零有14/54损失更高、9/54更低、31/54相同；0例成功转失败、1例失败转成功。该分布和置信区间体现少数较大改善与若干较小不利变化，不能把平均改善解读为错误更新普遍减少。48次实际直接清零均改变非零积分，另6例提前结束；按实际采用分项仅描述，不替代完整分配比较。

## 解释与反证

相同真实移动/测量后的LOCAL_PID_RESET_I−KEEP为+3.055556步，区间[−10.055556,20.777778]，成功52/54对53/54；14对不利、15对改善、25对相同，1例成功转失败。因而这次人口没有支持“移动后仅清零就能改善任务”的解释。区间仍宽，也不能据此证明积分清零在所有状态均无效。

相同获取后的REFERENCE_RESET−RESET_I为−5.759259，区间[−19.593056,2.555556]；参考映射贡献仍不确定。CARRY−REFERENCE_RESET为−4.537037，区间[−23.537037,9.407407]。两项均为预定次要比较，不能挑出CARRY替换失败主角，也不能唯一解释旧ARX/SS失败。

测量后的REFERENCE_RESET比NO_PROBE完整程序损失高13.740741步，区间[3.111111,29.203704]，成功53/54对54/54。这两个固定程序使用移动期间形成的同一参考，不用新增8步数据拟合新响应模型。比较反映费用、真实后状态和准入的共同效果；不等于所有信息获取都无价值，也不等于一个学会利用测量的新方法必然失败。

NO_PROBE成功54/54、平均114.166667，比RAW点均值低3.888889，区间[−39.261574,27.574074]；这也未建立相对RAW的独立优势。DIRECT_C8为45/54、150.166667，MOVE_INTEGRAL为48/54、168.296296。清零相对它们的均值较低，但两个区间上界分别4.592593和0.203704，仍不据此替换主门或声称算法创新。全部十程序和180分层面板见主报告。

## 分开的三个判断

严格映射、先存后消费、实际命令改变及零新增物理步骤已通过数值/执行资格；不能因此声称响应模型预测合格。这里没有新响应训练和预测资格，也未接入失败SS/ARX。本轮完整任务主要收益门失败；此前模型资格负结果不因一个廉价控制分支的点表现而改变。

72对原生/432对QUAL共同前缀、18/54对完整NOOP轨迹，以及全部共同移动/获取后状态核对通过；真实任务失败总计37例全部保留。原读者错误地比较终止墙钟耗时，已原样保留失败并单独冻结v2，仅投影该非物理计时字段。原生与QUAL物理数据均未重跑。展示环境缺SciPy的绘图失败也保留，用纯JSON读取器修复展示，未更改科学计算。

## 后续决定

**封存这个固定时点清零版本，不围绕该QUAL调时点、积分增益或增加选择门。现有证据不足以直接启动新一轮大规模采集。** 保留RAW PI、直接C8、积分、NO_PROBE、获取不更新/测量后标准参考等完整强对照。不能降低基线、筛掉困难组或将NO_PROBE换成新算法来完成目标。

TRAIN、CAL和最终自身历史另分配、另冻结完整费用和未使用种子；短验证必须真实执行，停止/拒绝保留已付代价和真实后状态。仅增加回归器、门控、置信区间或样本不构成新意。现有630例是已关闭的标准资格人口，不能据此调参后再称最终独立验证。
