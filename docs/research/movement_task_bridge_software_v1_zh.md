# 移动证据到任务执行：四种对照的软件接口

这一步完成的是可执行、可核查的标准对照接口。还没有开展新的
MetaWorld 任务比较，不能据此声称任务收益、模型可迁移或算法创新。
旧的选定位置辨识实验仍然未通过资格门槛。

## 名字与实际区别

“纠正器”把固定策略的原始动作转换为实际发出的指令。C8 表示由最初
8 步证据得到并保存的旧纠正器；MOVE 表示先完成一段规定的移动。

| 名字 | 直白含义 | 移动结束后使用什么 |
|---|---|---|
| `DIRECT_C8` | 直接继续任务 | 原来的 C8 |
| `MOVE_KEEP_C8` | 先移动，但不更新纠正 | 原来的 C8 |
| `MOVE_INTEGRAL` | 根据移动中累计的位置误差调整补偿 | 已保存的积分补偿 |
| `MOVE_ARX_KEEP` | 用整个移动过程估计新纠正；普通无效估计时保留旧纠正 | 有效则用保存的 ARX 估计，否则用移动前的 C8 |

ARX 是带外部输入的自回归模型：用最近的运动变化和发出的动作预测
下一步运动。此处使用历史训练的标准 ARX，再由实际运动估计输入映射；
它不是 LLM，也不是新训练的机器人策略。积分补偿只累计位置误差，
不等同于识别完整的输入矩阵。

三种 MOVE 方法的移动阶段完全相同，均调用原有 `LOCAL_PID`：最多
64 步；到达可见目标且满足原有稳定条件，或任务提前结束时停止移动。
总任务预算 500 步，进入时预留完整的 64 步和至少 100 步任务预算。
移动未到目标也保留全部已完成记录，之后按注册方法继续任务。
这与旧的“到达后再采八步探测”接口不同：新接口不增加探测。

如任务在移动时成功，立即保留成功和实际完成步数，不拟合、不再执行。
环境结束但没有成功时，截止损失为 500。普通无效 ARX 估计会沿用旧 C8；
未知状态、错误来源、异常或执行故障会保存失败，不静默替换成其他方法。

## 因果链及代码

1. [任务模型绑定](../../src/probe/movement_model_binding_v1.py)把三项任务
   分别绑定到历史系数的规范 JSON 哈希，拒绝任务错配和系数改写。
2. [来源加载器](../../src/analysis/movement_model_source_v1.py)检查原始
   manifest、模型、审计和审计绑定的全部数据文件，不重新训练。
3. [执行器](../../src/probe/movement_task_reference_v1.py)先保存方法选择、
   每步积分更新和指令，再执行。估计只接收全部实际移动响应与移动前
   三个观测；这三个观测提供真实的两段先前位移，不补零、不丢前两项响应。
4. [连续执行主机](../../src/analysis/movement_task_host_v1.py)核对旧 C8
   拟合、选择和实际使用的顺序，并从当前同一执行的物理记录提取历史。
   主机保留同一环境、噪声序列、物理时钟和一次受控重置，禁止重复进入。
   整个剩余任务的步数必须事先在全局预算内可用。
5. [记录核查器](../../src/analysis/movement_task_record_v1.py)独立于执行器
   的控制流逐事件核对：响应先于估计，估计先于纠正选择，选择先于指令。
   它重建响应历史、积分补偿、任务指令与总成本；共享原有 PID/矩阵运算。

主机只在保存的动作与允许的动作完全一致时执行；任务阶段的原始动作
必须来自当前观测上的实际固定策略查询。故障记录同时保存主机实际
尝试数、完成数、物理帧和策略查询，避免执行器尚未收到回执时漏记成本。

## 来源限制与费用

历史 ARX 来源为 `forward_prediction_20261014T064233Z_bb812df15401`。
原审计完整性通过，但状态是 `COMPLETED_FEASIBILITY_FAILED`；历史精度
门槛及跨条件物理适用性都不能宣称通过。此次绑定只证明使用了哪套系数。

加载器单列该来源的 21,010 个环境步、288 次受控重置；另外披露并保守
计入来源研究的旧比较依赖 2,304 步、144 次受控重置，共已知 23,314 步、
432 次受控重置。历史工厂重置总数和原生物理帧未知，保留 `null`，不能
记成零。这些是历史费用，不是这次软件开发的新仿真费用。
未来任务比较还须另计共同的 C8 来源和新在线执行，避免共享来源重复加总。

## 验证证据及剩余边界

新增 35 项针对性测试覆盖四种合法路径、不同纠正导致不同任务动作、
相同移动前缀、普通无效估计保留 C8、提前成功、500 步截止、错误模型、
私有字段、保存回执改写、重复操作、历史遗漏、成本改写、噪声替换、
中途重置和额外物理帧。记录核查不调用任务执行器或重新运行优化器。

针对性日志和全仓库检查证据保存在
[software_validation_v1](../../outputs/movement_task/software_validation_v1/)。
最终针对性测试 35/35 通过；全仓库测试 1,376/1,376 通过，测试主体
489.412 秒，含记录保存的进程耗时 493.043 秒。编译和依赖检查通过。
最终源码与 `targeted_v2`、全仓库检查的输入哈希一致；提交前核对见
[delivery_review.json](../../outputs/movement_task/software_validation_v1/delivery_review.json)。
部分合法 ARX 执行路径使用明确标注的合成估计；单轴 MuJoCo 测试不是
MetaWorld 科学任务，也不是估计精度验证。原生测试成本另存 JSON；
其覆盖范围仅为对应测试调用中的已仪表化测试，早期控制台运行未完整
保存原生费用，不能把已保存费用称为全部开发成本。

初次记录篡改测试对只读元组调用 `pop` 导致测试自身报错；改用替换切片
后通过。初次控制台发现会重复发现导入的旧测试类，随后改为模块引用。
两项均为新测试的缺陷；保留后续 `targeted_v1` 和加强估计结构验证后的
`targeted_v2` 独立日志，不覆盖历史实验或伪称科学实验失败已被修复。

尚需新版本的完整收集器、物理见证与数值独立审计、统计方案、固定样本量、
未使用种子配置和一次性冻结；这些完成之前不运行新科学数据。当前记录
核查器不能独自证明外部给定物理轨迹真实，也没有重新优化验证拟合数值。
四组对照只能检验移动及移动证据更新的任务价值；还未检验额外探测价值、
自适应获取决策、长期记忆或 LLM 收益，论文的七项完整要求仍然开放。
