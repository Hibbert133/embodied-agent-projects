# 随机比较能支持什么纠正更新结论

上一轮[192 对保存估计诊断](../../reports/inverse_error_attribution_development_v1.md)排除了以参数距离和未校准协方差单独接受更新的依据。本轮实现标准随机比较作为参考，并先检查它的统计对象与任务目标是否相符。它不是新算法，不调用 API，不启动机器人仿真，也不修改已完成实验的纠正器。

在历史 H_t 已知时，先保存旧／新两个合法命令及可预测的 m_0,m_1，再独立以已知概率 p_t 指派 Z_t。观察有界近期响应 Y_t∈[-1,1]。在一致性、指派条件随机且有重叠时，标准增广逆概率分数

    D_t = m_1-m_0 + Z_t(Y_t-m_1)/p_t
                    - (1-Z_t)(Y_t-m_0)/(1-p_t)

满足 E[D_t|H_t]=τ_t=E[Y_t(1)-Y_t(0)|H_t]。m 不必正确，但必须在指派和结果之前固定。取四个指派／响应端点求出可预测区间 [L_t,U_t]，则 X_t=D_t-τ_t 是条件均值零的增量，Hoeffding 上界给出

    E[exp(λ X_t - λ² (U_t-L_t)²/8)|H_t] ≤ 1.

令 V_n=Σ(U_t-L_t)²/4、S_n=Σ(D_t-τ_t)，用精度 ρ 的零均值正态对 λ 混合，得到标准非负超鞅

    M_n = sqrt(ρ/(ρ+V_n)) exp(S_n²/(2(ρ+V_n))).

Ville 不等式给出同时覆盖所有 n 的边界

    |S_n| ≤ sqrt((ρ+V_n) log((ρ+V_n)/(ρα²))).

因此区间围绕 ΣD_t/n，目标为**实际随机历史上近期效应的平均 Στ_t/n**，再与 [-2,2] 相交。空交集必须保留为空，不能删除该路径或改宽区间。上述推导是标准随机实验估计与正态混合集中界的组合，不是新定理；相关背景见 [Howard 等的置信序列研究](https://arxiv.org/abs/1810.08240)，本地公式逐步推导而非声称复现其全部算法。其范围不含真实机器人模型有效性。

区间不识别下一状态的效应，也不识别“从此一直采用新纠正器”的任务价值。效果随状态变化时，过去平均为正而当前效应为负并不违反该区间的覆盖保证。

更强的反例为两个有限时域系统：在前 64 步，无论如何随机指定旧／新动作，观察都为 Y(0)=-0.5、Y(1)=0.5。第 65 步的最终任务奖励，旧政策在两世界均为 0.5；新政策在世界 A 为 1、在 B 为 0。所有 64 步记录分布相同，近期差异都为 +1，终局政策排序却相反。任何只看这些记录的选择器，在两世界采用新的概率都相同，记为 q；最坏世界相对最佳政策的遗憾至少 max(0.5q,0.5(1-q))≥0.25。此标准两点构造不证明本仓库机器人就是该系统，却足以拒绝把近期响应区间当作无条件终局收益证书。

下一机制必须补足明确的结构，例如可验证的价值近似、足够长的响应视窗、跨任务终局监督或已证明的进展到终局关系，并计入获得这些信息的成本。不能用独立随机化一词隐去这个缺口。
