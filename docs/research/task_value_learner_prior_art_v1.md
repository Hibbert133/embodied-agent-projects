# 两阶段分支收益候选的原始文献边界

核查日期 2026-10-15。以下读取范围是摘要、指定技术／讨论段，不构成穷尽
新颖性认证；作者报告的实验数字不作为本项目结果或已复现结论。

| 原始来源 | 已有能力／读取范围 | 对新候选的约束 |
|---|---|---|
| [Liang 等，RSS 2020](https://arxiv.org/abs/2006.01952) | 摘要：学习面向任务相关参数的探索，再执行模型任务优化。 | 学习“有益于任务的探测”已经存在。 |
| [Dass 等，CoRL / PMLR 2025](https://proceedings.mlr.press/v270/dass25a.html) | 出版页摘要：信息采集与接收政策分解，接收政策提供采集训练奖励。 | 固定技能上的两层采集／执行架构本身不是差异。 |
| [Li 等，SPC，2026-03-25 v2 预印本](https://arxiv.org/html/2506.11279v2) | 摘要及引言：经控制优化映射评价模型、优化固定代理损失，并给条件迁移诊断。 | 更关心控制表现而不是预测精度也不是新目标；这里不优化物理模型或继承其理论。 |
| [Aoki 等，ToIA，2026-09-16 v1 预印本](https://arxiv.org/html/2609.19378v1) | 第 III 节和第 VI 节：以任务权重结合 GP 未来预测方差缩减，使用现有 MPPI 采样；讨论明确未显式重算更新后的控制决策。 | 任务相关信息采集分数不足以构成差异。显式后选择是值得实测的机制，但一般 dual control 已经考虑后验与未来行动。 |

这里最后一列是本项目判断，不是原作者评价。ToIA 的未来方向不是全领域
空白；既有 [dual stochastic MPC](https://proceedings.mlr.press/v120/arcari20a.html)
已经在场景树中考虑辨识与后续控制。当前标准核回归、分支价值和嵌套交叉拟合
也都不能单独称新方法。

可检验差异暂限定为本项目的执行机制：一次测量同时改变物理状态，并可能
产生被拒绝的新纠正；探测前预计测量后的 KEEP/UPDATE 选择，而非预先假定
估计一定成功。需要强固定、直接分支值、无后选择、KEEP 和标准任务相关准则
对照，且必须在独立新范围展示收益。当前原始 paired 数据只用于开发复用。
