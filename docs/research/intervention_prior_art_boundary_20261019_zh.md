# 中途纠正、物理回退与任务导向探测：本轮查新边界

核对日期：2026-10-19。本文在固定三分支采集期间完成，不读取其部分任务结果，不改变已冻结的协议。目的是约束后继方法的贡献表述和比较范围；不是穷尽查新，也没有复现下列算法。

## 三个直接相关的原始来源

|原始来源与实际阅读范围|已有机制|对本项目的直接约束|
|---|---|---|
|[SafeLoop，arXiv:2609.26313v1](https://arxiv.org/html/2609.26313v1)，2026-09-22；第III节、算法1、第IV-A节|冻结VLA外部的风险预测器和决策器选择继续、保存关节路点或物理回退；决策器以规则预热并用PPO训练|“固定策略外面加监测、记忆和切换”已有直接先例；不能仅凭这个架构主张创新|
|[RecoveryChaining，arXiv:2410.13979v2](https://arxiv.org/html/2410.13979v2)，2025-03-07修订；第IV、V节|在恢复动作与已有控制器选项组成的混合动作空间内学习；从查询状态实际执行后续控制器，用结局提供奖励|“从当前状态估计接管价值，再选已有控制器”已有先例；固定控制器不意味着选择机制新颖|
|[Wagenmaker、Simchowitz、Jamieson，ICML 2021](https://proceedings.mlr.press/v139/wagenmaker21a/wagenmaker21a.pdf)，第1、2节、算法1、定理2.2|在线性动力学与相应稳定、光滑条件下，以任务相关损失设计探索；TOPLE交替估计系统和选择实验输入|“只辨识任务需要的参数方向”与“用任务损失指导探测”已有理论依据，不能当成全新原则|

SafeLoop保存的是机器人关节路点，恢复动作推进物理时间；原文算法1后的说明将这部分时间与名义策略步区分。其低风险路点也明确不是形式化安全证书。因此将来若移植相关基线，应统一实际交互预算和可用观测，分别记训练与恢复费用，不能直接横比不同论文的步数或成功率。本项目目前没有实现这项移植。[原文第III节](https://arxiv.org/html/2609.26313v1)

RecoveryChaining训练时能保存故障的真实仿真状态，并从那里启动恢复学习；其第V节通过实际后续执行估计控制器可接管性。此训练接口与部署时的自然经验不同。未来借鉴它时须明确训练权限，不能把离线分支结局包装成当前代理已经观察到的经验。[原文第V节](https://arxiv.org/html/2410.13979v2)

TOPLE的保证不能直接搬到当前接触动力学、有限个纠正候选和500步成败截止损失上；本项目尚未证明其线性系统、光滑决策与其他定理条件。这里确认的是任务导向探测已有基础，而非声称我们的代码实现或超越了TOPLE。[原文第1、2节](https://proceedings.mlr.press/v139/wagenmaker21a/wagenmaker21a.pdf)

## 当前代码实际完成的范围

[本轮冻结协议](../protocols/delayed_switch_effects_development_v1.md)只规定从相同第16步历史出发，继续C8、改用C4或取消纠正。C4来自同一任务的前4步，尚未被验证成功；切换它不执行物理回退，也不恢复仿真状态。本轮没有学习何时选择、没有额外获取证据的分支，也没有任务内故障变化。

三个概念必须分开写：

- **参数切换**：机器人留在当前物理状态，后续指令使用另一份纠正参数；这是当前实现。
- **物理恢复**：实际执行动作，走到更适合继续任务的位置；当前三分支不包含这一操作。
- **证据重新获取**：支付交互成本，采集新观测并更新纠正方案；当前第16步之后没有这一分支。

以上区别只界定范围，不自动构成创新。完整论文仍需回答何种公开证据能区分操作的任务价值，以及决定获取新证据后能否在完整成本下改善结果。

## 对下一阶段的具体影响

以下是结合已读原文和仓库范围作出的研究判断，不是上述论文的结论：

1. 不把“继续／切换／停止”的菜单、保存参数、因果日志或冻结底层策略列为核心算法贡献。
2. 若开发选择器，保留普通条件均值回归、代价敏感树等标准决策基线；按实际所选任务损失评价。详见[决策损失与预测指标](decision_loss_alignment_20261019_zh.md)。
3. 若研究重新获取证据，必须实际实现并测量该操作，包括由它造成的物理状态变化与完整费用；已有三分支无法提供其结局，不能从其他状态拼接。
4. 统一部署权限后才能作直接性能比较。只实现一个相似阈值规则时，应写“受某工作启发的匹配基线”，不得写成原方法复现。
5. 目前缺失的是可区分于已有机制、并在新的独立任务上带来收益的方法。当前研究可提供开发数据与失败分析，但投稿就绪要求仍未满足。
