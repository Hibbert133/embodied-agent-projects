# 中途响应参考模型与旧纠正失效问题

本阶段新增可执行的中途响应估计参考及软件检验，没有新增MetaWorld科学案例、在线API调用或真实名义校准。上一轮9案例的完整结果仍见[执行资格报告](../../reports/physical_reprobe_execution_qualification_v1_zh.md)。本参考未取得物理辨识资格、任务收益或新颖性证据，CCF A目标继续保持未完成。

## 两个名字分别是什么意思

`WARM_HISTORY`表示“考虑探测开始时运动状态的8步估计”：它读探测前4帧真实观测和后续8步真实响应。`WARM_NO_HISTORY`表示“不使用起始运动历史的同数据估计”，用于检验那4帧是否有价值。这里warm指机器人已经执行过任务；它与只用于初始重置后数据的C8不是同一个模型。

## 已实现的计算与边界

[模型实现](../../src/probe/warm_response_reference_v1.py)把8个实际xy位移堆成16维输出y，采用工作均值

`y = offset + G·z + H·E[clip(X·theta + noise)] + residual`。

z包含当前xyz与测量位置的差、之前3个真实xyz位移，共12维；分别按既有位置门槛0.015和运动门槛0.003缩放。H为16×16的因果下三角响应，当前输出不能依赖未来命令。theta为二维动作矩阵与偏移，共6个参数；噪声标准差0.05，连续高斯裁剪均值及解析导数沿用已有数学函数。没有虚构零历史、访问隐藏mocap目标或使用真实扰动作为推断输入。

每任务仅从独立名义TRAIN窗口拟合offset、G、H及工作残差协方差；不带历史的对照在同样数据上重新拟合且G精确为零。岭系数1e-6，协方差使用0.05对角收缩和1e-12对角项。64个完整窗口只是软件最低样本数，不是新实验的最终样本量或功效保证。

独立变化的训练命令是必要条件。反复采集同一个固定8步探测程序，不能唯一学出完整H。实现同时检查输入设计满秩，以及扣除起始历史影响后仍保留16个输入方向；采用投影前的输入尺度，避免把几乎消失的剩余输入列重新放大后掩盖混淆。新的采集协议还必须证明训练命令与到达状态的来源及分配，数据类型本身不能证明名义执行器或独立性。

推断只接收已有严格`WarmWindow`，拒绝初始重置`ColdPrefix`、训练窗口、缺失窗口、未知字段和伪造资格标记。六参数广义最小二乘先检查学习响应的数值秩和条件数，再有界优化；逆矩阵不稳定则返回无效。条件数与残差均不是物理置信保证。G·z只是用可见历史解释响应，不等于完整恢复隐状态，也不证明名义模型能跨故障转移。

## 检验中暴露的更早前提

旧重新探测操作到达测量位置时继续使用旧C8纠正。上一轮使用了整段不变的偏置，尚未检查“偏差变化、旧纠正失效”时是否仍能到位。先做大批固定偏差校准会遗漏这一前提。

[可执行反例](../../docs/paper/check_relocation_stale_equilibrium_20261019.py)只假设理想运动学 `p_next=p+0.01·clip(u+b,-1,1)`、零噪声、无接触与隐藏执行器状态。旧纠正为恒等、速度为零时，原位置反馈为`u=-8·(p-anchor)`；常偏差b对应静止位置误差`b/8`。取约0.2的x偏差，误差约0.025，超过0.015进入门槛。直接执行原公开操作，64个合成回调步骤全部没有xyz运动，结果为`ANCHOR_NOT_REACHED`，新探测0步。只供评价的已知新偏差纠正从同一位置完成移动和探测，共16个合成步骤。

[反例原始记录](../../outputs/warm_response_reference/validation_v1/relocation_counterexample.json)保存命令、回执、公式及源散列。这里的64/16不是MetaWorld步数，也不是0.05噪声下的经验结果；新仿真帧、科学种子和API均为0。反例说明该操作没有普遍抗旧纠正失效的能力，不证明真实环境中的失败比例或唯一失败原因。

因此下一次科学采集应优先检查**旧纠正失效后的测量位置获取**：旧纠正必须先由真实早期数据保存，在预先规定的任务时刻改变评价器扰动，代理只接收合法观测，继续按既有预算尝试获取。冻结新种子、改变时刻、全部未到位/提前结束的分母及独立审计后再运行。不能把变化推迟到已经到达测量位置之后来绕开这个问题，也不能在看到失败后追加案例。

若之后采用积分反馈等常规抗偏差控制，须作为独立新版本，并把“移动期间积累的信息直接用于纠正”纳入强对照；不能预设额外8步脉冲必不可少。只有获取操作在所声明的变化范围内可用，才值得执行独立随机命令名义校准和新数据辨识资格；最终仍须完成计入移动/探测成本的任务对照与主动获取决策验证。

## 软件验证与文献边界

[新增测试](../../tests/test_warm_response_reference_v1.py)使用独立生成的代数训练和检验数据，验证已知参数恢复、起始历史对拟合的实际影响、同数据消融、裁剪均值解析导数、未来输入/泄漏拒绝、重复固定探测和输入历史混淆的拒绝、响应缺秩时停止，以及上述旧纠正反例。它们不证明真实机器人精度。开发时修复了合成夹具普通数值类型不合约的问题，并根据混淆测试把条件数缩放改为投影前尺度；这些调整都在任何新科学数据之前完成。

短序列中初始条件会影响系统辨识是已有问题，见[Risuleo等的论文摘要，arXiv v3](https://arxiv.org/abs/1504.08196v3)；本组件没有复现其EM算法或继承其理论。主动探索来辨识物理参数也已有[ASID](https://arxiv.org/abs/2404.12308v2)，任务相关探索见[Liang等，RSS 2020](https://www.roboticsproceedings.org/rss16/p085.html)。本阶段仅据这些已阅读的摘要明确新颖性边界，不称完整复现或系统文献综述。

是否在旧证据失效后能以完整成本取得有用信息，才是这里尚需解决的研究问题。标准响应模型、软件测试或上述理想反例都不能单独完成发表目标。
