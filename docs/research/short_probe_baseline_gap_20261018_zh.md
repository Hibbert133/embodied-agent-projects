# 四步联合估计基线的缺口

当前现代联合响应模型路线还没有验证“四步重新估计后直接执行任务”的廉价基线。
已有 BALANCED4 是四方向检查：需要刷新时仍完成八步；无缓存时也先测八步。
因此不能把它的任务结果当成四步新估计器的结果。这个缺口需要在后继方法晋级前
补齐，但不改变正在执行的[同状态机制测量](../protocols/paired_probe_effects_development_v1.md)。

## 代码证据

[当前联合估计接口](../../src/probe/cold_start_response.py)的 infer_operator 明确拒绝
长度不是 8 的前缀，返回 INCOMPLETE_EIGHT_STEP_PREFIX。
[时序参考](../../src/probe/chronological_cache_reference.py)中的 BALANCED4 使用均衡的
前四步检查；检查选择 RUN_CACHED 时沿用旧参数，选择 REFRESH8 时继续到八步。
无缓存的初始选择仍为 PROBE8。

这说明当前接口与对照尚未覆盖四步重估，不说明物理辨识一定需要八步。
它也不是对仓库全部历史估计器的穷尽判断：这里限定现代联合模型及当前时序参考。

## 四步数据何时可能足够

对二维仿射工作参数，令每步设计行为 (u_x,u_y,1)，组成 X。
六个参数分别控制两个输出轴；未经过动态响应映射的设计矩阵 H 每步贡献两行：

    (u_x,u_y,1,0,0,0)
    (0,0,0,u_x,u_y,1).

因此 rank(H)=2 rank(X)。若前四步仅在 x 轴上正负试探，X 的 y 列为零，
rank(X)=2、rank(H)=4，不能仅凭这些新数据唯一辨识六参数。
使用旧缓存先验填补未观测方向，与从当前四步独立重新辨识，是不同的信息条件。

四步正负 x／y 命令，或四步平衡的对角命令，可使 X 达到秩 3。
在名义动态响应映射可逆、且局部输入响应导数不退化的条件下，当前四步观测的
六参数 Jacobian 就可能达到满列秩。这里仅说明局部结构上的可能性；噪声、瞬态、
饱和、模型误差和数值条件数仍可能使四步估计不适于控制。

对角命令还需控制实际向量幅度。给两个轴各发送 0.4，与单轴幅度 0.4 的旧程序
具有不同的向量范数和能量，不能将这种增加隐藏在“少测四步”中。未来若比较，
应预先固定实际 float32 命令、范数约束及顺序。

## 后继比较需要保留的控制

第一项是完整任务程序的便宜参考：固定四步富激励后，用联合模型的因果前四步
边缘响应重新拟合，再执行相同固定政策。估计器需独立版本化，保留无效拟合，
不能修改当前八步接口或把旧模型资格直接当成四步任务资格。

第二项是同状态的增量数据控制：共享同一个四步程序和额外四步物理前缀，在共同
八步边界比较“保留四步估计”与“用全部八步重新估计”。这样才能区分额外动作与
新增数据的效果；四步估计无效、探测提前结束等案例仍需保留明确状态和分母。

ALWAYS8 及已有强参考必须保留。为避免只比较无效即停的弱基线，还需预先明确
四步拟合无效时继续获取到八步的参考，而不能事后补选一个更有利的回退规则。
四步结构满秩本身不构成方法晋级，任务成功、完整控制费用和来源费用仍需评价。

这些属于标准辨识和实验设计参考，不作为新算法。它们若表现良好，只会提高新获取
机制必须超过的基准。新方法仍须建立与既有[任务相关获取方法](correction_selection_prior_art_20261018_zh.md)
的区别，并按自身历史做独立时序确认。

本页只据现有代码和线性代数确认缺口，不读取正在采集的任务分支结果，不选择最优
四步程序，不拟合选择器，也不追加 API 或环境执行。具体估计实现、物理资格与任务
比较应在当前交付完成后，另行冻结协议、配置和新人口。
