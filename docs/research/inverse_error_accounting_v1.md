# 逆估计误差的有限变化会计与解释边界

目标是解释已保存的估计为何偏离注册执行器参数，不更改估计器。下面是
固定线性名义预测器、裁剪函数和伪逆的标准代数，不是新控制定理。

令 f_t(theta) 为在已记录可见历史上，名义预测器接收参数 theta 映射并
裁剪后的无新增噪声命令时的预测。y_t 为已观察位移，a_t 为实际执行输入，
m_t 为主机 float32 运算后的无新增噪声参考动作；它不等于裁剪后随机
执行动作的条件均值。定义

    r_total = y - f(theta_true)
    r_applied = y - f(a)
    r_noise = f(a) - f(m)
    r_rounding = f(m) - f(theta_true)

三项逐样本相加严格等于 r_total。r_noise 只是在固定预测器下传播的
输入差异，不是真实物理噪声的反事实作用。均方合计还包含两两交叉项。

对保存参数 theta_saved，令 delta=theta_saved-theta_true。LINEAR_ARX 的
参数作用仅通过两个裁剪后命令坐标进入。每坐标取裁剪差与裁剪前差的
比值；差为零时取任一符合恒等式的局部权重。这样构造有限变化矩阵 S，
使得 f(theta_saved)-f(theta_true)=S delta，包含穿越裁剪边界的情况。

令 r_fit=y-f(theta_saved)，P 为 S 的数值伪逆，则

    delta = P r_applied + P r_noise + P r_rounding
            - P r_fit + (I - P S) delta.

这是把恒等式左乘伪逆并加回零空间后的会计关系，不假定保存估计为无约束
最小二乘解。只有在线性未裁剪、满列秩且拟合驻点等条件下，后两项才可
近似消失；忽略它们会把裁剪和约束相关的修正错误计入前两项。

参数坐标按 (1,1,.3,1,1,.3) 缩放。每个分量在总误差方向上的有符号投影
可相加为总缩放误差范数；分量可能为负、可能相互抵消，不能解释为因果
百分比。增益矩阵 Frobenius 误差与偏置范数另行报告，不混成物理单位。
原保存量是有效参数假设；偏离注入参数不自动表示控制器更坏，接近注入
参数也不自动表示任务收益更好。任务结局必须分开报告。

真实参数和已执行动作仅用于评估器诊断，Agent 无法调用这组信息。原名义
预测器的训练对象是有噪声的请求命令，故执行输入下的预测残差不等于纯
确定性物理模型误差。本分析也不能单独证明反馈内生性、某个缺失状态或
裁剪是某次任务失败的独立原因。

需要先量化这些分量和修正，才能判断下一步应检验输入噪声建模、前向
适用性还是更新接受机制。[已有识别背景](passive_update_identification_gap_v1.md)
说明工具变量并非新想法，也不能在缺少相应假设时自动修复前向模型。
