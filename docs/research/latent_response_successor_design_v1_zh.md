# 下一响应基础的设计问题：公开历史初始化与多步响应

状态：**DESIGN_ONLY**，无训练/采集入口、无新TRAIN/CAL/QUAL种子或采集许可。
前置项是native_command_witness_v1的完整记录审计及原生软件合同通过。这个草稿
不把尚未执行的模型、对照或预算称为完成，不改变任何旧QUAL结果。

已完成的旧位置/短历史联合响应、GRU1/GRU16单步迁移与F20控制参考均未通过相应
门。新候选不能只是换名或增加容量。可检验的区别是：从真实已完成IO历史初始化
工作隐状态，在已知候选命令序列上连续预测多步，比较同容量无名义累计摘要的
初始化。该摘要假设恒等输入，与实际状态差异已有反证，必须作为可能有害的公开
特征检验，不能直接当作私有状态或无偏估计。私人mocap、真参数、实际噪声仅评估。

递归更新。此次读取范围分别为摘要、摘要/引言/模型编码节、摘要/引言/II–III节；
未复现算法/证明。2026文的输出误差噪声模型不能直接用于本环境的执行输入噪声。

新的执行协议需要在采样前解决：

- 给出确定模型结构、损失、训练计算预算、同容量去摘要控制和初始化控制；保留
  强历史H10/F20的单步比较，另给真正可用的直接多步回归/非线性和标准隐状态基线。
  不能让某基线读真实未来观测，再把它称为自主多步预测；也不能弱化强基线来过门。
- 严格区分可部署的预声明固定测量命令预测，与事后“给定已实际执行输入”的展开。
  固定策略未来动作依赖未来观测，入口时不可知；后者不能冒充入口在线预测。
  响应监督目标、物体/接触变量的传播及各基线权限须一致并在执行前冻结。
- 为输入变换变化和执行噪声说明可识别条件与不确定性语义。不能直接套用输出误差
  假设，也不能在旧QUAL上选特征、容量、门槛或筛掉获取失败。训练、校准和独立
 资格分别分组、分时序；参数范围、失败惩罚、预算和唯一主比较在新采样前冻结。
- 保留全部任务、变化/不变及获取可用性；空/短窗口不填零。只在有窗口子集的精度
  不能替代完整人口资格。CAL只能做执行前约定用途，独立资格不追加或选择最好来源。
