# 行动相关歧义已出现，贡献缺口仍在

新的 [坐标框架开发报告](../../reports/frame_evidence_development_v1.md)
通过独立冻结的一次执行获得 8/8 构造见证，标准反向八步 ARX 达到 16/16。
这是对上轮“不存在有用选择空间”的先决条件补充，不是新算法的晋级。
旧多项式构造的 0/16 见证失败以及 API 14/16 对 16/16 的负收益保持不变。

必须区分三种限制：

1. 重复单方向的输入支持不足：自由常数项能解释两个旋转；增加相同输入的
   样本数不能解决构造的歧义。此处代数上可证明路径输入相同。
2. 旧轨迹仿射的表示不足：完整十六步已经含区分信息，但旧表示/平移纠正
   无法表达旋转。此处不能把旧仿射失败解释成所有标定方法的失败。
3. 行动结果随机：三候选的成功集来自一次配对噪声实现，不是稳定标签。
   路径不可区分性成立不等于样本成功集在新噪声实现中不变。

校准基线已经解决全部样本，并比十六步减少平均在线成本。后续的 LLM

重复噪声实现；任何成功集不能从本轮反向当作稳定训练标签。不得用
9800–9807 调整旋转、偏置、ARX、探测或判断门，9808–9999 保留。
