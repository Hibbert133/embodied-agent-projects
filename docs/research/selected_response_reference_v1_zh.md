# 附近测量点的响应模型：实现与验证边界

上一阶段已提交 `1a0ae95`，72次执行经过独立审计。附近点PID在偏差不变、变化条件均为7/9完整测量，满足三任务各有窗口的执行要求；不变条件下仍有一个开门案例逊于附近点PD。本阶段不修改这些结果、控制增益或进入门槛，转向必要的下一步：从实际测量中估计未知动作偏差。

## 三个方法名

|代码名称|中文意思|使用的信息|
|---|---|---|
|SELECTED_INPUT_ONLY|附近点、只看输入|8步已发送动作与实际位移，响应系数不随位置改变|
|SELECTED_HISTORY|附近点、加入运动历史|再使用进入前4帧真实观测形成的相对位置与3次位移|
|SELECTED_POSE_HISTORY|附近点、位置和历史都使用|再使用当前手部绝对xyz位置，允许动作响应系数随位置线性变化|

三者必须使用同一任务、同一批完整名义TRAIN窗口，不能为复杂模型另外挑选有利样本。它们是标准回归参考，不是已证明的新算法。没有模型获得真实辨识资格或概率保证。

## 可执行模型

[实现](../../src/probe/selected_response_reference_v1.py)使用工作均值

`y = c + B·s + (H0 + px·Hx + py·Hy + pz·Hz)·E[clip(X·theta + noise)]`。

y为8个实际xy位移组成的16维向量；theta为二维动作矩阵和偏移的6个参数。s包含当前手部相对已保存目标的xyz差、之前3次真实xyz位移，以及绝对xyz位置。相对位置、历史位移沿用0.015、0.003缩放；绝对位置使用固定中心(0,0.7,0.35)和尺度(0.45,0.25,0.20)。p取进入测量时的绝对位置特征，在整个8步窗口内保持固定；实际手部之后仍会移动，这一有限窗口近似必须接受真实预测误差检验。无历史与无位置对照中的对应系数精确为零。

H的四个基矩阵都严格因果：早期输出不能使用未来输入。每时刻独立岭回归，系数1e-6，使用增广最小二乘避免正规方程进一步放大条件数；训练残差协方差使用0.05对角收缩及1e-12对角项。协方差仅是工作权重，不是校准过的误差范围。

复杂模型最后一步最多80个设计列，包含16个状态/常数列和64个输入及位置交互列。每任务最少160个完整训练窗口只是数值下限，不是最终科学样本量或功效论证。输入/交互设计必须满秩，扣除状态后仍保留全部输入方向；条件数≤1e6，使用投影前列尺度的最小奇异值≥1e-6。不能把几乎消失的剩余输入重新放大来掩盖混淆。只重复原固定8步程序，或在同一位置重复随机程序，都不能学出完整位置交互响应。

推断仅接受新`SelectedAnchorWindow`。初始重置`ColdPrefix`、旧固定点`WarmWindow`和名义训练记录均不可替代。训练所见手部位置的轴对齐范围外加0.01米，仅作为外推拒绝规则；它不是覆盖率、可达性、安全或隐状态充分性保证。6参数拟合保留±2矩阵元素、±0.3偏移边界、64次函数评估上限和逆矩阵奇异值限制。秩不足或越出训练位置范围时，在优化前返回无效。

## 新的名义采集接口

[公开操作](../../src/probe/selected_nominal_acquisition_v1.py)与旧固定探测操作独立版本化，保持附近点PID的目标规则、64步移动上限、100步保留预算、进入与探测范围门槛。区别是接收完整的预分配8步xy训练命令，每轴最大为0.8的float32表示，z和夹爪请求为0。命令在任何移动前保存，执行器逐条消费已保存命令，完整后只返回`NominalSelectedTrajectory(TRAIN)`。中断、未到位、越界均不生成完整训练样本。

[名义主机](../../src/analysis/selected_nominal_host_v1.py)要求此前实际使用过已保存的C8纠正，检查一个受控初始重置、原噪声序列、连续物理时钟和全部已发送动作。它仅接纳I矩阵、零偏移、零死区执行器；检查此前动作与名义机制和已记录噪声相符，操作期间再次检查。真扰动与实际受扰动作留在主机，不传给公开操作或模型。一次操作消费后禁止重用，无状态复制、恢复、额外策略查询或新参数拟合。

这些接口还不能证明训练命令独立分配。正式采集器必须在读取任务观测之前登记命令，由独立随机源生成；记录实际工厂重置、初始重置、初期C4/C8准备、任务推进、移动和探测的完整成本。所有未得到样本的尝试都要保留。不能反复采集到成功凑够160，再只报告成功者费用。完整窗口筛选还可能依赖所执行的命令：例如某些命令更容易造成越界或提前结束。预先随机分配和满秩检查不能消除这种筛选偏差，必须披露样本流失并用独立全人口评价检查实际误差。

## 与已有位置条件化辨识的关系

已核对Bamieh等2002年论文的出版方摘要：当系数对可测调度变量的函数形式已知时，LPV辨识可以化为线性回归，激励要求同时涉及输入和调度变量轨迹。因此本实现中的位置交互特征及联合输入秩检查属于常规建模工具，不能单独算创新。[出版方摘要](https://onlinelibrary.wiley.com/doi/abs/10.1002/rnc.706)

已阅读Chin等2020年论文第2节：该工作用局部模型的标准误构建高斯过程，主动选择下一工作点；其设定包括完整状态可测、各工作点稳定及独立同分布扰动。选择测量位置以降低模型不确定性已有直接先例。本项目仅有可见观测和有限历史，隐藏执行器目标不对估计器开放，也未验证这些假设，因此不能继承该文的方差性质。这里的残差协方差与数值秩通过，只能支持软件计算，真实误差仍需独立数据评价。[原论文第2节](https://arxiv.org/pdf/2005.00711)

上述对照明确了当前模块的常规方法属性，还不是完整新颖性审查。本项目待证明的是：在旧证据可能失效、获取过程本身消耗任务预算时，怎样决定是否重新测量，并取得强基线无法提供的任务收益。
