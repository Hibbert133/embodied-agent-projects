# 从单次赢家改为固定可见前缀下的继续策略代价

本阶段补足一个测量缺口，不将旧失败门改成通过，不拟合旧 IVR 权重，也不
宣称新的在线算法。发表目标仍需要竞争性机制、独立确认和完整论文。

## 已有实验回答了什么

旧 ACR utility-realization-stability 固定初始任务与一次探测证据，再重置
执行六次独立新验证；它研究有界补偿与重试的 status utility。
近期 early-evidence 与 executable-support 研究连续 500 步轨迹，但噪声重复
从初始状态即不同，因此同一名义上下文的前八步观测可能不同。
这些结果不能直接估计当前连续八步证据条件下的后续策略平均代价。

单次候选赢家经常反转，也不逻辑推出条件平均收益不可学习。例：停止分支
损失恒为 100，继续分支以各半概率为 0 或 150，则继续的期望损失为 75，
虽然单次赢家有一半反转。这个算术例子不是机器人任务收益或新定理。

## 新问题与控制

先固定一次真实八步对称探测的可见前缀，再改变后续执行噪声。所有分支
独立创建环境、只重置一次、实际重新执行前缀；不复制或恢复模拟器状态。
噪声在交互之前生成成不可变数组：同任务前八步完全相同，后 492 步由四个
独立的预先指定实现给出。轨迹中没有重播种、切换 RNG 或重置。

条件对象是该初始化机制、名义任务与同一可见前缀下的后续噪声分布；
声明的积分／模型／任务见证不证明所有观测相同隐状态的分布都相同。
生成未来噪声不等于执行未来环境，噪声数组和承诺摘要只属于评价器。

比较五个在该前缀后真正可选的固定继续策略：直接用八步 Gaussian 控制；
再探测八步但保留原控制；再探测八步后 Gaussian 更新；同样探测后点逆；
执行八步原 Gaussian 政策并利用自然观测更新。另保留原宽十六和完全不探测
作为总体对照；它们不属于同前缀决策组合。

测量的是这些**固定继续策略的条件损失**，不是纯信息价值或最优 Bayes
策略价值。KEEP 控制有助区分探测运动／时间与更新控制器的作用；也不能
把两者简单线性拆解成全局因果贡献。

## 跨未来实现的评价器查询表

对每个八步前缀、每个留出未来实现，只用其余三个实现的各继续策略平均
截止损失选择分支，再评价被留出的真实分支。平局按预登记的低探测顺序
处理。这个查询表使用相同前缀的反事实训练结果，是评价器诊断，不是可
部署 Agent、不是真实在线选择轨迹，也不是真正最优策略的上界。

主诊断是该查询表对始终直接八步控制的留出损失差，按算子流分层计算
区间；全部固定分支及逐前缀均值／范围保留。单次赢家一致率仅可描述，
不再作为期望损失是否可学习的替代门。四个未来样本不足以给出可靠的
逐状态分布保证；查询表无收益也不能推出条件最优策略不存在。它可能
只是三个训练未来不足以估计均值；有利诊断仍需可见特征方法和独立在线评价。
