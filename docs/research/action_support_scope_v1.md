# 行动输入支持与模型作用域：方法基础 v1

本阶段把“证据足以支持哪种声明”变成可执行的检查与只读审计。它服务于
持续的 CCF A 研究目标，不将已有线性代数或数据 informativity 当成创新。
没有新物理任务、API 调用、种子分配、参数拟合或历史结果重写。

## 需要区分的声明

框架小试的八步 ARX 比较的是预先公开的 I/90 度两类旋转。该先验使 x
方向响应可以决定 y 方向映射，因此 16/16 是有效的模型作用域内结果。
若声明覆盖未知的一般二维仿射执行器，x 方向数据并没有测量独立的 y
系数。两种声明不同；后者不能从前者的成功率推出。

新增 `src/probe/action_support.py` 只接受已发送命令和当前待发送命令。
不接受环境、当前真实算子、种子、随机数、任务结果或未来观察。它输出
输入秩、当前命令是否在已有输入张成空间内、可检查的零空间见证与
插值误差放大系数。所有结果明确不构成模型有效性、概率或任务成功保证。
可选的最便宜补充探测只是结构基线，仍须独立资格认证、物理安全检查及
统计精度判断；不得接到已完成的实验执行器并重跑原种子。

## 条件性命题与证明

限定静态、截断之前的平面仿射执行器：`f(u)=M [u_x,u_y,1]`。
将已发送命令增广为矩阵 X 的行，当前命令增广为 q。若执行器等价响应
无噪声且可观测，那么所有与这些响应一致的仿射映射在 q 上取相同值，
当且仅当 `q in row_span(X)`。

充分性：若 `q=X.T w`，则每个一致映射满足 `M q=Y.T w`，与未知 M 的
其余系数无关。必要性：若 q 的正交投影残差 r 非零，令
`Delta = a r.T / ||r||`，其中 a 是任意非零输出向量，则
`Delta X.T=0` 而 `Delta q=a ||r||`。M 与 M+Delta 在全部探测输入上一致，
在查询输入上不同。附加有限旋转、可逆性或参数界可能排除该见证，必须
另行公开这些模型条件，不能称其为无先验结论。

若观测等价响应满足每个分量误差 `|e_i|<=epsilon`，支持空间内的插值
响应分量误差不超过 `epsilon sum_i |w_i|`。这是确定性条件推导，没有
估计 epsilon，也没有保证机器人观察已经转成了合格的执行器响应。
输入全秩仍不证明模型正确、误差足够小或任务成功。MetaWorld 的惯性、
接触、饱和和未知名义动态使“可观测等价响应”成为另一个必须验证的条件。

实现把有限浮点命令按精确有理数解析，以行列式检查仿射张成空间，不能
把 1e-12 的未测方向按“近似为零”批准。相对数值秩阈值固定为 1e-10，
数值投影阈值为 1e-8，只用于并列诊断，不决定精确支持通过。返回的最小
二乘权重只是数值插值诊断；未提供物理响应估计或噪声置信区间。读取新
诊断结果前通过合成解析案例测试，不根据任务成败调整。仅覆盖 xy 与常数项，z/
夹爪、状态相关和非线性算子不在这个作用域内。

## 已有工作与实际贡献缺口

- [van Waarde 等，IEEE TAC 2020](https://arxiv.org/abs/1908.00468) 已研究
  数据是否足以完成特定分析/控制任务，且不总需要唯一系统辨识。因此
  输入支持与“为行动取证”不是我们的新定理。
- [Explore until Confident，RSS 2024](https://roboticsproceedings.org/rss20/p089.html)
  已将置信校准用于具身探索停止。校准后停止本身不是新方法。
- [Introspective Planning，NeurIPS 2024](https://proceedings.neurips.cc/paper_files/paper/2024/file/8451a20c5a7e0ee5671dda28f7daf7f3-Paper-Conference.pdf)
  已结合知识检索、推理和 conformal prediction 来减少不必要的澄清。
  记忆加校准的组合也不能直接作为本项目创新。
- [Provably-Safe, Online System Identification，RSS 2025](https://www.roboticsproceedings.org/rss21/p121.html)
  已联合安全激励轨迹与有界参数辨识；本阶段的输入检查不提供同等级的
  机器人安全保证。
- [Beyond Persistent Excitation，L-CSS 2021](https://research.rug.nl/en/publications/beyond-persistent-excitation-online-experiment-design-for-data-dr/)
  已以历史输入/输出在线选择激励以取得有用秩性质；“补齐缺少方向”本身
  不是我们的主动设计创新。
- [Select-DPC，L4DC 2026](https://proceedings.mlr.press/v331/naf26a.html)
  已在非线性输出反馈控制中在线选择相关轨迹，并比较标准/时间窗口 DeePC。
  最近子集与在线数据筛选也不是充分的新颖性证据。

尚待检验的研究方向是：对受预算约束的具身代理，将模型作用域、测量精度
和当前行动依赖分开记录，并在证据失效时补充必要方向的观测。需要实际
方法与强数据驱动控制/主动辨识比较、独立任务/算子/噪声证据，以及新能力
的因果消融。这个检查基础只明确了义务，未证明该方向新颖或优于已有方法。

## 与输入方向相关的证据老化候选

对时间变化的算子进一步显式假设逐系数漂移界
`|M_t[j,k]-M_i[j,k]| <= rho (t-i)`。精确插值查询 q 的分量响应误差外包络
半径可写为 `sum_i |w_i| (epsilon + rho (t-i) ||x_i||_1)`。这是把测量
误差与参数漂移分开的条件性三角不等式，未作为新控制定理声明。
没有时间信息或观测时间晚于查询时，原型不能批准该条件性推论。

原型使用最早/最近的独立输入子集，取有效外包络的交集。交集为空可以
否定声明的静态/漂移/误差条件；否则按查询与旧预测的距离提出条件复用、
补充时间有效性、补充精度或拒绝旧预测。合成测试证明：新 x 测量可恢复
x 查询的界，却不会自动恢复旧 y 证据；补测 y 后可拒绝旧模型。此处没有
声称为已知的最优实验设计，也没有从现有 MetaWorld 任务拟合 rho、epsilon
或容许响应误差。强集合辨识/C-optimal 主动设计比较与真实观察资格仍缺失。

这个候选把旧标量缓存戳改成查询依赖的验证义务，具有可检验的机制。
它尚未完成针对时变数据驱动控制的完整新颖性复核，也未连接在线执行器。
不能因为解析测试通过就升级成算法创新、真实机器人安全或任务收益结论。

## 只读诊断

对冻结的 176 个框架方法执行，统计两种支持条件：固定探测数据，以及
当前步之前的探测加已完成任务命令。后者只含当前查询前的历史，不能把
当前或未来命令加入之后再声称之前已覆盖。报告每方法所有案例的秩、
输入支持缺口和首次缺口位置，不以当前成功/失败来修改判断。
实际完整轨迹仅用于事后诊断；不是部署时可预知的未来命令包络。
各案例的结果保留作关联描述，不产生新任务表现或恢复率。

## 条件性复用核验原型

`src/probe/response_transfer.py` 增加了可执行的缓存响应核验原型。它从独立
输入子集以有理数消元求精确插值权重；给定合法可观测的等价响应与明确
假设的分量误差包络，构造 `sum w_i y_i ± epsilon sum |w_i|`，再与旧模型
在当前查询的预测比较。使用有向浮点舍入显示外包络，判断在精确有理数
上完成；不把数值近似或噪声标准差当成证明。

原型能提出缺少输入方向、精度不足、拒绝旧预测或条件性复用四种不同
建议。没有误差包络时返回未资格认证；所有建议的真实模型有效性和任务
保证仍为 False，不能直接驱动 MetaWorld。合成解析测试覆盖仅 y 系数改变
而 x 测量不变、补测后拒绝旧预测、未变模型与有界对抗误差。该原型是
标准集合辨识/插值基线，未证明新颖；它让下一方法实验必须解决的观察
资格、时序有效性、风险与预算义务可具体测试。

检查原 manifest/audit 的身份、全部原始文件散列，并用独立秩增量公式
复核投影判断：查询属于旧行空间，等价于加上该行不增加秩。保存工具
提交、源文件散列、审计散列和逐例诊断到新的输出目录。原数据和保留种子
不变；没有重新仿真、训练或修改旧选择。完成仓库验证后本地提交。
