# 重新获取证据的触发依据与任务风险

后继方法需要回答：当前控制器还能否可靠完成任务，新的物理测量是否值得其费用与状态改变。
检测模型变化、按不确定性设计激励、达标后停止测量，均已有直接相关方法。
本次核对补齐事件触发学习与统计停止规则；这是方法选择依据，不是新颖性认证。

## 三种概率问题应分别提出

**误报风险。** 参数滤波论文的定理 1 讨论模型正确时触发的概率，需满足其滤波分布条件。
本仓库 `UNCERTAINTY4` 检查四步响应的预测残差，尚未实现该论文的递归参数滤波与激励 MPC。
源参数协方差和名义响应协方差仍是工作模型，不能从相似的二次型获得该论文的保证。

一次检验的误报水平也不是完整自适应序列的误报水平。作为标准概率关系，若每次事件
的概率都不超过 α，m 次的并集只能直接用 min(1,mα) 上界；不要求独立。
若检查时刻由历史选择，还需先证明对应的条件或停止时刻性质。这不是新的理论结果，
也不否定原论文在其假设和声明范围内的结论。

**停止后的任务风险。** Poke and Strike 第 4.5 节利用成功任务中的不确定性分位数设定阈值。
对我们的后继方法而言，P(U≤c | success) 与 P(success | U≤c) 是两个条件量，
仅由前者不能推出后者。这里只说明借用阈值时需要检查的条件，不把它当作原论文的实验证伪。
若要声明停止后的风险界，必须定义全部成功、失败、停止上的损失和校准人口。

**重新测量的增量价值。** 低不确定性不直接给出再次测量的收益。新测量花费步数、改变
任务状态，并可能产生被拒绝的纠正；“测后不确定性降低”与“整体任务损失降低”不同。
当前同状态研究的固定程序效应已为这个区别提供测量方式，但尚不是可部署的决策规则。

## 对后继实现的具体要求

先保留正在运行的[四步与八步比较](../protocols/short_probe_reference_development_v1.md)。
它将补齐廉价重估参考；没有必要为了形成新名字，再增加一个未经任务验证的残差阈值。
后续设计需同时明确以下对象：

1. **决策输入与历史。** 使用当前观测、已经发送的动作、剩余预算，以及该方法自己较早
   实际形成的历史。持续维护参数估计和是否将估计用于控制，应是分开的操作。
2. **预测目标。** 明确比较的是固定政策继续执行、真实补测后更新、还是更新无效后保留。
   目标须包含整个剩余任务的损失与物理费用；局部响应残差只能作为输入或辅助目标。
3. **校准单位。** 跨单元复用会改变后续缓存与访问状态，候选方法必须按自身历史运行。
   同一个隐藏状态的多个未来噪声重复，不能充当多个独立校准状态；先前固定来源历史
   上的一次建议，也不能替代新方法完整时序流的部署风险。
4. **可比较对照。** 四步与八步完整程序、滚动被动辨识、普通变化检测和任务相关获取
   都应保留。若加入参数滤波型事件触发参考，要明确是完整复现还是受限适配，匹配其
   观测、连续控制和训练权限；单纯改名为 ETL 不满足这一要求。
5. **可检验差异。** 候选需事先指出标准参考在哪类可观察情形中会作出不利决定，以及
   新机制如何利用额外的合法证据改变决定。收益必须在新冻结人口检验，包含所有失败，
   而不是在本批结果出来后挑选任务或调整阈值。

若采用统计风险控制，机器人截止损失不能预设随探测长度单调：更多探测也可能损坏状态。
[Conformal Risk Control 的基本摘要范围](https://arxiv.org/abs/2208.02814v4)包含单调损失的
期望控制；LTT 提供处理非单调风险的既有路线。选择这些工具仍需证明所用样本、
部署分布与损失符合相应条件，不能把历史分支数据自动当成新政策的独立校准数据。

文献核对的新增仿真、训练和决策 API 调用均为零，也未进行阈值选择。核对时仅查看 MAIN 的运行状态与
完成计数，没有读取其中的方法成绩。文献笔记在冻结源码之外新增；MAIN 完成前不改变
源码提交。新方法、独立验证、消融与完整论文仍按[发表目标](publication_path_v1.md)推进。
