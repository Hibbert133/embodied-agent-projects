- [Parameter Filter-based Event-triggered Learning v1](https://arxiv.org/pdf/2204.02059)，本次读摘要及 II–IV 中的设置与触发框架，未复现定理：比较固定控制模型与参数滤波估计，显著偏离时激励、降低不确定性后再更新。其线性、全状态及噪声条件不能直接当成本项目联合 EKF 的保证。“先确认再更新”应是强参考，不能单独算新贡献。
- [ALCOI v2](https://arxiv.org/html/2404.09030v2)，本次读摘要、1–2：按控制目标设计辨识实验已有有限样本研究。该文的探索阶段不计控制成本，另用新评价 episode；这是与本项目单次连续获取及完整费用设定的区别，但区别本身不是新算法或新颖性证明，也不能以此断言所有双重控制方法都未覆盖本项目。

审问结论：冻结观测器只补一个标准参考。后续候选若只是参数滤波＋显著性门＋信息量停止，应关闭其独立新颖性措辞。真正要检验的是获取改变当前状态、纠正改变后续访问时，在同权限、同费用、同自身时序评价下能否学习更好的完整决策；通用完整程序风险／DR、用途相关辨识、模型适用范围和双重控制仍须正面对照。
