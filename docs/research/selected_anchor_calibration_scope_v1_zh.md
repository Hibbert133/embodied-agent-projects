# 测量位置选择与校准成本：当前研究边界

本说明在附近测量点的72次科学采集之前写成。当前已实现的是可执行的测量位置选择参考，尚未建立新位置上的响应模型。本文不登记新的训练/评价种子，不把操作资格当成完整研究目标。

## 为什么减少移动还不够

固定位置可能让参考响应模型覆盖较窄的状态范围，但需要从任务状态移动过去。附近位置可能减少移动，却扩大模型必须处理的绝对位置、高度和运动历史范围。这是本项目要检验的成本与模型适用性取舍，不能预设附近位置更优。每方法的完整账单需要同时包括在线移动、探测、计算及按同一任务单元数摊销的离线训练和资格数据。

安装环境的`SawyerXYZEnv.set_xyz_action`先裁剪动作，再乘`action_scale=0.01`，累加到mocap目标并裁剪到工作范围；观测到的手部运动还由后续物理步产生。因此当前观测姿态不是完整的执行器状态，不能直接将一个动作单位解释为已发生的一厘米手部位移。私有mocap状态可以用于评价核对，不能成为代理估计器的输入。

新`SelectedAnchorWindow`记录预先保存的目标、4帧真实进入历史和8步真实命令/响应。旧warm参考的进入条件和特征以固定点为中心，所以新类型明确被旧估计器拒绝。修改门槛、把坐标平移后交给旧模型，或者伪称初始重置，都不能证明模型适用于新数据。

## 下一阶段必须取得的证据

若执行资格支持继续，应另行冻结真实名义采集、模型拟合和留出辨识研究。训练需独立变化的实际输入，不能反复同一8步程序后声称识别完整响应矩阵；采集到位失败也要计入完整成本与分母。名义执行器的来源由主机证明，推断只读公开观测。

至少比较相同训练数据上的无历史参考、历史条件化参考，以及必要时加入绝对姿态条件的参考。姿态对输入响应系数的作用需要实测，不能只看到更多窗口就认定其不重要，也不能先断言复杂模型一定更好。设计必须检查扣除状态/历史后的输入秩与条件数，保留无效拟合和全人口失败惩罚。

留出辨识需要新种子、新噪声，覆盖注册的偏移及矩阵变化；模型在读取留出结果前冻结。固定点模型和附近点模型各自支付其全部名义来源成本。任务研究还须保留C8直接继续、移动后不改纠正、探测前积分补偿、完整移动轨迹的同模型估计、探测不更新纠正等对照，详见[移动信息参考](relocation_information_reference_v1_zh.md)。

## 与已有工作的关系

短数据辨识中处理初始状态不是新思想。Risuleo等研究了初始条件对核方法系统辨识的影响，并联合估计初始条件与核超参数；本文只据已阅读的摘要确认这一边界，没有复现其方法或引用其保证。[论文摘要](https://arxiv.org/abs/1504.08196v3)

ASID利用初始模拟器设计探索策略，收集用于修正物理参数的数据；任务导向探索也已有RSS 2020框架及机器人实验。因此“主动试探”“在有用的位置采样”或“考虑历史”都不足以单独构成新贡献。本项目仍需明确可区分的方法和完整成本任务收益，而当前位置规则只是参考操作。[ASID摘要](https://arxiv.org/abs/2404.12308v2)，[任务导向探索论文摘要](https://www.roboticsproceedings.org/rss16/p085.html)

以上三条仅为已核对摘要的局部对照，不是全面新颖性检索。CCF A目标仍保持未完成。
