# 获取完成后随机释放额外轨迹：可学习机制原型

状态：**待研究候选的公开接口与监督设计；尚无训练模型、原生部署资格或新任务收益。**
本文件不重新打开旧 ARX、SS、固定时点清零或旧 QUAL；不分配机器人种子。

## 问题、已有证据和可证伪假设

最新标准控制记忆实验的直接清零主比较为 −6.851852 步，95% 区间
[−24.722222,7.111574]，`NOT_QUALIFIED`。完整十程序、630 次执行及全部
37 个任务失败保留，见已有中文报告。测量与不测量的次要差异混合了真实
状态、费用和准入变化；旧程序并未用新增八步数据形成新模型，因而不能
据此断言信息没有价值。也不能把旧人口中的最佳程序当作可部署选择器。

本候选检验：**在获取动作已经实际改变状态以后，额外提供获取轨迹，
是否会通过一个固定、真实执行的接收策略改善完整任务损失；获取前能否
学会预测这个带符号效果，且比同数据直接程序表现回归更有用？**
如果额外轨迹不带来增量收益，或直接回归/廉价固定增益已解释全部优势，
则机制假设不成立；不能把移动本身的效果改称信息价值。

## 实验对象和信息边界

获取前的公开历史为 H。宏动作 a 为继续任务、八步短验证或移动后八步测量。
固定策略和 XY PI 外层保持原有定义，不训练底层策略。短验证正常推进
任务积分；移动暂停任务积分并从真实返回状态恢复。一次宏动作，不重复探测。

宏动作完成后才产生独立随机变量 R，0 表示屏蔽额外轨迹、1 表示释放。
两组接收者均拥有相同定义的共同输入 Z：真实获取前/后控制器记忆、39 维
当前观测、已付步数、阶段长度、退出原因和任务名。后状态、退出原因、
积分及观测内已有上一时刻信息都会传递信息。**屏蔽组绝不是无信息组。**
R=1 额外拥有真实命令与前后公开观测序列 S；不提供噪声、扰动真值、
私有状态、种子、随机状态、未来任务结果或来源身份。审计哈希、R 的位、
随机数和模型版本保留在审计层，均不作为模型特征。

空轨迹时两个模型输入逐字一致，并必须使用同一共同状态输出；不能用
释放标志或两套不同控制器人为制造“信息收益”。非空轨迹对一个有限接收
策略也可能有害。随机化在真实返回后进行，可以识别相对于这个共同接口
的**额外轨迹效应**；这不是“全部信息相对于纯物理作用”的因果中介分解。
跨不同实验单位无需假称物理状态逐字相等；需要真实随机化及完整组统计。

## 接收策略与实际控制

固定接收策略 ψ 在 Z 或 (Z,S) 上预测四种完整任务风险，选择
T∈{0.125,0.5,2,8} 秒。它仅改变现有外层 PI 的积分速率；已有积分 I、
控制器基映射、实际当前观测和步数全部保留，不清零积分、不采用失格的
ARX/SS 逆控制。它是标准增益选择，不单独作为算法创新。

两类输入共享共同风险头；有实际非空 S 时才允许额外的信号修正。
原型的输入为 123 维共同向量、最多 72×86 的实际轨迹张量和显式有效位。
补齐的零是被掩蔽的填充，不能解释为早期真实位移。训练架构尚未冻结。
四个 T 均数值合法，但这不等于预测合格、任务收益或安全保证。

主机先持久化接收选择和增益计划，再消费计划，下一步固定策略仅查询
一次，使用该选择发送命令。屏蔽和完整组对真实获取期间的控制相同；
若拒绝信息、保留原速率或提前结束，仍保留已发生的状态变化和费用。
当前纯数组实现证明计划到下一条发送命令的关系，**未认证原生物理主机**。

## 真实反馈、监督和冻结闭合

后续独立 TAIL_TRAIN 应随机执行 a 与返回后的 T，记录这个实际 T 的
完整终局。对同一次真实执行可构造完整/屏蔽两种预测输入，学习条件任务
风险；二者共用同一事实标签，不是两个独立样本。每条真实轨迹总权重一。
接收策略只用该训练阶段确定，然后将 ψ 的参数、编码器及哈希冻结。

随后独立 GATE_TRAIN 随机执行 a，在真实返回之后随机 R，并从当时真实
状态执行已冻结的 ψ_R，得到完整截止损失 Y：成功为全程序已付控制步，
失败/停止为 500。移动、验证、探测费用在 Y 中只出现一次；另列实际交互。
旧来源策略轨迹不能重标成新 ψ 的实际终局。

若 0<p=P(R=1)<1 已知且如实随机，并且整个独立组被排除在其 nuisance
预测的训练集外，采用标准 AIPW 标签：

```
M = μ0 + (1-R)(Y-μ0)/(1-p)
F = μ1 + R(Y-μ1)/p
D = F-M
```

μ0、μ1 可依赖已产生的 Z；它们服务方差控制，不替代真实终局。标签不裁剪，
可以小于 0、大于 500；D 可正可负。学习的获取前风险为 q0(H,a) 与
d(H,a)，程序评分 q0+R·d，不再增加一次获取成本。获取前不能读取 Z 或 S。
R=0 时返回状态仍可有益；不能强迫所有移动收益经由信息分支解释。

若接收前已经实际成功/终止/用尽 500 步，两个接收策略均无机会执行，
所以两种结果由执行语义相同，D=0；已知终局需与实际状态一致。空轨迹
同输入同 ψ 时亦相同。这是执行上的已知相等，不是给缺失反事实补零。

若更换 ψ、编码器或后选择规则，GATE 标签不再对应同一完整政策；必须
重新取得相应支持并另冻结，不能离线“修正”旧终局后沿用原资格。
当前接口只检验声明和数值；实际随机性、组划分和真实执行仍需原生记录审计。
