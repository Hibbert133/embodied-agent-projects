# 条件代价选择器的文献边界与研究作用

核查日期 2026-10-15。这里的普通 RBF、最近邻和任务均值选择都是强基准
建设；实现在线选择与发现新算法是不同要求。

[Xu 等 SATzilla](https://arxiv.org/abs/1111.2249)的出版信息为 JAIR 2008，
arXiv 收录为 2011；读取摘要和出版元数据。按实例预测算法表现并选择组合
成员已经存在，因此本项目的回归代价再取最小不能独立称为创新。

[Arcari 等 L4DC 2020](https://proceedings.mlr.press/v120/arcari20a.html)
的摘要描述了用场景树兼顾辨识和控制；一般未来知识与行动耦合也不是空白。
[Aoki 等 ToIA 2026 预印本](https://arxiv.org/html/2609.19378v1)的摘要和
引言说明任务相关的未来方差缩减以及已有 MPPI 采样上的计算。任务相关采集
本身不足以构成差异。本项目没有实现这些原论文的完整算法复现。

当前新测量与旧失败候选的区别是实际固定连续八步前缀，监督为四个不同
后续噪声实现的平均截止损失；测试在全新算子流上真实先选再执行。它处理
先前“单次赢家不稳定”与“期望任务代价是否可学习”被混用的问题，但均值
回归和重复采样降噪仍是标准方法。旧两阶段六步、旧群组、旧后选择及其
失败结论保持不变，不在那些群组上换特征或重新选阈值。

即使本轮有利，也仍需可明确区别于标准选择与 dual control 的新机制，
更广的独立故障和任务评价、实际校准资格或清楚的模型失配边界、以及完整
论文。若本轮无益，则不能用旧离线查询表的 92/96 代替新方法表现。
