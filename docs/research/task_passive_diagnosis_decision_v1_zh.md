# 任务 PI 与响应接口诊断后的判断

2026-10-22；来源结果提交 `4dcacc870c47cb3a842471159990daddac58936b`。本诊断全部是**事后描述性分析**，没有新环境交互、重置、物理帧、模型拟合或在线 LLM API 调用。没有更改原资格结论，也没有重新选择主方法、Ti、任务子集或样本量。

目前建议是：**先制定控制响应接口的独立资格协议，暂不开展增量控制或移动前获取的新采集。** 保留完整条件 F20 作为候选成分，不能把它逆映射成已合格的名义植物；简单增量或残差延续也不能仅凭公式作为替代接口。

支持这一判断的证据是：在八个资格程序各自真实访问的完整记录上，F20 原预测的总体下一步 MSE 均低于简单 XY 增量、四维增量和单位增益残差延续。两套冻结来源银行都出现这一结果。所有18个线性模型、26个预测量、三个任务×两条件和移动阶段均保留。这里是预测对比，未部署任何增量控制器，不能据此推断其完整任务结局。

任务 PI 本身提供了强被动参考，但锁定的 DIRECT_TASK_PI_T0.5 未通过同时超过 DIRECT_C8 与 MOVE_INTEGRAL 的共同资格门槛。RAW 的次要均值较低，仍保留次要身份。主方法全分母有26例相对 DIRECT_C8 损失增加，另有23例改善、5例持平。不得围绕资格数据调整参数，再把同人口成绩称为独立证据。

两个资格 PI 失败案例均未触发策略 XY 裁剪、基命令 XY 裁剪或 PI 发送限幅；最终执行器裁剪分别有10和17步。它们都长时间停留于固定策略的下降阶段代理，但没有逐步接触力或接触对。RAW 失败案例的输入偏差还相对影子基命令降低。裁剪、输入偏差、参考切换、参数误差不能单独解释失败，更不能把输入或预测指标替代任务收益。

下一份协议至少须在采集前明确以下契约：

1. 参考响应的物理单位、时间区间及其与固定策略目标的关系；区分正常策略参考、注入输入映射和机器人实际位移。
2. 命令、执行器输入、观测位移的时间对齐，以及执行器／物理动态、裁剪和必要历史如何进入模型。若需要新训练，另列训练人口、资格标准、失败规则和全部费用。
3. 保持同一当前观测与单次原策略查询，定义允许发送的 XY 候选及 Z／夹爪保持规则；任何假设动作必须实际执行才能产生控制证据。旧局部 XY 成分结果不扩展为 Z／夹爪资格。
4. 软件契约之后，用新接口自身生成的独立时序历史检验完整任务损失与成功率。保留 DIRECT_C8、MOVE_INTEGRAL、竞争性的锁定被动 PI、不获取、获取不更新及始终获取；不能只比较预测均方误差。
5. 开发选择和最终冻结分开，不使用当前资格历史重新调阈值。只有新控制基线有效，才进入移动前验证／重测／采用幅度的完整获取决策研究。

这是一份后续进入条件，不是已批准的采集冻结，不占用或预留新种子。仍需实现、测试、独立审计、预算与协议提交后才能开始新采集。已有失败 ARX／GRU 不再叠加选择规则。增量控制已有系统研究，见[本次查新](novelty_update_20261022_incremental_v1_zh.md)；新颖机制、强最终比较、独立部署和消融仍未完成。
