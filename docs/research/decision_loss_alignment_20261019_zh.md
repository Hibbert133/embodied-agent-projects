# 配对预测误差不能单独决定选择器是否有效

正在采集的中途切换研究仍按原冻结协议执行。本页不读取其中的任务结果、不训练模型、不修改其比较或门槛。它修正后继方法的评价设计：最终要最小化所执行动作的任务损失，不能把配对差MAE或“猜中这次赢家”的准确率当作充分或必要条件。

这不改变旧尾价值组件的失败结论。旧模型实际离线选择为94/96、平均损失95.02，固定更新为95/96、89.38，真实选择指标本身就更差。也不重新拟合旧数据、调整门槛或将旧模型晋级。

## 一个精确的反例

以下是人工构造的有限分布，不是机器人结果。公开上下文A、B各占一半；每次必须在CURRENT和ALTERNATIVE之间选一个。相同A中的两种未来，在作决定时不能区分。

|公开上下文|该未来的总体概率|CURRENT损失|ALTERNATIVE损失|
|---|---:|---:|---:|
|A|9/20|100|99|
|A|1/20|100|200|
|B|1/2|100|96|

定义差值D=ALTERNATIVE−CURRENT，负值有利于切换。A的条件均值为9.1，条件中位数为−1；B两者都是−4。预测为零时固定选择CURRENT。

|预测器|A/B预测差值|配对差MAE|猜中本次赢家的比例|实际期望任务损失|相对最优合法规则的额外损失|
|---|---|---:|---:|---:|---:|
|常零|0 / 0|7.45|5%|100|2|
|条件中位数|−1 / −4|5.05|95%|102.55|4.55|
|条件均值|9.1 / −4|9.09|55%|98|0|

MAE更低、猜对次数更多的中位数规则，忽略了A中少数但较大的切换损失。条件均值规则MAE反而比常零大，却正确地在A继续、在B切换。因此，“配对差MAE必须优于常零”也可能排除更好的动作规则。

这不是说均方误差在理论上必然错误：在足够表达能力和适当估计条件下，平方误差针对条件均值。实际有限数据、受限模型和训练分布下，总体回归误差仍不能自动替代真实选择效果。绝对误差针对中位数，而期望任务损失的决策取决于均值，两者尤其需要区分。

## 决策损失与加权错误的联系

对同一合法历史中实际支持的两个动作，令C₀、C₁为后续任务损失，D=C₁−C₀。给定任意动作d∈{0,1}，逐实现有

```text
C_d = min(C₀, C₁) + |D| × 1{d 不等于本次较优动作}。
```

当D=0时错误权重为零，并列怎样处理不影响这一恒等式。它说明直接数“猜错几次”会丢掉伤害大小。取期望后，最小化加权分类损失等价于最小化真实期望任务损失；这是标准代价敏感决策关系，不是新定理或机器人算法。

还需区别两个参照。上式的`min(C₀,C₁)`允许事后知道本次未来；合法规则只能看公开历史e。令m(e)=E[D|e]，最优合法规则按m的符号选择。预测差值m̂所诱导规则相对它的期望额外损失为

```text
E[ |m(e)| × 1{预测所选动作与条件均值最优动作不同} ]。
```

标准符号比较与Jensen不等式给出

```text
合法规则额外损失 ≤ E|m(e) − m̂(e)| ≤ E|D − m̂(e)|。
```

因此在真实测试分布下，一个已经成立的绝对误差上界仍可提供较松的风险上界；但两个模型MAE的排序不保证决策风险排序。训练误差或一个未来实现不能充当该总体上界的证书。

本例事后逐未来最小损失为97.55，最优合法规则为98；二者间的0.45来自当前公开上下文没有区分的未来。不能把97.55写成可部署方法成绩。

## 多动作训练时不能随意抹去权重

对每个完整、实际支持的损失向量L，定义非负权重wₐ=max_b L_b−Lₐ。若每个动作损失都已得到合法的离线监督，则

```text
E[wₐ|e] − E[w_b|e] = E[L_b|e] − E[Lₐ|e]。
```

所以按条件期望权重取最大，与按条件期望损失取最小一致。对不受参数化限制的概率向量，非归一化加权交叉熵`−Σₐ wₐ log pₐ(e)`的总体最优概率与`E[wₐ|e]`成比例；可由其熵加KL分解得到。总期望权重为零时所有动作等价，按预先指定的基线打破并列即可。这不保证有限模型、优化器或有限样本会达到该最优值。

若先将每条样本的w除以本条权重总和，再把所有样本等权训练，就相当于按这个总和的倒数重新加权场景，可能改变任务目标。计算脚本加入第三个辅助动作后，完整权重得到期望损失98，逐样本归一化得到102.55。不能把“它们都叫分类”当作目标等价的理由。

缺失动作的结局不能填零权重；另一物理状态上的结局也不能代替当前动作监督。不同动作可用集合、未能到达边界、失败/停止及组内依赖必须按实际合同处理。归约没有解决支持不足或分布变化问题。

后继学习研究应将真实所选任务损失、成功率和完整成本作为主评价；保留条件均值回归、代价敏感分类/决策树与固定强基线。MAE、RMSE、校准和赢家准确率可用于诊断，但不单独决定任务收益。学习器只能读取决策前公开证据；分组训练、验证和最终新人口必须独立登记。当前固定三分支采集既不是学习器测试，也未因本页增加训练或门槛。
