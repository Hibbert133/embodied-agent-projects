# 物理探测与纠正选择的相关工作草稿

任务导向的探测、变化后的重新辨识，以及探索到执行的切换，已有控制和机器人学习方法。这里关注的实证问题是：在固定低层政策上，额外探测造成的状态改变与随后采用新纠正参数，各自怎样影响有限预算内的任务损失。相关工作为这一比较提供了目标与基线，也限定了哪些机制不能单独视为新贡献。

## 面向任务的实验设计

[Wagenmaker 等，2021](https://proceedings.mlr.press/v139/wagenmaker21a.html)在线性动态系统中研究任务相关探索，将下游决策的难度与所需实验联系起来，并给出实例与任务相关的样本复杂度结果。因此，参数估计误差与任务目标之间的区别已有明确理论基础。接触操作中的经验比较需要另行检验模型与数据条件，不能从采用任务加权指标直接继承这些保证。

测量也可能必须通过运动才能获得。[Mutny 等，2023](https://proceedings.mlr.press/v206/mutny23a.html)将实验关联到 Markov 状态，通过控制状态转移分配测量，并提出顺序自适应的实验设计方法。这说明“采集动作会改变系统状态”本身并非新的问题设定。当前同状态比较将额外运动和参数更新分开测量，以确定它们在指定机器人程序中的实际作用；这一分解是程序损失的恒等式。

## 任务政策指导的信息获取

[Dass 等，2025](https://proceedings.mlr.press/v270/dass25a.html)提出 DISaM，将信息获取政策与信息接收政策分解训练，后者为前者提供训练奖励，并在测试时利用操作政策的动作不确定性调节探索。[Aoyama 等，2025](https://proceedings.mlr.press/v305/aoyama25a.html)利用特权任务政策对物理参数误差的敏感度生成探索奖励，训练探索政策与属性估计器，并采用不确定性规则切换至任务执行。两者均说明，固定一部分执行能力、另设获取机制，或使用任务相关的停止依据，都不是充分的创新区别。

它们的完整系统包含政策训练或物理属性监督，而当前实验保持官方低层政策固定。后继比较应明确额外训练数据与控制权限：完整复现需要保留原方法的核心学习目标；仅借用一个不确定性分数的受限适配，应按该分数或适配规则命名。不同任务上的原论文成功率不能直接并入本项目的对照表。

## 固定接口的校准与变化触发

[GAUGE，Zang 等，2026 年预印本](https://arxiv.org/html/2609.32154v1)面对不透明的四足机器人速度接口，在固定控制器之外学习命令到运动的响应模型。其任务命令分布加权方差降低准则与验证停止、有界逆补偿和变化后重新获取连接起来。这是固定接口校准的直接相关路线。本项目的 `TASK_IVR4` 使用当前指令的局部参考，`TASK_HISTORY_IVR4` 使用自身已有查询历史；它们没有复现 GAUGE 的完整测量、验证和部署流程。

[Schlor 等，2022 年预印本](https://arxiv.org/html/2204.02059v1)通过参数滤波器持续估计模型，以统计变化检验触发激励，并在不确定性降低后更新控制模型。其参数更新及触发条件建立在线性高斯等明确假设之上。当前响应模型的协方差是工作近似，因此相似的残差二次型不能自动获得相同的误报或性能保证。参数变化检测与补测的任务收益仍需分别评价。

## 观测后决策与本文评价范围

探测结果影响随后控制选择，也是双重控制的既有内容。[Arcari 等，2020](https://proceedings.mlr.press/v120/arcari20a.html)用场景树处理模型和参数不确定性，并在各场景获得的信息基础上优化后续控制。因此，预测“测后选择哪个控制器”或考虑接受与拒绝的分支，本身不足以形成新算法。

本文的[方法定义](paired_probe_measurement_methods_draft_zh.md)与[结果](paired_probe_measurement_results_20261019_zh.md)限定在四种实际执行的标准续跑程序上。补测后更新的平均收益说明指定程序在来源人口中有用；它不等于最优信息价值，也不证明一个只读取公开证据的代理能提前识别有益更新。候选获取方法仍需说明额外可用证据、决策机制及其相对于上述方法的区别，并在自身历史诱导的独立时序流上确认任务收益。
