# 从受控初始前缀衔接到中途干预

本次增加[公开准备器](boundary_prefix.py)和[私有连续主机](boundary_host.py)，为后续 MetaWorld 执行资格构造真实第16步边界。它们通过了12项软件检查。采集器、冻结 I/O、独立日志审计器及中文报告生成器现已完成，另有11项采集与审计测试通过。本说明记录冻结前的软件验证；这些测试没有运行21400–21402的新任务。

## 保存的参数与实际执行

公开准备器先执行固定四步，使用真实观测估计并保存 C4；再真实执行第二轮四步，用完整八步估计并保存 C8。第9–16步由 C8 实际纠正固定政策。C4 只是同任务的已保存候选，尚未用于任务动作，不是以前成功应用的技能。

主机核对模型与任务、实际初始重置、每份拟合输入、参数来源、政策查询、命令与当前观测。公开准备器接触不到种子、扰动真值、噪声带或原生状态。世界、原始噪声、时间及费用在准备器和既有干预器之间连续；直接循环对照不调用新干预器。

无效四步估计在第4步停止，无效八步估计在第8步停止。提前成功或终止保留原结束状态，不为凑齐边界继续执行或替换参数。后续真实资格必须按[独立协议](../../protocols/delayed_intervention_qualification_v1.md)冻结与执行。

[公开准备器测试](test_boundary_prefix.py)检查实际四步/八步数据来源、C8确实控制后续动作、无效与提前结束、日志回执变更，以及公开字段边界。[主机组合测试](test_boundary_host.py)在小型 MuJoCo 夹具上把准备器与原干预器真正连接。

## 当前资格状态

执行资格计划是三任务、每任务五种操作、最多7,500个控制步。`scripts/qualify_delayed_intervention_v1.py prepare` 会检查采集器、独立审计器、协议和测试均已提交，并核对两份软件资格回执的源码及产物哈希，缺少任一项则拒绝生成清单。

[独立审计器](../../../scripts/audit_delayed_intervention_v1.py)不导入准备器、干预执行器或采集器，按固定事件顺序重建两次拟合、全部候选来源、策略输出、实际纠正命令、私有噪声消费、前缀匹配与重置/帧数。只共享明确披露的估计器、固定策略、编码数学和费用加法。额外事件、未知公开字段、滞后时间戳、错误引用、未来拟合输入、被改写的命令/费用均被拒绝。

[采集与审计测试](../../../tests/test_delayed_intervention_qualification_v1.py)包括15个独立小型物理夹具，以及另一次完整15次执行的软件管线。完整管线保存压缩日志、案例、状态、完成回执，再由独立审计生成全案例中文报告；重复采集/审计拒绝覆盖。工厂异常和第17步已执行物理但未正常返回的异常也保留记录，不能进入完整资格。

最终冻结前软件回执见[collector_audit_v3](../../../outputs/delayed_intervention/software_v1/collector_audit_v3/receipt.json)：11项通过，单案例夹具386,125原生帧、725次主机尝试/724次返回，完整管线另付384,180原生帧。工厂及受控重置费用均计入，拟合和24步成功规则是人工设置。两个早期开发版本及对应源码快照保留在collector_audit_v1、v2，不能只报最终一次运行成本。一次系统Python导入失败没有执行物理；仓库完整测试的额外夹具费用保存在validation_v1/unittest_delayed_native_costs.json。

软件回执通过之后，仍须通过仓库全部检查并本地冻结提交，才能prepare、collect一次。实际结果以qualification_v1目录的清单、collection完成记录、独立audit回执及report_zh.md为准。真实资格异常不补跑同一人口；边界不可用不换种子。

软件检查不能替代 MetaWorld 资格、中途辨识、决策规则或新方法的独立任务收益。CCF A 目标所需的新贡献、强基线、消融和完整论文仍继续推进。
