# Experiment Reports

Reports in this directory are immutable records of completed development, tuning,
validation, and held-out experiments. Older reports use terms such as `recovery`,
`repair`, and `retry`. Those names are retained because they identify historical
methods, scripts, and CSV fields.

New work uses the canonical language in `docs/terminology.md`: diagnostic agent,
corrective intervention, verification rollout, and verified experience. Preserving
legacy terminology does not authorize future modules to treat an injected failure
label as an Agent-visible hypothesis.
