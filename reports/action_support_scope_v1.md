# 模型作用域、查询输入支持与证据老化：中文方法进展 v1

本轮实现了一个可检验的方法原型：分别检查当前输入方向是否被数据覆盖、
测量误差是否足够小、旧证据的时间边界是否仍能约束当前响应。原型能
提出补测、条件性复用、拒绝旧预测或拒绝声明的响应条件。它尚未取得
MetaWorld 的观察资格，不能作为在线控制器或算法创新结论。

同时完成了现有框架数据的只读诊断：标准八步方法的 16/16 成功依赖
已声明的两旋转先验，不能据此推断一般二维仿射算子的未测 y 系数。
其 1,026 个任务命令均在固定探测输入的张成空间之外；但每个案例只需
一个新增独立任务命令，累积命令支持便达到满秩。这要求后续比较加入
被动在线辨识，而不能只比较显式探测。命令支持不等于已经学准模型。

## 实现与解析验证

实现提交 `9181fe6`，分支 `codex/action-support-scope-v1`：

- `src/probe/action_support.py`：精确有理数的仿射输入支持检查、零空间
  见证、带预算的注册补测建议；浮点容差不用于批准未测方向。
- `src/probe/response_transfer.py`：精确插值、误差/漂移外包络、最早与
  最近独立输入子集的交集核验，以及查询依赖的缓存响应判断。
- `scripts/analyze_action_support.py`：仅用实际命令，分别重放固定探测
  支持和严格早于当前查询的累积支持；独立有理数消元复核结果。

新增 15 个解析测试覆盖 x 输入不能验证独立 y 系数、1e-12 未测方向、
零空间反例、对抗测量误差、补测预算、时间回跳/未来测量、静默 y 变化、
新 x 数据不恢复旧 y 证据，以及观测之间矛盾时否定声明的响应条件。
原型冻结前全部 **663 项仓库测试通过**（62.407 秒），编译、依赖、暂存
秘密扫描与差异检查通过。原实验、模型和策略没有修改。
[验证记录](../outputs/action_support/validation_v1.json) 保存工具提交、原数据
散列、逐例秩增量一致性与仓库检查范围。

条件性外包络对当前查询 `q=X.T w` 使用
`sum_i |w_i| (epsilon + rho (t-i) ||x_i||_1)`：测量误差与参数老化分开。
这只是明确假设下的集合辨识/三角不等式推导，未声明为新控制理论。
没有误差包络时不能批准复用；标准差 0.05 不能直接代替确定性误差界。
所有原型结果的模型资格、概率保证和任务成功保证仍为 False。

## 对下一方法实验的具体约束

先取得可观测执行器等价响应的独立资格，公开适用状态/输入域、误差事件
与时间漂移条件。原校准的点误差、训练残差和 Gaussian 标准差不能替代
这个契约；本轮没有补造或拟合这些参数。

比较至少需要当前最强八步有限先验方法、一般仿射的固定探测辨识、利用
实际任务反馈的被动校准辨识、查询相关/C-optimal 主动设计、稳健集合
辨识与时间窗口/变化检测基线。输入作用域、精度、时间有效性分别消融，
并使用独立的任务、算子和重复噪声数据。当前数据不能调节门槛或训练新
选择器，原保留种子仍未授权执行。

相关能力已有 [data informativity / TAC 2020](https://arxiv.org/abs/1908.00468)、
[在线激励设计 / L-CSS 2021](https://research.rug.nl/en/publications/beyond-persistent-excitation-online-experiment-design-for-data-dr/)、
[Explore until Confident / RSS 2024](https://roboticsproceedings.org/rss20/p089.html)、
[安全在线辨识 / RSS 2025](https://www.roboticsproceedings.org/rss21/p121.html)
与 [Select-DPC / L4DC 2026](https://proceedings.mlr.press/v331/naf26a.html)
覆盖。原型的最早/最近子集、插值边界和补齐方向均不够单独支撑新颖性。
还需要完整的时变数据驱动控制比较和实际方法收益证据。

本轮把研究问题推进到可执行的查询/时间依赖验证机制与明确的强基线
义务，未完成新颖性、真实观察资格、多任务前瞻验证或论文。持续的 CCF A
全文目标保持开放；此前 API 14/16 对基线 16/16 的负增益结果未改变。
